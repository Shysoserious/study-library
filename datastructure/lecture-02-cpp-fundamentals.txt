Useful Compiler Options
g++ -std=c++20 -Wall -Wextra -g main.cpp -o main
Option
What it does
-std=c++20
Selects the C++20 language rules and features.
-Wall -Wextra
Enables many useful warnings, such as unused variables.
It does not detect every bug.
-g
Includes information for a debugger: source lines and variables.
-o main
Names the output executable.
-O2
Enables optimization; use it when measuring performance.
-fsanitize=undefined
Adds runtime checks for many undefined operations,
including signed overflow, on supported toolchains.
