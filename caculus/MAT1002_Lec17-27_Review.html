1. The Second Derivative Test（二阶导数判别法）

📜Theorem（Second Derivative Test）

设 f 的所有二阶偏导数在某以 (a,b) 为中心的 open disk（开圆盘）上都连续，且 ∇f(a,b) = 0（即 (a,b) 是 critical point）。令：

H := H(a,b) := fxx(a,b) · fyy(a,b) − [fxy(a,b)]²
  • 若 H > 0 且 fxx(a,b) > 0 → (a,b) 是 local minimum
  • 若 H > 0 且 fxx(a,b) < 0 → (a,b) 是 local maximum
  • 若 H < 0 → (a,b) 是 saddle point（鞍点，无极值）
  • 若 H = 0 → 判别法inconclusive（无法断定）
H>0, fxx>0
→ local min
H>0, fxx<0
→ local max
H<0
→ saddle
H=0
→ inconclusive
💡 直觉记忆：H = "弯曲一致性"。H > 0 表示 x、y 两个方向弯曲方向一致（都凹上或都凹下），看 fxx 定凹凸；H < 0 表示两方向弯曲矛盾 → 鞍。H > 0 时 fxx ≠ 0（否则 H = −fxy² ≤ 0 矛盾）。

证明思路

🔍关键步骤

以 h := Δx, k := Δy 为"小变动"。由上节课的 Taylor 公式：

f(a+h, b+k) = f(a,b) + fx(a,b)h + fy(a,b)k + 12(fxxh² + 2fxyhk + fyyk²)|(a+ch, b+ck)

其中 c ∈ (0,1)。因为 ∇f(a,b) = 0，一阶项消失：

f(a+h,b+k) − f(a,b) = Q(c)   ①
其中 Q(t) := Qh,k(t) := ½(fxxh² + 2fxyhk + fyyk²)|(a+th, b+tk)

关键：把 Q(0) 配方（在 (a,b) 处求值）：

fxx(a,b) · Q(0) = ½[(fxxh + fxyk)² + H · k²]  ②

蓝色恒 ≥ 0，绿色由 H 的符号决定。

  1. Case 1: H > 0。方括号内总 > 0（(h,k) ≠ (0,0) 时），所以 fxx·Q(0) > 0。由连续性，在 (a,b) 附近 fxx·Q(c) > 0。若 fxx(a,b) > 0，则 Q(c) > 0 → f(a+h,b+k) > f(a,b) → local min。若 fxx(a,b) < 0，同理 → local max。
  2. Case 2: H < 0。考虑 P(t) = fxxt² + 2fxyt + fyy，判别式 4(fxy² − fxxfyy) = −4H > 0，P(t) 有两实根，抛物线穿过 t 轴 → P 时正时负。所以 Q(0) 取不同 (h,k) 时有正有负 → 不是极值 → saddle。
⚠️ H = 0 为何 inconclusive？ 反例：f(x,y) = x² → H = 0，是 local min；g(x,y) = −x² → H = 0，是 local max。同一 H = 0 可能对应不同结果，故需其他方法。

2. Taylor's Theorem（两变量版本）

🧮构造辅助函数

定义 F(t) := f(a+th, b+tk)。链式法则得：

F'(t) = fx·h + fy·k = (h ∂x + k ∂y) f
F''(t) = fxxh² + 2fxyhk + fyyk² = (h ∂x + k ∂y)² f

一般地，若 f 的 n 阶偏导在 (a,b) 邻域连续：

F(n)(t) = (h ∂x + k ∂y)n f

例：F(4)(t) = h⁴fxxxx + 4h³k·fxxxy + 6h²k²fxxyy + 4hk³fxyyy + k⁴fyyyy（二项式系数）

🎯Theorem（Taylor's Theorem, 两变量）

若 f 在包含 (a,b) 的某开圆盘（或矩形区域）R 上，至 (n+1) 阶偏导都连续，则对 R 中每一点 (a+h, b+k)：

f(a+h, b+k) = Σi=0n 1i!(h ∂x + k ∂y)if |(a,b) + 1(n+1)!(h ∂x + k ∂y)n+1f |(a+ch, b+ck)

其中 c ∈ (0,1)。最后一项是 remainder（余项），用于估算近似误差。

📝 Example 19.9.1：sin x · sin y 在原点的二次近似

求 f(x,y) = sin x sin y 在原点附近的二次近似。当 |x| ≤ 0.1, |y| ≤ 0.1 时近似误差多大？

解

在 (0,0) 处算偏导：

f(0,0) = sin 0 · sin 0 = 0;   fx(0,0) = cos 0 · sin 0 = 0;   fy(0,0) = 0

fxx(0,0) = −sin 0 · sin 0 = 0;   fxy(0,0) = cos 0 · cos 0 = 1;   fyy(0,0) = 0

二次近似：

f(x,y) ≈ f(0,0) + xfx+yfy|0 + ½(x²fxx + 2xyfxy + y²fyy)|0 = xy

误差估计：E(x,y) = (1/6)(x³fxxx + 3x²y·fxxy + 3xy²fxyy + y³fyyy)|(cx,cy)

所有三阶偏导的绝对值 ≤ 1（因为 sin, cos 绝对值 ≤ 1）。所以：

|E(x,y)| ≤ (1/6)[(0.1)³ + 3(0.1)³ + 3(0.1)³ + (0.1)³] ≤ 0.00133

3. 矩形上的二重积分（Double Integrals on Rectangles）

❓动机：立体体积

设 f 是矩形 R := [a,b] × [c,d] = {(x,y) : a ≤ x ≤ b, c ≤ y ≤ d} 上的非负两变量函数。如何求"介于 xy 平面与 f 的图像之间"那个立体的体积？

思路：切成小柱子来逼近。

📘Riemann Sum 与 Double Integral

步骤：

  1. 取 [a,b] 的划分 {x₀,...,xm} 和 [c,d] 的划分 {y₀,...,yn}，R 被分成 mn 个小矩形 Rij。
  2. 设 ΔAij = Rij 的面积，(xij*, yij*) 是 Rij 里任意一点。
  3. 底为 Rij、高为 f(xij*, yij*) 的柱体体积 ≈ f·ΔAij。
  4. 累加得 Riemann sum：Σi=1m Σj=1n f(xij*, yij*) ΔAij

定义（二重积分）：设 ‖P‖ 是划分中最大矩形宽度（norm）。若 Riemann sum 当 ‖P‖ → 0 时有极限，则称 f 在 R 上 integrable，极限记作：

∬R f(x, y) dA
📎 Remark：

• 连续函数一定可积。

• 在 R 上有界、只在"有限个点或有限段光滑曲线"上不连续的 f，仍然可积。

• 若 f ≥ 0，则立体体积 V := ∬R f dA。

计算方法：迭代积分（Iterated Integrals）

📝 动机例：求 z = 4 − x − y 在 R: 0 ≤ x ≤ 2, 0 ≤ y ≤ 1 上方的体积
方法 1：固定 x 切片

取 x₀ ∈ [0, 2]，在 x = x₀ 处的左侧"薄板"面积：

A(x₀) = ∫01 (4 − x₀ − y) dy

总体积：

V = ∫02 A(x) dx = ∫02 ∫01 (4 − x − y) dy dx

算出：内层 = 4y − xy − ½y² |01 = 4 − x − ½ → 外层 = ∫02(7/2 − x) dx = 5。

方法 2：固定 y 切片

V = ∫01 ∫02 (4 − x − y) dx dy = ... = 5（结果相同）

⭐Theorem（Fubini's Theorem，矩形版）

若 f 在 R := [a,b] × [c,d] 上连续，则：

∬R f(x,y) dA = ∫cd∫ab f(x,y) dx dy = ∫ab∫cd f(x,y) dy dx

两种迭代积分（iterated integrals）都等于二重积分，顺序可换。

💎 核心：连续 f 的二重积分都可以用迭代积分计算，且积分顺序可以交换。
📝 Example（练手）

计算 ∬R y sin(xy) dA，其中 R = [1, 2] × [0, π]。

提示：哪一种顺序容易？先 x 积分：∫ y sin(xy) dx = −cos(xy) |12 = cos y − cos 2y。再对 y 积：∫0π (cos y − cos 2y) dy = 0。

4. 一般有界区域上的二重积分

📘推广到任意闭有界区域

设 D 是 ℝ² 中有界（essential，必须）且通常也闭（usually the case）的区域，f 定义在 D 上。取一个包含 D 的矩形 R，构造新函数：

F(x, y) =
  f(x, y),   (x,y) ∈ D
  0,   (x,y) ∈ R \ D

定义 f 在 D 上的二重积分为：

∬D f(x,y) dA := ∬R F(x,y) dA

这样对矩形的理论就"扩展"到了一般区域。同样，若 f ≥ 0 且连续，则 ∬D f dA 就是 D 上立体的体积。

为什么必须有界？无界区域上 Riemann sum 的极限不好定义。为什么通常是闭的？保证边界也纳入积分域，避免细枝末节。
铺垫：这个抽象定义下一节将转化为具体的 Type I / Type II 区域迭代积分计算法。

1. Type I / Type II 区域

📘定义

平面区域 D 称为 Type I，若形如：

D = {(x, y) : a ≤ x ≤ b, g₁(x) ≤ y ≤ g₂(x)}

外层是 x 的常数限，内层是函数限。直觉：用"竖直条"扫过区域。

D 称为 Type II，若形如：

D = {(x, y) : c ≤ y ≤ d, h₁(y) ≤ x ≤ h₂(y)}

外层是 y 的常数限，内层是函数限。直觉："水平条"扫过。

Remark：同一个区域可以同时是 Type I 和 Type II（比如圆盘）。选哪个取决于哪种描述方便、哪种积分容易。
⭐Fubini's Theorem（Type I / Type II 版）

若 f 在 Type I 区域 D 上连续：

∬D f(x,y) dA = ∫ab∫g₁(x)g₂(x) f(x,y) dy dx

若 f 在 Type II 区域 D 上连续：

∬D f(x,y) dA = ∫cd∫h₁(y)h₂(y) f(x,y) dx dy
📝 Example

(a) 求 ∬D (x + 2y) dA，D 由抛物线 y = 2x² 和 y = 1 + x² 围成。

(b) 算 ∫01 ∫x1 sin(y²) dy dx

解 (a)

交点：2x² = 1 + x² → x² = 1 → x = ±1。在 [−1, 1] 上 1 + x² ≥ 2x²。Type I：

∫−11 ∫2x²1+x² (x + 2y) dy dx

内层：[xy + y²]|2x²1+x² = x(1+x²) + (1+x²)² − 2x³ − 4x⁴ = ... 积出 → 32/15

解 (b)：必须换序！sin(y²) 对 y 不可积

原积分区域：0 ≤ x ≤ 1, x ≤ y ≤ 1（Type I）。画图 → 换成 Type II：0 ≤ y ≤ 1, 0 ≤ x ≤ y。

∫01 ∫0y sin(y²) dx dy = ∫01 y·sin(y²) dy = ½(1 − cos 1)
💎 换序口诀：当内层被积函数"积不出来"时（如 sin(y²), ey², sin x/x 等），画图 → 换成 Type II / Type I。

2. 二重积分性质 + 面积与平均值

📐基本性质（设各积分存在）

(a) 线性：∬D (f ± g) dA = ∬D f dA ± ∬D g dA

(b) 常数倍：∬D cf dA = c ∬D f dA

(c) 单调性：若 f ≥ g 在 D 上处处成立，则 ∬D f dA ≥ ∬D g dA
特例：f ≥ 0 ⟹ ∬ f dA ≥ 0

(d) 可加性：若 D = D₁ ∪ D₂ 且 D₁、D₂ 除边界外不重叠：

∬D f dA = ∬D₁ f dA + ∬D₂ f dA
📘面积与平均值

对（通常闭且有界的）平面区域 D，其面积定义：

A(D) := ∬D dA = ∬D 1 dA

f 在 D 上的平均值（average value）：

1A(D) ∬D f(x,y) dA
📝 面积例题

求 D 的面积，D 由 y = x² 与 y = x + 2 围成。

解：交点 x² = x + 2 → x = −1, 2。Type I：A = ∫−12∫x²x+2 dy dx = ∫−12 (x + 2 − x²) dx = 9/2

3. 极坐标下的二重积分

💡动机

考虑 D = {(x,y) : 1 ≤ x² + y² ≤ 4, y ≥ 0}（上半圆环）。用 Type I/II 描述很麻烦！但用极坐标自然：

R = {(r, θ) : 1 ≤ r ≤ 2, 0 ≤ θ ≤ π}
🧮推导 dA = r dr dθ

把极坐标区域 0 ≤ a ≤ r ≤ b, α ≤ θ ≤ β 分成极坐标小矩形 Rij，对应 xy 平面上的 Dij。

取 Rij 的中心 (ri*, θj*)，其中 ri* = ½(ri−1 + ri)。

关键计算：Dij（"扇形环"）的面积：

ΔAij = ½(ri² − ri−1²) · Δθj = ½(ri + ri−1)(ri − ri−1)·Δθj = ri* · Δri · Δθj

于是 Riemann sum 变为：

Σ f(xij*, yij*) ΔAij = Σ f(ri* cos θj*, ri* sin θj*) · ri* Δri Δθj

取极限得定理。

⭐Theorem（极坐标二重积分）

若 f 在区域 D 上连续，D 的极坐标描述为 0 ≤ a ≤ r ≤ b, α ≤ θ ≤ β（且 0 ≤ β − α ≤ 2π）：

∬D f(x,y) dA = ∫αβ ∫ab f(r cos θ, r sin θ) · r dr dθ

更一般的情况（r 的界也是 θ 的函数）：α ≤ θ ≤ β, 0 ≤ h₁(θ) ≤ r ≤ h₂(θ)：

∬D f(x,y) dA = ∫αβ ∫h₁(θ)h₂(θ) f(r cos θ, r sin θ) r dr dθ
💎 Moral of the story：xy 下的 dA 在极坐标下变成 r dr dθ。
千万别忘记那个 r！
📝 典型例题

(a) 计算 ∫01∫0√(1−x²) (x² + y²) dy dx

解：D = 单位圆第一象限。极坐标：r ∈ [0,1], θ ∈ [0, π/2], x²+y² = r²。

∫0π/2∫01 r² · r dr dθ = (π/2)·(1/4) = π/8

(b) 四瓣玫瑰 r = cos 2θ 一瓣面积

解：一瓣：−π/4 ≤ θ ≤ π/4, 0 ≤ r ≤ cos 2θ。

A = ∫−π/4π/4∫0cos 2θ r dr dθ = ½∫−π/4π/4 cos²(2θ) dθ = π/8

(c) z = x²+y² 下、xy 平面上、圆柱 x²+y² = 2x 内的体积

解：圆柱极坐标：r = 2 cos θ, θ ∈ [−π/2, π/2]。

V = ∫−π/2π/2∫02cosθ r²·r dr dθ = ∫−π/2π/2 4 cos⁴θ dθ = 3π/2

4. 三重积分（Triple Integrals）

📘矩形体上的定义

设 f 是三变量函数，定义在矩形立体 R := [a,b] × [c,d] × [r,s]（"豆腐块"）上。仿照二重积分定义 Riemann sum 和极限：

∭R f(x,y,z) dV := lim‖P‖→0 Σi,j,k f(xijk*, yijk*, zijk*) ΔVijk

物理意义：若 f(x,y,z) 是密度函数，则 ∭R f dV = 物体的质量。

⭐Fubini's Theorem（三重积分）

若 f 在矩形立体 R = [a,b] × [c,d] × [r,s] 上连续：

∭R f dV = ∫rs∫cd∫ab f(x,y,z) dx dy dz

六种积分顺序全部相等，可以自由选择。

📝 Exercise

求 ∭R xyz² dV，R = [0,1] × [−1,2] × [0,3]。

∫01∫−12∫03 xyz² dz dy dx = 9·(3/2)·(1/2) = 27/4

一般有界立体上的三重积分

🧱可变 z 限的情况

设 E 形如 {(x,y,z) : (x,y) ∈ D, u₁(x,y) ≤ z ≤ u₂(x,y)}，D 是 E 在 xy 平面的投影。那么：

∭E f dV = ∬D [∫u₁(x,y)u₂(x,y) f(x,y,z) dz] dA

（内层：x, y 视为常数，对 z 积分）

若 D 是 Type I 区域 a ≤ x ≤ b, g₁(x) ≤ y ≤ g₂(x)：

∭E f dV = ∫ab∫g₁(x)g₂(x)∫u₁(x,y)u₂(x,y) f dz dy dx
📝 Example：四面体上的积分

求 ∭E z dV，E 是由 x=0, y=0, z=0, x+y+z=1 围成的四面体（tetrahedron）。

解

z 范围：0 ≤ z ≤ 1 − x − y。投影 D（令 z = 0）：x ≥ 0, y ≥ 0, x + y ≤ 1。

∫01∫01−x∫01−x−y z dz dy dx

内层 = ½(1−x−y)²。积两次 → 1/24。

📘体积与平均值

体积：V(E) := ∭E dV = ∭E 1 dV

平均值：1V(E) ∭E f dV

📝 Exercise：四面体体积

求四面体体积，四面体由 x + 2y + z = 2, x = 2y, x = 0, z = 0 围成。

V = ∫01∫x/21−x/2∫02−x−2y dz dy dx = 1/3

1. Cylindrical Coordinates（柱坐标）

📘定义

空间一点 P 可用 (r, θ, z) 表示，其中：

  • r, θ 是 P 在 xy 平面投影点的极坐标
  • z 仍是 P 的笛卡尔 z 坐标
(x, y, z) = (r cos θ, r sin θ, z)

可以理解为：极坐标 (r, θ) 表示水平位置，z 表示竖直高度。

适用场景：当立体 E 沿 z 方向是"平移"结构、或水平投影 D 适合用极坐标时（圆柱、圆锥、旋转体）。
⭐柱坐标三重积分

若 E = {(x,y,z) : (x,y) ∈ D, u₁(x,y) ≤ z ≤ u₂(x,y)}，且 D 的极坐标描述为 α ≤ θ ≤ β, 0 ≤ h₁(θ) ≤ r ≤ h₂(θ)（其中 0 ≤ β − α ≤ 2π），则：

∭E f(x,y,z) dV = ∫αβ∫h₁(θ)h₂(θ)∫u₁(r cos θ, r sin θ)u₂(r cos θ, r sin θ) f(r cos θ, r sin θ, z) r dz dr dθ
💎 Moral：从 xyz 换到柱坐标时，dV = r dz dr dθ。别忘 r！
📝 Example：质量问题

解

投影 D：0 ≤ r ≤ 1, 0 ≤ θ ≤ 2π。z: 1 − r² ≤ z ≤ 4。密度 = Kr。

质量 = ∫02π∫01∫1−r²4 Kr · r dz dr dθ = 2πK ∫01 r²(3 + r²) dr = 2πK(1 + 1/5)
= 12π/5 · K

2. Change of Variables Formula（2D 换元公式）

💡动机

极坐标已显示：∬D f(x,y) dA = ∬R f(r cos θ, r sin θ) r dr dθ。本质上我们做了代换 x = r cos θ, y = r sin θ，并把 dA 换成 r dr dθ。一般情况下，若换元 x = g(u,v), y = h(u,v)，公式是什么？

行列式的两个事实（warm-up）

① 平行四边形面积：若 u = ⟨a, b⟩, v = ⟨c, d⟩，则它们张成的平行四边形面积 = |det [[a, c], [b, d]]|。

② 可提取公因子：det [[λa, μc], [λb, μd]] = λμ · det [[a, c], [b, d]]。

📘变换 T 与 Jacobian

设 x = g(u,v), y = h(u,v)，g, h 有连续偏导。把它看作一个映射 T：uv 平面 → xy 平面：

T(u, v) := (g(u,v), h(u,v)) = (x, y)

设 R 是 uv 平面上的区域，D = T(R) 是它在 xy 平面上的像。把 R 剖成小矩形 Rij，T 把它们映成 Dij。

🧮Dij 面积的核心推导

固定 v₀，定义 r₁(u) := T(u, v₀)；固定 u₀，定义 r₂(v) := T(u₀, v)。

小矩形 Rij 的两条边在 T 下映成两个近似切向量：

u := T(u₀+Δu, v₀) − T(u₀, v₀) ≈ r₁'(u₀) Δu = ⟨∂x/∂u, ∂y/∂u⟩ Δu
v := T(u₀, v₀+Δv) − T(u₀, v₀) ≈ r₂'(v₀) Δv = ⟨∂x/∂v, ∂y/∂v⟩ Δv

Dij 近似为 u 和 v 张成的平行四边形：

A(Dij) ≈ |det [[∂x/∂u·Δu, ∂x/∂v·Δv], [∂y/∂u·Δu, ∂y/∂v·Δv]]| = |det [[∂x/∂u, ∂x/∂v], [∂y/∂u, ∂y/∂v]]| · Δu Δv

括号中的行列式就叫 Jacobian：

∂(x, y)∂(u, v) := det [[∂x/∂u, ∂x/∂v], [∂y/∂u, ∂y/∂v]] = ∂x∂u·∂y∂v − ∂x∂v·∂y∂u
⭐Theorem（二重积分换元公式）

设 f 在 xy 平面区域 D 上连续，变换 T: x = g(u,v), y = h(u,v) 满足：

  • T 把 uv 平面区域 R 映射到 D（即 D = T(R)）
  • T 在 R 的内部是 one-to-one（一一映射）
  • g, h 的偏导连续

那么：

∬D f(x, y) dx dy = ∬R f(g(u,v), h(u,v)) |∂(x,y)/∂(u,v)| du dv

记忆形式：dA = |∂(x,y)/∂(u,v)| du dv。Jacobian 取绝对值！

📝 Example（极坐标验证）

x = r cos θ, y = r sin θ：

∂(x, y)∂(r, θ) = det [[cos θ, −r sin θ], [sin θ, r cos θ]] = r cos²θ + r sin²θ = r ≥ 0

所以 ∬D f dA = ∬R f(r cos θ, r sin θ) r dr dθ ✓（和上节课吻合）

注：为保证一一映射，这里 r ≥ 0，且 θ 在长度 ≤ 2π 的区间内。

📝 两道换元例题

(a) 计算 ∬D e(x+y)/(x−y) dA，D 是顶点 (1,0), (2,0), (0,−2), (0,−1) 的梯形。

代换：令 u = x + y, v = x − y → x = (u+v)/2, y = (u−v)/2。

(b) 计算 ∫12∫1/yy √(y/x) e√(xy) dx dy

二、标量函数的线积分 Line Integrals of Scalar Functions

📘定义与动机

动机：求弯曲线（wire）的质量。线密度 f(x,y,z)，线 C 被分成小段 Δsk。

质量 ≈ Σ f(xk,yk,zk)·Δsk → 取极限 → 线积分 ∫C f ds

∫C f(x,y,z) ds = ∫ab f(r(t)) · |r'(t)| dt
📘关键要素

• |r'(t)| = √(x'²+y'²+z'²) = 运动的速率（speed）

• ds = |r'(t)| dt = 弧长微元

• f ≡ 1 时：∫C ds = 曲线 C 的弧长

• 两种物理意义：① f = 线密度 → ∫f ds = 质量；② f(x,y) ≥ 0 → ∫f ds = "围墙"面积

• 分段光滑（piecewise smooth）：∫C = ∫C₁ + ∫C₂ + ...

📝 ∫C (2+x²y) ds，C = 上半单位圆
Solution:

C: x=cosθ, y=sinθ, 0≤θ≤π。|r'|=1

= ∫₀π (2+cos²θ·sinθ) dθ = 2π + [−cos³θ/3]₀π = 2π + 2/3

答案：2π + 2/3

一、向量场的线积分 Line Integrals of F along C

在之前的学习中，我们已经知道了标量函数沿曲线的线积分。现在我们要学习的是向量场沿曲线的线积分，这在物理上的意义非常重要——它对应着力做功的计算。

📘直观理解

想象一个质点沿着曲线 C 移动，同时受到一个力场 F 的作用。力在路径上做的总功（work）就是向量场 F 沿曲线 C 的线积分。

只有力在运动方向上的分量才会做功，所以核心运算是点积（dot product）。

计算方法 Computation

设空间曲线 C 由参数方程给出：

r(t) = ⟨ x(t), y(t), z(t) ⟩,    a ≤ t ≤ b

则微分弧长向量为：

dr = ⟨ dx, dy, dz ⟩

如果向量场 F = ⟨ M(x,y,z), N(x,y,z), P(x,y,z) ⟩，那么：

∫C F · T ds = ∫C F · dr = ∫C M dx + N dy + P dz
= ∫C M dx + ∫C N dy + ∫C P dz
💡计算关键

实际计算时，我们把所有变量统一换成参数 t：

∫C M dx = ∫ab M(x(t), y(t), z(t)) · x'(t) dt

于是整个积分变为：

∫C M dx + N dy + P dz = ∫ab F(r(t)) · r'(t) dt

这就是说：把 F 沿路径参数化后，和 r'(t) 做点积，再对 t 积分。

📝 例题：力做功

题目：求力场 F = ⟨x, y, z⟩ 将一个质点沿曲线 C 移动所做的功，其中 C 的参数方程为：

r(t) = ⟨ cos(πt), t², sin(πt) ⟩,    t ∈ [0, 1]
✏️ 解题过程：

Step 1： 求 r'(t)：

r'(t) = ⟨ −π sin(πt), 2t, π cos(πt) ⟩

Step 2： 把 F 用 t 表示：

F(r(t)) = ⟨ cos(πt), t², sin(πt) ⟩

Step 3： 计算点积并积分：

F · r'(t) = cos(πt)·(−π sin(πt)) + t²·(2t) + sin(πt)·(π cos(πt))
= −π sin(πt)cos(πt) + 2t³ + π sin(πt)cos(πt) = 2t³

Step 4： 积分：

Work = ∫01 2t³ dt = 2t⁴4 |01 = 12

答案：W = 1/2

⚠️注意：巧妙的消项

在上面的例子中，−π sin(πt)cos(πt) 和 +π sin(πt)cos(πt) 恰好消掉了！这种情况在考试中非常常见。遇到看起来复杂的表达式，先展开点积，往往会有奇妙的化简。

二、流量与环量 Flow and Circulation

当向量场 F 表示的是流体的速度场（velocity field）时，线积分 ∫C F · T ds 有特殊的物理名称：

📘流量积分 Flow Integral

当 F 是流体的速度场时，积分 ∫C F · T ds 称为流量积分（flow integral）。它度量的是流体沿着曲线 C 方向的流动趋势。

📘环量 Circulation

当 C 是闭合曲线（即 r(a) = r(b)）时，流量积分被称为环量（circulation）。

环量度量的是流体沿闭合路径"旋转"的净趋势。

💡记号约定

• ∫C F · T ds 称为"向量场沿 C 的线积分"，也叫flow integral

• 当 C 是闭合曲线时，可以用 ∮C 替代 ∫C 来强调曲线是闭合的

⚠️方向（orientation）很重要！

对于流量和环量，曲线 C 的方向（orientation）至关重要！

因为反转 C 的方向，就会改变切向量 T 的方向，从而改变积分的符号。

反转方向 → 积分变号

简单曲线 Simple Curves

📘简单曲线 Simple Curve

一条曲线如果不自己交叉（does not cross itself），则称为简单曲线。

即：除了可能的起点和终点重合（闭合曲线）外，曲线上的每个点只经过一次。

简单曲线不自我交叉，非简单曲线有自交点

三、通量 Flux（ℝ² 中的向量场）

📘通量的定义 Flux

设 C 是一条简单闭合曲线（simple closed curve），F = ⟨M(x,y), N(x,y)⟩ 是 ℝ² 中的向量场，n 是 C 的外法向量（outward normal），则 F 穿过 C 的（向外）通量定义为：

Flux = ∮C F · n ds

物理意义：如果 F 是流体的速度场，通量度量的是流体穿过曲线 C 向外流出的趋势。正值表示净流出，负值表示净流入。

通量的计算公式

我们需要找到外法向量 n 的表达式。利用right-hand rule（右手定则）：

💡法向量的确定

• 如果 C 是逆时针方向（counterclockwise），则外法向量 n = T × k

• 如果 C 是顺时针方向（clockwise），则外法向量 n = k × T

假设 C 是逆时针方向。单位切向量 T = ⟨dx/ds, dy/ds⟩，于是：

n = T × k = ⟨dxds, dyds, 0⟩ × ⟨0, 0, 1⟩ = dyds i − dxds j

因此 n ds = dy i − dx j，代入通量定义得到：

∮C F · n ds = ∮C (M dy − N dx)
⚠️注意符号！

通量公式是 M dy − N dx，注意 N 前面是负号！这和线积分 M dx + N dy 不同。

记忆口诀：通量 = "M 配 dy，N 配 −dx"。

逆时针曲线上：T 为切向量，n 为外法向量，F 为向量场
📝 例题：求通量

题目：求向量场 F = ⟨x − y, x⟩ 穿过单位圆 C: x² + y² = 1 的通量。

✏️ 解题过程：

Step 1： 参数化（逆时针方向）：

C: x = cos t,   y = sin t,   0 ≤ t ≤ 2π

Step 2： 这里 M = x − y, N = x，所以：

dy = cos t · dt,    dx = −sin t · dt

Step 3： 代入通量公式 ∮ M dy − N dx：

Flux = ∫02π [(cos t − sin t)·cos t + cos t · sin t] dt
= ∫02π [cos²t − sin t·cos t + cos t·sin t] dt
= ∫02π cos²t dt

Step 4： 利用半角公式 cos²t = (1 + cos 2t)/2：

= ∫02π 1 + cos(2t)2 dt = 2π2 = π

答案：Flux = π

四、保守场 Conservative Fields

保守力（conservative force）是这样一种力：将质点在两点之间移动时做的总功与路径无关，只取决于起点和终点。

📘保守场的定义 Conservative Field

设 F 是定义在开区域 D 上的向量场。如果对于 D 中任意两点 A 和 B，以及从 A 到 B 的任意两条分段光滑曲线 C₁ 和 C₂，都有：

∫C₁ F · dr = ∫C₂ F · dr

则称 F 在 D 上是保守的（conservative）。

这样的线积分只依赖于起点和终点，而不依赖于路径本身，因此称为路径无关（path independent）。

📝 反例：F = ⟨−y, x⟩ 不是保守场

考虑向量场 F(x,y) = ⟨−y, x⟩。

取从 (0,0) 到 (1,1) 的两条路径：

• C₁: 直线段 (0,0) → (1,1)

• C₂: 曲线 r(t) = ⟨t, t²⟩, t ∈ [0,1]

可以验算：沿 C₁ 和 C₂ 的积分值不同！所以 F = ⟨−y, x⟩ 不是保守场。

这个向量场直觉上是一个"旋转场"——每个点的力都指向逆时针旋转方向，所以沿不同路径做的功自然不同。

五、线积分基本定理 Fundamental Theorem of Line Integrals (FTLI)

📕线积分基本定理 FTLI

设 C 是从 A 到 B 的分段光滑曲线，由 r(t) 参数化，t ∈ [a, b]。设 f 是一个实值函数，其梯度 ∇f 在包含 C 的区域 D 上连续。则：

∫C ∇f · dr = f(B) − f(A)

这个定理与一元微积分中的牛顿-莱布尼兹公式（Newton-Leibniz Formula）完全类似！

🔗与一元微积分的类比
一元微积分 向量微积分
公式 ∫ab f'(x) dx = f(b) − f(a) ∫C ∇f · dr = f(B) − f(A)
核心思想 "导数"的积分 = 端点值之差 "梯度"的线积分 = 端点值之差

由 FTLI 可以直接得到一个重要推论：

⭐推论：连续梯度场是保守场

任何连续的梯度场（gradient field）都是保守的。

因为 FTLI 告诉我们梯度的线积分只取决于端点 f(B) − f(A)，与路径无关。

势函数 Potential Function

📘势函数 Potential Function

如果 F = ∇f，则 f 称为 F 的势函数（potential function）。

类比物理：在重力场中，势函数就是重力势能；在电场中，势函数就是电势。

📝 例题：利用 FTLI 求做功

题目：求力 F = ⟨x, y⟩ 沿曲线 C（从 (1,1) 经过 (2,2) 再到 (3,1)）所做的功。

✏️ 解题过程：

Step 1： 检查 F 是否为梯度场：

F = ⟨x, y⟩ = ∇f, 其中 f(x,y) = 12 x² + 12 y²

Step 2： 应用 FTLI，只需计算端点值：

Work = ∫C F · dr = f(3,1) − f(1,1)
= 12(9 + 1) − 12(1 + 1) = 5 − 1 = 4

注意：虽然路径经过了 (2,2)，但由于 F 是保守场，中间经过什么点完全不影响结果！这就是 FTLI 的威力。

答案：W = 4

笔记上的原始例子答案是 W = 3（从 (1,1) 到 (2,2)）。利用 f(2,2) − f(1,1) = ½(4+4) − ½(1+1) = 4 − 1 = 3。本处拓展路径到 (3,1) 来强调端点的重要性。

六、梯度场 ⟺ 保守场 Gradient = Conservative

自然会问：除了梯度场之外，还有没有其他的保守场？答案是——

📘连通区域 Connected Region

区域 D 称为连通的（connected），如果 D 中任意两点都可以用一条完全落在 D 内的曲线相连。

直觉理解：连通区域就是"一整块"，没有被分成几块。

📕核心定理：保守场 ⟺ 梯度场

设 F 是一个在开连通区域（open connected region）D 上分量连续的向量场。则：

F 在 D 上保守  ⟺  F 是梯度场（即 F = ∇f 对某个 f）

换句话说，在连续且连通的条件下，保守场和梯度场是同一回事！

定理证明思路

💡证明思路（在 ℝ² 中）

"⟸" 方向（梯度场 → 保守场）：

直接由线积分基本定理 (FTLI) 得到。因为 ∫C ∇f · dr = f(B) − f(A)，只依赖于端点。

"⟹" 方向（保守场 → 梯度场）：这是更深刻的方向。

  1. 固定 D 中一点 A = (a,b)，定义 f(x,y) = ∫A(x,y) F · dr（由于保守性，与路径无关，所以定义是合理的）
  2. 选取一个特殊路径：先从 A 到 P₀ = (x₀, y)，再从 P₀ 水平走到 P = (x, y)
  3. 利用类似"微积分基本定理 (FTC)"的手法，对 x 求偏导：
    ∂∂x f(x,y) = ∂∂x ∫x₀x M(t, y) dt = M(x, y)
  4. 类似地，∂f/∂y = N(x,y)
  5. 于是 ∇f = ⟨M, N⟩ = F，即 F 是梯度场。 □

七、环路性质 The Loop Property

关于曲线的方向，有一个重要的记号：

📘反向曲线 Reverse Orientation

如果 C 是一条有方向的曲线，我们用 −C 表示同一条曲线但方向相反。则：

∫−C F · dr = − ∫C F · dr

反转方向，积分变号——这非常直觉：走回去做的功就是走过去做的功的负值。

📕环路性质定理 Loop Property

以下两个命题对任意向量场 F 是等价的（(a) ⟺ (b)）：

(a) F 在 D 上是保守的

(b) 对 D 中每一条闭合曲线 C，∮C F · dr = 0

F 保守  ⟺  ∮C F · dr = 0（对所有闭合 C）
💡为什么等价？直觉理解

(a) → (b)：如果场是保守的（路径无关），那么走一圈回到原点，功为 f(A) − f(A) = 0。

(b) → (a)：如果从 A 到 B 沿 C₁ 走和沿 C₂ 走，组合起来就是一个闭合路径 C₁ + (−C₂)。如果闭合路径的积分为 0，则 ∫C₁ = ∫C₂，即路径无关。

C₁ + (−C₂) 构成闭合路径。若所有闭合路径积分为 0，则 ∫C₁ = ∫C₂

反例警示：连通性的重要性

⚠️经典反例！

考虑向量场：

F(x,y) = ⟨ −yx² + y² , xx² + y² ⟩

这个向量场在 ℝ² \ {(0,0)}（去掉原点的平面）上定义。

它沿单位圆的线积分不等于 0（实际上等于 2π），因此它在 ℝ² \ {(0,0)} 上不是保守场。

关键原因：虽然 ℝ² \ {(0,0)} 是连通的，但它不是单连通的（simply connected）——有一个"洞"（原点）。环路性质定理要求定义域没有"洞"才能从"局部看起来像梯度场"推出"全局是保守场"。这个概念在后续的格林定理（Green's Theorem）中会进一步讨论。

Lecture 23 — Component Test & Green's Theorem

📌本节大纲

这节课是本周的"收官"：把保守场的判定工具补齐（Component Test），并引出向量微积分中最重要的定理之一 —— Green's Theorem（格林定理）。它把一条闭曲线上的线积分和该曲线围成区域上的二重积分联系起来。

1. Simply Connected（单连通区域）— 前置概念

📖定义

一个连通的平面区域 D 称为 simply connected（单连通的），如果 D 中每一条简单闭曲线（simple closed curve）所围成的区域都完全落在 D 内。

💡 直觉理解："no hole"——区域里没有洞。换个说法：D 中任何一条简单闭曲线都可以在 D 内被连续收缩为一个点（shrunk to a point without leaving D），不会被洞挡住。这个概念可以推广到三维空间。
左：区域内任意闭曲线都能收缩到一点；右：围住洞的闭曲线无法收缩
类比：一块完整的橡皮 → 单连通；一个甜甜圈形状 → 不是单连通（中间有洞）。

2. Component Test for Conservative Fields（2D）

🎯定理（Component Test for Conservative Fields, in ℝ²）

设 F(x,y) := ⟨M(x,y), N(x,y)⟩ 是定义在开的单连通区域 D 上的向量场，且 M 和 N 有连续偏导数。那么：

F 在 D 上保守  ⟺  ∂M∂y = ∂N∂x  在 D 上处处成立
这是判断保守场的"秒杀工具"！ 只需验算两个偏导是否相等。
⚠️ 三个前提缺一不可：

① 定义域是开集（open）

② 定义域是单连通（simply connected）

③ M, N 有连续偏导数

任何一个不满足，Component Test 都可能"失灵"！

📝 简单反例：F(x,y) = ⟨-y, x⟩

M = -y → ∂M/∂y = -1     N = x → ∂N/∂x = 1

-1 ≠ 1 → F 不是保守的。用 Component Test 一眼就看出来。

2.1 一个"看起来矛盾"的经典问题

🤔Problem

考虑向量场：

F(x, y) = ⟨ -yx² + y², xx² + y² ⟩

之前已经证明：这个 F 沿单位圆的环量 = 2π ≠ 0，所以 F 不保守。

但动手算一下会发现：∂M/∂y = ∂N/∂x 竟然成立！这不是和 Component Test 矛盾吗？

🔑关键解释

这个向量场的定义域是 ℝ² \ {(0,0)}（去掉原点的平面），而这个区域不是单连通——原点就是那个"洞"！

Component Test 的前提条件要求区域必须是单连通的，这里不满足，定理不适用，所以不矛盾。

考试必考：看到这类题，先查定义域是否单连通。原点/某条直线/整条射线被去掉的场，基本都要小心。

2.2 正面例题：判定 + 找势函数 + 求线积分

📝 完整例题

F(x, y) = ⟨3 + 2xy,  x² - 3y²⟩

(a) 证明 F 在 ℝ² 上保守。  (b) 找一个势函数 f。  (c) 计算 ∫C F · dr，其中 C 由 r(t) = ⟨et sin t, et cos t⟩，0 ≤ t ≤ π 参数化。

解答 (a)：用 Component Test

M = 3 + 2xy → ∂M/∂y = 2x

N = x² - 3y² → ∂N/∂x = 2x

两者相等 ✓，且 ℝ² 是单连通开集，M、N 偏导连续 ✓，所以 F 保守。

解答 (b)：找势函数 f（两步法）

Step 1. 对 M 关于 x 积分：

f(x, y) = ∫(3 + 2xy) dx = 3x + x²y + g(y)

注：g(y) 是"积分常数"，可以是 y 的函数（因为对 x 求导时 g(y) 会变成 0）。

Step 2. 对 f 关于 y 求偏导，令其等于 N：

∂f/∂y = x² + g'(y) = x² - 3y²  ⟹  g'(y) = -3y²  ⟹  g(y) = -y³ + C
f(x, y) = 3x + x²y - y³ + C
解答 (c)：用 FTLI（线积分基本定理）

因为 F 保守，直接用 ∫C F · dr = f(终点) - f(起点)。

终点 r(π) = ⟨eπ sin π, eπ cos π⟩ = ⟨0, -eπ⟩

起点 r(0) = ⟨0, 1⟩

f(0, -eπ) = 0 + 0 - (-eπ)³ = e3π

f(0, 1) = 0 + 0 - 1 = -1

∫C F · dr = e3π - (-1) = e3π + 1

2.3 Component Test in 3D

🎯三维版本

对于 F = ⟨M, N, P⟩ 定义在单连通 3D 区域上（且偏导连续），F 保守 ⟺ 下列三式同时成立：

∂P∂y = ∂N∂z,     ∂M∂z = ∂P∂x,     ∂N∂x = ∂M∂y
🧠 记忆技巧 —— 交叉配对：把三个分量 M, N, P 与三个变量 x, y, z 一一对应（M↔x, N↔y, P↔z）。每个分量对"不是自己的变量"求偏导，并"交叉"等于另一项：

3. Exact Differential Form（恰当微分形式）

📖定义

设 F = ⟨M, N, P⟩。线积分可以写成：

∫C F · dr = ∫C M dx + N dy + P dz

表达式 M dx + N dy + P dz 就叫做 differential form（微分形式）。

一个微分形式称为 exact（恰当的）在 D 上，如果它是某个标量函数 f 的全微分 df（total differential）：

df = fx dx + fy dy + fz dz
🔗关键联系
M dx + N dy + P dz 是 exact ⟺ F = ⟨M,N,P⟩ 是保守场（势函数即为 f）

"exact differential form" 和 "conservative vector field" 其实是同一件事的两种说法。

3.1 保守场的等价条件（本周总结）

⭐Theorem（关于保守场）

设 F 是分量连续的向量场，定义在开连通区域 D 上。下列条件等价：

  1. (a) F 在 D 上保守（conservative）
  2. (b) 存在函数 f 使得 F = ∇f 在 D 上成立（f 是势函数）
  3. (c) 对 D 中任意闭曲线 C，∮C F · dr = 0（环路性质）
附加：若 D 还是单连通的，则 (a) 还等价于 ∂M/∂y = ∂N/∂x（Component Test）。

4. Green's Theorem（Circulation Version / 环量版本）

🌟定理陈述

设 C 是 xy 平面上一条 counterclockwise（逆时针）、分段光滑的简单闭曲线，R 是 C 所围的区域。假设 M、N 在包含 R 的开区域上有连续偏导数。那么：

∮C F · T ds = ∮C M dx + N dy = ∬R (∂N∂x − ∂M∂y) dA
💎 核心思想：把沿闭曲线 C 的线积分（1 维）
与区域 R 上的二重积分（2 维）联系起来！
被积函数 ∂N/∂x - ∂M/∂y 就是向量场 F 的 二维旋度（curl 的 z 分量），衡量"局部旋转"。所以 Green 定理说：整体环量 = 局部旋转的累加。

4.1 推导过程（矩形为例）

📐设置

考虑矩形 R = [a, b] × [c, d]，边界 C 分四段（逆时针）：

🧮Step 1: 处理 ∮C M dx

在 C₂ 和 C₄（竖直线段）上，x 不变 → dx = 0 → 这两段积分为 0。

只剩 C₁ 和 C₃：

• C₁：r(t) = ⟨t, c⟩，t 从 a 到 b → ∫C₁ M dx = ∫ab M(t, c) dt

• C₃：注意是从右到左（逆时针要求），t 从 b 到 a → ∫C₃ M dx = ∫ba M(t, d) dt = − ∫ab M(t, d) dt

∮C M dx = ∫ab [M(t, c) − M(t, d)] dt
🧮Step 2: 用 FTC（微积分基本定理）"升维"

把 M 看作 y 的函数（t 当参数），由 FTC：

∫cd (∂M/∂y)(t, y) dy = M(t, d) − M(t, c)

移项：M(t, c) − M(t, d) = − ∫cd (∂M/∂y) dy

代回去（把 t 改名为 x）：

∮C M dx = − ∫ab∫cd (∂M/∂y) dy dx = −∬R (∂M/∂y) dA   ①
🧮Step 3: 类似地处理 ∮C N dy

在 C₁, C₃ 上 dy = 0，只剩 C₂, C₄。类似过程得到：

∮C N dy = +∬R (∂N/∂x) dA   ②
✅合并 ① + ② 得到 Green's Theorem！
∮C M dx + N dy = ∬R (∂N/∂x − ∂M/∂y) dA   ③

虽然这里只证了矩形的情况，但对 Type I + Type II 的区域、更一般的有简单闭边界的有界区域都成立（只需把区域分解再拼起来即可）。

4.2 例题详解

📝 Example 1：三角形上的顺时针环量

求 F = ⟨x⁴, xy⟩ 沿三角形（顶点 (0,0), (1,0), (0,1)）的顺时针环量。

解

注意方向！ Green 定理给的是逆时针；顺时针 = −逆时针。

M = x⁴, N = xy → ∂N/∂x = y, ∂M/∂y = 0

逆时针环量 = ∬R (y − 0) dA = ∬R y dA

三角形区域：0 ≤ x ≤ 1, 0 ≤ y ≤ 1 − x

∫01 ∫01−x y dy dx = ∫01 (1−x)²2 dx = 16
顺时针环量 = −1/6
📝 Example 2：Green 定理的威力！

计算 ∮C (3y − esin x) dx + (7x + √(y⁴+1)) dy，C 是圆 x² + y² = 9（逆时针）。

解

M = 3y − esin x,   N = 7x + √(y⁴+1)

∂N/∂x = 7,   ∂M/∂y = 3

令人惊叹：esin x 和 √(y⁴+1) 这些"根本积不出来"的项，求完偏导全消失了！

∬R (7 − 3) dA = 4 · 面积(R) = 4 · π(3)² = 36π
= 36π
💡 这就是 Green 定理最大的用处：当直接算线积分"无从下手"（出现 esin x, √(y⁴+1) 等不可积函数）时，转成二重积分往往会化简得不可思议。
📝 Exercise：上半圆环

计算 ∮C y² dx + 3xy dy，C 是 1 ≤ x² + y² ≤ 4, y ≥ 0 的正向边界。

解

∂N/∂x = 3y, ∂M/∂y = 2y → 被积 = y

上半圆环用极坐标：r ∈ [1, 2], θ ∈ [0, π]，y = r sin θ

∫0π ∫12 r sin θ · r dr dθ = (∫0π sin θ dθ) · (∫12 r² dr) = 2 · 73 = 14/3
= 14/3

5. 用 Green 定理证明 Component Test

🔬证明：F 保守 ⟺ ∂M/∂y = ∂N/∂x（在单连通 D 上）

⟹ 方向：假设 F 保守

存在 f 使得 F = ∇f = ⟨fx, fy⟩，即 M = fx, N = fy。那么：

∂M/∂y = (fx)y = fxy = fyx = (fy)x = ∂N/∂x

中间关键一步 fxy = fyx 用到了 Mixed Derivative Theorem（混合偏导定理，也叫 Clairaut's Theorem）——偏导连续时求导顺序可以交换。

⟸ 方向：假设 ∂M/∂y = ∂N/∂x 在 D 上成立

  1. 设 C 是 D 中任意简单闭曲线。
  2. 因 D 单连通 → C 围成的区域 R 完全在 D 内。
  3. 由 Green 定理：∮C F · T ds = ∬R (∂N/∂x − ∂M/∂y) dA = ∬R 0 dA = 0
  4. 若 C 是不简单的闭曲线，可以拆成若干简单闭曲线，每条积分都是 0，总和也是 0。
  5. 由环路性质（Loop Property，Lec 22）→ F 保守。✓
看到了吗？ Component Test 不是"凭空出现"的——它本质上是 Green 定理的推论！这就是为什么需要"单连通"这个条件：只有在单连通域上，闭曲线围成的 R 才一定完全在 D 内，Green 定理才能用。

6. Green's Theorem（Flux Version / 通量版本）

🌊定理陈述

在环量版本的同样假设下，但 C 的方向不再要求（只要是简单闭曲线）：

∮C F · n ds = ∮C M dy − N dx = ∬R (∂M∂x + ∂N∂y) dA
右边 ∂M/∂x + ∂N/∂y 就是向量场的 散度（divergence） ∇ · F，衡量"向外扩散的强度"。所以 Flux 版 Green 定理说：穿过 C 的总通量 = 区域内散度的累加。

7. 压轴：著名的"2π = 0" 悖论

🎭"证明" 2π = 0

设 F(x, y) = ⟨−y/(x²+y²), x/(x²+y²)⟩，C 是单位圆 x² + y² = 1（逆时针）。

  1. 直接参数化计算：∮C F · T ds = 2π。
  2. 验算偏导：∂M/∂y = ∂N/∂x 处处成立（可以动手算验证）。
  3. "套用" Green 定理：∮C F · T ds = ∬R (∂N/∂x − ∂M/∂y) dA = ∬R 0 dA = 0
  4. 所以 2π = 0 ??? ✅ WELL DONE??
🔑哪里错了？

Green 定理要求 M 和 N 在整个区域 R 上有连续偏导数，但这个 F 在原点 (0,0) 没有定义（分母为 0）！

单位圆 R 包含原点，所以 前提条件不满足，第 3 步里套用 Green 定理是非法的。悖论不存在。

与之前 Component Test "矛盾" 是同一个问题的两面！ 它们都要求定义域单连通 / 函数处处有定义。这个 F 的自然定义域 ℝ² \ {0} 不是单连通，而单位圆围的区域又包含了原点，所以无论是 Component Test 还是 Green 定理都不能用。

📋 Lecture 23 知识速查

🎯核心知识点

① Simply Connected（单连通）：区域内无洞，任何闭曲线都可收缩到一点。

② Component Test（2D）：开 + 单连通 + 偏导连续的前提下，

F 保守 ⟺ ∂M/∂y = ∂N/∂x

③ Component Test（3D）：三式交叉配对同时成立。

④ Exact Differential Form：M dx + N dy (+ P dz) 是某函数的全微分 ⟺ F 保守。

⑤ Green's Theorem — Circulation：

∮C M dx + N dy = ∬R (∂N/∂x − ∂M/∂y) dA，C 必须逆时针

⑥ Green's Theorem — Flux：

∮C M dy − N dx = ∬R (∂M/∂x + ∂N/∂y) dA

⑦ 何时用 Green 定理？当线积分中出现 esin x, √(y⁴+1) 等难积函数，且偏导后能化简时！

⑧ 致命陷阱：定义域有"洞"（如原点去除），任何依赖单连通的结论都失效。

Lecture 24 — Green 定理直观 & 参数曲面

📌本节大纲

这节课分两大块：

① Green's Theorem：不只背公式，还要理解 环量密度 与 散度 的物理意义，并把定理推广到带"洞"的一般区域。

② Parametric Surfaces（参数曲面）：引入曲面的 parametric 描述方式，推导 切平面 与 曲面面积 公式。

1. Green's Theorem 回顾

🎯两个版本（上节课已证）

Circulation（环量）版：

∮C F·dr  =  ∬R (∂N/∂x − ∂M/∂y) dA

Flux（通量）版：

∮C F·n ds  =  ∬R (∂M/∂x + ∂N/∂y) dA

其中 C 是区域 R 的逆时针边界，F = ⟨M, N⟩。

2. 被积函数的物理含义

📖两个关键量

① Circulation Density（环量密度）：

∂N∂x − ∂M∂y ≈ 环量 (沿某点附近的小闭曲线)小闭曲线围成的面积

衡量流体在该点打转/旋转的强度。正 → 逆时针，负 → 顺时针。

② Divergence（散度）：div F =

∂M∂x + ∂N∂y ≈ 向外通量 (沿某点附近的小闭曲线)小闭曲线围成的面积

衡量流体在该点膨胀/收缩的程度。div F > 0 → expanding（发散）；div F < 0 → compressing（收缩）。

3. 三个经典向量场示例

例 (a): F = ⟨Cx, Cy⟩ — 辐射型

形象：像水龙头在原点向外喷射

∂N/∂x − ∂M/∂y = 0 − 0 = 0  →  不旋转（no rotation）

div F = ∂M/∂x + ∂N/∂y = C + C = 2C

C > 0 → 向外膨胀（expanding）；C < 0 → 向内收缩（compressing）。

例 (b): F = ⟨−Cy, Cx⟩ — 旋转型

形象：像漩涡，原地打转但不扩散

∂N/∂x − ∂M/∂y = C − (−C) = 2C

C > 0 → 逆时针旋转 ↺；C < 0 → 顺时针旋转 ↻。

div F = 0 + 0 = 0  →  不膨胀不收缩

例 (c): F = ⟨Cy, 0⟩ — 水平剪切型

形象：流体上下不同方向流动，产生旋转效应

∂N/∂x − ∂M/∂y = 0 − C = −C

C > 0 → 顺时针旋转 ↻（注意符号！）；C < 0 → 逆时针。

div F = 0 → 无膨胀

三个例子背下来
辐射场 ⟨Cx, Cy⟩：只发散不转  |  旋转场 ⟨−Cy, Cx⟩：只转不发散  |  剪切场 ⟨Cy, 0⟩：会旋转但不发散

4. Green's Theorem 直观理解（"拼图法"）

💡核心思想

把区域 R 切成很多小方格。对每个小方格应用 Green 定理（用环量密度 × 面积近似它的边界环量）：

  1. 对每个小方格计算 (∂N/∂x − ∂M/∂y) dA
  2. 把所有小方格的结果求和 → ∬R (∂N/∂x − ∂M/∂y) dA
  3. 关键观察：相邻两个方格的公共边，环量方向相反（一个向上、一个向下），互相抵消
  4. 最后只剩下整个区域 R 最外层边界上的环量
"拼图思想"：内部公共边相抵，只剩外层边界
💡 重要：Flux 版本的道理完全一样——把每个小方格的散度 × 面积累加，内部相邻边的通量符号相反相抵，剩下的就是外层边界上的通量。

5. Green 定理的推广版本

🤔问题：带洞的区域怎么办？

之前的 Green 定理要求 C 是一条简单闭曲线。但如果区域 R 有"洞"（比如环形区域），边界就不是一条简单闭曲线，而是两条或更多的并集。原定理不能直接用！


方向相反 → 抵消 切完后每块都是"简单区域"，可以单独用 Green 定理；切割线走了两次方向相反，互相抵消。
处理有洞区域：先切割成简单区域 → 分别用定理 → 切线抵消
🎯Green 定理（一般版本，Circulation）
∬R (∂N/∂x − ∂M/∂y) dA  =  ∮positively oriented boundary C F·dr

这里 C 是一条或多条闭曲线的并集（可以是 C₁ ∪ C₂ ∪ ...）。

⚠️ "Positively oriented（正方向）" 的定义：沿 C 走的时候，区域 R 始终在你的左手边。
→ 外边界：逆时针（Counterclockwise）
→ 内边界（洞的边界）：顺时针（Clockwise）
记忆法：想象你贴着边界散步，R 永远在你左边。

6. Parametric Surfaces（参数曲面）定义

📖定义

ℝ³ 中的曲面 S 称为 parametric surface（参数曲面），如果它能写成：

x = x(u, v),   y = y(u, v),   z = z(u, v),   (u, v) ∈ R

其中 R 是 ℝ² 中的一个区域（称为 parameter domain，参数域）。

等价地，可以写成向量函数：

r(u, v) = ⟨x(u,v), y(u,v), z(u,v)⟩,   (u,v) ∈ R

所以参数曲面就是向量函数 r 的值域（range）。

参数化：把平面区域 R "揉" 成三维空间中的曲面 S
直觉：像把一块平面上的布（参数域 R），按照 r(u,v) 这个"揉捏方式"，塑造成三维空间中的一个曲面。参数 u, v 就是布上的"经纬坐标"。

7. 参数化示例

📝 例 (a): 锥面 z = √(x²+y²) 的两种参数化
方法一：直角坐标

令 u = x, v = y，则 z = √(u²+v²)：

r(u, v) = ⟨u,  v,  √(u²+v²)⟩

参数域：xy 平面的任意区域（如圆盘 u²+v² ≤ R²）。

方法二：极坐标

令 x = r cosθ, y = r sinθ，则 z = √(r²cos²θ + r²sin²θ) = r：

r(r, θ) = ⟨r cosθ,  r sinθ,  r⟩

参数域：例如 r ∈ [0, R₀], θ ∈ [0, 2π]。

同一个曲面可以有无数种参数化，选哪种取决于哪种更"对称"、更便于计算。
📝 例 (b): 球面 x² + y² + z² = a²

使用球坐标，固定 ρ = a：

r(φ, θ) = ⟨a sinφ cosθ,  a sinφ sinθ,  a cosφ⟩

参数域：φ ∈ [0, π], θ ∈ [0, 2π]。

注意：φ 是从正 z 轴开始的角度，范围是 [0, π]，不是 [0, 2π]！

8. Tangent Planes（切平面）

💡构造切平面的思路

在参数曲面上一点 P₀ = r(u₀, v₀)，通过两条"网格曲线"求切向量：

① 固定 u = u₀：让 v 变 → 得到曲面上一条曲线 C₁（v-曲线）。

② 固定 v = v₀：让 u 变 → 得到曲面上另一条曲线 C₂（u-曲线）。

两条曲线在 P₀ 交叉，各自的切向量都在切平面内，它们的叉积就是法向量！

u rv ru × rv (法向量) 固定 u=u₀ → 得蓝线 C₁；固定 v=v₀ → 得红线 C₂；交点 P₀ 处两切向量叉积即法向量。
参数曲面切平面的构造：沿网格线取切向量，叉积得法向量
🎯关键公式

v-曲线的切向量（固定 u=u₀）：

rv = ⟨∂x/∂v,  ∂y/∂v,  ∂z/∂v⟩  |(u₀, v₀)

u-曲线的切向量（固定 v=v₀）：

ru = ⟨∂x/∂u,  ∂y/∂u,  ∂z/∂u⟩  |(u₀, v₀)

法向量：

n = ru × rv

（前提：叉积 ≠ 0，否则切平面无法定义）

📖Smooth Surface（光滑曲面）

参数曲面 S 称为 smooth（光滑的），如果：

① ru 和 rv 在参数域上都连续；

② 对参数域内每一点都有 ru × rv ≠ 0。

光滑性保证曲面处处有良定义的切平面、没有尖点或自交。

9. Surface Area（曲面面积）— 核心公式

💡推导思想（小平行四边形近似）

把参数域 R 切成很多小矩形 Δu × Δv。每个小矩形映射到曲面上的一小片。

当 Δu, Δv 很小时，这一小片近似是一个平行四边形：

→ 沿 u 方向的边：Δu · ru

→ 沿 v 方向的边：Δv · rv

平行四边形面积 = |Δu ru × Δv rv| = |ru × rv| Δu Δv

u Δv rv Δσ | 黄色小片面积 | ≈ | Δu ru × Δv rv | = | ru × rv | Δu Δv
每一小块曲面 ≈ 一个平行四边形（两边为 Δu·r_u 与 Δv·r_v）
⭐曲面面积公式（参数形式）
Area(S) = ∬S dσ  =  ∬R |ru × rv|  du dv

其中 R 是参数域，dσ 是曲面的面积元素。

10. 显式形式 z = f(x, y) 的特殊情形

💡自然参数化

当曲面可以显式写成 z = f(x, y) 时，选最自然的参数化：

x = u,   y = v,   z = f(u, v)

即 r(u, v) = ⟨u, v, f(u, v)⟩。

计算偏导：

ru = ⟨1, 0, fx⟩,     rv = ⟨0, 1, fy⟩

叉积：

ru × rv = ⟨−fx, −fy, 1⟩

模长：

|ru × rv| = √(fx² + fy² + 1)
⭐显式曲面面积公式
A = ∬R √(fx² + fy² + 1)  dx dy

其中 R 是曲面 S 在 xy 平面上的投影（即 f 的定义域）。

⭐⭐⭐ 这是本节课最常考的公式之一，务必记牢。

📝 例题：圆锥面的切平面和曲面面积

设 S 是曲面 z = √(x² + y²)，且 z ≤ 2。

(a) 求在点 (√2/2, √2/2, 1) 处的切平面方程。

(b) 求 S 的曲面面积。

(a) 求偏导

f(x, y) = √(x² + y²)

fx = x / √(x²+y²),   fy = y / √(x²+y²)

代入 (√2/2, √2/2)，此时 √(x²+y²) = √(1/2+1/2) = 1：

fx(√2/2, √2/2) = (√2/2)/1 = √2/2

fy(√2/2, √2/2) = (√2/2)/1 = √2/2

切平面（通过 (√2/2, √2/2, 1)，法向量 ⟨−fx, −fy, 1⟩ = ⟨−√2/2, −√2/2, 1⟩）：

−(√2/2)(x − √2/2) − (√2/2)(y − √2/2) + (z − 1) = 0

整理：

−(√2/2) x − (√2/2) y + z = 0
(b) 用显式面积公式

计算被积函数：

fx² + fy² = x²/(x²+y²) + y²/(x²+y²) = 1

所以 √(fx² + fy² + 1) = √2（常数！）

定义域：z ≤ 2 即 √(x²+y²) ≤ 2，即 R 是半径 2 的圆盘。

A = ∬R √2 dx dy = √2 · (π · 2²) = √2 · 4π
A = 4√2 π
📝 例题：美式橄榄球曲面

参数化下图曲面（称为"American football"），并求其面积。

已知特征：在高度 z 处横截面是半径 cos z 的圆（z ∈ [−π/2, π/2]）。

参数化

取 z 本身为一个参数，θ 为横截圆上的角度：

r(z, θ) = ⟨cos z · cos θ,   cos z · sin θ,   z⟩

参数域：z ∈ [−π/2, π/2], θ ∈ [0, 2π]。

计算偏导

rz = ⟨−sin z cos θ, −sin z sin θ, 1⟩

rθ = ⟨−cos z sin θ, cos z cos θ, 0⟩

叉积（展开略）：|rz × rθ| = cos z · √(1 + sin²z)

积分得最终面积
A = ∫02π ∫−π/2π/2 cos z √(1+sin²z) dz dθ

令 t = sin z, dt = cos z dz，t ∈ [−1, 1]：

A = 2π ∫−11 √(1+t²) dt

这是经典积分（查表或 t=tan u）：∫√(1+t²)dt = (t/2)√(1+t²) + (1/2)ln|t + √(1+t²)|

A = 2π [√2 + ln(1 + √2)]

一、Surface Integrals（曲面积分）

📘 Definition: 标量曲面积分

设 S 是光滑曲面，g(x,y,z) 是 S 上的密度函数（如 kg/m²）。S 的质量由surface integral给出：

$$\iint_S g(x,y,z)\, d\sigma$$

其中 $d\sigma$ 是曲面面积元素。直观上，这是将曲面分成小片 $\Delta\sigma_k$，在每片上取 $g(x_k^*, y_k^*, z_k^*)$ 值乘以面积元，求和取极限。

📕 计算公式

参数形式 $(x,y,z) = \mathbf{r}(u,v)$：

$$\iint_S g\, d\sigma = \iint_R g(\mathbf{r}(u,v))\, |\mathbf{r}_u \times \mathbf{r}_v|\, du\, dv$$

显式形式 $z = f(x,y)$：

$$\iint_S g\, d\sigma = \iint_R g(x,y,f(x,y))\, \sqrt{f_x^2 + f_y^2 + 1}\, dx\, dy$$
💡 与 Lec 24 的联系

当 $g = 1$ 时，曲面积分就退化为曲面面积公式——正好是 Lec 24 学的 $A(S) = \iint_R |\mathbf{r}_u \times \mathbf{r}_v|\, du\, dv$。

现在我们在面积的基础上乘了一个"权重函数" $g$。

🟢 Example 16.6.4

题目：计算 $\iint_S \sqrt{x(1+2z)}\, d\sigma$，其中 $S$ 是曲面 $z = y^2/2$ 在三角形区域 $R: x \geq 0, y \geq 0, x+y \leq 1$ 上的部分。

解题：显式形式 $z = y^2/2$，故 $f_x = 0$，$f_y = y$：

$$d\sigma = \sqrt{0 + y^2 + 1}\, dx\, dy = \sqrt{1+y^2}\, dx\, dy$$

代入 $z = y^2/2$：$\sqrt{x(1+2 \cdot y^2/2)} = \sqrt{x(1+y^2)}$，积分变为：

$$\iint_R \sqrt{x(1+y^2)} \cdot \sqrt{1+y^2}\, dx\, dy = \iint_R \sqrt{x}\,(1+y^2)\, dx\, dy$$

计算积分：区域 $R: x \geq 0,\; y \geq 0,\; x+y \leq 1$，先积 $x$（$0$ 到 $1-y$），再积 $y$（$0$ 到 $1$）：

$$\int_0^1 (1+y^2) \int_0^{1-y} x^{1/2}\, dx\, dy = \int_0^1 (1+y^2) \cdot \frac{2}{3}(1-y)^{3/2}\, dy$$

令 $u = 1-y$，$du = -dy$，$y = 1-u$，$y^2 = (1-u)^2 = 1-2u+u^2$：

$$= \frac{2}{3}\int_0^1 (2-2u+u^2)\, u^{3/2}\, du = \frac{2}{3}\int_0^1 \left(2u^{3/2} - 2u^{5/2} + u^{7/2}\right) du$$
$$= \frac{2}{3}\left[\frac{4}{5}u^{5/2} - \frac{4}{7}u^{7/2} + \frac{2}{9}u^{9/2}\right]_0^1 = \frac{2}{3}\left(\frac{4}{5} - \frac{4}{7} + \frac{2}{9}\right)$$

通分（公分母 315）：$\dfrac{4}{5} = \dfrac{252}{315}$，$\dfrac{4}{7} = \dfrac{180}{315}$，$\dfrac{2}{9} = \dfrac{70}{315}$

$$= \frac{2}{3} \cdot \frac{252 - 180 + 70}{315} = \frac{2}{3} \cdot \frac{142}{315} = \boxed{\frac{284}{945}}$$

三、Flux（通量）定义

💡 Flux 的物理动机

想象流体以密度 $\rho$、速度 $\mathbf{v}$ 流过一块面积为 $A$ 的平面区域 $D$：

垂直穿过时：质量流率 = $\rho v A$

斜着穿过时：只计算速度在法方向的分量 → 质量流率 = $\rho(\mathbf{v} \cdot \mathbf{n}) A$

其中 $\mathbf{n}$ 是 $D$ 的单位法向量。推广到一般曲面和变密度场：

$$\text{质量流率} = \iint_S \rho(x,y,z)\,\mathbf{v}(x,y,z) \cdot \mathbf{n}(x,y,z)\, d\sigma$$
📘 Definition: Flux（通量）/ Surface Integral of Vector Field

设 $\mathbf{F}$ 是 $\mathbb{R}^3$ 中的连续向量场，$S$ 是可定向曲面，$\mathbf{n}$ 是指定方向的单位法向量。flux of F across S（通量）为：

$$\text{Flux} = \iint_S \mathbf{F} \cdot \mathbf{n}\, d\sigma$$

关键：$\mathbf{n} = \mathbf{n}(x,y,z)$ 是连续变化的法向量，指定了曲面的"朝向"和通量的测量方向。

Flux 的物理含义：向量场 F 穿过曲面 S 的净流量

四、Flux 计算公式（参数形式）

📕 Parametric Form

若曲面 $S$ 由 $\mathbf{r}(u,v)$ 参数化，单位法向量 $\mathbf{n} = \pm\dfrac{\mathbf{r}_u \times \mathbf{r}_v}{|\mathbf{r}_u \times \mathbf{r}_v|}$，则：

$$\iint_S \mathbf{F} \cdot \mathbf{n}\, d\sigma = \iint_R \mathbf{F} \cdot \frac{\mathbf{r}_u \times \mathbf{r}_v}{|\mathbf{r}_u \times \mathbf{r}_v|}\, |\mathbf{r}_u \times \mathbf{r}_v|\, du\, dv$$

$|\cdot|$ 相消后得到核心公式：

$$\boxed{\iint_S \mathbf{F} \cdot \mathbf{n}\, d\sigma = \pm\iint_R \mathbf{F} \cdot (\mathbf{r}_u \times \mathbf{r}_v)\, du\, dv}$$

$\pm$ 由 $\mathbf{n}$ 的方向（题目指定）决定。记 $d\vec{S} = (\mathbf{r}_u \times \mathbf{r}_v)\, du\, dv$。

⚠️ 标量曲面积分 vs 通量积分

标量曲面积分：$\iint g\, d\sigma$，需要 $|\mathbf{r}_u \times \mathbf{r}_v|$（取绝对值）

通量积分：$\iint \mathbf{F} \cdot d\vec{S}$，不取绝对值（方向有意义！）

五、显式曲面 z=f(x,y) 的 Flux

📕 Explicit Form Flux Formula

若 $S$ 由 $z = f(x,y)$ 给出，以 $x, y$ 为参数：

$\mathbf{r}_x = \langle 1, 0, f_x \rangle$，$\mathbf{r}_y = \langle 0, 1, f_y \rangle$，$\mathbf{r}_x \times \mathbf{r}_y = \langle -f_x,\, -f_y,\, 1 \rangle$

设 $\mathbf{F} = \langle M, N, P \rangle$，则（向上通量用 $+$，向下用 $-$）：

$$\boxed{\iint_S \mathbf{F} \cdot \mathbf{n}\, d\sigma = \pm\iint_R (-Mf_x - Nf_y + P)\, dx\, dy}$$

注意 $\langle -f_x, -f_y, 1 \rangle$ 的 $z$ 分量为 $+1$，对应向上的法方向。

六、Flux 例题

🟢 Example 16.6.5

题目：求 $\mathbf{F} = \langle yz, x, -z^2 \rangle$ 穿过曲面 $S: y = x^2$（$0 \leq x \leq 1$，$0 \leq z \leq 4$）的 flux。

解：

Step 1 — 参数化：用 $(x, z)$ 作为参数，$\mathbf{r}(x,z) = \langle x,\, x^2,\, z \rangle$，参数域 $R = [0,1] \times [0,4]$。

Step 2 — 叉积：

$$\mathbf{r}_x = \langle 1,\, 2x,\, 0 \rangle, \quad \mathbf{r}_z = \langle 0,\, 0,\, 1 \rangle$$
$$\mathbf{r}_x \times \mathbf{r}_z = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ 1 & 2x & 0 \\ 0 & 0 & 1 \end{vmatrix} = \langle 2x,\, -1,\, 0 \rangle$$

该向量 $y$ 分量为 $-1$，指向 $y$ 的负方向。若题目要求向 $y$ 正方向，需取负号（此处假设用 $\langle 2x, -1, 0 \rangle$）。

Step 3 — 点积：在曲面上 $y = x^2$，代入 $\mathbf{F} = \langle yz,\, x,\, -z^2 \rangle = \langle x^2 z,\, x,\, -z^2 \rangle$：

$$\mathbf{F} \cdot (\mathbf{r}_x \times \mathbf{r}_z) = \langle x^2 z,\, x,\, -z^2 \rangle \cdot \langle 2x,\, -1,\, 0 \rangle = 2x^3 z - x$$

Step 4 — 积分：

$$\text{Flux} = \int_0^1 \int_0^4 (2x^3 z - x)\, dz\, dx = \int_0^1 \left[x^3 z^2 - xz\right]_0^4 dx$$
$$= \int_0^1 (16x^3 - 4x)\, dx = \left[4x^4 - 2x^2\right]_0^1 = 4 - 2 = \boxed{2}$$
🟢 Example: 球面 inward flux

题目：求 $\mathbf{F} = \langle z, y, x \rangle$ 穿过单位球面 $x^2+y^2+z^2=1$ 的向内 flux。

解：

Step 1 — 参数化：$\mathbf{r}(\phi,\theta) = \langle \sin\phi\cos\theta,\, \sin\phi\sin\theta,\, \cos\phi \rangle$，$\phi \in [0,\pi]$，$\theta \in [0,2\pi]$。

Step 2 — 叉积（向外）：

$$\mathbf{r}_\phi \times \mathbf{r}_\theta = \sin\phi\, \langle \sin\phi\cos\theta,\, \sin\phi\sin\theta,\, \cos\phi \rangle$$

该向量指向球外侧。题目要求向内，所以取负号。

Step 3 — 点积：在球面上 $x = \sin\phi\cos\theta$，$y = \sin\phi\sin\theta$，$z = \cos\phi$：

$$\mathbf{F} \cdot (\mathbf{r}_\phi \times \mathbf{r}_\theta) = \langle \cos\phi,\, \sin\phi\sin\theta,\, \sin\phi\cos\theta \rangle \cdot \sin\phi\, \langle \sin\phi\cos\theta,\, \sin\phi\sin\theta,\, \cos\phi \rangle$$
$$= \sin\phi\left(\cos\phi\sin\phi\cos\theta + \sin^2\phi\sin^2\theta + \sin\phi\cos\theta\cos\phi\right)$$
$$= \sin\phi\left(2\sin\phi\cos\phi\cos\theta + \sin^2\phi\sin^2\theta\right)$$

Step 4 — 积分：对 $\theta$ 积分，注意 $\int_0^{2\pi}\cos\theta\, d\theta = 0$，$\int_0^{2\pi}\sin^2\theta\, d\theta = \pi$：

$$\text{Flux (outward)} = \int_0^{\pi}\int_0^{2\pi} \sin\phi\left(2\sin\phi\cos\phi\cos\theta + \sin^2\phi\sin^2\theta\right) d\theta\, d\phi$$
$$= \int_0^{\pi} \sin\phi \cdot \pi\sin^2\phi\, d\phi = \pi\int_0^{\pi}\sin^3\phi\, d\phi = \pi \cdot \frac{4}{3} = \frac{4\pi}{3}$$

向内 flux = 取负号：

$$\text{Flux (inward)} = \boxed{-\frac{4\pi}{3}}$$

七、Curl（旋度）

📘 Definition: Curl 旋度

设 $\mathbf{F} = \langle M, N, P \rangle$ 是三维向量场，其curl（旋度）定义为：

$$\text{curl}\, \mathbf{F} := \left(\frac{\partial P}{\partial y} - \frac{\partial N}{\partial z}\right)\mathbf{i} + \left(\frac{\partial M}{\partial z} - \frac{\partial P}{\partial x}\right)\mathbf{j} + \left(\frac{\partial N}{\partial x} - \frac{\partial M}{\partial y}\right)\mathbf{k}$$
💡 记忆方法：行列式形式

把 $\nabla$ 看成"符号向量" $\langle \partial/\partial x,\, \partial/\partial y,\, \partial/\partial z \rangle$，则：

$$\text{curl}\, \mathbf{F} = \nabla \times \mathbf{F} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ M & N & P \end{vmatrix}$$
🔮 Curl 各分量的物理含义

Curl 的三个分量分别对应不同坐标平面上的 circulation density（环量密度）：

• i 分量 = $\partial P/\partial y - \partial N/\partial z$ → yz-plane 上的环量密度

• j 分量 = $\partial M/\partial z - \partial P/\partial x$ → xz-plane 上的环量密度

• k 分量 = $\partial N/\partial x - \partial M/\partial y$ → xy-plane 上的环量密度

其实 Lec 23 学的 2D circulation density $\frac{\partial N}{\partial x} - \frac{\partial M}{\partial y}$ 就是 curl 的 k 分量！

八、Curl 例题

🟢 Example 16.7.1

题目：求 $\mathbf{F} = \langle x^2 - z,\; xe^z,\; xy \rangle$ 的 curl。

解：$M = x^2 - z$，$N = xe^z$，$P = xy$

$$\text{curl}\, \mathbf{F} = \left(\frac{\partial(xy)}{\partial y} - \frac{\partial(xe^z)}{\partial z}\right)\mathbf{i} + \left(\frac{\partial(x^2-z)}{\partial z} - \frac{\partial(xy)}{\partial x}\right)\mathbf{j} + \left(\frac{\partial(xe^z)}{\partial x} - \frac{\partial(x^2-z)}{\partial y}\right)\mathbf{k}$$
$$= (x - xe^z)\,\mathbf{i} + (-1 - y)\,\mathbf{j} + (e^z - 0)\,\mathbf{k} = \langle x - xe^z,\; -1-y,\; e^z \rangle$$
Curl 的几何含义：描述向量场在每个点的局部旋转

Lecture 26 — Stokes 定理 & 散度定理

Stokes 定理 Stokes' Theorem

💡 动机

在 Lec 25 中我们学了曲面的 Flux 积分和 Curl。现在的核心问题是：

能不能把沿闭合曲线的线积分（环量）转化成曲面上的面积分？

答案就是 Stokes 定理——它把 $\oint_C \mathbf{F}\cdot d\mathbf{r}$ 化成 $\iint_S \mathrm{curl}\,\mathbf{F}\cdot\hat{\mathbf{n}}\,d\sigma$，避免了逐段参数化边界曲线的繁琐计算。

📜 Stokes 定理 Stokes' Theorem

设 $S$ 是分段光滑的有向曲面（oriented surface），边界为分段光滑闭合曲线 $C$。设向量场 $\mathbf{F}$ 的各分量在包含 $S$ 的开区域上有连续偏导数。若 $C$ 关于曲面法向量 $\hat{\mathbf{n}}$ 是正向的（positively oriented，即从 $\hat{\mathbf{n}}$ 的一侧看是逆时针），则

$$\oint_C \mathbf{F}\cdot d\mathbf{r} = \iint_S \mathrm{curl}\,\mathbf{F}\cdot\hat{\mathbf{n}}\,d\sigma$$

左边是线积分（沿边界曲线的环量），右边是曲面积分（curl 的通量）。

📖 正向约定 Positive Orientation

右手法则：若 $\hat{\mathbf{n}}$ 朝"上方"（即 $z$ 分量 $> 0$），则从上方俯视时 $C$ 应为逆时针方向。

更一般地：右手大拇指指向 $\hat{\mathbf{n}}$ 方向，四指弯曲方向就是 $C$ 的正方向。

🔗 与 Green 定理的关系

Green 定理是 Stokes 定理的特殊情形：当 $S$ 完全在 $xy$ 平面上且 $\hat{\mathbf{n}} = \hat{\mathbf{k}} = \langle 0,0,1\rangle$ 时，

$$\oint_C M\,dx + N\,dy = \iint_R \left(\frac{\partial N}{\partial x} - \frac{\partial M}{\partial y}\right)dA$$

这正好是 $\mathrm{curl}\,\mathbf{F}\cdot\hat{\mathbf{k}}$ 在平面区域 $R$ 上的积分。

💡 Stokes 定理的直觉

把曲面 $S$ 剖分成很多小块。每个小块上，$\mathrm{curl}\,\mathbf{F}\cdot\hat{\mathbf{n}}\,\Delta\sigma$ 近似于小闭合曲线的环量。

相邻小块的公共边上，线积分方向相反、互相抵消（与 Green 定理的证明思路相同）。

最终只剩下外边界 $C$ 上的线积分。

Stokes 例1：三角形曲面 Stokes Example: Triangle

📝 例题：三角形上的线积分

计算 $\oint_C \mathbf{F}\cdot d\mathbf{r}$，其中 $\mathbf{F} = \langle x+2y,\, x+3z,\, 2x+y\rangle$，$C$ 是过顶点 $A=(2,0,0)$、$B=(0,2,1)$、$K=(0,0,2)$ 的三角形边界（按 $A\to B\to K\to A$ 的顺序）。

直接法（逐段）：需要参数化 $\overrightarrow{BK}$、$\overrightarrow{KA}$、$\overrightarrow{AB}$ 三段并分别积分——非常繁琐。

Stokes 定理法：

  • 确定方向：从 $\hat{\mathbf{n}}$ 的一侧看，$C$ 应为逆时针（$z$ 分量 $> 0$ 时从上方看）
  • 求法向量：$\overrightarrow{AB}\times\overrightarrow{AK} = \begin{vmatrix}\hat{\mathbf{i}}&\hat{\mathbf{j}}&\hat{\mathbf{k}}\\-2&2&1\\-2&0&2\end{vmatrix} = \langle 4,2,4\rangle$，单位法向量 $\hat{\mathbf{n}} = \langle\tfrac{2}{3},\tfrac{1}{3},\tfrac{2}{3}\rangle$
  • 求 Curl：$$\mathrm{curl}\,\mathbf{F} = \begin{vmatrix}\hat{\mathbf{i}}&\hat{\mathbf{j}}&\hat{\mathbf{k}}\\\partial_x&\partial_y&\partial_z\\x+2y&x+3z&2x+y\end{vmatrix} = \langle -2,-2,-1\rangle$$
  • 曲面方程：三角形所在平面为 $4(x-2)+2y+4z = 0$，即 $z = 2 - x - \tfrac{1}{2}y$。$xy$ 平面投影区域 $R$ 是三角形
  • 计算 $d\sigma$：$|\mathbf{r}_x \times \mathbf{r}_y| = \sqrt{1 + f_x^2 + f_y^2} = \sqrt{1+1+\tfrac{1}{4}} = \tfrac{3}{2}$
  • 积分： $$\oint_C \mathbf{F}\cdot d\mathbf{r} = \iint_R \langle -2,-2,-1\rangle \cdot \langle\tfrac{2}{3},\tfrac{1}{3},\tfrac{2}{3}\rangle \cdot \tfrac{3}{2}\,dA = \iint_R (-4)\,dA = -4\cdot\text{Area}(R)$$
  • 结果：$\text{Area}(R) = \tfrac{1}{2}\cdot 2\cdot 2 = 2$，所以 $\oint_C \mathbf{F}\cdot d\mathbf{r} = -4 \times 2 = \boxed{-8}$

Stokes 例2：鞍面 Stokes Example: Saddle Surface

📝 例题：柱面内的曲面 flux

设 $S$ 是曲面 $z = y^2 - x^2$ 在柱面 $x^2+y^2\leq 1$ 内的部分。求 $\mathrm{curl}\,\mathbf{F}$ 向上通过 $S$ 的通量，其中 $\mathbf{F} = \langle y, -x, x^2\rangle$。

  • 用 Stokes 定理转化：$\iint_S \mathrm{curl}\,\mathbf{F}\cdot\hat{\mathbf{n}}\,d\sigma = \oint_C \mathbf{F}\cdot d\mathbf{r}$，其中 $C$ 是 $S$ 的边界
  • 边界 $C$：$z = y^2 - x^2$ 与 $x^2+y^2 = 1$ 的交线。在圆上 $z = \sin^2\theta - \cos^2\theta$，参数化为 $\mathbf{r}(\theta) = (\cos\theta,\,\sin\theta,\,\sin^2\theta - \cos^2\theta)$，$\theta\in[0,2\pi]$（从上方看逆时针）
  • 计算线积分：$$\oint_C \mathbf{F}\cdot d\mathbf{r} = \int_0^{2\pi}\bigl[\sin\theta(-\sin\theta) + (-\cos\theta)(\cos\theta) + \cos^2\theta(2\sin\theta\cos\theta + 2\cos\theta\sin\theta)\bigr]d\theta$$
  • 化简：$$= \int_0^{2\pi}(-1 + 4\cos^2\theta\sin\theta)\,d\theta = \bigl[-\theta - \cos^4\theta\bigr]_0^{2\pi} = \boxed{-2\pi}$$

Stokes 定理的推论 Consequence of Stokes' Theorem

📜 曲面无关性

若两个有向曲面 $S_1$ 和 $S_2$ 有相同的边界 $C$且法向量朝向同一侧，则

$$\iint_{S_1} \mathrm{curl}\,\mathbf{F}\cdot\hat{\mathbf{n}}\,d\sigma = \iint_{S_2} \mathrm{curl}\,\mathbf{F}\cdot\hat{\mathbf{n}}\,d\sigma$$

这就是说：curl 的通量只取决于边界，与具体选取的曲面无关——这类似于保守场中"线积分只取决于端点"的性质。

📝 利用推论简化计算

求 $\mathbf{F} = \langle x^2+z,\, y^2+2x,\, z^2-y\rangle$ 沿曲线 $C$ 的环量，其中 $C$ 是球面 $x^2+y^2+z^2=1$ 与 $z = \sqrt{x^2+y^2}$ 的交线（从上方看逆时针）。

思路：联立两个方程得 $x^2+y^2 = \tfrac{1}{2}$，$z = \tfrac{1}{\sqrt{2}}$。$C$ 是在平面 $z=\tfrac{1}{\sqrt{2}}$ 上半径 $\tfrac{1}{\sqrt{2}}$ 的圆。

取 $S$ 为平面 $z=\tfrac{1}{\sqrt{2}}$ 上的圆盘（而非复杂的球面或锥面），$\hat{\mathbf{n}} = \hat{\mathbf{k}}$：

$$\oint_C \mathbf{F}\cdot d\mathbf{r} = \iint_S \mathrm{curl}\,\mathbf{F}\cdot\hat{\mathbf{k}}\,d\sigma = \iint_S \left(\frac{\partial N}{\partial x} - \frac{\partial M}{\partial y}\right)dA = \iint_S (2-0)\,dA = 2\cdot\text{Area}(S) = 2\pi\cdot\tfrac{1}{2} = \boxed{\pi}$$

3D 分量检验 3D Component Test

📜 3D 保守场的判定

设 $\mathbf{F} = \langle M, N, P\rangle$，各分量在 $D\subseteq\mathbb{R}^3$（$D$ 开且单连通）上有连续偏导数，则

$$\mathbf{F}\text{ 在 }D\text{ 上保守} \quad\Longleftrightarrow\quad P_y = N_z,\quad M_z = P_x,\quad N_x = M_y \text{ 在 }D\text{ 上}$$

右边等价于 $\mathrm{curl}\,\mathbf{F} \equiv \mathbf{0}$ 在 $D$ 上。

📜 证明思路

$(1)\Rightarrow(2)$：若 $\mathbf{F} = \nabla f$，则 $M = f_x, N = f_y, P = f_z$。由混合偏导相等（Clairaut 定理）：$P_y = f_{zy} = f_{yz} = N_z$，类似可得其余两个。

$(2)\Rightarrow(1)$：$(2)$ 等价于 $\mathrm{curl}\,\mathbf{F} \equiv \mathbf{0}$。对任何闭合曲线 $C$，由 Stokes 定理：

$$\oint_C \mathbf{F}\cdot d\mathbf{r} = \iint_S \mathrm{curl}\,\mathbf{F}\cdot\hat{\mathbf{n}}\,d\sigma = 0$$

满足 Loop Property（环路性质），因此 $\mathbf{F}$ 保守。$\square$

🔗 保守场 = 无旋场

$\mathrm{curl}\,\mathbf{F} \equiv \mathbf{0}$ 意味着 $\mathbf{F}$ 在每个点都不产生旋转，称为无旋场（irrotational field）。

分量检验告诉我们：在单连通开区域上，保守场和无旋场是同一回事。

散度 Divergence

📖 散度的定义 Definition of Divergence

给定向量场 $\mathbf{F} = \langle M, N, P\rangle$，其散度为

$$\mathrm{div}\,\mathbf{F} = \nabla\cdot\mathbf{F} = \frac{\partial M}{\partial x} + \frac{\partial N}{\partial y} + \frac{\partial P}{\partial z}$$

（2D 情形：$\mathbf{F} = \langle M, N\rangle$ 时，$\mathrm{div}\,\mathbf{F} = M_x + N_y$）

💡 散度的几何意义

$\mathrm{div}(\mathbf{F})(P_0)$ 描述向量场在 $P_0$ 点的向外通量密度（outward flux density）：

$\mathrm{div}\,\mathbf{F}(P)$含义
$> 0$$P$ 点是源（expanding / diverging）
$< 0$$P$ 点是汇（compressing / shrinking）
$= 0$$P$ 点无净通量（incompressible）
📝 散度计算示例

(a) $\mathbf{F}(x,y,z) = \langle -x, -y, -z\rangle$：$\mathrm{div}\,\mathbf{F} = -1-1-1 = -3$（处处压缩，向内聚集）

(b) $\mathbf{F}(x,y,z) = \langle 0, z, 0\rangle$（$= z\hat{\mathbf{j}}$）：$\mathrm{div}\,\mathbf{F} = 0+0+0 = 0$（无源无汇，不可压缩）

div(curl F) = 0 Divergence of Curl

📜 散度与旋度的关系

若 $\mathbf{F}$ 是 $\mathbb{R}^3$ 中分量有连续二阶偏导数的向量场，则

$$\mathrm{div}(\mathrm{curl}\,\mathbf{F}) \equiv 0$$

即 $\nabla\cdot(\nabla\times\mathbf{F}) = 0$。

💡 实用判别法

如果 $\mathrm{div}\,\mathbf{G} \neq 0$，则 $\mathbf{G}$ 不可能是任何向量场的 curl。

例：$\mathbf{F}(x,y,z) = \langle xy, xyz, -y^2\rangle$，$\mathrm{div}\,\mathbf{F} = y + xz - 0 = y + xz \neq 0$。所以 $\mathbf{F}$ 不是任何向量场的 curl field。

散度定理 Divergence Theorem

📜 散度定理（高斯定理）Divergence Theorem (Gauss' Theorem)

设 $\mathbf{F} = \langle M, N, P\rangle$ 的各分量有连续偏导数。若 $E$ 是有界闭区域，$S$ 是 $E$ 的边界（闭曲面），法向量 $\hat{\mathbf{n}}$向外（outward），则

$$\iint_S \mathbf{F}\cdot\hat{\mathbf{n}}\,d\sigma = \iiint_E \mathrm{div}\,\mathbf{F}\,dV$$

左边是通过闭曲面的向外通量（outward flux），右边是散度在体积上的积分。

📖 闭曲面 Closed Surface

闭曲面是指将空间分成"内部"（有界）和"外部"（无界）两个区域的曲面。

例如：球面 $x^2+y^2+z^2 = a^2$、正方体表面 → 是闭曲面。

半球面、开口的碗形曲面 → 不是闭曲面。

散度的物理意义 Physical Meaning of Divergence

📖散度 = 向外通量密度 div as Outward Flux Density

回忆散度的定义：设 $\mathbf{F} = \langle M, N, P \rangle$，则

$$\mathrm{div}\,\mathbf{F} = \nabla \cdot \mathbf{F} = \frac{\partial M}{\partial x} + \frac{\partial N}{\partial y} + \frac{\partial P}{\partial z}$$

物理直觉：考虑一个极小的长方体（边长 $\Delta x, \Delta y, \Delta z$），中心在 $(x_0, y_0, z_0)$。计算 $\mathbf{F}$ 穿过六个面的总向外通量（outward flux）。

💡微元通量的推导

三对面分别贡献：

顶/底面（$\pm\hat{k}$ 方向）：通量 $\approx \dfrac{\partial P}{\partial z}\,\Delta x\,\Delta y\,\Delta z$

左/右面（$\pm\hat{i}$ 方向）：通量 $\approx \dfrac{\partial M}{\partial x}\,\Delta x\,\Delta y\,\Delta z$

前/后面（$\pm\hat{j}$ 方向）：通量 $\approx \dfrac{\partial N}{\partial y}\,\Delta x\,\Delta y\,\Delta z$

总通量 $\approx \left(\dfrac{\partial M}{\partial x} + \dfrac{\partial N}{\partial y} + \dfrac{\partial P}{\partial z}\right)\Delta V = \mathrm{div}\,\mathbf{F} \cdot \Delta V$

所以 $\mathrm{div}\,\mathbf{F}$ 就是单位体积的向外通量——"微观通量密度"。

散度定理 Divergence Theorem

⭐散度定理 Divergence Theorem

设 $\mathbf{F} = \langle M, N, P \rangle$ 是分量具有连续偏导数的向量场，$E$ 是有界闭立体（bounded solid），$S$ 是 $E$ 的边界闭曲面（closed surface），法向量向外，则

$$\iint_S \mathbf{F} \cdot \mathbf{n}\, d\sigma = \iiint_E \mathrm{div}\,\mathbf{F}\, dV$$

左边 = 总通量（宏观），右边 = 微观通量密度的体积积分。将微元通量在整个立体上求和，相邻面的通量互相抵消，只剩最外层边界的通量。

📖闭曲面 Closed Surface

闭曲面是将空间分为两个区域的曲面："内部"（有界）和"外部"（无界）。

例如：球面 $x^2+y^2+z^2 = a^2$、立方体壳 → ✅ 闭曲面

半球面、平面上的抛物面 → ❌ 不是闭曲面（有"边界"）

散度定理例题 Examples

✏️例1：球面上的通量

求 $\mathbf{F} = \langle z, y, x \rangle$ 穿过球面 $x^2+y^2+z^2 = 1$（向外）的通量。

解法：用散度定理替代繁琐的曲面积分。

  • $\mathrm{div}\,\mathbf{F} = \dfrac{\partial z}{\partial x} + \dfrac{\partial y}{\partial y} + \dfrac{\partial x}{\partial z} = 0 + 1 + 0 = 1$
  • $\displaystyle\iint_S \mathbf{F}\cdot\mathbf{n}\,d\sigma = \iiint_B 1\,dV = \mathrm{Vol}(B) = \frac{4}{3}\pi(1)^3 = \frac{4}{3}\pi$

直接用体积就完成了，比逐面算曲面积分简单得多。

✏️例2：长方体上的通量

求 $\mathbf{F} = \langle x^2, 4xyz, ze^x \rangle$ 穿过长方体 $[0,3]\times[0,2]\times[0,1]$ 边界的通量。

解法：直接计算六个面的曲面积分非常繁琐，用散度定理。

  • $\mathrm{div}\,\mathbf{F} = 2x + 4xz + e^x$
  • $\displaystyle\iint_S \mathbf{F}\cdot\mathbf{n}\,d\sigma = \iiint_E (2x + 4xz + e^x)\,dV$
  • 被积函数不含 $y$，先对 $y$ 积分：$\displaystyle\int_0^2 dy = 2$
  • $\displaystyle = 2\int_0^3\int_0^1 (2x + 4xz + e^x)\,dz\,dx = 2\int_0^3 \left[(2x+e^x)z + 2xz^2\right]_0^1 dx$
  • $\displaystyle = 2\int_0^3 (2x + e^x + 2x)\,dx = 2\int_0^3 (4x + e^x)\,dx$
  • $= 2\left[2x^2 + e^x\right]_0^3 = 2(18 + e^3 - 1) = 2(17 + e^3)$

更一般的立体 More General Solids

📜可分解立体上的散度定理

散度定理可以用于能分解为有限多个有界闭立体的区域。

典型例子：球壳 $E: b^2 \leq x^2+y^2+z^2 \leq a^2$（$0 < b < a$）。

将 $E$ 看作两个区域的并集，边界 $S$ 由外球面 $S_a$ 和内球面 $S_b$ 组成：

$$\iint_S \mathbf{F}\cdot\mathbf{n}\,d\sigma = \iint_{S_a} \mathbf{F}\cdot\mathbf{n}\,d\sigma - \iint_{S_b} \mathbf{F}\cdot\mathbf{n}\,d\sigma$$

注意内球面 $S_b$ 的外法向量（相对于 $E$）是向内指向原点的，所以取减号。

✏️例3：逆平方场的通量

$\mathbf{F} = \dfrac{1}{(x^2+y^2+z^2)^{3/2}}\langle x, y, z \rangle$，求 $\mathbf{F}$ 穿过球壳边界 $S$ 的通量。

解法：令 $\rho = \sqrt{x^2+y^2+z^2}$，则 $M = x/\rho^3$。

  • $\dfrac{\partial M}{\partial x} = \dfrac{\rho^3 - x \cdot 3\rho^2 \cdot \frac{x}{\rho}}{\rho^6} = \dfrac{\rho^2 - 3x^2}{\rho^5}$
  • 同理 $\dfrac{\partial N}{\partial y} = \dfrac{\rho^2 - 3y^2}{\rho^5}$，$\dfrac{\partial P}{\partial z} = \dfrac{\rho^2 - 3z^2}{\rho^5}$
  • $\mathrm{div}\,\mathbf{F} = \dfrac{3\rho^2 - 3(x^2+y^2+z^2)}{\rho^5} = \dfrac{3\rho^2 - 3\rho^2}{\rho^5} = 0$
  • 因此 $\displaystyle\iiint_E \mathrm{div}\,\mathbf{F}\,dV = 0$

由此得到 $\displaystyle\iint_{S_a}\mathbf{F}\cdot\mathbf{n}\,d\sigma = \iint_{S_b}\mathbf{F}\cdot\mathbf{n}\,d\sigma$，即该场穿过所有包含原点的球面的通量都相同（与半径无关）。

四大定理对比 The Four Big Theorems

⭐四大定理：统一视角

每个定理都将一个微分算子在区域上的积分转化为边界上的积分。

算子定理公式
$\dfrac{d}{dx}$ 微积分基本定理 FTC $\displaystyle\int_{[a,b]} f'(x)\,dx = f(b) - f(a)$
$\nabla$ 线积分基本定理 FTLI $\displaystyle\int_C \nabla f \cdot d\mathbf{r} = f(B) - f(A)$
$\nabla\times$ Stokes 定理 $\displaystyle\iint_S (\nabla\times\mathbf{F})\cdot\mathbf{n}\,d\sigma = \oint_C \mathbf{F}\cdot d\mathbf{r}$
$\nabla\cdot$ 散度定理 $\displaystyle\iiint_E \nabla\cdot\mathbf{F}\,dV = \iint_S \mathbf{F}\cdot\mathbf{n}\,d\sigma$

统一模式：$\displaystyle\int_{\Omega}(\text{微分算子作用于 }f/\mathbf{F}) = \int_{\partial\Omega}(f/\mathbf{F} \text{ 在边界上的值})$

🔗2D 特例：Green 定理的两种形式
3D 定理2D 特例 (Green 定理)
Stokes $\displaystyle\iint_S \mathrm{curl}\,\mathbf{F}\cdot\mathbf{n}\,d\sigma = \oint_C \mathbf{F}\cdot d\mathbf{r}$ $\displaystyle\iint_R (\mathrm{curl}\,\mathbf{F})\cdot\hat{k}\,dA = \oint_C \mathbf{F}\cdot d\mathbf{r}$（环量形式）
Divergence $\displaystyle\iiint_E \mathrm{div}\,\mathbf{F}\,dV = \iint_S \mathbf{F}\cdot\mathbf{n}\,d\sigma$ $\displaystyle\iint_R \mathrm{div}\,\mathbf{F}\,dA = \oint_C \mathbf{F}\cdot\mathbf{n}\,ds$（通量形式）
📜保守场 ⟺ 梯度场

设 $\mathbf{F}$ 是开连通区域 $D$ 上分量连续的向量场，则以下等价：

(1) $\mathbf{F}$ 是保守场（conservative）：$\oint_C \mathbf{F}\cdot d\mathbf{r} = 0$ 对 $D$ 中所有闭曲线成立

(2) $\mathbf{F}$ 是梯度场（gradient field）：存在 $f$ 使得 $\mathbf{F} = \nabla f$

"$\Leftarrow$" 由线积分基本定理直接得到。"$\Rightarrow$" 的证明在 Lec 22 中讨论。
