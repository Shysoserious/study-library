Lecture 6 — 二项级数与Taylor定理

6.1 二项级数 Binomial Series

📐广义二项系数

对任意实数 $\alpha$ 和正整数 $n$，定义generalized binomial coefficient：

$$\binom{\alpha}{n} = \frac{\alpha(\alpha-1)(\alpha-2)\cdots(\alpha-n+1)}{n!}$$

约定 $\binom{\alpha}{0} = 1$。

⭐二项级数定理

对任意实数 $\alpha$，当 $|x| < 1$ 时：

$$(1+x)^\alpha = \sum_{n=0}^{\infty}\binom{\alpha}{n}x^n = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + \cdots$$

收敛半径 $R = 1$（当 $\alpha \in \mathbb{N}$ 时，级数有限项即为二项式定理）。

📝常用二项展开

$\frac{1}{\sqrt{1+x}} = (1+x)^{-1/2} = \sum_{n=0}^{\infty}\binom{-1/2}{n}x^n$，$|x|<1$

$\sqrt{1+x} = (1+x)^{1/2} = 1 + \frac{1}{2}x - \frac{1}{8}x^2 + \frac{1}{16}x^3 - \cdots$

6.2 大O与小o记号 Big O / Little o Notation

📐大O记号 Big O

设 $f,g$ 在某点 $a$ 的邻域有定义，$g(x)\neq 0$。称 $f(x) = O(g(x))$（$x\to a$），若：

$$\exists\, M > 0,\;\exists\,\delta > 0,\;\forall\,0<|x-a|<\delta:\;|f(x)|\le M|g(x)|$$

等价地：$\frac{f(x)}{g(x)}$ 在 $x\to a$ 时有界。

📐小o记号 Little o

称 $f(x) = o(g(x))$（$x\to a$），若：

$$\lim_{x\to a}\frac{f(x)}{g(x)} = 0$$

直觉：$f$ 比 $g$ "高阶无穷小"，$f$ 远小于 $g$。

💡运算法则

以 $x\to 0$ 为例：

• $o(x^n) + o(x^n) = o(x^n)$

• $o(x^m)\cdot o(x^n) = o(x^{m+n})$

• $x^m \cdot o(x^n) = o(x^{m+n})$

• 若 $m \le n$，则 $o(x^n) = o(x^m)$（高阶可并入低阶）

• $O(x^n)$ 类似，但保持有界而非趋零

📝利用 Taylor 展开 + o 记号求极限

求 $\lim_{x\to 0}\frac{\sin x - x + \frac{x^3}{6}}{x^5}$：

解：

$\sin x = x - \frac{x^3}{6} + \frac{x^5}{120} + o(x^5)$

$\sin x - x + \frac{x^3}{6} = \frac{x^5}{120} + o(x^5)$

所以极限 $= \frac{1}{120}$。

6.3 Taylor定理 (O/o 版本)

⭐带 Peano 余项的 Taylor 定理

设 $f$ 在 $x=a$ 处 $n$ 次可微，则：

$$f(x) = \sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k + o\big((x-a)^n\big),\quad x\to a$$

这是 Taylor 定理的Peano remainder形式，只需 $f$ 存在 $n$ 阶导数。

⭐带 Lagrange 余项 (大 O 版本)

设 $f$ 在包含 $a$ 的开区间上 $n+1$ 次可导，则：

$$f(x) = \sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k + O\big((x-a)^{n+1}\big)$$

余项 $R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}$ 对某 $c$ 介于 $a,x$ 之间。

⚠️o 与 O 的区别

• $o((x-a)^n)$：余项比 $(x-a)^n$ 更高阶（只需 $n$ 阶可导）

• $O((x-a)^{n+1})$：余项与 $(x-a)^{n+1}$ 同阶有界（需 $n+1$ 阶可导）

O 版本信息更精确，但要求更强。

6.4 Euler 公式 Euler's Formula

⭐Euler 公式

定义 $e^{i\theta}$ 通过幂级数的方式：

$$e^{i\theta} = \cos\theta + i\sin\theta$$

特别地，当 $\theta = \pi$ 时得到 Euler's identity：$e^{i\pi} + 1 = 0$。

💡推导思路

将 $e^x$, $\cos x$, $\sin x$ 的 Taylor 级数形式代入 $e^{ix}$：

$e^{ix} = \sum \frac{(ix)^n}{n!} = \underbrace{\sum \frac{(-1)^k x^{2k}}{(2k)!}}_{\cos x} + i\underbrace{\sum \frac{(-1)^k x^{2k+1}}{(2k+1)!}}_{\sin x}$

🔗应用：三角恒等式

利用 $e^{i(\alpha+\beta)} = e^{i\alpha}\cdot e^{i\beta}$，可以一步推出加法公式：

$\cos(\alpha+\beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta$

$\sin(\alpha+\beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$

6.5 Taylor 定理的证明

⭐证明核心思路 (Rolle 定理)

对 Lagrange 余项形式的 Taylor 定理，证明的关键步骤：

  1. 构造辅助函数 $F(t) = f(x) - \sum_{k=0}^{n}\frac{f^{(k)}(t)}{k!}(x-t)^k$
  2. 构造 $G(t) = F(t) - \left(\frac{x-t}{x-a}\right)^{n+1}F(a)$
  3. 验证 $G(a) = G(x) = 0$
  4. 由 Rolle 定理，$\exists\, c$ 介于 $a,x$ 之间使得 $G'(c) = 0$
  5. 计算 $G'(t)$ 得到余项表达式

Lecture 7 — 参数曲线

7.1 参数曲线的定义 Parametric Curves

📐参数方程

若 $x = f(t)$，$y = g(t)$，$t\in[a,b]$，则曲线 $C$ 由参数 $t$ 参数化表示。

$t = a$ 为initial point，$t = b$ 为terminal point。

📝摆线 Cycloid

车轮沿直线滚动时轮缘上一点的轨迹：

$$x = a(t - \sin t),\quad y = a(1 - \cos t)$$

其中 $a$ 是车轮半径。一个完整拱形对应 $t\in[0,2\pi]$。

7.2 切线与二阶导数

⭐参数曲线的斜率

设 $x = f(t)$, $y = g(t)$ 均可微且 $f'(t)\neq 0$，则：

$$\frac{dy}{dx} = \frac{g'(t)}{f'(t)} = \frac{dy/dt}{dx/dt}$$
⭐二阶导数
$$\frac{d^2y}{dx^2} = \frac{\frac{d}{dt}\left(\frac{dy}{dx}\right)}{\frac{dx}{dt}} = \frac{\frac{d}{dt}\left(\frac{g'(t)}{f'(t)}\right)}{f'(t)}$$

注意：$\frac{d^2y}{dx^2} \neq \frac{g''(t)}{f''(t)}$！必须先对 $\frac{dy}{dx}$ 关于 $t$ 求导，再除以 $\frac{dx}{dt}$。

📝摆线的切线

摆线 $x=a(t-\sin t)$, $y=a(1-\cos t)$：

$\frac{dy}{dx} = \frac{a\sin t}{a(1-\cos t)} = \frac{\sin t}{1-\cos t}$

在 $t=\pi$ 时，切线垂直（$\frac{dx}{dt}=0$ 但 $\frac{dy}{dt}\neq 0$）。

7.3 弧长 Arc Length

⭐参数曲线弧长公式

设 $C: x=f(t), y=g(t)$，$t\in[a,b]$，$f',g'$ 连续且曲线不自交，则：

$$L = \int_a^b \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}\,dt = \int_a^b\sqrt{f'(t)^2 + g'(t)^2}\,dt$$
📐弧长微分

Arc length differential：

$$ds = \sqrt{dx^2 + dy^2} = \sqrt{f'(t)^2 + g'(t)^2}\,dt$$

对 $y = h(x)$：$ds = \sqrt{1 + (dy/dx)^2}\,dx$。

📝摆线一拱弧长

$L = \int_0^{2\pi}\sqrt{a^2(1-\cos t)^2 + a^2\sin^2 t}\,dt = a\int_0^{2\pi}\sqrt{2(1-\cos t)}\,dt$

利用 $1-\cos t = 2\sin^2(t/2)$：$L = 2a\int_0^{2\pi}|\sin(t/2)|\,dt = 8a$。

7.4 参数曲线下的面积

⭐面积公式

参数曲线 $(f(t), g(t))$ 与 $x$ 轴之间的面积（$g(t)\ge 0$）：

$$A = \int_a^b g(t)\cdot f'(t)\,dt$$

注意积分方向：若 $f(a) > f(b)$ 则需取绝对值。

📝摆线一拱面积

$A = \int_0^{2\pi}a(1-\cos t)\cdot a(1-\cos t)\,dt = a^2\int_0^{2\pi}(1-\cos t)^2\,dt = 3\pi a^2$

7.5 旋转曲面面积 Surface of Revolution

⭐旋转曲面面积公式

曲线绕 $x$ 轴旋转所得曲面面积：

$$S = \int_a^b 2\pi\,|g(t)|\,\sqrt{f'(t)^2 + g'(t)^2}\,dt = \int 2\pi\,|y|\,ds$$

绕 $y$ 轴旋转则用 $2\pi|x|\,ds$。

7.6 极坐标简介 Polar Coordinates

📐极坐标系

平面上的点用 $(r,\theta)$ 表示：$r$ 为到原点的距离，$\theta$ 为与正 $x$ 轴的夹角。

$$x = r\cos\theta,\quad y = r\sin\theta,\quad r^2 = x^2+y^2,\quad \tan\theta = \frac{y}{x}$$
⚠️注意事项

• 极坐标表示不唯一：$(r,\theta)$ 与 $(r, \theta+2k\pi)$ 是同一点

• 允许 $r < 0$：$(-r,\theta)$ 等价于 $(r,\theta+\pi)$

• 原点用 $(0,\theta)$ 表示（任意 $\theta$）

📝常见极坐标曲线

• 圆：$r = a$（半径为 $a$ 的圆）

• 心形线 Cardioid：$r = a(1+\cos\theta)$

• 玫瑰线 Rose：$r = a\cos(n\theta)$

• 双纽线 Lemniscate：$r^2 = a^2\cos(2\theta)$

Lecture 8 — 极坐标与三维空间

8.1 极坐标对称性 Symmetry Tests

💡对称性判定
对称轴替换测试
关于 $x$ 轴对称$\theta \to -\theta$ 方程不变
关于 $y$ 轴对称$\theta \to \pi-\theta$ 方程不变
关于原点对称$r \to -r$ 方程不变

8.2 极坐标曲线作图

📝心形线 $r = 1 - \cos\theta$

分析步骤：

  1. 对称性：$\theta\to -\theta$ 不变，关于 $x$ 轴对称
  2. 特殊值：$\theta=0$ 时 $r=0$；$\theta=\pi$ 时 $r=2$
  3. $r$ 的增减：$0\to\pi$ 上 $r$ 从 0 增到 2
  4. 由对称性画出完整图形
📝双纽线 $r^2 = \cos 2\theta$

注意 $\cos 2\theta \ge 0$ 才有意义，即 $\theta\in[-\pi/4,\pi/4]\cup[3\pi/4,5\pi/4]$。

图形为"∞"形。关于 $x$ 轴、$y$ 轴、原点都对称。

8.3 极坐标斜率与弧长

⭐极坐标曲线的斜率

对 $r = f(\theta)$，视为参数方程 $x = r\cos\theta$, $y = r\sin\theta$：

$$\frac{dy}{dx} = \frac{\frac{dr}{d\theta}\sin\theta + r\cos\theta}{\frac{dr}{d\theta}\cos\theta - r\sin\theta}$$
⭐极坐标弧长公式
$$L = \int_\alpha^\beta \sqrt{r^2 + \left(\frac{dr}{d\theta}\right)^2}\,d\theta$$
📝心形线 $r = 1-\cos\theta$ 的弧长

$r' = \sin\theta$，$r^2 + r'^2 = (1-\cos\theta)^2 + \sin^2\theta = 2(1-\cos\theta)$

$L = \int_0^{2\pi}\sqrt{2(1-\cos\theta)}\,d\theta = 2\int_0^{2\pi}|\sin(\theta/2)|\,d\theta = 8$

8.4 极坐标面积 Polar Area

⭐极坐标面积公式

曲线 $r = f(\theta)$，$\theta\in[\alpha,\beta]$ 所围区域面积：

$$A = \frac{1}{2}\int_\alpha^\beta r^2\,d\theta = \frac{1}{2}\int_\alpha^\beta [f(\theta)]^2\,d\theta$$

几何直觉：将区域划分为无穷多个扇形，每个扇形面积 $\approx \frac{1}{2}r^2\,d\theta$。

📝心形线 $r = 1+\cos\theta$ 的面积

$A = \frac{1}{2}\int_0^{2\pi}(1+\cos\theta)^2\,d\theta = \frac{1}{2}\int_0^{2\pi}\left(1+2\cos\theta+\cos^2\theta\right)d\theta = \frac{3\pi}{2}$

💡两条极曲线之间的面积

若 $0\le g(\theta)\le f(\theta)$，则两曲线之间面积：

$$A = \frac{1}{2}\int_\alpha^\beta\left([f(\theta)]^2 - [g(\theta)]^2\right)d\theta$$

8.5 三维坐标系 3D Coordinate System

📐三维笛卡尔坐标

$\mathbb{R}^3$ 中一点用 $(x,y,z)$ 表示。三个坐标平面：

• $xy$ 平面：$z=0$

• $xz$ 平面：$y=0$

• $yz$ 平面：$x=0$

坐标轴遵循right-hand rule（右手定则）。

8.6 距离公式与球面

⭐空间距离公式

$P_1(x_1,y_1,z_1)$ 与 $P_2(x_2,y_2,z_2)$ 之间距离：

$$d = \sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}$$
📐球面方程

圆心 $(a,b,c)$、半径 $r$ 的球面：

$$(x-a)^2 + (y-b)^2 + (z-c)^2 = r^2$$

Lecture 9 — 向量与点积叉积

9.1 向量基础 Vectors

📐向量的定义与运算

向量 $\vec{v} = \langle v_1, v_2, v_3\rangle$ 是有大小和方向的量。

• 加法：$\vec{u}+\vec{v} = \langle u_1+v_1, u_2+v_2, u_3+v_3\rangle$

• 数乘：$c\vec{v} = \langle cv_1, cv_2, cv_3\rangle$

• 模：$|\vec{v}| = \sqrt{v_1^2+v_2^2+v_3^2}$

• 单位向量：$\hat{v} = \frac{\vec{v}}{|\vec{v}|}$

📐中点公式

$P_1(x_1,y_1,z_1)$ 与 $P_2(x_2,y_2,z_2)$ 的中点：

$$M = \left(\frac{x_1+x_2}{2},\;\frac{y_1+y_2}{2},\;\frac{z_1+z_2}{2}\right)$$
💡标准基向量

$\vec{i} = \langle 1,0,0\rangle$，$\vec{j} = \langle 0,1,0\rangle$，$\vec{k} = \langle 0,0,1\rangle$

任何向量 $\vec{v} = v_1\vec{i} + v_2\vec{j} + v_3\vec{k}$。

9.2 点积 Dot Product

📐点积的两种定义

代数定义：$\vec{u}\cdot\vec{v} = u_1v_1 + u_2v_2 + u_3v_3$

几何定义：

$$\vec{u}\cdot\vec{v} = |\vec{u}||\vec{v}|\cos\theta$$

其中 $\theta$ 是两向量的夹角，$0\le\theta\le\pi$。

⭐点积的性质

• $\vec{u}\cdot\vec{v} = \vec{v}\cdot\vec{u}$（交换律）

• $\vec{u}\cdot(\vec{v}+\vec{w}) = \vec{u}\cdot\vec{v}+\vec{u}\cdot\vec{w}$（分配律）

• $(c\vec{u})\cdot\vec{v} = c(\vec{u}\cdot\vec{v})$

• $\vec{u}\cdot\vec{u} = |\vec{u}|^2$

• $\vec{u}\perp\vec{v} \iff \vec{u}\cdot\vec{v} = 0$

💡夹角公式
$$\cos\theta = \frac{\vec{u}\cdot\vec{v}}{|\vec{u}||\vec{v}|}$$

9.3 投影 Projection

⭐向量投影

$\vec{u}$ 在 $\vec{v}$ 方向上的scalar component（标量投影）：

$$\text{comp}_{\vec{v}}\vec{u} = \frac{\vec{u}\cdot\vec{v}}{|\vec{v}|} = |\vec{u}|\cos\theta$$

$\vec{u}$ 在 $\vec{v}$ 方向上的vector projection：

$$\text{proj}_{\vec{v}}\vec{u} = \frac{\vec{u}\cdot\vec{v}}{|\vec{v}|^2}\vec{v} = \frac{\vec{u}\cdot\vec{v}}{\vec{v}\cdot\vec{v}}\vec{v}$$
🔗物理应用：功

力 $\vec{F}$ 沿位移 $\vec{d}$ 所做的功：

$$W = \vec{F}\cdot\vec{d} = |\vec{F}||\vec{d}|\cos\theta$$

9.4 叉积 Cross Product

📐叉积的定义

$\vec{u}\times\vec{v}$ 是一个向量，用行列式计算：

$$\vec{u}\times\vec{v} = \begin{vmatrix}\vec{i}&\vec{j}&\vec{k}\\u_1&u_2&u_3\\v_1&v_2&v_3\end{vmatrix} = \langle u_2v_3-u_3v_2,\; u_3v_1-u_1v_3,\; u_1v_2-u_2v_1\rangle$$
⭐叉积的几何意义

• 方向：垂直于 $\vec{u}$ 和 $\vec{v}$ 所在平面，由右手定则确定

• 大小：

$$|\vec{u}\times\vec{v}| = |\vec{u}||\vec{v}|\sin\theta$$

• 几何意义：等于 $\vec{u}$ 与 $\vec{v}$ 张成的parallelogram（平行四边形）面积

⚠️叉积不满足交换律

$\vec{u}\times\vec{v} = -(\vec{v}\times\vec{u})$（反交换律）

$\vec{u}\times\vec{u} = \vec{0}$

$\vec{u}\parallel\vec{v} \iff \vec{u}\times\vec{v} = \vec{0}$

Lecture 10 — 空间直线与平面

10.1 三重标量积 Triple Scalar Product

⭐三重标量积
$$(\vec{u}\times\vec{v})\cdot\vec{w} = \begin{vmatrix}u_1&u_2&u_3\\v_1&v_2&v_3\\w_1&w_2&w_3\end{vmatrix}$$

几何意义：等于 $\vec{u}, \vec{v}, \vec{w}$ 张成的parallelepiped（平行六面体）的有向体积。

$$V = |(\vec{u}\times\vec{v})\cdot\vec{w}|$$
🔗力矩 Torque

力 $\vec{F}$ 关于支点的力矩 torque：

$$\vec{\tau} = \vec{r}\times\vec{F}$$

其中 $\vec{r}$ 是从支点到力作用点的向量。$|\vec{\tau}| = |\vec{r}||\vec{F}|\sin\theta$。

10.2 空间直线方程 Lines in Space

📐直线的参数方程

过点 $P_0(x_0,y_0,z_0)$、方向向量 $\vec{v} = \langle a,b,c\rangle$ 的直线：

$$\vec{r}(t) = \vec{r}_0 + t\vec{v} \implies \begin{cases}x = x_0+at\\y = y_0+bt\\z = z_0+ct\end{cases}$$

对称形式（$a,b,c\neq 0$）：$\frac{x-x_0}{a} = \frac{y-y_0}{b} = \frac{z-z_0}{c}$

💡两点确定直线

过 $P_1$ 和 $P_2$ 的直线：方向向量 $\vec{v} = \overrightarrow{P_1P_2}$，取 $P_0 = P_1$。

10.3 平面方程 Planes

📐平面的方程

过点 $P_0(x_0,y_0,z_0)$、法向量 $\vec{n} = \langle A,B,C\rangle$ 的平面：

$$A(x-x_0)+B(y-y_0)+C(z-z_0) = 0$$

或一般形式：$Ax + By + Cz = D$。

💡求平面法向量的方法

• 已知平面上两个向量 $\vec{u},\vec{v}$：$\vec{n} = \vec{u}\times\vec{v}$

• 已知三点 $P,Q,R$：$\vec{n} = \overrightarrow{PQ}\times\overrightarrow{PR}$

10.4 点到直线/平面距离

⭐点到平面的距离

点 $P(x_1,y_1,z_1)$ 到平面 $Ax+By+Cz=D$ 的距离：

$$d = \frac{|Ax_1+By_1+Cz_1-D|}{\sqrt{A^2+B^2+C^2}}$$
⭐点到直线的距离

点 $S$ 到直线（过 $P$，方向 $\vec{v}$）的距离：

$$d = \frac{|\overrightarrow{PS}\times\vec{v}|}{|\vec{v}|}$$
📐异面直线 Skew Lines

两条直线若既不平行也不相交，则称为异面直线。两异面直线之间的距离：

$$d = \frac{|(\overrightarrow{P_1P_2})\cdot(\vec{v}_1\times\vec{v}_2)|}{|\vec{v}_1\times\vec{v}_2|}$$

其中 $P_1,P_2$ 分别在两直线上，$\vec{v}_1,\vec{v}_2$ 是方向向量。

10.5 柱面与二次曲面 Cylinders and Quadric Surfaces

📐柱面

Cylinder：由平行于某一固定直线的直线族生成的曲面。

例：$x^2+y^2 = 1$ 在 $\mathbb{R}^3$ 中是圆柱面（沿 $z$ 轴方向无约束）。

📐二次曲面

常见二次曲面：

名称方程

Lecture 11 — 向量函数

11.1 向量函数的定义 Vector-Valued Functions

📐向量函数

向量函数 $\vec{r}(t) = \langle f(t), g(t), h(t)\rangle = f(t)\vec{i}+g(t)\vec{j}+h(t)\vec{k}$

其中 $f,g,h$ 称为component functions（分量函数）。

定义域：三个分量函数定义域的交集。

11.2 极限与连续

⭐分量运算

向量函数的极限、连续性都是逐分量进行的：

$$\lim_{t\to t_0}\vec{r}(t) = \left\langle\lim_{t\to t_0}f(t),\;\lim_{t\to t_0}g(t),\;\lim_{t\to t_0}h(t)\right\rangle$$

$\vec{r}$ 在 $t_0$ 连续 $\iff$ 每个分量在 $t_0$ 连续。

11.3 导数与切向量

📐向量函数的导数
$$\vec{r}'(t) = \lim_{\Delta t\to 0}\frac{\vec{r}(t+\Delta t)-\vec{r}(t)}{\Delta t} = \langle f'(t), g'(t), h'(t)\rangle$$

$\vec{r}'(t)$ 是曲线在该点的tangent vector（切向量）。

📐单位切向量
$$\vec{T}(t) = \frac{\vec{r}'(t)}{|\vec{r}'(t)|}$$

$\vec{T}$ 是unit tangent vector，指向曲线前进方向。

11.4 求导法则

⭐向量函数的求导法则

设 $\vec{u}(t)$, $\vec{v}(t)$ 可微，$c(t)$ 是标量函数：

  1. $\frac{d}{dt}[c(t)\vec{u}(t)] = c'(t)\vec{u}(t)+c(t)\vec{u}'(t)$
  2. $\frac{d}{dt}[\vec{u}(t)+\vec{v}(t)] = \vec{u}'(t)+\vec{v}'(t)$
  3. $\frac{d}{dt}[\vec{u}(t)\cdot\vec{v}(t)] = \vec{u}'(t)\cdot\vec{v}(t)+\vec{u}(t)\cdot\vec{v}'(t)$
  4. $\frac{d}{dt}[\vec{u}(t)\times\vec{v}(t)] = \vec{u}'(t)\times\vec{v}(t)+\vec{u}(t)\times\vec{v}'(t)$
    （叉积顺序不能交换！）
  5. $\frac{d}{dt}[\vec{u}(c(t))] = c'(t)\vec{u}'(c(t))$（链式法则）
⭐等长向量的性质

若 $|\vec{r}(t)| = $ 常数，则：

$$\vec{r}(t)\cdot\vec{r}'(t) = 0$$

即：等长向量总是与其导数正交。（想象在球面上运动，速度总是切于球面）

11.5 积分与抛体运动

📐向量函数的积分
$$\int_a^b \vec{r}(t)\,dt = \left\langle\int_a^b f(t)\,dt,\;\int_a^b g(t)\,dt,\;\int_a^b h(t)\,dt\right\rangle$$

不定积分：$\int\vec{r}(t)\,dt = \vec{R}(t)+\vec{C}$（$\vec{C}$ 为常向量）。

🔗抛体运动 Projectile Motion

设重力加速度 $\vec{a} = -g\vec{j}$，初速度 $\vec{v}_0 = (v_0\cos\alpha)\vec{i}+(v_0\sin\alpha)\vec{j}$：

$$\vec{r}(t) = (v_0\cos\alpha)t\,\vec{i} + \left[(v_0\sin\alpha)t - \frac{1}{2}gt^2\right]\vec{j}$$

由 $\vec{a}\to\vec{v}\to\vec{r}$ 两次积分得到。

Lecture 12 — 弧长参数与曲率

12.1 抛体运动分析

⭐抛体运动关键公式

初速 $v_0$，仰角 $\alpha$，重力 $g$：

最大高度（$y$ 分量速度为零时）：

$$H = \frac{v_0^2\sin^2\alpha}{2g}$$

飞行时间（$y=0$ 时）：

$$T = \frac{2v_0\sin\alpha}{g}$$

水平射程 Range：

$$R = \frac{v_0^2\sin 2\alpha}{g}$$

最大射程在 $\alpha = 45°$ 时取得。

12.2 弧长参数 Arc Length Parameter

📐弧长参数

从 $t = t_0$ 开始沿曲线测量的弧长：

$$s(t) = \int_{t_0}^{t}|\vec{r}'(\tau)|\,d\tau = \int_{t_0}^{t}\sqrt{f'(\tau)^2+g'(\tau)^2+h'(\tau)^2}\,d\tau$$

$\frac{ds}{dt} = |\vec{r}'(t)|$（弧长变化率 = 速率）。

💡弧长参数化的好处

以弧长 $s$ 为参数时，$|\vec{r}'(s)| = 1$，即单位切向量就是 $\vec{r}'(s) = \vec{T}(s)$。

这使得曲率等几何量的表达式更简洁。

12.3 曲率 Curvature

📐曲率的定义

曲率衡量曲线弯曲的程度：

$$\kappa = \left|\frac{d\vec{T}}{ds}\right|$$

即单位切向量关于弧长的变化率的模。

⭐曲率的计算公式

用参数 $t$ 计算：

$$\kappa = \frac{|\vec{T}'(t)|}{|\vec{r}'(t)|} = \frac{|\vec{r}'(t)\times\vec{r}''(t)|}{|\vec{r}'(t)|^3}$$

平面曲线 $y = f(x)$：

$$\kappa = \frac{|f''(x)|}{[1+(f'(x))^2]^{3/2}}$$
📝圆的曲率

半径为 $a$ 的圆：$\vec{r}(t) = a\cos t\,\vec{i}+a\sin t\,\vec{j}$

$|\vec{r}'| = a$，$|\vec{r}''| = a$，$|\vec{r}'\times\vec{r}''| = a^2$

$\kappa = \frac{a^2}{a^3} = \frac{1}{a}$。曲率恒等于半径的倒数。

12.4 主法向量与密切圆

📐主法向量 Principal Unit Normal
$$\vec{N} = \frac{\vec{T}'(t)}{|\vec{T}'(t)|}$$

$\vec{N}$ 指向曲线弯曲的方向（曲线的"内侧"），且 $\vec{N}\perp\vec{T}$。

📐密切圆 Osculating Circle

在曲线某点处最佳拟合曲线的圆称为密切圆。

• 曲率半径 radius of curvature：$\rho = \frac{1}{\kappa}$

• 密切圆的圆心在曲线该点沿 $\vec{N}$ 方向距离 $\rho$ 处

• 密切圆与曲线在该点有相同的切线和曲率

💡直觉理解

• $\kappa$ 大 $\Rightarrow$ $\rho$ 小 $\Rightarrow$ 曲线弯曲剧烈

• $\kappa = 0$ 表示直线（$\rho = \infty$）

• 曲率就是"每走单位弧长，方向转了多少角度"

🔗TNB 框架预告

$\vec{T}$（切向量）、$\vec{N}$（主法向量）、$\vec{B} = \vec{T}\times\vec{N}$（副法向量）构成Frenet-Serret frame。

这个正交基在空间曲线上沿弧长移动，是微分几何的核心工具。
