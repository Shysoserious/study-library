Lec 1-5 · 多元基础

三、多元极限、偏导、连续性

3.1 多元极限的判定流程必考
必背流程
  1. 先尝试代入：若分母 $\to$ 非零数，直接代入即可（如 2025 Q2(iii)）。
  2. 分子非零、分母 $\to 0$ $\Rightarrow$ 极限不存在（如 2023 Q2(i)）。
  3. $0/0$ 不定型 选择路径检验：
    • 线性路径 $y=kx$。
    • 抛物路径 $y=kx^2$（针对 $\frac{x^2 y}{x^4+y^2}$ 这类）。
    • $y=mx^n$ 一般幂路径。
    不同路径得到不同极限 $\Rightarrow$ DNE。
  4. 同路径 + 极坐标：$x=r\cos\theta,\,y=r\sin\theta$；若可写成 $r\cdot g(\theta)$ 且 $|g(\theta)|$ 有界，则 $\to 0$。
  5. 夹逼定理：常用 $|x|\le\sqrt{x^2+y^2}$，$|xy|\le\frac{1}{2}(x^2+y^2)$。
⚠ 常见陷阱
  • 抛物路径陷阱：分子分母都含 $x^4$ 或 $y^2$ 时，仅用 $y=kx$ 极限可能为 $0$，但 $y=kx^2$ 给出依赖 $k$ 的值。必须再试抛物路径（2025 Q2(ii)）。
  • 分离连续 ≠ 联合连续：经典反例 $f=\frac{xy}{x^2+y^2}$（$f(0,0)=0$）每个轴上连续但联合不连续（2025 Q1(ii)）。
3.2 偏导与 Clairaut 定理必考
Clairaut（Schwarz）定理

若 $f_{xy}$ 与 $f_{yx}$ 在某点附近都连续，则两者相等。 $$f_{xy}=f_{yx}.$$ 实操中：算出 $f_x$ 求 $\partial_y$ 得 $f_{xy}$，算出 $f_y$ 求 $\partial_x$ 得 $f_{yx}$，互相验证一定相等，否则一定算错。

⚠ 分段函数衔接处

对于分段函数（2023 Q3 的 $f$），衔接线 $y=0$ 上的偏导必须用差商定义计算： $$f_y(x_0,0)=\lim_{h\to 0}\frac{f(x_0,h)-f(x_0,0)}{h}.$$ 要分别计算 $h\to 0^+$ 与 $h\to 0^-$，两侧不一致则该点偏导不存在。这是 2023 Q3 中 $f_{yy}$ 在 $y=0$ 处不存在的原因。

3.3 连续性与简单连通性概念常考
必背的概念辨析
  • 简单连通：每条闭合曲线都能在区域内连续收缩到一点。
    • $\mathbb R^2\setminus\{0\}$：不简单连通（围绕原点的圈无法收缩）。
    • $\mathbb R^3\setminus\{0\}$：简单连通（3D 中可"绕开"挖掉的点）。
    • $\mathbb R^3\setminus\{z$ 轴$\}$：不简单连通。
  • 积分区域可加性的成立条件：$R=R_1\cup R_2\Rightarrow\iint_R=\iint_{R_1}+\iint_{R_2}$ 仅当 $R_1\cap R_2$ 为零测集（如一条线段）。重叠面积非零时双重计数（2025 Q1(iv)）。
Lec 7-10 · 微分学

四、梯度、方向导数、切平面

4.1 梯度与方向导数必考
必背公式

梯度：$\nabla f=\left(\frac{\partial f}{\partial x_1},\dots,\frac{\partial f}{\partial x_n}\right)$。

方向导数（$\hat u$ 必须是单位向量）： $$D_{\hat u}f=\nabla f\cdot\hat u=|\nabla f|\cos\theta.$$

关键事实：

  • 梯度方向 = 增长最快方向，最大增长率 $=|\nabla f|$。
  • $-\nabla f$ 方向 = 下降最快方向。
  • 梯度垂直于等值面（这是切平面公式的根本来源）。
  • $D_{\hat u}f=0\Leftrightarrow\hat u$ 沿等值面切方向（2023 Q1(iii)）。

⚠ 容易丢分的地方
  • 题目给的方向向量未必是单位向量，必须先归一化（除以 $|\mathbf v|$）。
  • 验证：2025 Q1(vi) 题目给的 $(1/3,2/3,2/3)$ 是单位向量（$1/9+4/9+4/9=1$），可以直接用。但要养成验证习惯。
4.2 切平面与法线（两套公式）必考
隐式曲面 $F(x,y,z)=c$

法向量 $\mathbf n=\nabla F(P_0)$。
切平面：$F_x(P_0)(x-x_0)+F_y(P_0)(y-y_0)+F_z(P_0)(z-z_0)=0$。
法线：$(x,y,z)=P_0+t\nabla F(P_0)$。

显式曲面 $z=f(x,y)$

法向量 $\mathbf n=(f_x(P_0),\,f_y(P_0),\,-1)$（或反向 $(-f_x,-f_y,1)$）。
切平面：$z-z_0=f_x(P_0)(x-x_0)+f_y(P_0)(y-y_0)$。
法线：$(x,y,z)=(x_0,y_0,z_0)+t(f_x,f_y,-1)$。

★ 转换技巧

显式 $z=f(x,y)$ 总能改写为隐式 $F=z-f(x,y)=0$。这时 $\nabla F=(-f_x,-f_y,1)$，与显式公式一致。两种方法等价；考试用哪个看具体形式：

  • 题目给 $z=x^2-y^2$ 这类，直接用显式公式（2025 Q4）。
  • 题目给 $x^2+2y^2+z^2=4$ 这类，用隐式 $\nabla F$（2023 Q4）。

4.3 链式法则常考
多元链式法则

若 $w=f(x,y,z)$，$x,y,z$ 都依赖参数 $t$（或更多变量），则 $$\frac{\partial w}{\partial t}=f_x\frac{\partial x}{\partial t}+f_y\frac{\partial y}{\partial t}+f_z\frac{\partial z}{\partial t}.$$ 球坐标特例（2023 Q1(i)）：$\partial z/\partial\theta=0$，所以 $\partial w/\partial\theta=-y f_x+x f_y$。

4.4 叉积与方向常考
两平面交线方向

若两平面法向量为 $\mathbf n_1,\mathbf n_2$，则交线方向为 $$\mathbf d=\mathbf n_1\times\mathbf n_2.$$ 单位方向 $\hat d=\mathbf d/|\mathbf d|$（也可取相反方向，2025 Q1(vii)）。

叉积分量公式： $$\mathbf a\times\mathbf b=\det\begin{pmatrix}\mathbf i&\mathbf j&\mathbf k\\a_1&a_2&a_3\\b_1&b_2&b_3\end{pmatrix}.$$

Lec 11-15 · 优化与级数

五、Taylor、极值、级数

5.1 二元 Taylor 展开必考
二阶 Taylor（在 $(a,b)$ 处）
$$f(a+h,b+k)\approx f(a,b)+f_x h+f_y k+\tfrac{1}{2}\!\left(f_{xx}h^2+2f_{xy}hk+f_{yy}k^2\right)+\cdots$$

在 $(0,0)$ 处的二次近似： $$Q(x,y)=f(0,0)+f_x(0,0)x+f_y(0,0)y+\tfrac{1}{2}\big(f_{xx}(0,0)x^2+2f_{xy}(0,0)xy+f_{yy}(0,0)y^2\big).$$

★ 速算技巧（乘积形）

对 $f=g(x)\cdot h(y)$，把 $g,h$ 分别展到 1-2 阶，相乘后保留 $\le n$ 阶项。
例：$\ln(1+x)\sin y=(x-\frac{x^2}{2}+\cdots)(y-\frac{y^3}{6}+\cdots)$，二次保留 $xy$（其它都 $\ge 3$ 阶），得 $Q=xy$（2025 Q1(viii)）。

5.2 无约束极值：Hessian 判别必考
二元二阶判别

设 $\nabla f(x_0,y_0)=\mathbf 0$（临界点），令 $$D=f_{xx}(x_0,y_0)\,f_{yy}(x_0,y_0)-[f_{xy}(x_0,y_0)]^2.$$ 判别：

  • $D>0,\,f_{xx}>0$：局部极小。
  • $D>0,\,f_{xx}<0$：局部极大。
  • $D<0$：鞍点。
  • $D=0$：判别失效，需更高阶分析或特殊讨论。

5.3 约束极值：Lagrange 乘子必考
单约束 Lagrange

极值化 $f$ 在 $g=c$ 上 $\Leftrightarrow$ 解 $$\nabla f=\lambda\nabla g,\quad g=c.$$ 解出所有候选点后，代回 $f$ 比较大小（紧致集上必取到最值）。

多约束

极值化 $f$ 在 $g_1=c_1,g_2=c_2$ 上 $\Leftrightarrow$ $\nabla f=\lambda_1\nabla g_1+\lambda_2\nabla g_2$。

⚠ Lagrange 易错
  • 退化情形必须单独讨论：例如 $\nabla T=\lambda\nabla g$ 中变量为 $0$ 的情况（2023 Q6 的 $z=0$ 退化分支）。
  • 解方程时常用消去法（一式比另一式），但要注意不能两边除以可能为 $0$ 的量。
  • 边界（端点）分别讨论 — 紧致区域上极值可能在边界。
5.4 距离最小化（替代 Lagrange 的简洁解法）必考
模板：原点到平面 $ax+by+cz=d$ 最近点

沿法向量方向参数化：$(at,bt,ct)$。代入平面：$(a^2+b^2+c^2)t=d\Rightarrow t=\frac{d}{a^2+b^2+c^2}$。最近点 $(at,bt,ct)$。距离 $|d|/\sqrt{a^2+b^2+c^2}$（2023 Q5）。

模板：原点到直线最近点

(1) 把交线参数化（用一个变量 $t$）；(2) 写 $D^2(t)=x(t)^2+y(t)^2+z(t)^2$；(3) 求 $\frac{d}{dt}D^2=0$ 解 $t$；(4) 代回得点（2025 Q5）。

5.5 级数（必背常用展开）常考
必背 Taylor 级数（在 $0$ 处）
  • $e^x=\sum\frac{x^n}{n!}=1+x+\frac{x^2}{2}+\frac{x^3}{6}+\cdots$
  • $\sin x=x-\frac{x^3}{6}+\frac{x^5}{120}-\cdots$
  • $\cos x=1-\frac{x^2}{2}+\frac{x^4}{24}-\cdots$
  • $\ln(1+x)=x-\frac{x^2}{2}+\frac{x^3}{3}-\cdots\;(|x|<1)$
  • $\frac{1}{1-x}=\sum x^n=1+x+x^2+\cdots\;(|x|<1)$
  • 二项级数：$(1+x)^\alpha=\sum_{n=0}^\infty\binom{\alpha}{n}x^n$，其中 $\binom{\alpha}{n}=\frac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!}$。
★ $\sum$ 级数求和技巧

2025 Q1(ix) $\sum\frac{2n+1}{n!}$ 拆分技巧：

  • $\sum_{n=0}^\infty\frac{1}{n!}=e$。
  • $\sum_{n=1}^\infty\frac{n}{n!}=\sum_{n=1}^\infty\frac{1}{(n-1)!}=e$。
  • $\sum_{n=2}^\infty\frac{n(n-1)}{n!}=\sum_{n=2}^\infty\frac{1}{(n-2)!}=e$。
一般任何形如 $\sum\frac{P(n)}{n!}$ 的级数都可拆成这些已知和。

5.6 交错级数偶考
Leibniz 判别法

若 $u_n>0$、$u_n$ 单调递减、$u_n\to 0$，则 $\sum(-1)^n u_n$ 收敛。
注意：这是充分条件，不是必要。即收敛交错级数的 $u_n$ 不一定单调（2023 Q1(ix) 答案 F）。

Lec 13-17 · 多重积分

六、二重 / 三重积分与变量代换

6.1 二重积分的关键步骤必考
模板：四步法
  1. 画区域：找出所有边界曲线交点。
  2. 选积分顺序：观察被积函数对哪个变量积分最简单（如 $e^{y^3}$ 必须先对 $x$ 积分 — 2025 Q7(b)）。
  3. 定上下限：外层是常数区间，内层是函数区间。
  4. 逐层计算：先内后外。
6.2 极坐标 / 柱坐标 / 球坐标必考
极坐标 (2D)
$x=r\cos\theta,\;y=r\sin\theta,\;\;\boxed{dA=r\,dr\,d\theta}.$
柱坐标 (3D)
$x=r\cos\theta,\;y=r\sin\theta,\;z=z,\;\;\boxed{dV=r\,dr\,d\theta\,dz}.$
球坐标 (3D)
$x=\rho\sin\varphi\cos\theta,\;y=\rho\sin\varphi\sin\theta,\;z=\rho\cos\varphi,\;\;\boxed{dV=\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta}.$

其中 $\rho\ge 0,\;0\le\varphi\le\pi,\;0\le\theta\le 2\pi$。

⚠ 体积元最常忘记的因子
  • 极坐标 / 柱坐标：忘记乘 $r$。 2025 Q1(v) 答案明确说明"漏 $r$ 扣 1 分"。
  • 球坐标：忘记乘 $\rho^2\sin\varphi$。
6.3 变量代换与 Jacobian必考
公式

变换 $x=x(u,v),\,y=y(u,v)$，则 $$dx\,dy=\left|\frac{\partial(x,y)}{\partial(u,v)}\right|du\,dv,\quad\frac{\partial(x,y)}{\partial(u,v)}=\det\begin{pmatrix}x_u&x_v\\y_u&y_v\end{pmatrix}.$$ 取绝对值是关键。还有反向公式 $\frac{\partial(x,y)}{\partial(u,v)}=\frac{1}{\partial(u,v)/\partial(x,y)}$（更便捷时使用）。

模板：变量代换四步
  1. 把每条边界 $\to (u,v)$ 表达。如 2023 Q9 中 $y=1$ 变成 $uv=1$。
  2. 画 $(u,v)$ 区域 $G$。
  3. 把被积函数 $\to (u,v)$ 形式。
  4. 乘 $|J|$。
6.4 换序积分必考
★ 何时必须换序

当被积函数对当前内层变量没有初等原函数时，必须换序。常见信号：

  • $e^{y^2},e^{y^3},\sin(y^2),\cos(y^2)$ 类函数（2025 Q7(b) $e^{y^3}$）。
  • $\frac{e^{-x}-e^{-2x}}{x}$ 等含 $\frac{1}{x}$ 差形式（2023 Q7(ii) Frullani）。

参数双重积分技巧（Frullani 型）
$$\frac{e^{-ax}-e^{-bx}}{x}=\int_a^b e^{-tx}\,dt\;(0原积分变成 $\int_0^\infty\int_a^b e^{-tx}\,dt\,dx$，交换顺序后内积分简单。

Lec 17-25 · 向量场

七、向量场与三大定理

7.1 保守场判定必考
判据（curl = 0）

3D 向量场 $\mathbf F=(P,Q,R)$ 在单连通域上保守 $\Leftrightarrow$ $$P_y=Q_x,\quad P_z=R_x,\quad Q_z=R_y.$$ （等价于 $\nabla\times\mathbf F=\mathbf 0$。）

2D 向量场 $\mathbf F=(P,Q)$ 上保守 $\Leftrightarrow P_y=Q_x$。

⚠ 单连通的关键

分量测试通过 + 域非单连通 $\Rightarrow$ 不能下保守结论（2025 Q1(iii)，著名的 $\frac{(-y,x)}{x^2+y^2}$ 反例）。务必检查域是否单连通。

7.2 势函数构造必考
三步构造法
  1. $\phi_x=P$ 对 $x$ 积分：$\phi=\int P\,dx+C(y,z)$。
  2. 对上式求 $\phi_y$ 比较 $Q$：解出 $C(y,z)$ 中的 $y$ 部分，得 $C(y,z)=\cdots+D(z)$。
  3. 对完整 $\phi$ 求 $\phi_z$ 比较 $R$：解出 $D(z)$，通常 $D'=0$。
基本定理（路径无关）
$$\int_C\mathbf F\cdot d\mathbf r=\phi(B)-\phi(A),\quad C\text{ 是从 }A\text{ 到 }B\text{ 的任意分段光滑路径}.$$
7.3 Green 定理（2D）必考
两种形式

环量（旋度）形式： $$\oint_C P\,dx+Q\,dy=\iint_D(Q_x-P_y)\,dA.$$

通量（散度）形式： $$\oint_C\mathbf F\cdot\hat{\mathbf n}\,ds=\iint_D(P_x+Q_y)\,dA.$$

这里 $C$ 是 $D$ 的边界，正向为「使得 $D$ 在左侧」（即从外部看是逆时针）。

7.4 Stokes 定理（3D 曲面 ↔ 边界曲线）必考
公式
$$\iint_S(\nabla\times\mathbf F)\cdot d\mathbf S=\oint_{\partial S}\mathbf F\cdot d\mathbf r.$$

方向约定（右手定则）：手指沿 $\partial S$ 正方向，拇指指向 $S$ 法线方向。

★ 何时使用 Stokes
  • 当 $\mathbf F=\nabla\times\mathbf A$ 形式给出（2023 Q12，$\mathbf A$ 含 $e^{xyz},\cos(xz)$ 复杂项）—— 直接转线积分巨简化。
  • 当 $\nabla\times\mathbf F$ 计算困难时，逆向用 Stokes 把面积分变成线积分（2025 Q13）。
  • 在边界上某些项变为常数 / 0（如 $z=0$ 时 $z^2,\sqrt z=0$），可大幅简化。
7.5 散度（Gauss）定理必考
公式
$$\oiint_{\partial V}\mathbf F\cdot d\mathbf S=\iiint_V\nabla\cdot\mathbf F\,dV.$$

这里 $\partial V$ 是 $V$ 的封闭外表面，外向法向。

★ 何时使用散度定理
  • 闭曲面（球、立方体、抛物面 + 底盖等）的通量计算，首选散度定理。
  • $\nabla\cdot\mathbf F$ 形式简单（多项式、对称）时极高效。
  • 开曲面（如单独的抛物面）不能直接用，需补一个底盘构成闭曲面再减去底盘的通量。
7.6 经典恒等式（必背）
  • $\nabla\cdot(\nabla\times\mathbf F)=0$（旋度的散度恒为 $0$）— 这意味着 curl 场过任意闭曲面通量恒为 $0$。
  • $\nabla\times(\nabla f)=\mathbf 0$（梯度的旋度恒为 $0$）— 保守场旋度为 $0$。
  • $\nabla\cdot(\nabla f)=\Delta f=f_{xx}+f_{yy}+f_{zz}$（Laplacian，2023 Q1(vii)）。

九、十大题型解题模板

模板 1：二元极限
  1. 代入：分子有限非零、分母 $\to 0$ → DNE。分母 $\to$ 非零数 → 直接代入。
  2. $0/0$：极坐标判 $r\cdot$(有界) $\to 0$。
  3. 路径检验：$y=kx,y=kx^2,y=mx^n$ 不一致 → DNE。
  4. 夹逼：写出 $|表达式|\le g(r)\to 0$。
模板 2：二阶偏导数
  1. 分别算 $f_x,f_y$。
  2. $f_{xx}=(f_x)_x$；$f_{yy}=(f_y)_y$。
  3. $f_{xy}=(f_x)_y$，与 $f_{yx}=(f_y)_x$ 必须相等（连续时）。
  4. 分段函数衔接处用差商定义。
模板 3：切平面 + 法线
  1. 识别隐式 $F=c$ 还是显式 $z=f(x,y)$。
  2. 计算法向量：$\nabla F$ 或 $(f_x,f_y,-1)$。
  3. 切平面方程：法向量 $\cdot$ $(x-x_0,y-y_0,z-z_0)=0$。
  4. 法线参数：$P_0+t\cdot\mathbf n$。
模板 4：约束极值（Lagrange）
  1. 列方程组：$\nabla f=\lambda\nabla g$ + $g=c$。
  2. 用消去法（一式比另一式）化简。
  3. 讨论变量为 $0$ 的退化情形。
  4. 所有候选点代入 $f$，比较找最大/最小。
模板 5：无约束极值（Hessian）
  1. 解 $\nabla f=\mathbf 0$ 找所有临界点。
  2. 计算 $D=f_{xx}f_{yy}-f_{xy}^2$。
  3. $D>0,f_{xx}>0$：极小；$D>0,f_{xx}<0$：极大；$D<0$：鞍。
模板 6：二重积分换序
  1. 原顺序写出区域：$a\le x\le b,\,g(x)\le y\le h(x)$。
  2. 把每条边界曲线改写为 $x=$ 函数 of $y$。
  3. 新顺序：$y$ 范围用整体边界，$x$ 范围由 $y$ 决定。
模板 7：变量代换
  1. 计算 $|J|=\left|\frac{\partial(x,y)}{\partial(u,v)}\right|$。
  2. 映射边界：每条 $xy$ 边界 $\to (u,v)$ 表达式。
  3. 画 $(u,v)$ 区域 $G$。
  4. $\iint_D f(x,y)\,dA=\iint_G f(x(u,v),y(u,v))|J|\,du\,dv$。
模板 8：保守场三步走
  1. 检验 curl $=\mathbf 0$ + 域单连通。
  2. 三步构造势函数 $\phi$。
  3. $W=\phi(B)-\phi(A)$。
模板 9：Stokes / Green / Divergence 选择
  1. 2D 闭曲线 + 区域 → Green。
  2. 3D 闭曲面 + 包围体 → Divergence。
  3. 3D 开曲面 + 边界曲线 → Stokes（或补盖用 Divergence）。
  4. 选 $\nabla\cdot\mathbf F$ 或 $\nabla\times\mathbf F$ 中较简单的一个判断方向。
模板 10：Stokes 反向用法
  1. 当 $\nabla\times\mathbf F$ 难算时，反向用 Stokes 把面积分变成线积分。
  2. 在边界曲线上 $\mathbf F$ 通常会大幅简化（如 $z=0$ 时含 $z$ 的项消失）。
  3. 参数化边界：常用 $(R\cos t,R\sin t,0)$。
  4. 计算 $\oint\mathbf F\cdot d\mathbf r$。
