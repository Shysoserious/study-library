Lecture 13 — 多元函数、极限与连续

1. 多元函数基础（Functions of Several Variables）

从一元 f(x) 推广到多元 f(x,y) 或 f(x,y,z)。函数 f: D → ℝ，其中 D ⊆ ℝⁿ。

核心概念

概念定义ℝ² 中的直觉
interior point（内点）某个以 P 为中心的 open ball 完全在 D 内P 周围一小圈都在 D 里
boundary point（边界点）任何以 P 为中心的 open ball 都同时包含 D 内和 D 外的点P 恰好在 D 的边上
open（开集）D 中每个点都是内点不包含边界
closed（闭集）D 包含所有边界点包含边界
bounded（有界）D 可以放进某个有限半径的 ball 里不会无限延伸

图与等值线/等值面

图（Graph）：n 元函数的图在 ℝⁿ⁺¹ 中。例如 f(x,y) 的图是 ℝ³ 中的曲面 z = f(x,y)。

等值线（Level curve）：f(x,y) = K（固定常数）在 ℝ² 中画出的曲线。如 f = 100 − x² − y² 的等值线是同心圆。

等值面（Level surface）：f(x,y,z) = K 在 ℝ³ 中画出的曲面。如 f = √(x²+y²+z²) 的等值面是同心球。

💡 等高线地图的理解：f(x,y) 想象为山的海拔高度，等值线就是地图上的等高线。梯度方向 = 等高线的法方向 = 上山最快方向（后面 Lec 15 会讲）。

2. 极限（Limits）

ε-δ 定义：

lim(x,y)→(x₀,y₀) f(x,y) = L 意味着：

∀ε>0, ∃δ>0, 使得 ∀(x,y)∈D, 0 < √((x−x₀)²+(y−y₀)²) < δ ⟹ |f(x,y)−L| < ε

⚠️ 与一元的关键区别：一元中 x→x₀ 只有左右两个方向。多元中 (x,y)→(x₀,y₀) 有无穷多个方向和路径！极限存在要求沿所有路径趋近的结果都相同。

2.1 沿路径判断极限不存在（Limits Along Paths）

定理：如果沿两条不同路径趋近 (x₀,y₀) 得到不同的极限值，则极限 D.N.E.（does not exist）。

📝 Example (a): lim(x,y)→(0,0) xy/(x²+y²)

沿 y = kx：lim = k/(1+k²)。取 k=1 得 1/2，取 k=−1 得 −1/2。不同 → 极限 D.N.E.

📝 Example (b): lim(x,y)→(0,0) xy²/(x²+y⁴)

沿 y = kx：lim = 0（所有直线路径极限都是 0！）但这不能证明极限存在。

沿 x = ky²：lim = k/(k²+1)。取不同 k 得不同值 → 极限 D.N.E.

⚠️ 易错点：沿所有直线路径极限相同 ≠ 极限存在！可能沿抛物线或其他曲线路径得到不同值。Example (b) 就是经典反例。

2.2 证明极限存在——夹逼定理

Squeeze (Sandwich) Theorem：

若 g(x,y) ≤ f(x,y) ≤ h(x,y)，且 lim g = lim h = L，则 lim f = L。

📝 lim(x,y)→(0,0) 3x²y/(x²+y²)

因为 |y| ≤ √(x²+y²)，所以 |3x²y/(x²+y²)| ≤ 3|x²|·√(x²+y²)/(x²+y²) ≤ 3√(x²+y²) → 0。

（或直接用 x²/(x²+y²) ≤ 1，得 |3x²y/(x²+y²)| ≤ 3|y| → 0。）

极限 = 0
💡 极限题的策略：
• 先沿几条路径（y=0, x=0, y=x, y=x²）试探 → 不同就 D.N.E.
• 如果都一样，尝试用夹逼或极坐标（令 x=rcosθ, y=rsinθ, r→0）证明极限存在

3. 连续性（Continuity）

定义：f 在 x₀ 处连续 ⟺ limx→x₀ f(x) = f(x₀)

多项式函数、有理函数（分母≠0处）、三角函数等的合成都是连续的。

连续函数的复合：若 f 是多元连续函数，g 是单变量连续函数（且定义域匹配），则 g∘f 连续。

例：f(x,y) = cos(xy/(x²+1)) 在 ℝ² 上连续。

重要反例：f(x,y) = xy/(x²+y²)（(0,0)处定义为0）有两个偏导数在(0,0)处存在，但 f 在(0,0)处不连续（因为极限不存在）。
偏导数存在 ≠ 连续 ≠ 可微（后面 Lec 14 详细讨论）。

Lecture 14 — 偏导数与可微性

4. 偏导数（Partial Derivatives）

定义：

∂f∂x(x₀,y₀) := limh→0 f(x₀+h, y₀) − f(x₀, y₀)h

计算方法：把 y 当常数，对 x 求导。反之亦然。

记号：∂f/∂x = fx = Dxf = D₁f。

📝 f(x,y) = x² + 3xy + y − 1

fx(x,y) = 2x + 3y，fy(x,y) = 3x + 1

fx(4,−5) = 8−15 = −7，fy(4,−5) = 12+1 = 13

💡 几何含义：fx(x₀,y₀) 是曲面 z=f(x,y) 在点 (x₀,y₀) 处，沿 x 方向的切线斜率（固定 y=y₀ 的截面曲线上的斜率）。

5. 高阶偏导数 & 混合导数定理

fxx = (fx)x，fxy = (fx)y，fyx = (fy)x，fyy = (fy)y。

Mixed Derivative Theorem（混合导数定理/Clairaut 定理）

若 f 定义在包含 (a,b) 的开区域上，且 fxy 和 fyx 都在 (a,b) 处连续，则：

fxy(a,b) = fyx(a,b)

推广：所有该阶连续偏导可以任意交换求导顺序，如 fxxyz = fxyzx = fzxxy = ...

⚠️ 偏导数存在 ≠ 连续：f(x,y) = xy/(x²+y²)（(0,0)处为0）在(0,0)处有偏导数，但不连续。

6. 可微性（Differentiability）

6.1 一元回顾 → 二元推广

一元：f 在 x₀ 可微 ⟺ Δf = f'(x₀)·Δx + ε·Δx，其中 ε→0 当 Δx→0。

二元推广：f 在 (x₀,y₀) differentiable（可微）⟺ fx 和 fy 都存在，且：

Δz = fxΔx + fyΔy + ε₁Δx + ε₂Δy

其中 ε₁, ε₂ → 0 当 (Δx,Δy) → (0,0)。

💡 可微的本质：函数在该点有切平面，且切平面近似的误差是"高阶小量"。

6.2 判定可微性

充分条件定理：

若 fx 和 fy 在包含 (x₀,y₀) 的开区域上存在，且在 (x₀,y₀) 处连续，则 f 在 (x₀,y₀) 可微。

可微 → 连续：

若 f 在 (x₀,y₀) 可微，则 f 在 (x₀,y₀) 连续。

关系链（非常重要！）

偏导数连续 ⟹ 可微 ⟹ 连续
偏导数连续 ⟹ 可微 ⟹ 偏导数存在
反向均不成立！
📝 f(x,y) = xy 的可微性

fx = y，fy = x，都连续 → f 可微。验证：

f(x₀+Δx, y₀+Δy) − f(x₀,y₀) = y₀Δx + x₀Δy + ΔxΔy，其中 ε = Δx → 0 ✓

Lecture 15 — 链式法则、隐函数求导、方向导数与梯度

7. 链式法则（Chain Rule）

7.1 Special Case 1：z = f(x(t), y(t))

dzdt = ∂z∂x · dxdt + ∂z∂y · dydt

Branch diagram（树形图）：z 分叉到 x,y，再各自连到 t。沿每条路径乘，不同路径加。

📝 z = x²y + 3xy⁴，x = sin(2t)，y = cos t。求 dz/dt|t=0
答案：6

7.2 Special Case 2：z = f(x(s,t), y(s,t))

∂z/∂s = (∂z/∂x)(∂x/∂s) + (∂z/∂y)(∂y/∂s)
∂z/∂t = (∂z/∂x)(∂x/∂t) + (∂z/∂y)(∂y/∂t)

7.3 一般情况

General Chain Rule

u = f(x₁,...,xₙ)，每个 xᵢ = gᵢ(t₁,...,tₘ)，全部可微。则：

∂u∂tⱼ = ∂u∂x₁∂x₁∂tⱼ + ··· + ∂u∂xₙ∂xₙ∂tⱼ
💡 Branch diagram（树形图）记忆法：
• 从 u 出发，画分叉到每个中间变量 xᵢ，再从每个 xᵢ 分叉到底层变量 tⱼ
• 每条从 u 到 tⱼ 的路径：沿途偏导数相乘
• 所有路径的结果相加

8. 隐函数求导（Implicit Differentiation）

8.1 两变量：F(x,y) = 0 定义 y = h(x)

隐函数定理（2D）：

若 F(x,y) 可微，F(x,y)=0 定义 y 为 x 的可微函数，且 Fy ≠ 0，则：

dydx = − FxFy
📝 x³ + y³ = 6xy，求在 (3,3) 处的切线斜率

F(x,y) = x³+y³−6xy。Fx = 3x²−6y，Fy = 3y²−6x。

dy/dx|(3,3) = −Fx(3,3)/Fy(3,3) = −(27−18)/(27−18) = −1

8.2 三变量：F(x,y,z) = 0 定义 z = h(x,y)

∂z∂x = − FxFz     ∂z∂y = − FyFz    (Fz ≠ 0)

9. 方向导数与梯度（Directional Derivatives & Gradient）

9.1 方向导数定义

定义：

u = ⟨u₁, u₂⟩ 是单位向量，f 在 (x₀,y₀) 沿 u 方向的方向导数：

Duf(x₀,y₀) := limh→0 f(x₀+hu₁, y₀+hu₂) − f(x₀,y₀)h
💡 偏导数是方向导数的特例：fx = D⟨1,0⟩f（沿 x 轴方向），fy = D⟨0,1⟩f（沿 y 轴方向）。

9.2 计算公式

定理（f 可微时）：

Duf = ∇f · u = fxu₁ + fyu₂

其中 ∇f := ⟨fx, fy⟩ 叫做 gradient vector（梯度向量）。

📝 f(x,y) = xey + cos(xy)，在 (2,0) 处沿 v = ⟨3,−4⟩ 方向

先单位化：|v| = 5，u = ⟨3/5, −4/5⟩。

∇f = ⟨ey−ysin(xy), xey−xsin(xy)⟩。在(2,0)：∇f = ⟨1, 2⟩。

Duf = ⟨1,2⟩·⟨3/5,−4/5⟩ = 3/5 − 8/5 = −1

9.3 梯度的几何意义

Meaning 1：最快方向

• 最快增大方向 = ∇f 方向

• 最快减小方向 = −∇f 方向

• 最大增长率 = |∇f|

• ∇f ⊥ u → Duf = 0（不增不减）

Meaning 2：垂直于等值线/面

• ∇f 在任何点垂直于过该点的等值线

• 证明：等值线参数化 r(t)，f(r(t))=K → ∇f · r' = 0

• 等值线的切线方程：fx(x−x₀)+fy(y−y₀)=0

📝 温度 T = 80/(1+x²+2y²+3z²)，在 (1,1,−2) 处最快升温方向？

∇T(1,1,−2) = (−5/8)⟨−1,−2,6⟩ （计算省略）

最快方向 = ∇T/|∇T| 的方向。最大变化率 = |∇T| = (5/8)√41 °C/m

📝 椭圆 x²/8 + y²/2 = 1 在 (−2,1) 处的切线

f(x,y) = x²/8 + y²/2。∇f = ⟨x/4, y⟩。∇f(−2,1) = ⟨−1/2, 1⟩。

切线：−1/2·(x+2) + 1·(y−1) = 0 → y = x/2 + 2

梯度的代数性质

规则公式
Sum/Difference∇(f±g) = ∇f ± ∇g
Constant Multiple∇(kf) = k∇f
Product∇(fg) = f∇g + g∇f
Quotient∇(f/g) = (g∇f − f∇g)/g²

Lecture 16 — 切平面、线性近似与优化

10. 切平面与线性近似（Tangent Planes & Linear Approximation）

10.1 等值面的切平面

等值面 f(x,y,z) = K 在点 P₀(x₀,y₀,z₀) 的切平面：

fx(P₀)(x−x₀) + fy(P₀)(y−y₀) + fz(P₀)(z−z₀) = 0

法向量 = ∇f(P₀)。法线方向 = ∇f(P₀)。

10.2 函数图 z=f(x,y) 的切平面

在点 (x₀, y₀, f(x₀,y₀)) 的切平面：

z = f(x₀,y₀) + fx(x₀,y₀)(x−x₀) + fy(x₀,y₀)(y−y₀)

10.3 线性近似（Linearization）

L(x,y) = f(x₀,y₀) + fx(x₀,y₀)(x−x₀) + fy(x₀,y₀)(y−y₀)

L 叫做 f 在 (x₀,y₀) 处的 linearization（线性化），f(x,y) ≈ L(x,y) 叫做 standard linear approximation 或 tangent plane approximation。

11. 误差估计与全微分

11.1 误差上界

若所有二阶偏导连续且绝对值 ≤ M，则线性近似误差：

|E(x,y)| ≤ 12 M (|x−x₀| + |y−y₀|)²

三变量版：|E| ≤ ½M(|x−x₀|+|y−y₀|+|z−z₀|)²

📝 f(x,y,z) = x²y + 3sinz 在 (2,1,0) 附近，x∈[1.99,2.01] 等

计算所有二阶偏导绝对值的上界 M，代入公式。

11.2 全微分（Total Differential）

dz = fx(x₀,y₀) dx + fy(x₀,y₀) dy

dz 是线性近似的增量（切平面上的变化），不是 Δz（真实变化）。dz 是 x₀,y₀,dx,dy 的函数。

📝 圆柱体 V = πr²h，r 和 h 各有小变化 dr, dh

dV = 2πrh·dr + πr²·dh

这就是体积的近似变化量。

12. 优化：极值与鞍点（Optimization）

12.1 Local Extrema（局部极值）

First Derivative Test（一阶导数判别）：

若 f 在内点 (a,b) 取局部极值，且 fx(a,b) 和 fy(a,b) 都存在，则：

fx(a,b) = 0 且 fy(a,b) = 0   （即 ∇f = 0）

Critical point（临界点）：内点 (a,b) 满足 ∇f(a,b) = 0，或至少一个偏导数不存在。

Saddle point（鞍点）：临界点，但在任何邻域内 f 既有大于 f(a,b) 的值也有小于的值。

注意：临界点不一定是极值点！反例：f(x,y)=y²−x²，(0,0)是临界点但是鞍点。

12.2 Second Derivative Test（详见 Lec 18 的详细证明）

H>0, fxx>0
→ local min
H>0, fxx<0
→ local max
H<0
→ saddle
H=0
→ inconclusive

其中 H = fxxfyy − (fxy)²。

📝 f(x,y) = x⁴ + y⁴ − 4xy + 1 的局部极值

fx = 4x³−4y = 0，fy = 4y³−4x = 0 → 临界点 (1,1) 和 (−1,−1)。

两点都给出 H>0, fxx>0 → 两个 local minimum

12.3 Global/Absolute Extrema（全局极值）

Extreme Value Theorem：

连续函数 f 在闭且有界（closed and bounded）域 D 上一定取到全局最大值和最小值。

⚠️ 条件缺一不可：
• 不闭（如开圆盘 x²+y²<1）→ 可能没有最值（如 f(x,y)=x 在开圆盘上无最大值）
• 不有界 → 同理

求闭有界域上全局极值的步骤

1
在 D 内部找所有 critical points，计算 f 值
2
在 D 的边界上找极值（把边界参数化为一元函数问题）
3
比较所有候选点的 f 值：最大的是 global max，最小的是 global min
📝 f(x,y) = 2+2x+4y−x²−y² 在三角形 (x=0, y=0, y=9−x) 上

内部：fx=2−2x=0, fy=4−2y=0 → (1,2)。f(1,2) = 7

边界 ℓ₁（x=0, 0≤y≤9）：候选 (0,0), (0,2), (0,9)

边界 ℓ₂（y=0, 0≤x≤9）：候选 (0,0), (1,0), (9,0)

边界 ℓ₃（y=9−x）：p(x) = −43+16x−2x²，p'=0 → x=4, y=5。候选 (4,5), (0,9), (9,0)

比较全部：f(1,2)=7, f(0,0)=2, f(0,2)=6, f(0,9)=−43, f(1,0)=3, f(9,0)=−61, f(4,5)=−11

Global max = 7 at (1,2)，Global min = −61 at (9,0)

Lecture 17 — Lagrange 乘子法 & 线性近似误差证明

13. 带等式约束的优化（Optimization with Equality Constraints）

13.1 问题引入

Lec 16 讲了"求 f 在闭有界域 D 上的全局极值"——先找内部 critical points，再检查边界。但如果我们只关心边界上的极值（或者约束条件是某个曲线/曲面），内部 critical points 方法就不适用了。

问题形式：

Maximize / Minimize   f(x₁, ..., xₙ)

Subject to (s.t.)   g(x₁, ..., xₙ) = 0

含义：在满足约束 g = 0 的点集 C 上，找 f 的最大/最小值。

两个引入例题

例 1：连续函数 f(x,y) 在单位圆盘 x²+y² ≤ 1 上的最高海拔？

方法：内部找 critical points + 边界上找极值（边界 = x²+y² = 1）。

→ 边界上的问题就是：Max f(x,y), s.t. x²+y² = 1（这就是 constrained optimization）。

例 2：曲面 S: x²−z²−1 = 0 上距原点最近的点。

→ Min √(x²+y²+z²), s.t. x²−z²−1 = 0。等价于 Min x²+y²+z²（去掉根号不改极值点）。

试试 critical point 方法？f = x²+y²+z²，fx=2x, fy=2y, fz=2z → 唯一 critical point (0,0,0)，但 (0,0,0) 不在曲面上！

→ 需要新方法。

13.2 Lagrange Multiplier 的几何直觉

考虑 2D 情况：Max f(x,y), s.t. g(x,y) = 0。

约束 g(x,y) = 0 画出一条曲线 C。我们在曲线 C 上走动，观察 f 的变化。

核心定理（Thm 14.8.12, 2D 版本）

设 f(x,y) 在区域 D 上可微，C 是 D 内部的一条光滑曲线 r(t) = ⟨x(t), y(t)⟩。若 P₀ 是 C 上的一个内点且 f 在 P₀ 处（相对于 C 上的点）取得局部极值，则：

∇f(P₀) ⊥ r'(t₀)

（梯度垂直于曲线的切线方向）

这个定理对 f(x,y,z) 和 C: r(t) = ⟨x(t), y(t), z(t)⟩ 同样成立。

证明（简洁版）

1
令 g(t) := f(x(t), y(t))，即 f 沿曲线 C 的值。
2
因为 f 在 P₀ = (x(t₀), y(t₀)) 取局部极值 → g(t) 在 t₀ 取极值 → g'(t₀) = 0。
3
链式法则：g'(t₀) = fx(P₀)·x'(t₀) + fy(P₀)·y'(t₀) = ∇f(P₀) · r'(t₀)
4
所以 ∇f(P₀) · r'(t₀) = 0，即 ∇f ⊥ r'。□
💡 关键推论：约束曲线 C 由 g(x,y) = 0 定义。回忆 ∇g 垂直于 g 的等值线/面，所以 ∇g 也 ⊥ C。
既然 ∇f ⊥ C，∇g ⊥ C，要么 ∇g = 0，要么 ∇f = λ∇g（两者平行，λ ∈ ℝ）。这就是 Lagrange 乘子法的来源！

13.3 The Method of Lagrange Multipliers（拉格朗日乘子法）

方法步骤（单约束）：

问题：Max/Min f(x, y [, z])   s.t.   g(x, y [, z]) = 0

前提：f, g 可微，且在约束集上 ∇g ≠ 0。

1
联立方程组：∇f = λ∇g 且 g = 0（2D 是 3 个方程 3 个未知数 x, y, λ；3D 是 4 个方程 4 个未知数）。
2
解出所有满足条件的点 (x, y [, z])。
3
计算 f 在这些点上的值，最大的就是 constrained max，最小的就是 constrained min。
⚠️ 注意：
① λ 本身不需要报告，只是辅助工具。
② 该方法只给出候选点——如果存在性已知（如连续函数在有界闭集上），比较 f 值即可。
③ 如果约束集不有界/不闭，需要单独论证极值存在性。

13.4 例题详解

📝 例 1：椭圆上的极值

求 f(x,y) = xy 在椭圆 x²8 + y²2 = 1 上的最大值和最小值。

Step 1：令 g(x,y) = x²/8 + y²/2 − 1。

∇f = ⟨y, x⟩，∇g = ⟨x/4, y⟩。

方程 ∇f = λ∇g：

y = λ · x/4   ①

x = λ · y   ②

x²/8 + y²/2 = 1   ③

Step 2：由 ①②：y = λx/4，x = λy → x = λ(λx/4) = λ²x/4。

若 x ≠ 0 → λ² = 4 → λ = ±2。

λ = 2: y = 2x/4 = x/2。代入③：x²/8 + x²/8 = 1 → x² = 4 → x = ±2, y = ±1。

λ = −2: y = −x/2。同理 → x = ±2, y = ∓1。

若 x = 0：由② → λy = 0 → y = 0（但不满足③ → 无解）。

Step 3：计算 f 值：

f(2, 1) = 2,   f(−2, −1) = 2,   f(2, −1) = −2,   f(−2, 1) = −2

Max = 2 at (2,1), (−2,−1)；Min = −2 at (2,−1), (−2,1)

椭圆上 xy=2 的切点是 max，xy=−2 的切点是 min

📝 例 2：曲面 x²−z²−1=0 上距原点最近的点

Min f(x,y,z) = x²+y²+z²,   s.t. g(x,y,z) = x²−z²−1 = 0.

∇f = ⟨2x, 2y, 2z⟩，∇g = ⟨2x, 0, −2z⟩。

∇f = λ∇g：

2x = λ·2x   →   2x(1−λ) = 0   ①

2y = 0   →   y = 0   ②

2z = −2λz   →   2z(1+λ) = 0   ③

x²−z²−1 = 0   ④

由②：y = 0。

由①：x = 0 或 λ = 1。

若 x = 0 → ④ 变成 −z²−1 = 0 → z² = −1，无实数解。所以 λ = 1。

由③（λ=1）：2z(1+1) = 4z = 0 → z = 0。

由④：x²−0−1 = 0 → x = ±1。

候选点：(1, 0, 0) 和 (−1, 0, 0)。f(±1, 0, 0) = 1。

最近点 (±1, 0, 0)，最小距离 = 1

13.5 Two Equality Constraints（双约束）

有时要同时满足两个约束：

Max/Min f(x,y,z)

s.t. g₁(x,y,z) = 0 且 g₂(x,y,z) = 0

几何上：g₁=0 和 g₂=0 各定义一个曲面 S₁ 和 S₂，它们的交线 C = S₁ ∩ S₂ 就是约束集。

关键推理：

在极值点 P₀：∇f 必须 ⊥ 交线 C。而 ∇g₁ 和 ∇g₂ 也都 ⊥ C（分别垂直于各自的等值面）。

所以 ∇f 一定在 ∇g₁ 和 ∇g₂ 张成的平面内（假设二者不平行且非零），即：

∇f = λ₁ ∇g₁ + λ₂ ∇g₂

双约束方程组（3D，5 方程 5 未知数 x, y, z, λ₁, λ₂）：

∇f(x,y,z) = λ₁∇g₁(x,y,z) + λ₂∇g₂(x,y,z)

g₁(x,y,z) = 0,   g₂(x,y,z) = 0

📝 例 3：平面截圆柱上距原点最近/最远的点

平面 x+y+z = 1 与圆柱 x²+y² = 1 交成椭圆。求椭圆上距原点最近和最远的点。

Min/Max f = x²+y²+z², s.t. g₁ = x+y+z−1 = 0, g₂ = x²+y²−1 = 0.

∇f = ⟨2x, 2y, 2z⟩, ∇g₁ = ⟨1, 1, 1⟩, ∇g₂ = ⟨2x, 2y, 0⟩

方程组（写出 ∇f = λ₁∇g₁ + λ₂∇g₂ 的分量形式）：

2x = λ₁ + 2λ₂x  ①

2y = λ₁ + 2λ₂y  ②

2z = λ₁  ③

x+y+z = 1  ④

x²+y² = 1  ⑤

由③ λ₁ = 2z。由①−②：2(x−y) = 2λ₂(x−y)。

Case 1: x = y。由⑤ 2x² = 1 → x = y = ±√2/2。由④ z = 1−x−y。

x = y = √2/2 → z = 1−√2，f = 1+(1−√2)² = 4−2√2。

x = y = −√2/2 → z = 1+√2，f = 1+(1+√2)² = 4+2√2。

Case 2: x ≠ y → λ₂ = 1 → ①③ → 2x = 2z+2x → z=0。由④ x+y=1。加上⑤得 (x+y)²−2xy=1 → 1−2xy=1 → xy=0。

x=0, y=1 或 x=1, y=0。f(0,1,0) = 1，f(1,0,0) = 1。

Farthest: (√2/2, √2/2, 1−√2) 和 (−√2/2, −√2/2, 1+√2)
Closest: (0, 1, 0) 和 (1, 0, 0)

14. 线性近似误差的证明（Proof: Error of Linear Approximation）

定理：误差界

设 f 的所有二阶偏导在包含 (x₀, y₀) 的某区域 R 上连续，且 |fxx|, |fxy|, |fyy| ≤ M（M 在 R 上的上界）。

令 E(x,y) = f(x,y) − L(x,y)（L 是在 (x₀,y₀) 处的线性近似），则：

|E(x,y)| ≤ 12 M (|x−x₀| + |y−y₀|)²

证明思路（一维 Taylor 展开 → 二维）

令 h = Δx, k = Δy（小增量），定义一维函数：

F(t) := f(x₀ + th, y₀ + tk),   t ∈ [0, 1]

当 t 从 0 变到 1，F(t) 就"沿着直线"从 (x₀,y₀) 走到 (x₀+h, y₀+k)。

1
对 F(t) 用一维 Taylor：
F(1) = F(0) + F'(0) + ½F''(c)，其中 0 < c < 1。
2
算 F'(t)：链式法则：
F'(t) = fx·h + fy·k   (偏导在 (x₀+th, y₀+tk) 处)
3
算 F''(t)：再求导（偏导连续 → F' 可微）：
F''(t) = fxx·h² + 2fxy·hk + fyy·k²
4
代入 Taylor 展开：
F(1) = f(x₀,y₀) + [fx(x₀,y₀)·h + fy(x₀,y₀)·k] + ½[fxxh² + 2fxyhk + fyyk²]某中间点
前两项 = L(x₀+h, y₀+k)（线性近似），所以余下的 = E。
5
估计误差：三角不等式 + |fxx|, |fxy|, |fyy| ≤ M：
|E| = ½|fxxh² + 2fxyhk + fyyk²|
  ≤ ½(M·h² + 2M·|h||k| + M·k²)
  = ½M(|h| + |k|)²
💡 要点：把多元问题化成一元——令 F(t) = f(x₀+th, y₀+tk)，然后对 t 用 Taylor 定理。这个"化多元为一元"的技巧在各种证明中反复出现。

极值判定流程

1
求 fx=0, fy=0 找 critical points
2
对每个 critical point 算 H = fxxfyy−fxy²
3
H>0 且 fxx>0 → min；H>0 且 fxx<0 → max；H<0 → saddle；H=0 → 需其他方法
4
若求全局极值：还需检查边界，比较所有候选点
🎯 考试关键提醒（Lec 13-17）：

1. 极限：不同路径不同值 → D.N.E.；所有直线路径相同 ≠ 极限存在（还需检查曲线路径）

2. 可微性：偏导连续 → 可微（最常用判据）。可微 → 连续 → 极限存在

3. 链式法则：用 branch diagram 不会出错。注意沿每条路径乘、不同路径加

4. 隐函数求导：dy/dx = −Fx/Fy（别忘负号和分母条件 Fy≠0）

5. 方向导数：u 必须是单位向量！题目给的可能不是单位向量，要先归一化

6. 梯度：⊥ 等值线/面；方向 = 最快增长方向；|∇f| = 最大增长率

7. 全局极值：内部 critical points + 边界极值 → 比较全部候选点

9. Lagrange 乘子法：∇f = λ∇g 联立 g=0；λ 只是辅助未知数，不用报告

10. 双约束：∇f = λ₁∇g₁ + λ₂∇g₂；几何上 ∇f 在 ∇g₁, ∇g₂ 张成的平面内

11. 误差估计：|E| ≤ ½M(|Δx|+|Δy|)²，M 是二阶偏导的上界
