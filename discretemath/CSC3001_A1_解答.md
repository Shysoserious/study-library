## 1. Propositional Logic（命题逻辑）

### (a) p ⊕ q ≡ ¬(p ↔ q)

**思路**：异或 XOR「恰好一个为真」，双条件 ↔「真假一致」。两者天然互为否定——直接列真值表逐行比对即可。

**Answer (truth table):**

| p | q | p ⊕ q | p ↔ q | ¬(p ↔ q) |
|---|---|-------|-------|-----------|
| T | T | F | T | F |
| T | F | T | F | T |
| F | T | T | F | T |
| F | F | F | T | F |

The columns for `p ⊕ q` and `¬(p ↔ q)` are identical in every row, hence **p ⊕ q ≡ ¬(p ↔ q)**. ∎

### (b) (p ∧ q) ⊕ (p ∨ q) ≡ p ⊕ q

**思路**：把 ⊕ 按定义 `A ⊕ B ≡ (A ∧ ¬B) ∨ (¬A ∧ B)` 展开，第一个分支会自相矛盾归 F，第二个分支用 De Morgan 展开后恰是 p ⊕ q。

**Answer (logical equivalences):** Let A = p ∧ q, B = p ∨ q. Then

```
(p ∧ q) ⊕ (p ∨ q)
  ≡ [(p ∧ q) ∧ ¬(p ∨ q)] ∨ [¬(p ∧ q) ∧ (p ∨ q)]      (def. of ⊕)
  ≡ [(p ∧ q) ∧ (¬p ∧ ¬q)] ∨ [(¬p ∨ ¬q) ∧ (p ∨ q)]   (De Morgan)
  ≡ F ∨ [(¬p ∨ ¬q) ∧ (p ∨ q)]                        (p ∧ ¬p ≡ F)
  ≡ [(¬p ∨ ¬q) ∧ p] ∨ [(¬p ∨ ¬q) ∧ q]                (distributive law)
  ≡ [(¬p ∧ p) ∨ (¬q ∧ p)] ∨ [(¬p ∧ q) ∨ (¬q ∧ q)]
  ≡ [F ∨ (p ∧ ¬q)] ∨ [(¬p ∧ q) ∨ F]                  (¬p ∧ p ≡ F, ¬q ∧ q ≡ F)
  ≡ (p ∧ ¬q) ∨ (¬p ∧ q)
  ≡ p ⊕ q                                             (def. of ⊕)
```

Therefore **(p ∧ q) ⊕ (p ∨ q) ≡ p ⊕ q**. ∎

## 2. Set Theory（集合）

### (a) True / False（判断对错）

**思路**：分清 ∈（元素属于集合）与 ⊆（子集）。∅ 是任何集合的子集，但 ∅ 未必是某集合的「元素」。

**Answer:**

| Statement | T/F | Justification |
|---|---|:---:|---|
| i. ∅ ∈ {{∅}, {1}} | **False** | The elements of {{∅},{1}} are {∅} and {1}. ∅ is not equal to either {∅} or {1}. |
| ii. ∅ ⊆ {{∅}, {1}} | **True** | The empty set is a subset of every set. |
| iii. {1} ∈ {1, {{1}}} | **False** | The elements of {1, {{1}}} are 1 and {{1}}. {1} is neither. |
| iv. {{1}} ⊆ {1, {1}, {{1}}} | **True** | The only element of {{1}} is {1}, and {1} ∈ {1, {1}, {{1}}}. |

### (b) Prove or disprove（证明或反证）

**i. P(A ∪ B) = P(A) ∪ P(B)** — **思路**：幂集 P(A ∪ B) 含「跨 A、B」的子集（如 {1,2}），而 P(A) ∪ P(B) 放不下这种元素，一般不等——举反例。

**Answer: False.** Let A = {1} and B = {2}. Then A ∪ B = {1, 2}, so {1, 2} ∈ P(A ∪ B). But

```
P(A) ∪ P(B) = {∅, {1}} ∪ {∅, {2}} = {∅, {1}, {2}},
```

which does **not** contain {1, 2}. Hence P(A ∪ B) ≠ P(A) ∪ P(B). (C plays no role here.) ∎

**ii. A − (B − C) = (A − B) ∪ (A ∩ C)** — **思路**：元素论证（element argument）。把差集 `A − (B − C)` 翻译成「在 A 且不在 B−C」，即「在 A 且（不在 B 或在 C）」，分配后正好是右边两项之并。

**Answer: True.** For any x,

```
x ∈ A − (B − C)
  ⟺ x ∈ A ∧ x ∉ (B − C)
  ⟺ x ∈ A ∧ ¬(x ∈ B ∧ x ∉ C)
  ⟺ x ∈ A ∧ (x ∉ B ∨ x ∈ C)                       (De Morgan)
  ⟺ (x ∈ A ∧ x ∉ B) ∨ (x ∈ A ∧ x ∈ C)             (distributive law)
  ⟺ x ∈ (A − B) ∨ x ∈ (A ∩ C)
  ⟺ x ∈ (A − B) ∪ (A ∩ C).
```

Since the two sides have exactly the same members, **A − (B − C) = (A − B) ∪ (A ∩ C)**. ∎

## 3. First-Order Logic（一阶逻辑）

Domain = all students in the class. Predicates: R(x), S(x), M(x).

### (a) Translation（翻译）

**i. "There is a student who solved all the practice problems but did not get an A on the midterm exam."**

```
∃x (S(x) ∧ ¬M(x))
```

**ii. "Every student who both reviewed the lecture notes and solved all the practice problems got an A on the midterm exam."**

```
∀x ((R(x) ∧ S(x)) → M(x))
```

### (b) Negation（否定，把 ¬ 压到谓词前）

**思路**：¬∃→∀、¬∀→∃ 交换，`A → B ≡ ¬A ∨ B`，再 De Morgan 去掉外层否定。

```
¬[ ∃x ∀y ((R(x) ∨ ¬M(y)) → S(x)) ]
  ≡ ∀x ¬[ ∀y ((R(x) ∨ ¬M(y)) → S(x)) ]
  ≡ ∀x ∃y ¬[(R(x) ∨ ¬M(y)) → S(x)]
  ≡ ∀x ∃y ¬[¬(R(x) ∨ ¬M(y)) ∨ S(x)]        (A → B ≡ ¬A ∨ B)
  ≡ ∀x ∃y [(R(x) ∨ ¬M(y)) ∧ ¬S(x)]         (De Morgan, double negation)
```

Final: **∀x ∃y [(R(x) ∨ ¬M(y)) ∧ ¬S(x)]** — every negation now immediately precedes a predicate (¬M, ¬S).

### (c) Validity via rules of inference（推理规则）

Premises:

1. ∀x (R(x) → S(x))
2. ∃x (M(x) ∧ ¬S(x))

Conclusion: ∃x (M(x) ∧ ¬R(x))

**Answer:**

| Step | Statement | Rule |
|---|---|---|
| 1 | ∃x (M(x) ∧ ¬S(x)) | Premise |
| 2 | M(c) ∧ ¬S(c) | Existential instantiation (1), for some specific c |
| 3 | M(c) | Simplification (2) |
| 4 | ¬S(c) | Simplification (2) |
| 5 | ∀x (R(x) → S(x)) | Premise |
| 6 | R(c) → S(c) | Universal instantiation (5), x = c |
| 7 | ¬R(c) | Modus tollens (4, 6) |
| 8 | M(c) ∧ ¬R(c) | Conjunction (3, 7) |
| 9 | ∃x (M(x) ∧ ¬R(x)) | Existential generalization (8) |

Hence the argument is valid. ∎

## 4. Analysis of a Logical Predicate（逻辑谓词性质）

Domain = ℤ. P(x, y) ≡ ∃k ∈ ℤ (k ≥ 0 ∧ y = x + 2k). 即 y = x + 一个非负偶数.

**思路**：三条性质都靠「把 y−x 写成 2k」这个结构。自反取 k=0；反对称靠两方向相加后 2(k₁+k₂)=0 迫使 k₁=k₂=0；传递把两个 k 相加。

### (a) Reflexive（自反）

**Answer:** For any x ∈ ℤ, take k = 0. Then k ≥ 0 and x = x + 2·0 = x + 0, so P(x, x) holds. Therefore **∀x ∈ ℤ, P(x, x)**. ∎

### (b) Anti-symmetric（反对称）

**Answer:** Suppose P(x, y) and P(y, x). Then there exist k₁, k₂ ≥ 0 such that y = x + 2k₁ and x = y + 2k₂. Substituting the first into the second gives

```
x = (x + 2k₁) + 2k₂ = x + 2(k₁ + k₂),
```

so 2(k₁ + k₂) = 0, hence k₁ + k₂ = 0. Since k₁, k₂ ≥ 0, this forces k₁ = k₂ = 0. Therefore y = x + 0 = x, i.e. x = y. Hence **(P(x, y) ∧ P(y, x)) → (x = y)**. ∎

### (c) Transitive（传递）

**Answer:** Suppose P(x, y) and P(y, z). Then there exist k₁, k₂ ≥ 0 with y = x + 2k₁ and z = y + 2k₂. Then

```
z = (x + 2k₁) + 2k₂ = x + 2(k₁ + k₂).
```

Let k = k₁ + k₂. Since k₁, k₂ ≥ 0, we have k ≥ 0 and k ∈ ℤ, and z = x + 2k. Therefore P(x, z). Hence **(P(x, y) ∧ P(y, z)) → P(x, z)**. ∎

## 5. Mathematical Proofs（数学证明）

### (a) Contraposition（逆否证明）

**命题**：对任意整数 n，若 n² + 4n + 7 是偶数，则 n 是奇数。

**思路**：逆否命题 =「若 n 是偶数，则 n²+4n+7 是奇数」。设 n=2m，代入后把「偶数项」拢成 2·(整数) 再 +1，即奇数。

**Answer (contrapositive):** The contrapositive is: if n is even, then n² + 4n + 7 is odd. Suppose n is even, so n = 2m for some integer m. Then

```
n² + 4n + 7 = (2m)² + 4(2m) + 7 = 4m² + 8m + 7 = 2(2m² + 4m + 3) + 1.
```

Since 2m² + 4m + 3 is an integer, n² + 4n + 7 is odd. By contraposition, if n² + 4n + 7 is even then n is odd. ∎

### (b) Induction（归纳：4^{n+1} + 5^{2n−1} 被 21 整除）

**Answer:** Let P(n) be "21 | (4^{n+1} + 5^{2n−1})".

**Base case (n = 1):** 4² + 5¹ = 16 + 5 = 21, which is divisible by 21. ✓

**Inductive step:** Assume 4^{k+1} + 5^{2k−1} = 21t for some integer t. Then

```
4^{(k+1)+1} + 5^{2(k+1)−1}
  = 4^{k+2} + 5^{2k+1}
  = 4 · 4^{k+1} + 5² · 5^{2k−1}
  = 4 · 4^{k+1} + 25 · 5^{2k−1}
  = 4 · 4^{k+1} + (4 + 21) · 5^{2k−1}              (key: 25 = 4 + 21)
  = 4(4^{k+1} + 5^{2k−1}) + 21 · 5^{2k−1}
  = 4(21t) + 21 · 5^{2k−1}
  = 21(4t + 5^{2k−1}),
```

which is divisible by 21. So P(k) → P(k+1). By induction, **21 | (4^{n+1} + 5^{2n−1}) for every n ≥ 1**. ∎

### (c) Induction（归纳：∑ 1/k³ ≤ 3/2 − 1/(2n²)）

**Answer:** Let P(n) be "∑_{k=1}^{n} 1/k³ ≤ 3/2 − 1/(2n²)".

**Base case (n = 1):** LHS = 1, RHS = 3/2 − 1/2 = 1, so 1 ≤ 1 holds. ✓

**Inductive step:** Assume ∑_{k=1}^{n} 1/k³ ≤ 3/2 − 1/(2n²). Then

```
∑_{k=1}^{n+1} 1/k³ = ∑_{k=1}^{n} 1/k³ + 1/(n+1)³
                  ≤ 3/2 − 1/(2n²) + 1/(n+1)³.
```

It suffices to show 3/2 − 1/(2n²) + 1/(n+1)³ ≤ 3/2 − 1/(2(n+1)²), i.e.

```
1/(n+1)³ ≤ 1/(2n²) − 1/(2(n+1)²) = ((n+1)² − n²) / (2n²(n+1)²) = (2n+1) / (2n²(n+1)²).
```

Clearing the positive denominators, this is equivalent to

```
2n² ≤ (2n+1)(n+1) = 2n² + 3n + 1,
```

which holds because 3n + 1 ≥ 0 for all n ≥ 1. Hence ∑_{k=1}^{n+1} 1/k³ ≤ 3/2 − 1/(2(n+1)²). By induction the inequality holds for all n ≥ 1. ∎

### (d) Strong induction（强归纳：递推闭式 a_n = 3·2^{n−1} + 2·(−1)^n）

**Answer:** Let a₁ = 1, a₂ = 8, aₙ = aₙ₋₁ + 2aₙ₋₂ (n ≥ 3). Claim: aₙ = 3·2^{n−1} + 2·(−1)^n for all n ≥ 1.

**Base cases:**

- n = 1: 3·2⁰ + 2·(−1)¹ = 3 − 2 = 1 = a₁. ✓
- n = 2: 3·2¹ + 2·(−1)² = 6 + 2 = 8 = a₂. ✓

**Inductive step:** Assume the formula holds for all integers from 1 up to n (n ≥ 2). Then for n + 1 ≥ 3,

```
a_{n+1} = a_n + 2a_{n−1}
        = [3·2^{n−1} + 2·(−1)^n] + 2[3·2^{n−2} + 2·(−1)^{n−1}]     (induction hypothesis)
        = 3·2^{n−1} + 2·(−1)^n + 3·2^{n−1} + 4·(−1)^{n−1}
        = 3·2^n + 2·(−1)^n + 4·(−1)^{n−1}
        = 3·2^n + 2·(−1)^n − 4·(−1)^n                                 ((−1)^{n−1} = −(−1)^n)
        = 3·2^n − 2·(−1)^n
        = 3·2^n + 2·(−1)^{n+1},
```

which is exactly the claimed formula for n + 1. By strong induction, **aₙ = 3·2^{n−1} + 2·(−1)^n for all n ≥ 1**. ∎
