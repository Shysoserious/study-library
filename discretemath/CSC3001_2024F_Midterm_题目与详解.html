第 1 题 · 括号计数（卡特兰数）20 分

Let \(n\) be a positive integer. We want to compute how many valid ways to add \(n\) pairs of parentheses. E.g. there are 5 valid ways to add 3 pairs of parentheses, namely ((())), (()()), (())(), ()(()), ()()(). Let \(r_n\) denote the number of ways to add \(n\) pairs of parentheses, and denote \(r_0 = 1\).

(a) (10 points) Find a recursion of \(r_n\) using \(r_0, r_1, \dots, r_{n-1}\). Briefly justify your solution.

(b) (10 points) Find \(r_4\) and \(r_5\).

详解

思路：这是卡特兰数（Catalan number）的经典递推。核心想法是看第一个 “(” 与谁配对。任何一个合法的括号串，第一个字符一定是 “(”（合法串不可能以 “)” 开头），它必定在某个位置和后面的一个 “)” 配对，而这对括号恰好“包住”中间若干对、并在它右边留下其余若干对。于是可以按“第一对括号里面装了几对”来分类累加，得到自卷积形式的递推。

解答 Solution

We have \[ r_n = \sum_{i=1}^{n} r_{i-1}\, r_{n-i}, \qquad r_0 = 1. \] Justification. In any valid arrangement, the first symbol must be “(”. Let this opening parenthesis be matched by the parenthesis that closes the \(i\)-th pair (so together they form the \(i\)-th pair, \(1 \le i \le n\)). Then:

  • inside this pair there are exactly \(i-1\) pairs, contributing \(r_{i-1}\) ways;
  • to the right of this pair there are exactly \(n-i\) pairs, contributing \(r_{n-i}\) ways.

Summing over all possible \(i = 1, \dots, n\) gives the recursion.

Using \(r_0 = 1\) and the recursion:

\(r_1 = r_0 r_0 = 1\)

\(r_2 = r_0 r_1 + r_1 r_0 = 1 + 1 = 2\)

\(r_3 = r_0 r_2 + r_1 r_1 + r_2 r_0 = 2 + 1 + 2 = 5\)

\(r_4 = r_0 r_3 + r_1 r_2 + r_2 r_1 + r_3 r_0 = 5 + 2 + 2 + 5 = 14\)

\(r_5 = r_0 r_4 + r_1 r_3 + r_2 r_2 + r_3 r_1 + r_4 r_0 = 14 + 5 + 4 + 5 + 14 = 42\)

Hence \(\boxed{r_4 = 14}\) and \(\boxed{r_5 = 42}\).

补：这就是卡特兰数 \(r_n = \tfrac{1}{n+1}\binom{2n}{n}\)，序列 \(1,1,2,5,14,42,\dots\)。递推的“自卷积”结构是它的标志（LN5 阶梯问题 / 括号匹配都归到它）。

第 2 题 · 一阶逻辑翻译20 分

Let \(D\) be the domain of all people. Let predicate \(\text{nice}(x)\), \(x\in D\), denote that \(x\) is a nice person; predicate \(\text{busy}(x)\), \(x\in D\), denote that \(x\) is a busy person; and \(\text{friend}(x,y)\), \(x,y\in D\), denote that \(x,y\) are friends. Using \(D\), nice, busy and friend, represent the following statements in first-order logic.

• Every busy person has at least one friend;

• Nice people never have a busy person as a friend.

详解

思路：一阶逻辑翻译的套路：先写量词，再写蕴含（\(\to\)）连接“限定条件”与“结论”。第一条是“对所有 \(x\)：若 \(x\) 忙，则 \(x\) 至少有一个朋友（存在 \(y\) 与之是朋友）”。第二条注意“never … as a friend”＝“不存在这样的 \(y\)：\(y\) 忙且与 \(x\) 是朋友”，等价地可说“\(x\) 的所有朋友里没有忙人”。

解答 Solution

Every busy person has at least one friend: \[ \forall x\in D,\ \big(\text{busy}(x) \to \exists y\in D,\ \text{friend}(x,y)\big). \]

Nice people never have a busy person as a friend: \[ \forall x\in D,\ \Big(\text{nice}(x) \to \neg \exists y\in D,\ \big(\text{busy}(y) \land \text{friend}(x,y)\big)\Big). \] Equivalently (pushing the negation inside): \[ \forall x\in D,\ \forall y\in D,\ \big(\text{nice}(x) \land \text{busy}(y) \to \neg \text{friend}(x,y)\big). \]

术语对照：量词 quantifier（\(\forall\) universal / \(\exists\) existential）、蕴含 implication、否定 negation、合取 conjunction。

第 3 题 · 裂项求和（幂和公式）16 分

Let \(k,n\) be positive integers. Alice recently learned a “telescoping” trick to derive the sum of integer power formulas. Namely, by \[ k^4 - (k-1)^4 = k^4 - (k^4 - 4k^3 + 6k^2 - 4k + 1) = 4k^3 - 6k^2 + 4k - 1, \] Alice knows \[ \sum_{k=1}^{n} \big[k^4 - (k-1)^4\big] = 4\sum_{k=1}^{n} k^3 - 6\sum_{k=1}^{n} k^2 + 4\sum_{k=1}^{n} k - \sum_{k=1}^{n} 1. \]

(a) (8 points) Show that \(\displaystyle \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}\).

(b) (8 points) Find a polynomial formula for \(\displaystyle \sum_{k=1}^{n} k^3\).

详解

思路：(a) 直接数学归纳法证明平方和公式。(b) 用题目给的裂项（telescoping）恒等式：左边 \(\sum [k^4-(k-1)^4]\) 相邻项相消，只剩 \(n^4 - 0^4 = n^4\)；右边把已知的 \(\sum k^2\)（(a) 的结果）、\(\sum k = n(n+1)/2\)、\(\sum 1 = n\) 代入，解出 \(\sum k^3\)。这题不需要从零推三次方和，只需代已知量。

解答 Solution

We prove by induction on \(n\).

Base case \(n=1\): LHS \(= 1^2 = 1\), RHS \(= \tfrac{1\cdot 2\cdot 3}{6} = 1\). ✓

Inductive step. Assume the formula holds for \(n\); we prove it for \(n+1\): \[ \sum_{k=1}^{n+1} k^2 = \sum_{k=1}^{n} k^2 + (n+1)^2 = \frac{n(n+1)(2n+1)}{6} + (n+1)^2 = \frac{n+1}{6}\big[n(2n+1) + 6(n+1)\big]. \] Now \(n(2n+1) + 6(n+1) = 2n^2 + 7n + 6 = (n+2)(2n+3)\), so \[ \sum_{k=1}^{n+1} k^2 = \frac{(n+1)(n+2)(2n+3)}{6}, \] which is exactly the formula with \(n\) replaced by \(n+1\). By induction the formula holds for all \(n \in \mathbb{Z}^{+}\).

The left-hand side of the telescoping identity equals \[ \sum_{k=1}^{n}\big[k^4-(k-1)^4\big] = (1^4-0^4) + (2^4-1^4) + \cdots + (n^4-(n-1)^4) = n^4. \] Substituting the known sums \(\sum k^2 = \frac{n(n+1)(2n+1)}{6}\), \(\sum k = \frac{n(n+1)}{2}\), \(\sum 1 = n\): \[ n^4 = 4\sum_{k=1}^{n} k^3 - 6\cdot\frac{n(n+1)(2n+1)}{6} + 4\cdot\frac{n(n+1)}{2} - n = 4\sum_{k=1}^{n} k^3 - n(n+1)(2n+1) + 2n(n+1) - n. \] Hence \[ 4\sum_{k=1}^{n} k^3 = n^4 + n(n+1)(2n+1) - 2n(n+1) + n. \] Expanding \(n(n+1)(2n+1) = 2n^3+3n^2+n\) and \(-2n(n+1) = -2n^2-2n\): \[ 4\sum_{k=1}^{n} k^3 = n^4 + 2n^3 + n^2 = n^2(n^2 + 2n + 1) = n^2(n+1)^2. \] Therefore \[ \boxed{\ \sum_{k=1}^{n} k^3 = \frac{n^2(n+1)^2}{4} = \Big(\frac{n(n+1)}{2}\Big)^2\ }. \]

补：这个裂项技巧是“用更高一次的差分恒等式反推低次幂和”的通用方法（要推 \(\sum k^p\) 就展开 \(k^{p+1}-(k-1)^{p+1}\)）。

第 4 题 · 形如 4k+3 的素数无穷多16 分

Prove that there are infinitely many prime numbers of the form \(4k+3\) for some nonnegative integer \(k\).

详解

思路：这是欧几里得式反证法（Euclid-style contradiction）。假设只有有限个 \(4k+3\) 型素数 \(q_1,\dots,q_n\)，构造 \(Q = 4q_1 q_2 \cdots q_n - 1\)。关键三步：① \(Q\) 本身也是 \(4k+3\) 型；② 任何 \(q_j\) 都不能整除 \(Q\)（因为 \(Q\equiv -1 \pmod{q_j}\)）；③ \(Q\) 的素因子都是奇数（\(4k+1\) 型或 \(4k+3\) 型），若全为 \(4k+1\) 型，乘积也应是 \(4k+1\) 型，与 \(Q\) 是 \(4k+3\) 型矛盾。于是必存在一个不在列表里的 \(4k+3\) 型素因子，矛盾。

解答 Solution

Suppose, for contradiction, that the primes of the form \(4k+3\) are exactly \(q_1, q_2, \dots, q_n\). Define \[ Q = 4q_1 q_2 \cdots q_n - 1. \]

Step 1. \(Q \equiv -1 \equiv 3 \pmod 4\), so \(Q\) is of the form \(4k+3\). In particular \(Q\) is odd, so \(Q\) is not divisible by \(2\).

Step 2. For each \(j\), \(Q = q_j(4\prod_{i\neq j} q_i) - 1\), hence \(Q \equiv -1 \pmod{q_j}\). Thus \(q_j \nmid Q\) for every \(j\); none of the listed primes divides \(Q\).

Step 3. Every prime factor of \(Q\) is odd, hence is either of the form \(4k+1\) or of the form \(4k+3\). Note that the product of numbers of the form \(4k+1\) is again of the form \(4k+1\) (since \((4a+1)(4b+1) = 4(4ab+a+b) + 1\)). If all prime factors of \(Q\) were of the form \(4k+1\), then \(Q\) itself would be of the form \(4k+1\), contradicting Step 1. Therefore \(Q\) has at least one prime factor of the form \(4k+3\).

By Step 2, this prime factor is not among \(q_1,\dots,q_n\) — a contradiction to our assumption that these were all such primes. Hence there are infinitely many primes of the form \(4k+3\).

术语对照：反证法 proof by contradiction、合数 composite、素数 prime、整除 divisibility、同余 congruence。

第 5 题 · 欧几里得算法步数上界（Lamé）12 分

Let \(a,b,n\) be nonnegative integers and \(a \ge b\). Consider Euclid's greatest common divisor algorithm:

gcd(a, b)
    if b = 0 then
        Output a
    else
        Write a = qb + r, where q = ⌊a/b⌋, r = a − qb     (1)
        Output gcd(b, r)
    end if

Let \(f_1 = f_2 = 1\), \(f_k = f_{k-1} + f_{k-2}\), \(\forall k \ge 2\). Show that if \(b < f_n\), \(n \ge 1\), then \(\gcd(a,b)\) executes line (1) for at most \(n-1\) times.

详解

思路：用逆否命题 + 强归纳。要证“\(b < f_n \Rightarrow\) 至多执行 \(n-1\) 次”，等价于证其逆否：“若至少执行 \(n\) 次，则 \(b \ge f_n\)”。更具体地证一个更强的命题：欧几里得算法对 \((a,b)\) 至少执行 \(n\) 次除法的必要条件是 \(a \ge f_{n+1}\) 且 \(b \ge f_n\)。归纳步的直觉：第一次除法把问题降为 \((b,r)\)，而 \((b,r)\) 还要再执行 \(n-1\) 次，由归纳假设 \(b \ge f_n\) 且 \(r \ge f_{n-1}\)，于是 \(a = qb + r \ge b + r \ge f_n + f_{n-1} = f_{n+1}\)——正好是斐波那契递推。

解答 Solution

We prove the stronger claim, which implies the desired statement by contraposition:

Claim. For \(n \ge 1\), if Euclid's algorithm on \((a,b)\) (with \(a \ge b \ge 0\)) executes line (1) at least \(n\) times, then \(a \ge f_{n+1}\) and \(b \ge f_n\).

Base case \(n = 1\). Executing line (1) at least once means \(b \neq 0\), so \(b \ge 1 = f_1\), and \(a \ge b \ge 1 = f_2\). ✓

Inductive step. Assume the claim holds for \(n\), and suppose line (1) is executed at least \(n+1\) times. The first execution writes \(a = qb + r\) with \(0 \le r < b\) and \(q = \lfloor a/b\rfloor \ge 1\). The recursive call \(\gcd(b,r)\) then executes line (1) at least \(n\) times, so by the induction hypothesis, \[ b \ge f_{n+1}, \qquad r \ge f_n. \] Therefore \[ a = qb + r \ge b + r \ge f_{n+1} + f_n = f_{n+2}. \] So \(a \ge f_{n+2}\) and \(b \ge f_{n+1}\), completing the induction.

Now take the contrapositive of the \(b\)-bound: if \(b < f_n\), then the algorithm cannot execute line (1) at least \(n\) times, i.e. it executes line (1) at most \(n-1\) times. ∎

补：这就是 Lamé 定理（Gabriel Lamé, 1844）——欧几里得算法的最坏情形输入恰是一对相邻斐波那契数，它也是计算复杂度理论的起点之一。

第 6 题 · 向日葵引理16 分

Let \(k, r\) be positive integers.

(a) (8 points) Let \(F = \{\{1,2,3\},\{1,3,4\},\{1,3,5\},\{2,6,7\},\{5,8,9\},\{4,7,9\}\}\). Find a set \(W \subseteq F\) and a set \(S\), such that \(|W| \ge 3\), while every pair of distinct sets \(X,Y \in W\), \(X \neq Y\), satisfy \(X \cap Y = S\).

(b) (8 points) Let \(F\) be a collection of more than \(k!(r-1)^k\) distinct non-empty sets each of size at most \(k\). Prove that there is a collection \(W\) of at least \(r\) distinct sets in \(F\), such that there exists a set \(S\) where for every pair of distinct sets \(X,Y\) in \(W\), \(X \neq Y\), we have \(X \cap Y = S\).

详解

思路：先交代定义：一组集合叫向日葵（sunflower），若存在公共的核（core） \(S\)，使得任意两片的交都恰好是 \(S\)。(a) 直接观察：\(\{1,2,3\},\{1,3,4\},\{1,3,5\}\) 三片两两交都是 \(\{1,3\}\)，即核 \(S=\{1,3\}\)。(b) 是 Erdős–Rado 向日葵引理，标准证法是对 \(k\) 归纳：先取一个“两两不交”的极大子族 \(\mathcal A\)；若它片数 \(\ge r\) 就完工（空核）。否则它的并集 \(B\) 很小（\(\le k(r-1)\)），由鸽笼原理 \(B\) 中某个元素 \(x\) 落在至少 \(\frac{|F|}{|B|} > (k-1)!(r-1)^{k-1}\) 个集合里；把这些集合删去 \(x\) 得到元素数 \(\le k-1\) 的新族，用归纳假设找到向日葵，再把 \(x\) 加回去即可。

解答 Solution

Definition. A collection \(W=\{A_1,\dots,A_m\}\) is a sunflower if there is a set \(S\) (the core) such that \(A_i\cap A_j = S\) for all \(i\neq j\).

Take \[ W = \big\{\{1,2,3\},\ \{1,3,4\},\ \{1,3,5\}\big\}, \qquad S = \{1,3\}. \] Checking the pairwise intersections: \[ \{1,2,3\}\cap\{1,3,4\} = \{1,3\},\quad \{1,2,3\}\cap\{1,3,5\} = \{1,3\},\quad \{1,3,4\}\cap\{1,3,5\} = \{1,3\}. \] All equal \(S\), and \(|W|=3 \ge 3\). ✓

We prove by induction on \(k\).

Base case \(k=1\): \(F\) contains more than \(1!(r-1)^1 = r-1\) distinct non-empty sets, each of size at most 1, hence each is a singleton. So \(F\) contains at least \(r\) pairwise-disjoint 1-element sets; any \(r\) of them form a sunflower with core \(S = \varnothing\).

Inductive step. Assume the statement for \(k-1\) (and smaller). Let \(\mathcal A = \{A_1,\dots,A_t\}\) be a maximal family of pairwise disjoint members of \(F\) (maximal means no further set can be added while preserving pairwise disjointness).

  • If \(t \ge r\), then \(\mathcal A\) itself is a sunflower with \(t \ge r\) petals and core \(S=\varnothing\), and we are done.

So assume \(t \le r-1\). Let \(B = A_1 \cup \cdots \cup A_t\). Since each \(|A_i| \le k\), \[ |B| \le k t \le k(r-1). \] By maximality of \(\mathcal A\), every member of \(F\) intersects \(B\). By the pigeonhole principle, some element \(x \in B\) lies in at least \[ \frac{|F|}{|B|} > \frac{k!(r-1)^k}{k(r-1)} = (k-1)!(r-1)^{k-1} \] members of \(F\). Consider the family \[ F_x = \big\{ A \setminus \{x\} : A \in F,\ x \in A \big\}. \] Every set in \(F_x\) has size at most \(k-1\), and \(F_x\) contains more than \((k-1)!(r-1)^{k-1}\) distinct sets. By the induction hypothesis, \(F_x\) contains a sunflower \(W'\) with \(r\) petals and some core \(S'\). Adding \(x\) back to every set of \(W'\) yields \(r\) distinct sets of \(F\) whose pairwise intersections are all \(S' \cup \{x\}\). Hence \(F\) contains a sunflower with \(r\) petals, as required. ∎

补：这就是 Erdős–Rado（1960）向日葵引理，其界已被后续工作改进到 \(O(r\log(kr))^k\)（见 Tao 的博客）。术语：核 core、花瓣 petal、两两不交 pairwise disjoint、极大 maximal、鸽笼原理 pigeonhole principle。
