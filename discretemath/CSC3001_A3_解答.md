## 1. Linear Congruence & Chinese Remainder Theorem（一次同余 + 中国剩余定理，20 分）

### (a) Solve 18x ≡ 30 (mod 42)

**思路**：先算 gcd(18, 42) = 6。定理：`ax ≡ b (mod m)` 有解 ⟺ gcd(a, m) | b，且解数恰为 gcd(a, m) 个（互不同余 mod m）。这里 6 | 30，所以有 6 个解。先把方程**约去公因子**（连同模数一起除以 gcd），化成 3x ≡ 5 (mod 7)，此时 gcd(3,7)=1，再乘 3 的逆元（3·5 = 15 ≡ 1 mod 7，逆元是 5）。

**Answer:** Since gcd(18, 42) = 6 and 6 | 30, the congruence has exactly 6 incongruent solutions modulo 42. Dividing the congruence and the modulus by 6 gives

```
3x ≡ 5  (mod 7).
```

Since 3 · 5 = 15 ≡ 1 (mod 7), the inverse of 3 modulo 7 is 5. Multiplying by 5,

```
x ≡ 25 ≡ 4  (mod 7).
```

Therefore the six incongruent solutions modulo 42 are

```
x ≡ 4, 11, 18, 25, 32, 39  (mod 42).
```

∎

### (b) CRT：x ≡ 2 (mod 5), x ≡ 3 (mod 7), x ≡ 4 (mod 9)

**思路**：5、7、9 两两互素（pairwise coprime），CRT 保证唯一解 mod M = 5·7·9 = 315。公式：M₁ = M/5 = 63, M₂ = 45, M₃ = 35，各求 Mᵢ 关于对应模数的逆元 yᵢ，然后 x ≡ Σ(余数ᵢ · Mᵢ · yᵢ) (mod 315)。

**Answer:** The moduli 5, 7, 9 are pairwise coprime and M = 315. Let M₁ = 63, M₂ = 45, M₃ = 35.

```
y₁ = 63⁻¹ mod 5:  63 ≡ 3,  3·2 = 6 ≡ 1  →  y₁ = 2
y₂ = 45⁻¹ mod 7:  45 ≡ 3,  3·5 = 15 ≡ 1 →  y₂ = 5
y₃ = 35⁻¹ mod 9:  35 ≡ 8,  8·8 = 64 ≡ 1 →  y₃ = 8
```

Then

```
x = 2·63·2 + 3·45·5 + 4·35·8 = 252 + 675 + 1120 = 2047 ≡ 157  (mod 315).
```

So the smallest nonnegative solution is **x = 157**. It is unique modulo 315 because the moduli are pairwise coprime (the CRT guarantees a unique solution modulo their product M = 315). ∎

## 2. Fermat's Little Theorem: 42 | (n⁷ − n)（费马小定理，16 分）

**思路**：42 = 2·3·7，三个因子两两互素，所以只需分别证 2 |、3 |、7 | 再相乘。对 3 和 7 用费马小定理（若 p ∤ n 则 n^(p−1) ≡ 1 (mod p)）；对 2 用「奇偶相同」即可。

**Answer:** Since 2, 3, 7 are pairwise coprime, it suffices to prove n⁷ − n is divisible by each of 2, 3, 7.

*Divisible by 7.* If 7 | n, then n⁷ − n ≡ 0 (mod 7). If 7 ∤ n, Fermat's Little Theorem gives n⁶ ≡ 1 (mod 7), so n⁷ = n·n⁶ ≡ n (mod 7). Hence 7 | n⁷ − n in both cases.

*Divisible by 3.* If 3 | n, clearly n⁷ − n ≡ 0 (mod 3). If 3 ∤ n, Fermat's Little Theorem gives n² ≡ 1 (mod 3), hence n⁶ ≡ 1 and n⁷ ≡ n (mod 3). Hence 3 | n⁷ − n.

*Divisible by 2.* n⁷ and n have the same parity (odd⁷ = odd, even⁷ = even), so n⁷ − n is even, i.e. 2 | n⁷ − n.

Since 2, 3, 7 are pairwise coprime, their product 42 divides n⁷ − n. Therefore **42 | (n⁷ − n)** for every positive integer n. ∎

## 3. Simple graph with pairwise distinct degrees（度序列，12 分）

**思路**：设图有 n ≥ 2 个顶点，每个顶点的度 ∈ {0, 1, …, n−1}，共 n 个可能取值。若要 n 个度**两两不同**，则这 n 个度必须恰好取满 {0, 1, …, n−1}。但这不可能：度为 n−1 的顶点与所有其他顶点相邻（尤其与度为 0 的顶点相邻），而度为 0 的顶点与谁都不相邻——两者矛盾（pigeonhole / handshake 论证）。

**Answer:** No. Suppose G has n ≥ 2 vertices and all degrees are pairwise distinct. Each degree lies in {0, 1, …, n−1}, which has n values, so the n vertices must take exactly the degrees 0, 1, …, n−1. In particular some vertex v has degree n−1 (adjacent to every other vertex) and some vertex w has degree 0 (adjacent to nothing). But v being adjacent to all vertices forces v to be adjacent to w, contradicting deg(w) = 0. Hence no such simple graph exists. ∎

## 4. Number of perfect matchings in K₂ₙ（完全图完美匹配，16 分）

**思路**：固定顶点 1，它的配对对象有 2n−1 种选法；再固定剩下顶点里标号最小的一个，其配对对象有 2n−3 种选法；依此类推，直到最后两个顶点只有 1 种。乘积即 (2n−1)(2n−3)⋯3·1 = (2n−1)!!。

**Answer:** Fix one vertex; its partner can be chosen in 2n−1 ways. Fix the smallest remaining vertex; its partner can be chosen in 2n−3 ways. Continuing this way, the number of perfect matchings is

```
(2n−1)(2n−3)···(3)(1) = (2n−1)!! = (2n)! / (2ⁿ · n!).
```

∎

## 5. Bipartite graph & Hall's condition（二分图 + Hall 条件，18 分）

### (a) State Hall's condition

**思路**：Hall 定理（婚姻定理）——存在从 U 到 V 的完美匹配，当且仅当 U 的**每个**子集 S 的邻域大小 ≥ |S|。

**Answer:** A perfect matching saturating U exists if and only if for every subset S ⊆ U,

```
|N(S)| ≥ |S|,
```

where N(S) = ⋃_{u∈S} N(u) is the neighborhood of S. ∎

### (b) Verify + construct

**思路**：逐子集验证（重点是那些「紧」的子集，如 {u₂,u₃,u₄} 邻域恰为 {v₂,v₃,v₄}，大小 3 = 3）。再直接构造一个完美匹配：v₁ 只与 u₁ 相邻，必须配 u₁；剩下 u₂u₃u₄ 与 v₂v₃v₄ 可配 u₂–v₂、u₃–v₄、u₄–v₃。

**Answer:** We check Hall's condition for the nonempty subsets S ⊆ U. The only singleton with a neighbor constraint is u₁ (|N(u₁)| = 2 ≥ 1). For the two- and three-element subsets, the tightest cases are:

```
N({u₂,u₃}) = {v₂,v₃,v₄} (size 3 ≥ 2)
N({u₂,u₄}) = {v₂,v₃,v₄} (size 3 ≥ 2)
N({u₃,u₄}) = {v₂,v₃,v₄} (size 3 ≥ 2)
N({u₂,u₃,u₄}) = {v₂,v₃,v₄} (size 3 ≥ 3)
N(U) = {v₁,v₂,v₃,v₄} (size 4 ≥ 4)
```

and all remaining subsets have even larger neighborhoods. Hence |N(S)| ≥ |S| for every S ⊆ U, so Hall's condition holds and a perfect matching exists. One such matching is

```
{ u₁–v₁, u₂–v₂, u₃–v₄, u₄–v₃ }.
```

∎

## 6. Eulerian cycle / path of Kₘ,ₙ（完全二分图的欧拉回路/路径，18 分）

**思路**：先记两条定理（图连通前提下）：① 有欧拉**回路** ⟺ 所有顶点度数为偶；② 有欧拉**路径**（非回路）⟺ 恰有 0 或 2 个奇度顶点。Kₘ,ₙ（m,n ≥ 1）恒连通，U 侧 m 个顶点度数都是 n，V 侧 n 个顶点度数都是 m。奇度顶点数 = (n 奇 ? m : 0) + (m 奇 ? n : 0)，令它 ≤ 2 即可推出全部四种情形。

**Answer:**

*(a) Eulerian cycle.* Kₘ,ₙ is connected (m, n ≥ 1), so it has an Eulerian cycle iff every vertex has even degree. The m vertices in U all have degree n, and the n vertices in V all have degree m. Hence all degrees are even iff **m and n are both even**. ∎

*(b) Eulerian path.* A connected graph has an Eulerian path (possibly a cycle) iff the number of odd-degree vertices is 0 or 2. In Kₘ,ₙ the odd-degree vertices are: the m vertices of U (if n is odd) plus the n vertices of V (if m is odd). So the number of odd-degree vertices is

```
odd = (n odd ? m : 0) + (m odd ? n : 0).
```

This equals 0 iff m and n are both even (the Eulerian-cycle case). It equals 2 exactly in these cases:

- n odd, m even: odd = m = 2, i.e. (m, n) = (2, k) with k odd;
- n even, m odd: odd = n = 2, i.e. (m, n) = (k, 2) with k odd;
- m = n = 1: odd = 1 + 1 = 2, i.e. (m, n) = (1, 1).

(If m, n are both odd and not both 1, then odd = m + n ≥ 4 > 2, so no Eulerian path exists.) Hence Kₘ,ₙ has an Eulerian path iff

```
(m, n) = (both even)  OR  (2, k) with k odd  OR  (k, 2) with k odd  OR  (1, 1).
```

∎
