第 1 题 · 整数表示 Z = {3s+5t}16 分

Show that \(\mathbb{Z} = \{3s + 5t \mid s, t \in \mathbb{Z}\}\), where \(\mathbb{Z}\) denotes the set of integers.

详解

思路：证明两个集合相等，标准做法是双向包含（double inclusion）。方向一 \(\supseteq\)（右集合 ⊆ 整数集）平凡：整数对加法、乘法封闭，所以 \(3s+5t\) 一定是整数。方向二 \(\subseteq\)（任意整数都能写成 \(3s+5t\)）是难点，技巧是找一组具体的 \(s,t\) 把任意 \(n\) 表示出来。因为 \(3\) 和 \(5\) 互素（\(3\cdot 2 + 5\cdot(-1) = 1\)），把该式两边乘 \(n\) 即得 \(n = 3(2n) + 5(-n)\)。

解答 Solution

(⊇) Since addition and multiplication are closed on the integers, for any \(s,t\in\mathbb{Z}\) we have \(3s+5t \in \mathbb{Z}\). Hence \(\{3s+5t \mid s,t\in\mathbb{Z}\} \subseteq \mathbb{Z}\).

(⊆) For any \(n \in \mathbb{Z}\), take \(s = 2n\) and \(t = -n\). Then \[ 3s + 5t = 3(2n) + 5(-n) = 6n - 5n = n. \] Thus \(n = 3(2n) + 5(-n) \in \{3s+5t \mid s,t\in\mathbb{Z}\}\), so \(\mathbb{Z} \subseteq \{3s+5t \mid s,t\in\mathbb{Z}\}\).

By double inclusion, \(\mathbb{Z} = \{3s+5t \mid s,t\in\mathbb{Z}\}\).

补：本质是“两个互素整数 \(a,b\) 的所有整系数线性组合恰是全体整数”，即 \(\gcd(3,5)=1 \Rightarrow \{3s+5t\}=\mathbb{Z}\)。更一般地 \(\{as+bt\}=\gcd(a,b)\mathbb{Z}\)（LN6：gcd = 最小正线性组合 spc）。

第 2 题 · 集合包含与差集16 分

Let \(A, B, C\) be sets. Prove or disprove: If \(A \subseteq B\), \(a \in A\), \(a \notin (B - C)\), then \(a \in C\).

详解

思路：命题成立。用反证法（proof by contradiction）最顺：假设结论不成立即 \(a \notin C\)。由 \(a \in A \subseteq B\) 得 \(a \in B\)；于是 \(a \in B\) 且 \(a \notin C\)，按差集定义 \(a \in B - C\)，这与已知 \(a \notin (B-C)\) 矛盾。也可直接证：\(a \in B\) 且 \(a \notin (B-C)\)，而 \(B-C = B \cap \overline{C}\)，故 \(a \notin B-C\) 意味着“\(a \notin B\) 或 \(a \in C\)”，配合 \(a\in B\) 只能 \(a \in C\)。

解答 Solution

The statement is true. We prove it by contradiction.

Assume \(a \notin C\). Since \(A \subseteq B\) and \(a \in A\), we have \(a \in B\). Together with \(a \notin C\), the definition of set difference gives \(a \in B - C\). But this contradicts the hypothesis \(a \notin (B - C)\). Therefore the assumption was false, and \(a \in C\). ∎

Alternative (direct): \(a \in B\) and \(a \notin (B-C)\). Since \(B - C = B \setminus C\), \(a \notin B \setminus C\) means \(a \notin B\) or \(a \in C\). As \(a \in B\), it must be that \(a \in C\).

术语对照：差集 set difference \(B - C = \{x \mid x \in B,\ x \notin C\}\)、反证法 proof by contradiction。

第 3 题 · 递推关系建模20 分

Express the following as recurrence relations and initial conditions. It is not required to solve the recurrence.

(a) (10 points) Count the number of \(n\)-bit binary strings where every occurrence of \(1\) is immediately followed by at least two \(0\)s.

(b) (10 points) Count the number of \(n\)-bit binary strings with at most two \(1\)s.

详解

思路：这两小题都是“按结尾分情形（reason by cases）”搭递推。(a) 合法的串不可能以 \(1\) 或 \(10\) 结尾（因为 \(1\) 后面必须跟两个 \(0\)），所以只看结尾为 \(000\)（由合法 \(n-1\) 位串补一个 \(0\) 得到）与结尾为 \(100\)（由合法 \(n-3\) 位串补 \(100\) 得到）两种，得 \(a_n = a_{n-1} + a_{n-3}\)。(b) 按“末位加 0 还是加 1”分：加 0 直接接在任意合法 \(n-1\) 位串后（\(a_{n-1}\)）；加 1 则要求前 \(n-1\) 位里最多只有 1 个 \(1\)——0 个 1 的有 1 种、恰 1 个 1 的有 \(\binom{n-1}{1}=n-1\) 种，合计 \(n\) 种，得 \(a_n = a_{n-1} + n\)。

解答 Solution

Let \(a_n\) be the number of valid \(n\)-bit strings. A valid string cannot end in \(1\) (that \(1\) would have no following \(0\)s) and cannot end in \(10\) (the \(1\) would be followed by only one \(0\)). So the only possible endings are:

  • ending in \(000\): append \(0\) to any valid \((n-1)\)-bit string — contributes \(a_{n-1}\);
  • ending in \(100\): append \(100\) to any valid \((n-3)\)-bit string — contributes \(a_{n-3}\).

Hence \[ a_n = a_{n-1} + a_{n-3}, \qquad a_0 = a_1 = a_2 = 1. \] (Initial values: \(a_0=1\) for the empty string; \(a_1=1\), the string “0”; \(a_2=1\), the string “00”.)

Let \(b_n\) be the number of \(n\)-bit strings with at most two \(1\)s. Reason by the last bit:

  • append \(0\): to any valid \((n-1)\)-bit string — contributes \(b_{n-1}\);
  • append \(1\): the prefix must contain at most one \(1\). There is exactly \(1\) prefix with zero \(1\)s, and \(\binom{n-1}{1} = n-1\) prefixes with exactly one \(1\), for a total of \(1 + (n-1) = n\) such prefixes.

Hence \[ b_n = b_{n-1} + n, \qquad b_0 = 1. \]

术语对照：递推关系 recurrence relation、初始条件 initial condition、按情形讨论 reason by cases、二进制串 binary string。

第 4 题 · 因子分解（Shor 算法背景）16 分

Let \(N\) be an odd composite number that is not a prime power. Let \(a\) be an integer with \(2 \le a < N\), and \(r\) be the smallest positive integer satisfying the congruence \[ a^{r} \equiv 1 \pmod{N}. \] Assume that \(a\) and \(N\) are picked in a way that \(r\) is an even number.

(a) (8 points) Show that \(N \nmid a^{r/2} - 1\).

(b) (8 points) Show that if \(\gcd(N, a^{r/2}+1) \neq N\), then \(\gcd(N, a^{r/2}-1)\) is a nontrivial factor of \(N\) (a factor of \(N\) that is not \(1\) or \(N\) itself).

详解

思路：(a) 用 \(r\) 的最小性（minimality）：若 \(N \mid a^{r/2}-1\)，则 \(a^{r/2}\equiv 1 \pmod N\)，而 \(r/2\) 是比 \(r\) 更小的正整数，矛盾。(b) 分两步：先证 \(g=\gcd(N, a^{r/2}-1)\) 是 \(N\) 的因子且 \(g\neq N\)（由 (a)）；再证 \(g\neq 1\)——因为 \(a^r\equiv 1\pmod N\) 意味着 \(N \mid (a^{r/2}-1)(a^{r/2}+1)\)，若 \(g=1\)，则 \(N\) 与第一个因子互素，由欧几里得引理 \(N \mid a^{r/2}+1\)，即 \(\gcd(N, a^{r/2}+1)=N\)，与题设矛盾。故 \(g\) 既不是 1 也不是 \(N\)，是非平凡因子（nontrivial factor）。

解答 Solution

Suppose, for contradiction, that \(N \mid a^{r/2} - 1\). Then \(a^{r/2} \equiv 1 \pmod N\). Since \(r\) is even, \(r/2\) is a positive integer smaller than \(r\). This contradicts the minimality of \(r\) (the smallest positive integer with \(a^r \equiv 1 \pmod N\)). Hence \(N \nmid a^{r/2} - 1\).

Let \(g = \gcd(N, a^{r/2}-1)\). By definition \(g\) is a factor of \(N\). By part (a), \(N \nmid a^{r/2}-1\), so \(g \neq N\).

Since \(a^r \equiv 1 \pmod N\), we have \(N \mid a^r - 1 = (a^{r/2}-1)(a^{r/2}+1)\). Suppose \(g = 1\), i.e. \(\gcd(N, a^{r/2}-1) = 1\). Because \(N\) divides the product \((a^{r/2}-1)(a^{r/2}+1)\) and is coprime to the first factor, Euclid's lemma gives \(N \mid a^{r/2}+1\), so \(\gcd(N, a^{r/2}+1) = N\), contradicting the assumption \(\gcd(N, a^{r/2}+1) \neq N\). Therefore \(g \neq 1\).

Thus \(g = \gcd(N, a^{r/2}-1)\) is a factor of \(N\) with \(g \neq 1\) and \(g \neq N\), i.e. a nontrivial factor of \(N\). ∎

补：这就是 Shor 量子分解算法的数论核心——只要找到偶数阶 \(r\) 且 \(a^{r/2}\not\equiv -1\pmod N\)，两次 gcd 就能劈出 \(N\) 的非平凡因子。术语：阶 order、非平凡因子 nontrivial factor、欧几里得引理 Euclid's lemma。

第 5 题 · 斐波那契恒等式16 分

Let \(F_n\) denote the \(n\)-th Fibonacci number defined by \(F_0 = 0\), \(F_1 = 1\), and \(F_n = F_{n-1} + F_{n-2}\) for \(n \ge 2\).

(a) (8 points) Prove that for any positive integers \(m\) and \(n\), \(F_{m+n} = F_m F_{n+1} + F_n F_{m-1}\).

(b) (8 points) Prove that for integers \(m, n > 1\), \(\gcd(F_m, F_n) = F_{\gcd(m,n)}\).

详解

思路：(a) 用矩阵幂。令 \(A = \begin{pmatrix}1&1\\1&0\end{pmatrix}\)，归纳可证 \(A^k = \begin{pmatrix}F_{k+1}&F_k\\F_k&F_{k-1}\end{pmatrix}\)。于是 \(F_{m+n}\) 是 \(A^{m+n-1}\) 的左上角元素，而 \(A^{m+n-1} = A^n A^{m-1}\)，左上角 =（\(A^n\) 第一行）·（\(A^{m-1}\) 第一列）\(= F_{n+1}F_m + F_n F_{m-1}\)。(b) 核心是一个“减法引理”：\(m>n\) 时 \(\gcd(F_m,F_n)=\gcd(F_{m-n},F_n)\)。由 (a) 把 \(F_m = F_{m-n}F_{n+1} + F_{m-n-1}F_n\) 代入，且 \(\gcd(F_{n+1},F_n)=1\)（相邻斐波那契数互素），可把含 \(F_n\) 的那项“约掉”。反复用此引理，指数 \((m,n)\) 按欧几里得算法递减，直到落到 \(\gcd(F_{\gcd(m,n)}, F_0) = F_{\gcd(m,n)}\)。

解答 Solution

Let \(A = \begin{pmatrix}1&1\\1&0\end{pmatrix}\). We first prove by induction that \[ A^{k} = \begin{pmatrix} F_{k+1} & F_k \\ F_k & F_{k-1} \end{pmatrix} \quad \text{for all } k \ge 1. \] Base \(k=1\): \(A^1 = \begin{pmatrix}1&1\\1&0\end{pmatrix} = \begin{pmatrix}F_2&F_1\\F_1&F_0\end{pmatrix}\). ✓ Step: \(A^{k+1} = A \cdot A^k = \begin{pmatrix}1&1\\1&0\end{pmatrix}\begin{pmatrix}F_{k+1}&F_k\\F_k&F_{k-1}\end{pmatrix} = \begin{pmatrix}F_{k+1}+F_k & F_k+F_{k-1}\\ F_{k+1} & F_k\end{pmatrix} = \begin{pmatrix}F_{k+2}&F_{k+1}\\F_{k+1}&F_k\end{pmatrix}\). ✓

Now \(F_{m+n}\) is the \((1,1)\) entry of \(A^{m+n-1} = A^n A^{m-1}\). Therefore \[ F_{m+n} = \big[A^{m+n-1}\big]_{1,1} = \big[A^n A^{m-1}\big]_{1,1} = \big(F_{n+1},\ F_n\big)\cdot\big(F_m,\ F_{m-1}\big)^{\mathsf T} = F_m F_{n+1} + F_n F_{m-1}. \] ∎

We use the well-known fact \(\gcd(F_{n+1}, F_n) = 1\), which follows by induction: \[ \gcd(F_{n+1},F_n) = \gcd(F_n + F_{n-1}, F_n) = \gcd(F_{n-1}, F_n) = \cdots = \gcd(F_1, F_0) = \gcd(1,0) = 1. \]

For \(m > n\), using part (a) with indices \(m-n\) and \(n\): \[ F_m = F_{(m-n)+n} = F_{m-n}F_{n+1} + F_{m-n-1}F_n. \] Hence \[ \gcd(F_m, F_n) = \gcd\!\big(F_{m-n}F_{n+1} + F_{m-n-1}F_n,\ F_n\big) = \gcd(F_{m-n}F_{n+1},\ F_n). \] Since \(\gcd(F_{n+1}, F_n) = 1\), this equals \[ \gcd(F_{m-n}, F_n). \] This reduction replaces \((m,n)\) by \((m-n, n)\), exactly one step of Euclid's algorithm. Repeating it (and handling the symmetric case \(n > m\) by swapping) drives the index pair down to \((\gcd(m,n), 0)\). Finally \[ \gcd(F_m, F_n) = \gcd(F_{\gcd(m,n)},\ F_0) = \gcd(F_{\gcd(m,n)}, 0) = F_{\gcd(m,n)}. \] ∎

术语对照：矩阵幂 matrix power、归纳法 induction、互素 coprime、欧几里得算法 Euclid's algorithm。这个结论表明“斐波那契数的 gcd 与下标的 gcd 是同一套结构”。

第 6 题 · 二进制串翻牌游戏16 分

A \(2000\)-bit binary string has all its bits initially \(1\). In each step, Alice could pick a bit from the first \(1951\) bits that is a \(1\), and toggle that bit and the next \(49\) bits to its right (toggle means change \(1\) to \(0\) and \(0\) to \(1\)). A consecutive block of \(50\) bits will have their value changed as a consequence in each step. Alice will keep playing the game until such a bit cannot be found.

(a) (8 points) Write, from left to right, the bit string as a binary number, ignoring the leading zeros. Show that this binary number decreases in each step.

(b) (8 points) Show that regardless of Alice's strategy, the game terminates in an even number of steps.

详解

思路：(a) Alice 每次选的都是 \(1\)，且这个 \(1\) 是被翻转的 50 位里最靠左（最高位）的那一位（右边 49 位都在它右侧、权值更低）。最高被翻转位从 \(1\to 0\)，所以整串对应的二进制数严格减小。(b) 关键找一个每步恰好翻转一次的“不变量指标”：看位置 \(1, 51, 101, \dots, 1+50k\ (k=0,\dots,39)\) 这 40 个特定位。任意一步翻转的 50 个连续位置里，恰好包含其中一个这样的位（因为 50 个连续整数中恰有一个模 50 余 1）。所以这 40 位的“和”的奇偶性每步都改变。初始 40 位全是 1，和为 40（偶）；结束态前 1951 位全 0，这些位也是 0，和为 0（偶）。奇偶性从偶回到偶，必须经过偶数次翻转。

解答 Solution

In each step Alice toggles a block of \(50\) consecutive bits whose leftmost bit is a \(1\). Among all toggled bits, the most significant one is this leftmost bit, and it changes from \(1\) to \(0\). All changes to less significant bits cannot compensate for this decrease in the most significant position. Therefore the value of the binary number strictly decreases in each step.

Consider the positions \(1 + 50k\) for \(k = 0, 1, \dots, 39\), i.e. positions \(1, 51, 101, \dots, 1951\), and let \[ S = \text{sum of the bits at these positions}. \]

Every step toggles \(50\) consecutive bits, and among any \(50\) consecutive integers exactly one is congruent to \(1 \pmod{50}\). Hence each step toggles exactly one of the bits counted in \(S\), so the parity of \(S\) flips in every step.

Initially all \(40\) such bits are \(1\), so \(S = 40\) (even). Since the value decreases by at least \(1\) each step and starts finite (part (a)), the game must terminate; at termination all of the first \(1951\) bits are \(0\), in particular all \(40\) counted bits are \(0\), so \(S = 0\) (even).

As the parity of \(S\) flips each step and goes from even (\(40\)) back to even (\(0\)), the number of steps must be even. ∎

补：这是一个“用不变量（invariant）的奇偶性证明步数”的经典题型——不变量本身每一步都在变，但它的奇偶性是被锁定的（LN4 不变量法 invariant method）。
