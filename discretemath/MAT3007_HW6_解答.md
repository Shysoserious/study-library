## Problem 1（20 分）True or False

**中文思路总纲：** 这几题都在考 L14 的两个核心事实——（1）`A` 全幺模 + `b` 整数 ⟹ **每个** BFS（基本可行解）都是整数，而且这与目标 `c` 无关；（2）"LP 最优解是整数"和"**存在**一个整数最优解"是两件不同的事。分支定界那一侧（c、d）考的是关闭节点的条件和"到底谁才必须取整数"。

---

### (a) If `A` is TU and `b` is integral, then every LP relaxation with a bounded optimum has an integer optimal BFS — even if `c` is not integral.

**讲解：** 对。积分性定理（integrality theorem）说的是：`A` 全幺模（every square submatrix has det ∈ {0, ±1}）、`b` 整数时，**每一个** BFS 的各个分量都是整数。而 LP 基本定理（fundamental theorem of LP）保证：只要可行域非空且最优值有限（bounded），就**存在**一个最优 BFS。这两条一拼，就直接推出存在整数最优 BFS。关键点：BFS 由 `A`、`b` 决定，跟 `c` 一点关系都没有——`c` 只决定"哪个顶点是最优的"，不决定"顶点是不是整数"。所以 `c` 不是整数也照样成立。

**Answer: True.**

The integrality theorem says: if `A` is TU and `b` is integral, then **every** basic feasible solution is integral. The fundamental theorem of LP says that if the feasible region is nonempty and the optimal value is bounded, an optimal BFS exists. Combining the two, an optimal BFS exists and it is integral. The vector `c` plays no role in whether a BFS is integral — it only selects *which* vertex is optimal — so the statement holds even for non-integral `c`.

---

### (b) If `A` is TU and `b` is integral, then every optimal solution of the LP relaxation is integral.

**讲解：** 错。积分性定理保证的是**存在**整数最优解（某个最优 BFS 是整数），不是"**所有**"最优解都是整数。如果最优面（optimal face）上既有整数顶点又有分数点，那分数点也是最优解。反例要抓一个"最优面退化成一条边"的情形。

**Answer: False.** Counterexample:

```
max  x1 + x2
s.t. x1 + x2 ≤ 1,   x1, x2 ≥ 0.
```

In standard form (adding slack `s`): max `x1 + x2` s.t. `x1 + x2 + s = 1`, `x1, x2, s ≥ 0`. Here `A = [1 1 1]` is TU (its only square submatrices are 1×1 with determinant 1), and `b = [1]` is integral. The optimal value is 1, and the optimal face is `{x1 + x2 = 1, x1, x2 ≥ 0}`. This face contains the integer BFS `(1, 0, 0)`, but also the non-integral optimum `(1/2, 1/2, 0)`. Hence not every optimal solution is integral.

---

### (c) In branch-and-bound, if `⌊U_N⌋ ≤ L` then the node can be closed even if the LP optimum of the node is fractional (as long as we only need one optimal solution).

**讲解：** 对。`U_N` 是该节点子树的**上界**（子树里任何整数可行解的目标 ≤ `U_N`），而目标是整数，所以子树里最好的整数解目标 ≤ `⌊U_N⌋`。若 `⌊U_N⌋ ≤ L`（`L` 是当前 incumbent 的最优值），那么这棵子树里任何整数解都不可能比 incumbent 更好。既然目标只是找**一个**最优解（不是枚举所有最优解），这个节点就可以直接关闭（fathom by bound），不必再分支。即使节点的 LP 最优是分数也没关系——`⌊U_N⌋` 已经把上界压到整数了。

**Answer: True.**

Every integer-feasible point in the node's subtree has objective value at most `U_N`, hence at most `⌊U_N⌋` (since the objective is integral). If `⌊U_N⌋ ≤ L`, no solution in this subtree can beat the incumbent, so the node can be fathomed without branching — regardless of whether its LP optimum is fractional. (This is only valid when a single optimal solution suffices, as stated.)

---

### (d) In a mixed-integer linear program (MILP), if the LP relaxation of a node has a non-integer coordinate, then branching is required at that node.

**讲解：** 错。MILP 里**只有被声明为整数（integer）的变量**才必须取整数，连续（continuous）变量取分数是完全合法的。所以判断要不要分支，只看"整数变量"有没有分数——如果所有整数变量都已经是整数、只有连续变量是分数，这个解对 MILP 就是可行的，不需要分支。题干说的"any noninteger coordinate"把连续变量也算进去，太宽了。

**Answer: False.**

In a MILP, only the variables declared to be integer must take integral values; continuous variables may be fractional. So a node needs branching only when some *integer-constrained* variable is fractional in the LP optimum. A counterexample: `max x2 s.t. x1 + 2x2 ≤ 1, x1 ≥ 0, x2 ≥ 0`, with `x1` integer and `x2` continuous. The node's LP optimum is `(x1, x2) = (0, 1/2)` — `x1 = 0` is integral, and the only fractional coordinate `x2 = 1/2` is a continuous variable, so the solution is feasible for the MILP subproblem and no branching is required.

## Problem 2（20 分）Reading a branch-and-bound tree

**中文思路：** 先把树"读"清楚——确认父子关系、DFS（左优先）访问顺序，然后按分支定界的四条关闭规则（integrality / infeasibility / bound / incumbent 更新）逐节点判定。关键量：下界 `L` = 目前最好的整数解（incumbent）；上界 `U` = 所有**活跃**叶节点 LP 上界的最小值（再用"目标取整数"把分数上界收紧）。

**树结构（已从图中坐标确认）：**

```
                  A (128.6)
                 /        \
            B (126.75)    G (123.4)
            /     \        /     \
        C (116) D (125.8) H (119.6) I (122.4)
                /    \
           E (infeas) F (119)
```

DFS（left-first）访问顺序：`A → B → C → D → E → F → G → H → I`。

---

### (a) Largest lower bound `L`

**讲解：** 下界 = 当前最好的整数可行解。图里只有两个整数解：`C = 116` 和 `F = 119`。取最大，`L = 119`（incumbent 是节点 F）。

**Answer:** `L = 119` (the incumbent, node F).

---

### (b) Smallest certified upper bound `U`

**讲解：** 上界 = 所有仍**活跃**（还没关闭）的叶节点 LP 值的 min。活跃叶是 `H (119.6)` 和 `I (122.4)`。所以 `U = min(119.6, 122.4) = 119.6`。再利用"目标值是整数"这一点：`z* ≤ 119.6` 且 `z*` 为整数 ⟹ `z* ≤ ⌊119.6⌋ = 119`。所以**可证明的（certified）**上界是 `U = 119`。

（注意此时 `L = U = 119`，说明最优值 `z* = 119` 已经被这棵树确定了。）

**Answer:** `U = 119`. The active leaves are H and I with LP bounds 119.6 and 122.4, giving `min(119.6, 122.4) = 119.6`. Since `z*` is integral, `z* ≤ 119.6` implies `z* ≤ ⌊119.6⌋ = 119`, so the certified upper bound is `U = 119`.

---

### (c) Which leaves can be closed, which must remain active

**讲解：** 逐叶判定：

- **C = 116**（整数）：**可关闭**，fathomed by integrality。但 116 < 119，不更新 incumbent。
- **E**（不可行）：**可关闭**，fathomed by infeasibility。
- **F = 119**（整数）：**可关闭**，fathomed by integrality，并把 incumbent 更新为 119。
- **H = 119.6**（分数）：`⌊119.6⌋ = 119 ≤ L = 119`，**可关闭**，fathomed by bound。
- **I = 122.4**（分数）：`⌊122.4⌋ = 122 > L = 119`，既不整数、又没被 bound 压下去，**必须保持活跃**（需要继续分支）。

**Answer:**

| Node | Value | Status | Reason |
|------|-------|--------|--------|
| C | 116 (integral) | **close** | fathomed by integrality; 116 < 119 does not improve incumbent |
| E | infeasible | **close** | fathomed by infeasibility |
| F | 119 (integral) | **close** | fathomed by integrality; updates incumbent to `L = 119` |
| H | 119.6 | **close** | fathomed by bound: `⌊119.6⌋ = 119 ≤ L = 119` |
| I | 122.4 | **must remain active** | `⌊122.4⌋ = 122 > 119`, fractional and not bounded |

So C, E, F, H can be closed; **I must remain active** (branch next).

---

### (d) Branching constraints at node B

**讲解：** 节点 B 的 LP 解里 `x3 = 11/4` 是唯一分数分量（`x1 = 2, x2 = 3, x4 = 4, x5 = 6` 都是整数）。所以围绕 `x3` 分支：左孩子（C）加 `x3 ≤ ⌊11/4⌋ = 2`，右孩子（D）加 `x3 ≥ ⌈11/4⌉ = 3`。

**Answer:** The LP solution at B is `(x1, x2, x3, x4, x5) = (2, 3, 11/4, 4, 6)`, with the single fractional coordinate `x3 = 11/4`. Hence B branches on `x3`: the left child (C) adds the constraint **`x3 ≤ 2`**, and the right child (D) adds **`x3 ≥ 3`**.

## Problem 3（30 分）Branch-and-bound for an integer program

问题：`max 23x + 16y` s.t. `11x + 3y ≤ 77`, `3x + 4y ≤ 81`, `x, y ∈ Z≥0`。

**中文思路：** 这是标准的 2 变量整数规划分支定界。先解 LP 松弛（图解法或顶点枚举），得分数最优后，选一个分数变量分支（`≤ ⌊·⌋` 和 `≥ ⌈·⌉`），DFS 左优先展开，每到一个整数解就更新 incumbent，每到一个"上界 ≤ incumbent"或不可行的节点就关闭。

---

### (a) LP relaxation

**讲解：** 松弛掉 `x, y ∈ Z` 变成 `x, y ≥ 0` 的线性规划。可行域是凸多边形，顶点是 (0,0)、(7,0)、(0,81/4)、(13/7,132/7)。目标梯度 (23,16) 指向右上，逐顶点比较：

- (0,0): 0
- (7,0): 23·7 = 161
- (0,81/4): 16·(81/4) = 324
- (13/7, 132/7): 23·(13/7) + 16·(132/7) = 299/7 + 2112/7 = 2411/7 ≈ 344.43

最大值 2411/7 在交点 (13/7, 132/7) 取得。

**Answer (a):** Solving the LP relaxation `max 23x + 16y` s.t. `11x + 3y ≤ 77, 3x + 4y ≤ 81, x, y ≥ 0`, the optimal vertex is the intersection of the two constraints:

`11x + 3y = 77`, `3x + 4y = 81` ⟹ `x = 13/7`, `y = 132/7`, with value

`z^LP = 23·(13/7) + 16·(132/7) = 2411/7 ≈ 344.43`.

(Justification: the feasible polygon has vertices (0,0), (7,0), (0,81/4), (13/7,132/7) with objective values 0, 161, 324, 2411/7 respectively; the largest is 2411/7. Since the feasible region is bounded and the objective is linear, the maximum is attained at a vertex.)

---

### (b) Round to nearest integer

**讲解：** 把 (13/7, 132/7) ≈ (1.86, 18.86) 舍入到最近整数得 (2, 19)。**检查可行性**：`11·2 + 3·19 = 22 + 57 = 79 > 77`，违反第一条约束。所以 (2, 19) **不可行**——舍入通常不可行（这也正是需要分支定界的原因）。

**Answer (b):** Rounding `(13/7, 132/7) ≈ (1.86, 18.86)` to the nearest integer gives `(x, y) = (2, 19)`. This is **infeasible**: `11·2 + 3·19 = 79 > 77`, violating the first constraint.

---

### (c) Full DFS branch-and-bound tree

**讲解：** 分支变量选 `x`（先整 `x`）。每步记录节点 LP 解、值、关闭理由与 incumbent。

**Answer (c):** (branch on `x` first; DFS left-first)

```
Root (LP relax): (13/7, 132/7),  z = 2411/7 ≈ 344.43   — x = 13/7 fractional
   ├─ [x ≤ 1]  Node1: (1, 39/2),  z = 335               — y = 39/2 fractional
   │    ├─ [y ≤ 19]  Node3: (1, 19),  z = 327           — INTEGER → incumbent = 327, close (integrality)
   │    └─ [y ≥ 20]  Node4: (1/3, 20), z = 983/3 ≈ 327.67 — ⌊327.67⌋ = 327 ≤ L = 327, close (bound)
   └─ [x ≥ 2]  Node2: (2, 55/3),  z = 1018/3 ≈ 339.33   — y = 55/3 fractional
        ├─ [y ≤ 18]  Node5: (23/11, 18), z = 3697/11 ≈ 336.09 — x = 23/11 fractional
        │    ├─ [x ≤ 2]  Node6: (2, 18),  z = 334       — INTEGER → incumbent = 334, close (integrality)
        │    └─ [x ≥ 3]  Node7: (3, 44/3), z = 911/3 ≈ 303.67 — ⌊303.67⌋ = 303 < 334, close (bound)
        └─ [y ≥ 19]  Node8: infeasible                  — close (infeasibility)
```

**最优解：`(x*, y*) = (2, 18)`，最优值 `z* = 334`。**

（各节点数值核对：Node1 里 `x=1` 代入 `3x+4y≤81 ⟹ y≤39/2`；Node4 里 `y=20` 代入 `11x+3y≤77 ⟹ x≤17/11`，实际紧约束给 `x=1/3`；Node5 里 `y=18` 代入 `11x+3y≤77 ⟹ x≤23/11`；Node7 里 `x=3` 代入 `3x+4y≤81 ⟹ y≤18`，由 `11x+3y≤77 ⟹ y≤44/3`，取 `44/3`；Node8 里 `y≥19` 且 `x≥2` ⟹ `11x+3y≥22+57=79>77` 不可行。）

---

### (d) Integrality gap

**讲解：** integrality gap = LP 松弛最优值 − IP 最优值。

**Answer (d):** `z^LP − z^IP = 2411/7 − 334 = (2411 − 2338)/7 = 73/7 ≈ 10.43`.

## Problem 4（30 分）Binary IP via branch-and-bound

问题：

```
max  27x1 + 41x2 + 23x3 + 32x4
s.t. 18x1 + 15x2 + 16x3 + 21x4 ≤ 39      (budget)
     x3 + x4 ≤ 1
     x3 ≤ x1
     x4 ≤ x2
     x1, x2, x3, x4 ∈ {0, 1}
```

---

### (a) Interpret the three structural constraints

**讲解：** 这是"4 个 0-1 项目 + 预算"的选址模型。第一条是资金预算（39 千元），后三条是"逻辑/依赖"约束。

**Answer (a):**

- `x3 + x4 ≤ 1`: **at most one of the two printing stations** (upper and lower campus) can be opened — they are mutually exclusive (e.g., share one budget pool or one demand center).
- `x3 ≤ x1`: the lower-campus printing station **can be opened only if** the lower-campus study hub is opened — it depends on `x1`.
- `x4 ≤ x2`: the upper-campus printing station **can be opened only if** the upper-campus study hub is opened — it depends on `x2`.

(So `x1, x2` are the two study hubs; `x3, x4` are the two printing stations that each require their corresponding hub.)

---

### (b) Branch-and-bound solution

**中文思路：** 先解根节点 LP 松弛，得分数解后按分数变量分支（0/1 二进制，分支就是固定 `xi = 0` 或 `xi = 1`）。DFS 左优先（先固定 0）。每遇整数解更新 incumbent，每遇 bound 或 infeasible 关闭。

**根节点 LP 松弛：** `(x1, x2, x3, x4) = (1/6, 1, 0, 1)`，`z = 155/2 = 77.5`。

（核对：`18·(1/6) + 15·1 + 16·0 + 21·1 = 3 + 15 + 21 = 39` ✓（紧）；`x3 + x4 = 1` ✓（紧）；`x3 ≤ x1`: `0 ≤ 1/6` ✓；`x4 ≤ x2`: `1 ≤ 1` ✓（紧）。值 `27·(1/6) + 41 + 0 + 32 = 4.5 + 73 = 77.5` ✓。）

唯一分数分量是 `x1 = 1/6`，围绕 `x1` 分支。

**Answer (b):** (branch on the fractional variable, DFS left-first: fix `= 0` first)

```
Root (LP): (1/6, 1, 0, 1),            z = 155/2 = 77.5      — x1 = 1/6 fractional
   ├─ [x1 = 0]  Node A: (0, 1, 0, 1), z = 73                — INTEGER → incumbent = 73, close
   └─ [x1 = 1]  Node B: (1, 1, 0, 2/7), z = 540/7 ≈ 77.14   — x4 = 2/7 fractional
        ├─ [x4 = 0]  Node C: (1, 1, 3/8, 0), z = 613/8 = 76.625 — x3 = 3/8 fractional
        │    ├─ [x3 = 0]  Node C1: (1, 1, 0, 0), z = 68     — INTEGER (68 < 73), close, no update
        │    └─ [x3 = 1]  Node C2: (1, 1/3, 1, 0), z = 191/3 ≈ 63.67 — ⌊63.67⌋ = 63 < 73, close (bound)
        └─ [x4 = 1]  Node D: infeasible                     — close (infeasibility)
```

各节点数值核对：

- **Node A** (`x1 = 0`): `x3 ≤ x1 = 0 ⟹ x3 = 0`; 剩 `max 41x2 + 32x4` s.t. `15x2 + 21x4 ≤ 39`, `x4 ≤ x2`, `0 ≤ x2, x4 ≤ 1`。取 `x2 = 1, x4 = 1`，预算 `15 + 21 = 36 ≤ 39` ✓，值 `41 + 32 = 73`。
- **Node B** (`x1 = 1`): 剩 `max 41x2 + 23x3 + 32x4` s.t. `15x2 + 16x3 + 21x4 ≤ 21`, `x3 + x4 ≤ 1`, `x4 ≤ x2`。`x2` 性价比最高（41/15 ≈ 2.73），取 `x2 = 1`，余预算 6 全给 `x4`（性价比 32/21 ≈ 1.52 高于 `x3` 的 23/16 ≈ 1.44）：`x4 = 6/21 = 2/7`, `x3 = 0`。值 `27 + 41 + 32·(2/7) = 68 + 64/7 = 540/7 ≈ 77.14`。
- **Node C** (`x1 = 1, x4 = 0`): 剩 `max 41x2 + 23x3` s.t. `15x2 + 16x3 ≤ 21`, `0 ≤ x2, x3 ≤ 1`。`x2` 性价比高，`x2 = 1`，`x3 = 6/16 = 3/8`。值 `27 + 41 + 23·(3/8) = 68 + 69/8 = 613/8 = 76.625`。
- **Node C1** (`x3 = 0`): `x2 ≤ 21/15 = 1.4 ⟹ x2 = 1`，值 `27 + 41 = 68`（整数）。
- **Node C2** (`x3 = 1`): `15x2 ≤ 21 − 16 = 5 ⟹ x2 = 1/3`，值 `27 + 41·(1/3) + 23 = 50 + 41/3 = 191/3 ≈ 63.67`。
- **Node D** (`x1 = 1, x4 = 1`): `x4 ≤ x2 ⟹ x2 = 1`，则预算 `18 + 15 + 21 = 54 > 39`，不可行。

**最优解：`(x1, x2, x3, x4) = (0, 1, 0, 1)`，最优值 `z* = 73`。**

含义：开放上校区学习中心（`x2 = 1`）+ 上校区打印站（`x4 = 1`），总投资 `15 + 21 = 36`（千元）= **36,000 元**，收益 73。
