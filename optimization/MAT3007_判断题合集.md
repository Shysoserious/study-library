## 1. 样卷 Q1（5 道，每题 3 分）

> 说明：只判 True/False，不用解释。

**1(a)** In a linear programming (LP) problem, every basic solution is an extreme point.
**答案：False。**
讲解：基本解要「**可行**」才是顶点（BFS ⟺ 顶点）。A basic solution is an extreme point iff it is **feasible**。

**1(b)** If an LP problem has multiple distinct optimal solutions, then there are at least two distinct optimal solutions that are extreme points.
**答案：False。**
讲解：反例 `min x₁ s.t. x₁=1, x≥0` —— 无穷多最优解（所有 x=(1,x₂), x₂≥0），但只有一个顶点 (1,0)ᵀ。

**1(c)** A basic solution associated with basis B of the standard form LP min cᵀx s.t. Ax=b, x≥0 is optimal if A_B⁻¹b ≥ 0 and cᵀ − c_BᵀA_B⁻¹A ≥ 0.
**答案：True。**
讲解：就是**停机准则**：A_B⁻¹b≥0（可行）+ 判别数 c̄ = cᵀ−c_BᵀA_B⁻¹A ≥ 0（对偶可行）⟹ 最优。

**1(d)** In the two-phase simplex method, the original problem is infeasible if and only if the optimal objective value of the auxiliary problem of phase I is strictly positive.
**答案：True。**
讲解：Phase I 最优值 w*>0 ⟺ 人造变量赶不干净 ⟺ 原不可行；w*=0 ⟺ 原可行。

**1(e)** A point x* ∈ Rⁿ is optimal to the standard form LP min cᵀx s.t. Ax=b, x≥0 if there exists (y*, s*) such that Aᵀy* + s* = c, s* ≥ 0, and xᵢ*·sᵢ* = 0 for i=1,…,n.
**答案：False。**
讲解：缺**①原可行**。给定条件只有「对偶可行 + 互补松弛」，x* 可能不满足 Ax=b、x≥0。三条件缺一不可。

## 2. HW2 P1（3 道）

> 背景：标准形 LP，P={x: Ax=b, x≥0}，A∈R^{m×n} 行线性无关。

**2(a)** The set of all optimal solutions (assuming existence) must be bounded.
**答案：False。**
讲解：目标恒为常数（c=0）时，**整个可行域都是最优解**。若可行域无界，最优解集就无界。
反例：`min 0 s.t. x₁−x₂=0, x₁,x₂≥0`（m=1）。可行域是射线 { (t,t): t≥0 }，无界；目标恒 0，处处最优。

**2(b)** At every optimal solution, no more than m variables can be positive.
**答案：False。**
讲解：稀疏性定理说的是「**存在**一个最优解 ≤ m 个正分量」，不是「每个」。非顶点的最优解可以有更多正分量。
反例：`min −x₁−x₂ s.t. x₁+x₂+s=1, x≥0`（m=1）。最优点 (1/2,1/2,0) 有 2 个正分量 > m=1。

**2(c)** If there is more than one optimal solution, then there are uncountably many optimal solutions.
**答案：True。**
讲解：可行域是凸集、目标是线性函数。两个不同最优解 x¹、x² 连成的**整条线段** λx¹+(1−λ)x² 都最优；非退化线段上有**不可数**多个点。

## 3. HW3 P1（3 道）

> 背景：标准形 min cᵀx s.t. Ax=b, x≥0，A∈R^{m×n}（m<n）行线性无关，x̂ 是基 B={B(1),…,B(m)} 对应的 BFS。

**3(a)** A_B x̂_B = b, and A_B′ x̂_B′ ≠ b for every basis B′ ≠ B.
**答案：False。**
讲解：前半 `A_B x̂_B = b` 是对的（BFS 定义）。后半错在**退化**：当 x̂ 的正分量个数 < m 时，同一点可以是**多个不同基**的基本解，此时对某个 B′≠B 也有 A_B′ x̂_B′ = b。

**3(b)** Every optimal solution of the LP is a basic feasible solution.
**答案：False。**
讲解：最优**面**上非顶点的点也是最优，但不是 BFS。
反例：`min 0 s.t. x₁+x₂=1, x≥0`。整条线段都最优，中点 (1/2,1/2) 最优但非 BFS。

**3(c)** If the LP is unbounded and we apply the simplex method, starting from x̂, using the Bland's rule, the algorithm will ultimately find a basic direction d such that cᵀd < 0 and d ≥ 0 (after finite number of iterations).
**答案：True。**
讲解：Bland 规则保证**不循环 → 有限步终止**；LP 无界时不可能满足停机条件（c̄≥0，否则就有最优解，矛盾），所以只能以「检测到无界」终止——即某 c̄ⱼ<0 且 B⁻¹aⱼ≤0。对应方向 d（dⱼ=1，d_B=−B⁻¹aⱼ≥0，其余 0）满足 **cᵀd = c̄ⱼ < 0 且 d ≥ 0**。

## 4. HW4 P1（4 道）

> 背景：标准形 min cᵀx s.t. Ax=b, x≥0，对偶 max bᵀy s.t. Aᵀy≤c，A∈R^{m×n}（m<n）行线性无关。

**4(a)** If the primal LP has a unique optimal solution, then its dual has a unique optimal solution.
**答案：False。**
讲解：原最优解**退化**时，对偶可有多重最优。
反例：`min x₁ s.t. x₁+x₂=1, x₁=0, x≥0`。原唯一最优 x*=(0,1)（值 0）。对偶 `max y₁ s.t. y₁+y₂≤1, y₁≤0`：最优 y₁=0，**y₂≤1 任意** → 无穷多个对偶最优（值 0）。

**4(b)** Suppose y* is a dual basic feasible solution, i.e. Aᵀy* ≤ c and there exists a basis B such that (y*)ᵀ = c_BᵀA_B⁻¹. If A_B⁻¹b ≥ 0, then y* is optimal to the dual problem.
**答案：True。**
讲解：A_B⁻¹b≥0 = 原可行①；Aᵀy*≤c = 对偶可行②；基本解自动满足互补松弛③（基变量 c̄_B=0、非基 x_N=0）。**三条件齐满 ⟹ 最优**。

**4(c)** Let (x,y) be a pair of solutions feasible to the primal and the dual. Let v* denote the optimal objective value of the primal. Then yᵀAx ≤ v*.
**答案：True。**
讲解：yᵀAx = yᵀb = bᵀy（因 Ax=b）。弱对偶 bᵀy ≤ cᵀx 对**所有**可行 x 成立，取最小即 bᵀy ≤ min cᵀx = v*。

**4(d)** If the polyhedron P={x: Ax=b, x≥0} is nonempty and bounded, then the polyhedron Q={y: Aᵀy ≤ c} is nonempty and bounded.
**答案：False。**
讲解：Q 非空（P 有界 ⟹ 原最优存在 ⟹ 强对偶给对偶最优），但 Q 可能**无界**。
反例：`min x₁ s.t. x₁=1, x₁≥0`。P={1} 有界；对偶 Q={y: y≤1}=(−∞,1] 无界（向下无限延伸）。

## 5. 高频考点小结（这 15 题反复考的东西）

1. **基本解 vs 顶点**：基本解**可行**才是顶点（1(a)、3(b) 都在考这条线）。
2. **最优解的「存在性 vs 每个」**：稀疏性定理说「存在 ≤m 个正分量」，不是「每个」（2(b)）。
3. **多最优解**：两个最优解 ⟹ 整段线段最优 ⟹ 不可数多（2(c)）；但「至少两个顶点」不一定（1(b)）。
4. **最优证书 = 三条件**：①原可行 + ②对偶可行 + ③互补松弛。缺一不可（1(e) 缺①）。
5. **停机准则**：A_B⁻¹b≥0 且 c̄≥0 ⟺ 最优（1(c)、4(b)）。
6. **两阶段**：Phase I 最优值>0 ⟺ 原不可行（1(d)）。
7. **无界判定**：c̄ⱼ<0 且 B⁻¹aⱼ≤0，Bland 保证有限步找到方向（3(c)）。
8. **对偶唯一性**：原退化 ⟹ 对偶多重（4(a)）；弱对偶给 yᵀAx≤v*（4(c)）。
9. **P 有界 ≠ Q 有界**（4(d)）。
