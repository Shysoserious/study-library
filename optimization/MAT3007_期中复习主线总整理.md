> 本文是"从代数角度从头过一遍"这轮复习的完整记录：主线（Stop 1–8）＋ 期中前的动手技能与独立知识块。
> 教学目标：**每个代数式子都知道它的含义**，而不是背解题模板。
> 考试与作业全英文，关键术语顺带英文。

## 0. 这轮复习的一句话地图

整门课其实只有**一个对象**和**一个问题**：

```
对象：min cᵀx  s.t.  Ax = b,  x ≥ 0   （标准形 standard form，一个线性规划）
问题：我怎么知道手上的 x 是不是最优？不是的话，怎么改进？
```

把它们焊成一条线的，是**一条恒等式**（无条件成立，对任意 x、任意 y）：

```
gap = cᵀx − bᵀy = Σⱼ xⱼ · c̄ⱼ    其中 c̄ⱼ = cⱼ − Aⱼᵀy
```

这条式子的右端 Σⱼ xⱼc̄ⱼ 要想等于 0（最优），需要**三个条件**：

| 编号 | 条件 | 英文 | 作用 |
|---|---|---|---|
| ① | 原可行 | primal feasible (Ax=b, x≥0) | 保证每个 xⱼ ≥ 0 |
| ② | 对偶可行 | dual feasible (Aᵀy ≤ c，即 c̄ⱼ ≥ 0) | 保证每个 c̄ⱼ ≥ 0 |
| ③ | 互补松弛 | complementary slackness (xⱼc̄ⱼ = 0) | 保证每项都 = 0，总和 = 0 |

**①+② ⟹ 每项 xⱼc̄ⱼ ≥ 0 ⟹ gap ≥ 0（弱对偶 weak duality）。再加 ③ ⟹ gap = 0（强对偶 strong duality / 最优）。** 三条件全满足 = 最优解。

# 第一部分：主线（Stop 1–8）

## Stop 1 · 标准形与代数对象（列视角 / 基 / BFS）

### 标准形与两种变换

标准形要求 `min cᵀx s.t. Ax=b, x≥0`。任何线性规划都能化成标准形：

- **≤ 约束** → 加**松弛变量 slack variable**（+s，表示"剩下的资源"）。
- **≥ 约束** → 减**剩余变量 surplus variable**（−s）。
- **自由变量 free variable** x 可正可负 → 拆成 x = x⁺ − x⁻，x⁺, x⁻ ≥ 0。

### 列视角（读代数式最重要的习惯）

把 Ax = b 按列展开：

```
Ax = Σⱼ xⱼ aⱼ = b
```

**aⱼ（A 的列）= 变量 xⱼ 的"配方列/recipe"；xⱼ = 用量。**
把每列看成"积木"，xⱼ 是用几块这块积木，拼出右边的 b。

- **行 = 约束（资源 resource）**：一条 aᵀx ≤ b 里的 aᵀ 是 A 的**行**。
- **列 = 变量（配方 recipe）**：aⱼ 是 A 的**列**。

### 基、基本解、基本可行解

- **自由度 degrees of freedom = n − m**（n 个变量、m 个独立约束）。
- **基 basis B**：从 A 里挑 m 个线性无关的列，拼成 m×m **可逆**方阵。
- **基本解 basic solution**：非基变量全取 0（x_N=0），基变量 x_B = B⁻¹b。
- **基本可行解 BFS（basic feasible solution）**：基本解 + x_B ≥ 0。
- **退化 degenerate**：某个基变量取值 = 0。

**代数含义：** 一个基 = 一种"选 m 个变量当家、其余归零"的选法；BFS = 这种选法还恰好落在可行域里（非负）。

## Stop 2 · 顶点 ⟺ BFS（几何 = 代数）

### 定义

- **凸组合 convex combination**：x = Σλᵢxᵢ，Σλᵢ=1，λᵢ≥0。
- **顶点（极点）extreme point**：不能写成两个不同可行点的凸组合的点。直观上就是多面体的"角点"。

### 定理：x 是顶点 ⟺ x 是 BFS

**证明要点（扰动 argument）：** 若 x 的正分量对应的列 {aⱼ : xⱼ>0} **线性相关**，则存在非零 d（只在正分量位置取值），使 Σdⱼaⱼ=0。于是 x±εd 都还满足 Ax=b；ε 取足够小还保证非负 → x 是两个可行点的凸组合 → **不是顶点**。反之线性无关则无法上下扰动。

**结论：** "角点"（几何）和"BFS"（代数）是同一件事的两种说法。找最优解 = 在所有 BFS（顶点）里挑一个。

### LP 基本定理（Fundamental Theorem）

有最优解 ⟹ 存在一个**最优 BFS**（最优值一定能在顶点上取到）。
证明思路：取**支撑最小**的最优解 x*，若它有个非基变量非 0 且可沿方向 d 滑动，则 cᵀd=0（否则会更好，矛盾）→ 可滑到支撑更小，矛盾。

---

## Stop 3 · 判别数（缩减成本）的代数含义

对某个基 B，定义**判别数 reduced cost**：

```
c̄ⱼ = cⱼ − c_BᵀB⁻¹aⱼ
```

**含义（最重要的一句）：引入 1 单位非基变量 xⱼ，目标函数的净变化 = 直接收益 − 间接代价。**

- **cⱼ**：直接收益（直接加进目标）。
- **c_BᵀB⁻¹aⱼ**：间接代价（要腾地方，基变量要让位，让位造成的损失）。
- **B⁻¹aⱼ**：为了给 xⱼ 腾 1 单位，每个基变量要"动多少"。

**最优性条件（min 问题）：c̄ⱼ ≥ 0 对所有 j。** 因为非基变量只能从 0 往正方向提，若某个 c̄ⱼ < 0，把它提进去目标还会降 → 不是最优。

> 约定：**c̄_B = 0**（基变量的判别数恒为 0）。检查时注意 c̄_B 与 A_Bᵀy 的方向要对齐（列 − 列，或行 − 行）。

---

## Stop 4 · 单纯形法 = 换基

单纯形法（原单纯形 primal simplex）就是**在可行顶点之间跳，一路把判别数修到全 ≥0**。

每次迭代四步：

1. **读判别数**：有 c̄ⱼ < 0 就未最优。
2. **选进入 entering**：取某个 c̄ⱼ < 0（常用最负的）。
3. **比值检验 ratio test**：θ* = min (x_B)ᵢ / (B⁻¹aⱼ)ᵢ，**只对正的分量**取比值。
4. **选离开 leaving**：比值最小的那个基变量出基（先降到 0）。

**换基后 x_B 更新**：x_B ← x_B − θ*·B⁻¹aⱼ，目标变化 Δz = θ*·c̄ⱼ。

**无界 unbounded**：c̄ⱼ < 0 且 B⁻¹aⱼ ≤ 0（整列没有正项）→ 比值检验无上限 → 目标能无限降。

> 两个坑（考试高频）：比值检验选**最小**比值；**出基的是比值最小的那个基变量**（不是系数大的）。

## Stop 5 · 对偶变量 y 与间隙恒等式（整门课的脊椎骨）

### 定义对偶变量 y

```
yᵀ = c_BᵀB⁻¹
```

### 两条关键事实

1. **bᵀy = cᵀx 对任何基成立**（不只是最优基）：

```
bᵀy = yᵀb = c_BᵀB⁻¹b = c_Bᵀx_B = cᵀx   （因为 x_N = 0）
```

2. **判别数 c̄ = 对偶松弛（同一个向量）**：

```
c̄ = c − Aᵀy
```

### 间隙恒等式（无条件成立）

```
cᵀx − bᵀy = xᵀ(c − Aᵀy) = Σⱼ xⱼ c̄ⱼ
```

**注意：** 恒等式本身**无条件**成立；它 **≥0** 当且仅当 x 可行（x≥0）**且** y 对偶可行（c̄≥0）。关键在 y 的可行性（c̄≥0），x≥0 是背景。

### 基本 y vs 一般 y（曾混淆点）

- **基本 y（从公式 c_BᵀB⁻¹）**：有限个，每个基对应一个；可能是对偶不可行的（c̄ 有负）。
- **一般 y**：对偶可行区域里连续无限个；其中的顶点 = 那些"对偶可行"的基本 y。

**最优性只多要求一件事：对偶可行（c̄≥0）。** 因为 bᵀy=cᵀx 对任何基都已成立。

## Stop 6 · 弱对偶 / 强对偶 / 互补松弛

### 对偶问题（标准形 min 的原-对偶对）

```
原 (P)：min cᵀx  s.t. Ax=b, x≥0
对偶 (D)：max bᵀy  s.t. Aᵀy ≤ c,  y 自由
```

### 弱对偶 weak duality

任何原可行 x、任何对偶可行 y 都有 **cᵀx ≥ bᵀy**。

证明：cᵀx − bᵀy = xᵀ(c−Aᵀy) ≥ 0（x≥0 且 c−Aᵀy≥0）。

推论：原无界 ⟹ 对偶不可行；对偶无界 ⟹ 原不可行。

### 强对偶 strong duality

原问题有最优解 ⟹ 对偶也有，且 **p* = d***。
证明：取最优基 B，y = c_BᵀB⁻¹，则 c̄≥0（对偶可行）且 bᵀy=cᵀx* → y 是对偶最优。

### 互补松弛 complementary slackness

最优时：**xⱼ · c̄ⱼ = 0 对每个 j**（gap=Σxⱼc̄ⱼ=0 且每项非负，故每项=0）。

两侧版本：
- 变量侧：xⱼ · (Aᵀy − c)ⱼ = 0（正变量 ⟹ 对应对偶约束紧）
- 约束侧：yᵢ · (bᵢ − Aᵢx) = 0（正乘子 ⟹ 对应原约束紧）

**互补松弛是"双向"的**：可用它从原解构造对偶解、从对偶解恢复原解。

### 三条件 = 最优证书

①原可行 + ②对偶可行 + ③互补松弛 ⟺ 最优。单纯形法就是凑齐这三条。

### 状态组合表

原/对偶各自只有 有限最优 / 无界 / 不可行 三态；可行组合只有 4 种（两者都不可行可同时发生，其余受限）。

## Stop 7 · 影子价格与敏感性（对偶的"含义"）

### 影子价格 shadow price

yᵢ = 资源 bᵢ 的**边际价值**：多 1 单位资源，最优值改善多少。

```
yᵢ = ∂V/∂bᵢ   （V(b) = bᵀy* 对 b 求偏导）
```

**代数来源：** 由 V(b)=bᵀy*（强对偶目标值），对 bᵢ 求导即得 yᵢ。**仅在基不变时有效。**

### 互补松弛给出"松紧 → y"

- 资源**松**（有剩余，bᵢ−Aᵢx > 0）→ yᵢ = 0（再给也没用）。
- 资源**紧**（刚好用完，bᵢ−Aᵢx = 0）→ yᵢ > 0（再给就改善）。

### 生产例子（max）

max x₁+2x₂ s.t. x₁+x₂≤8（木料）, 2x₁+x₂≤6（劳力）→ x*=(0,6)，y*=(0,2)。
木料松 → y₁=0；劳力紧 → y₂=2。

### 符号约定（Nachuan Xiao 的 min 版，可纯逻辑推导，勿死记）

| 原约束 | 对偶变量符号 |
|---|---|
| min + ≥ | y ≥ 0 |
| min + ≤ | y ≤ 0 |
| min + = | y 自由 |

| 原变量 | 对偶约束 |
|---|---|
| x ≥ 0 | Aᵀy ≤ c |
| x ≤ 0 | Aᵀy ≥ c |
| x 自由 | Aᵀy = c |

> max 问题三步：①取负目标 ②套 min 表 ③令 u=−y 翻回来。max→对偶是 min，约束方向 ≥。

## Stop 8 · 内点法（interior point method）

### 三条件 → 三种算法（维护两个、追第三个）

**维护 maintain = 全程成立的不变量（算法结构自动锁死）；追 chase = 一开始不成立、一步步修到成立的目标。**

| 方法 | 维护（自动成立） | 追（一步步修） |
|---|---|---|
| 原单纯形 primal simplex | ①原可行 + ③互补（基本解间隙恒0） | ②对偶可行（把 c̄ 修到 ≥0） |
| 对偶单纯形 dual simplex | ②对偶可行 + ③互补 | ①原可行（把 x_B 修到 ≥0） |
| 内点法 interior point | ①原可行 + ②对偶可行（待在内部） | ③互补（把间隙 nμ 压到 0） |

### 内点法：扰动互补松弛

把互补松弛从 `xⱼc̄ⱼ = 0` 平移成 `xⱼc̄ⱼ = μ`（同一个小正数 μ）。然后**把 x、c̄、y 一起当作未知数解方程组**：

```
未知数：x(n) + y(m) + c̄(n) = 2n+m 个
方程：  Ax=b(m) + c̄=c−Aᵀy(n) + xⱼc̄ⱼ=μ(n) = 2n+m 个
```

正好一样多 → 每个 μ 对应唯一一个点 (x(μ), y(μ))，这条曲线叫**中心路径 central path**。

### 为什么"每对乘积都是 μ"（关键疑问的解答）

**xⱼc̄ⱼ=μ 是"约束"，不是"巧合"。** x 和 c̄ 不是先给定再碰运气去凑乘积，它们是和 y 一起被**解**出来的未知数。方程个数=未知数个数，解出来自然每对乘积都=μ。

### 间隙 = nμ

由间隙恒等式 + 扰动：

```
cᵀx − bᵀy = Σⱼ xⱼc̄ⱼ = Σⱼ μ = nμ
```

**gap = nμ 就是"间隙恒等式 + 互补松弛扰动成 μ"的直接结果。** μ→0 时 gap=nμ→0，回到真正互补松弛（=0），滑到顶点 x*。

### 内点法特点

多项式时间、解是**稠密**的（非顶点、非稀疏）；与单纯形法（顶点、稀疏）互补。

---

## 总复盘：一条线收束

> **线性规划 = 一个对象（min cᵀx s.t. Ax=b, x≥0）+ 一条恒等式（cᵀx−bᵀy = Σxⱼc̄ⱼ）+ 三个条件（原可行、对偶可行、互补松弛）。最优 = 三条件齐满 = gap 归零。单纯形、对偶单纯形、内点法，就是三种"维护两个、追一个"的路径。**

```
Stop 1-2  搭对象：标准形、BFS、顶点         → "我站在哪个候选点上？"
Stop 3    判别数 c̄ⱼ                        → 间隙恒等式里【每一项】的含义
Stop 4    单纯形 = 换基                     → 追②（把 c̄ 修到 ≥0）
Stop 5    定义 yᵀ=c_BᵀB⁻¹，推出间隙恒等式     → 【脊椎骨出现】
Stop 6    弱/强对偶 + 互补松弛               → 间隙恒等式的三种"读法"
Stop 7    影子价格 yᵢ=∂V/∂bᵢ               → 间隙恒等式对 b 求导
Stop 8    内点法：xⱼc̄ⱼ=μ                    → 右端=nμ，追③的另一条路
```

# 第二部分：动手技能（计算题）

## 1. 单纯形表格 simplex tableau

**表格不是新算法**，就是把换基（左乘 B⁻¹）写进格子的记账本。

### 结构（两块）

```
┌─────────────────────────┬──────┐
│  目标行：c̄ᵀ（判别数）    │ −z₀  │   ← 缩减成本 + 目标值取负
├─────────────────────────┼──────┤
│  约束行：Ā = B⁻¹A       │ b̄    │   ← B⁻¹A + B⁻¹b
└─────────────────────────┴──────┘
```

- **Ā = B⁻¹A**：把 Ax=b 左乘 B⁻¹ 后的系数；每列 = 该变量"让位"多少（就是 B⁻¹aⱼ）。
- **b̄ = B⁻¹b = x_B**：最右列 = 当前基变量取值。
- **−z₀ = −c_BᵀB⁻¹b**：右下角是**负**的目标值（读值要再取负！）。
- **基变量列 = 单位向量 eᵢ**：因为 B⁻¹B = I。

**单位向量 unit vector** = 只有一个 1 的向量（eᵢ，坐标轴方向）。单位阵基 B=I ⟹ x_B=b ⟹ 右边抄下来就是 BFS。

### 四步（每次迭代）

1. 读判别数（有负 → 未最优）
2. 选进入（最负 c̄ⱼ）
3. 比值检验选离开（正分量取最小比）
4. 主元 Gauss–Jordan 消元（把进基列消成单位向量）

### 完整例子

`min −x₁−2x₂ s.t. 2x₁+x₂+s₁=4, x₁+x₂+s₂=3`

**初始表格**（基 {s₁,s₂}）：

```
基  | x₁  x₂  s₁  s₂ | RHS
----|----------------|----
s₁  |  2   1   1   0 |  4
s₂  |  1   1   0   1 |  3
----|----------------|----
    | −1  −2   0   0 |  0
```

x₂ 进基（c̄₂=−2 最负），比值 4/1、3/1 → s₂ 出基，主元=1。消元后：

```
基  | x₁  x₂  s₁  s₂ | RHS
----|----------------|----
s₁  |  1   0   1  −1 |  1
x₂  |  1   1   0   1 |  3
----|----------------|----
    |  1   0   0   2 |  6      ← c̄ 全≥0 → 最优
```

### 读最终表格（三样 + B⁻¹）

```
① 原最优解：RHS 列读基变量 → x_B=(s₁,x₂)=(1,3) → x*=(0,3,1,0)
② 最优值：右下角取负 → z* = −6
③ 对偶最优解：slack 列取负 → y₁=−c̄_{s₁}=−0=0, y₂=−c̄_{s₂}=−2 → y*=(0,−2)
④ B⁻¹：slack 列的系数 = [[1,−1],[0,1]]
```

**为什么 slack 列取负读 y*：** c̄_{sᵢ} = c_{sᵢ} − yᵀa_{sᵢ} = 0 − yᵀeᵢ = −yᵢ，故 yᵢ = −c̄_{sᵢ}。

## 2. 两阶段法 / Big-M / 哑主元

### 为什么需要：找初始 BFS

原单纯形**维护①原可行**，所以要先有一个可行顶点。≤约束加松弛后自动有单位阵基（BFS 一眼可得）；**≥或=约束没有单位阵**，起步卡住。

**卡点代数本质：** ≥约束减剩余变量 −s，其列 = −eᵢ（不是单位向量），硬当基变量算 x=−1·b <0，不可行。

### 两阶段法 two-phase method

塞**人造变量 artificial variable** yᵢ（系数 +1），把 −1 顶成正的单位向量，造出单位阵基。

- **Phase I**：min Σyᵢ，把 y 压到 0。
  - **w\*=0 ⟺ 原问题可行**，并得到一个可行顶点；
  - **w\*>0 ⟺ 原问题不可行**。
- **Phase II**：扔掉 y，恢复原目标，从可行顶点出发优化。

### Big-M（同一件事的"一遍过"写法）

目标改成 `min cᵀx + M·Σyᵢ`（M 巨大正数）。y>0 被 M 狠狠惩罚，先赶干净 y，再优化原目标。数值难看，**考试推荐两阶段法**。

### 哑主元 dummy pivot（退化主元）

**触发场景：** Phase I 结束 w*=0 时，某个人造变量 yᵢ **还赖在基里、取值 0**（退化）。不能直接删（基会少一列、不可逆）。

**决策流程：**

```
w*=0 时挨个查 yᵢ 是否还在基里：
  都在基外 → 干净，直接删人造列，进 Phase II
  某个 yᵢ 还在基里(=0)：
    看 yᵢ 那行：
      ├─ 有非零真变量列 xⱼ → 哑主元：以(yᵢ行, xⱼ列)为主元消元，xⱼ进、yᵢ出
      └─ 真变量列全 0      → 冗余约束 redundant → 删掉这行 + yᵢ
```

**"哑"的含义：** 这次主元 θ* = 0/|非零系数| = 0，**点不动、基在动**（退化），对数值无任何贡献，唯一任务是"把假变量赶出基、腾坑给真变量"。

### 例子（触发哑主元）

`min x₁+x₂ s.t. x₁+2x₂=1, x₁=1`

Phase I 迭代一次后：

```
基  | x₁  x₂  y₁  y₂ | RHS
----|----------------|----
x₁  |  1   2   1   0 |  1
y₂  |  0  -2  -1   1 |  0     ← y₂ 还是基，RHS=0，触发！
----|----------------|----
w   |  0   2   2   0 |  0     ← w₀=0，Phase I 最优
```

哑主元：(y₂行, x₂列)=−2 为主元，消元后：

```
基  | x₁  x₂  y₁  y₂ | RHS
----|----------------|----
x₁  |  1   0   0   1 |  1
x₂  |  0   1   1/2 -1/2 |  0
----|----------------|----
w   |  0   0   1   1 |  0
```

y₁、y₂ 全出基 → 删人造列 → 基 {x₁,x₂}，x*=(1,0)，值 1（退化顶点，x₂ 是基但=0）。

## 3. 灵敏度分析 sensitivity analysis（四类变化）

**核心思想：** 问题微变，只需检查"哪个条件被破坏"，不用全部重算。

### 从 final tableau 读四样东西

最优表格里藏着：①最优基 B（左列）②原最优解 x_B（RHS 列）③最优值 z*（右下角取负）④对偶解 y*（slack 列取负）⑤B⁻¹（slack 列，因为 slack 初始是 I，消元后变 B⁻¹）。

### 四类变化总表

| 变化 | 威胁哪个条件 | 检查什么 | 读哪 |
|---|---|---|---|
| 改 b | ①原可行 | x_B' = B⁻¹b' ≥ 0？ | RHS 列 × 新 b |
| 改 c（非基） | ②对偶可行 | c̄ⱼ' = c̄ⱼ + Δcⱼ ≥ 0？ | 目标行 |
| 改 c（基） | ②对偶可行 | 整行判别数重算 | B⁻¹ 列 |
| 加变量 | ②对偶可行 | c̄ = c − yᵀa ≥ 0？ | y* × 新列 |
| 加约束 | ①原可行 | x* 代入新约束？ | 直接代 |

### 关键点

- **改 b**：b 只出现在 x_B=B⁻¹b 和 z₀=c_BᵀB⁻¹b，所以**只有 RHS 列和右下角两处变**，B⁻¹、判别数行、y* 都不动。
  - 若新 x_B' ≥ 0 → 基仍最优，新值 z' = z* + (y*)ᵀΔb。
  - 若某分量 <0 → ①破但②完好 → 用**对偶单纯形**（维护②③、追①）一步重启。
  - ⚠️ **右下角也要更新**（−z₀ 变了），很多人只改 RHS 列漏掉右下角。
- **改 c**：c 不影响 x_B，只影响判别数。非基变量 c̄ⱼ'=c̄ⱼ+Δcⱼ 看是否仍 ≥0；基变量要重算整行。
- **加变量**：算 c̄ = c − yᵀa，≥0 则不引入、原解仍最优，<0 则进基继续。
- **加约束**：x* 满足新约束 → 没影响；违反 → 重算。

# 第三部分：规则与独立大题

## 4. 退化 / 循环 / Bland 规则

- **退化 degenerate**：某个基变量 = 0。后果：比值检验可能 θ*=0（点不动、基在动）。
- **循环 cycling**：θ*=0 一直发生，同一批基绕圈，永不前进（退化 + 坏选法才触发）。
- **Bland 规则**（破循环保险丝）：
  - 进基：所有 c̄ⱼ<0 里选**下标最小**的 j；
  - 出基：比值平局时选**下标最小**的基变量。
  - 保证**有限步终止**；代价是通常更慢，只在兜底/保终止时用。
- **考点**：退化 ⟹ 基不唯一（同一顶点对应多个基）；Bland 保证不循环。

## 5. 建模 modeling（线性化技巧）

得分点在**线性化**，别踩非线性雷：

- **绝对值必须拆两条，不能写 |·|：**
  ```
  "任意两种食物份数差 ≤3"
  ❌ |xᵢ − xⱼ| ≤ 3           ← 非线性，扣分
  ✓  xᵢ − xⱼ ≤ 3 且 xⱼ − xᵢ ≤ 3
  ```
  （|xᵢ−xⱼ|≤3 ⟺ 差在 −3 到 3 之间 ⟺ 两条线性不等式。）
- **0-1 变量逻辑约束**：
  ```
  "选 A 就不能选 B"：  x_A + x_B ≤ 1
  "至少选一个"：       x_A + x_B ≥ 1
  "选了 A 才允许 B"：  x_B ≤ x_A
  ```
- **固定成本 big-M**：y∈{0,1}，`x ≤ M·y`（y=0 强制 x=0）。
- **营养配餐**：min 总成本 s.t. 每种营养 ≥ 下限（看清 ≥ 方向）。

## 6. 顶点覆盖 LP 近似

- **顶点覆盖 vertex cover**：选最少点，覆盖每条边的两端之一。
  ```
  IP：min Σx_v s.t. x_u+x_v≥1 (每条边), x_v∈{0,1}
  LP 松弛：把 x_v∈{0,1} 放宽成 0≤x_v≤1
  ```
- **界**：v_LP ≤ v_IP（min 问题，域越大值越小/相等）。
- **积分性间隙 integrality gap** = v_IP − v_LP。Petersen 图（HW2 P4）：LP=5（全 1/2）、IP=6，间隙=1。
- **关键定理：极点坐标 ∈ {0, 1/2, 1}。**
  证明（扰动）：反设某极点坐标不在 {0,1/2,1}，把非 {0,1/2,1} 的坐标同 ±ε，两端和 ≥1 且都不在边界 → 有双向可行方向 → 是两点凸组合 → 非极点，矛盾。
- **2-近似算法**：LP 最优 x* 中 ≥1/2 设 1、<1/2 设 0。
  - 可行：每边 x_u+x_v≥1 ⟹ 至少一个 ≥1/2 ⟹ 设 1 覆盖。
  - ≤2 倍：设 1 的点真实代价 1 ≤ 2·x_v*，求和 ≤ 2Σx_v* = 2v_LP ≤ 2v_IP。

## 7. 整数优化（L14，今年新增可能考）

- **LP 松弛 relaxation**：丢掉整数约束，得界。min：v_LP ≤ v_IP；max：v_LP ≥ v_IP（松弛是乐观估计）。
- **全幺模 TU（totally unimodular）**：A 每个方子阵行列式 ∈ {−1,0,1}。
- **定理**：A 全幺模 + b 整数 ⟹ 每个 BFS 都整数 ⟹ 松弛精确，无需分支定界。
- **代数依据（Cramer 法则）**：x_B 第 i 分量 = det(Bⁱ)/det(B)，det(B)=±1（幺模），Bⁱ 整数 → 商是整数。
- **TU 判别（行划分测试，充分条件）**：行能分两组，满足 ①每列最多两个非零 ②同组两非零反号、异组两非零同号。二分匹配矩阵、网络流关联矩阵都满足 → 都是 TU。

```
主线（理解）：    标准形 → BFS/顶点 → 判别数 → 单纯形 → 对偶y+间隙恒等式
                → 强弱对偶+互补松弛 → 影子价格 → 内点法
动手（计算）：    simplex tableau 读表/主元；两阶段法+哑主元；灵敏度四类变化
规则（T/F）：    退化/Bland；对偶符号表；互补松弛双向
独立大题：       建模线性化；顶点覆盖2-近似；整数优化松弛+TU（若在范围）
```

**核心一句话（背这一个就够）：**

> 线性规划 = 一个对象（min cᵀx s.t. Ax=b, x≥0）+ 一条恒等式（cᵀx−bᵀy = Σxⱼc̄ⱼ）+ 三个条件（原可行①、对偶可行②、互补松弛③）。最优 = 三条件齐满 = gap 归零。单纯形、对偶单纯形、内点法 = 三种"维护两个、追一个"的路径。
