## 模板一：灵敏度 + 单纯形表 综合（源自 HW5 P1）

**Setup（原题）：**
```
maximize  3x1 + 4x2 + 3x3 + 6x4
s.t.  2x1 + x2 − x3 + x4 ≥ 12
      x1 + x2 + x3 + x4  = 8
      −x2 + 2x3 + x4     ≤ 10
      x1,x2,x3,x4 ≥ 0
```
转 min 标准形：c = (−3,−4,−3,−6,0,0)，6 个变量 x1..x4, s1, s2。
最终单纯形表给出：**基 B={1,4,6}，x\*=(4,0,0,4,0,6)，最优值 V\*=36**；非基变量是 {x2,x3,s1}，判别数 r_N=(2,9,3)；A_B⁻¹e₂=(−1,2,−2)。

---

**(a) 写对偶 + 互补松弛反解 y\* + 唯一性【原】**

套路：①对偶变量符号规则——min 标准形下，对偶是 max bᵀy s.t. Aᵀy≤c（y 自由；原 ≤ 约束给 y≤0，原 ≥ 给 y≥0，原 = 给 y 自由）。
②反解 y\*：xⱼ\*>0 ⟹ 对偶第 j 约束取等（c̄ⱼ=0）；原约束不紧 ⟹ 对应 yᵢ=0。③唯一性：原最优**非退化**（基变量全正）+ 互补松弛方程唯一解 ⟹ 对偶唯一。
答案：y\*=(−3,9,0)，唯一。

**(b) 非基系数变 / 基系数变【原】**

套路：
- **非基 cⱼ→cⱼ+Δ**：只有这一个判别数变，保持最优 ⟺ **c̄ⱼ+Δ ≥ 0**（min）。解和最优值都不变。
- **基系数 cⱼ→cⱼ+Δ**（xⱼ 是第 t 个基变量）：**c̄_N′ = c̄_N − Δ·(A_B⁻¹A_N 的第 t 行)**，保持最优 ⟺ c̄_N′≥0。

答案：c3→1：Δ=+2，r3′=9+2=11≥0 → 不变。c3→12：Δ=−9，r3′=0 → 不变（但出现多个最优）。c1→1：Δ=+2，c̄_N′=(2,9,3)−2·(0,−2,−1)=(2,13,5)≥0 → 不变，新值 28。c1→7：Δ=−4，c̄_N′=(2,1,−1) → 有负 → 变，新 x\*=(8,0,0,0,4,10)，值 56。

**(c) b 的保持最优范围【原】**

套路：**x_B′ = x_B\* + λ·(A_B⁻¹ 的第 i 列)**，保持最优 ⟺ x_B′ ≥ 0。此时 y\* 不变，最优值 V′=V\*+yᵢλ。
答案：b₂=8：x_B+λA_B⁻¹e₂=(4,4,6)+λ(−1,2,−2)≥0 ⟹ λ∈[−2,3] ⟹ **b₂∈[6,11]**。

**(d) 从表直接读 A_B⁻¹ 和 y\*【补】**

套路：最终表中，**原单位阵所在的那几列 = A_B⁻¹**（把最优基列拼回单位阵，对应位置就是 A_B⁻¹）。**y\* = A_B⁻ᵀc_B**（= c_BᵀA_B⁻¹）。和 (a) 互补松弛法互相印证。
答案：读表得 A_B⁻¹；y\*=A_B⁻ᵀc_B=(−3,9,0)，与 (a) 一致。

**(e) 加新变量 x5【补】**

套路：**c̄₅ = c₅ − y\*ᵀa₅**（a₅ 是新变量的列）。≥0 → 基不变仍最优；<0 → x5 进基（要换基）。
示例：a₅=(0,1,0)ᵀ，c₅=5 → c̄₅=5−(−3,9,0)·(0,1,0)=5−9=−4<0 → 进基。若 c₅=12 → c̄₅=3≥0 → 仍最优。

**(f) b 具体变到某值，算新 x\* 和最优值【补】**

套路：**x̃_B = x_B\* + A_B⁻¹Δb**。≥0 → 基仍最优，y\* 不变，新值 V′=V\*+yᵀΔb；<0 → 基失效。
示例：b₂=8→9：x̃_B=(4,4,6)+1·(−1,2,−2)=(3,6,4)≥0 → 仍最优，新 x\*=(3,0,0,6,0,4)，新值 36+9·1=45。

**(g) 退化性 / 唯一性判断【补】**

套路：基变量**全 >0 ⟺ 非退化 ⟺ 原最优唯一**（且对偶也唯一）。若某基变量=0 或某非基判别数=0 → 可能退化/多解。
答案：x\*=(4,0,0,4,0,6) 基变量 x1=4,x4=4,s2=6 全正 → 非退化 → 唯一。对照 (b)：c3→12 时 r3′=0 → 出现多解。

**(h) 加新约束，检查 x\* 是否仍最优【补】**

套路：把 x\* 代入新约束。**满足 → x\* 仍最优；违反 → 需对偶单纯形重算**（考「代入检查」这一步）。
示例：加 x1+x4≤8：4+4=8≤8 ✓ → 仍最优。加 x1≤3：4>3 ✗ → 不再最优。

## 模板二：顶点覆盖 2-近似（源自样卷 Q6）

**Setup（原题）：** 无向图 G=(V,E)，V={1..n}。
```
(IP) v* = min Σxᵢ  s.t. xᵢ+xⱼ≥1 ∀{i,j}∈E, xᵢ∈{0,1}
(LP) vr* = min Σxᵢ  s.t. xᵢ+xⱼ≥1, 0≤xᵢ≤1   （松弛）
```

**(a) 证 vr\* ≤ v\*【原】**

套路：**松弛扩大可行域**（整数约束放宽）+ 目标同为 min ⟹ 最优值只能更小。一句话拿下。

**(b) 证任意顶点 x 满足 xᵢ∈{0,1/2,1}（半整性）【原】**

套路（**中点矛盾法**，万能技巧）：设 I₋₁={i: xᵢ∈(0,1/2)}、I₊₁={i: xᵢ∈(1/2,1)}。若二者非空，构造 y、z：
```
yᵢ = xᵢ−ε (i∈I₊₁),  xᵢ+ε (i∈I₋₁),  否则 xᵢ
zᵢ = xᵢ+ε (i∈I₊₁),  xᵢ−ε (i∈I₋₁),  否则 xᵢ
```
ε 足够小则 y,z 可行、≠x，且 **x=(y+z)/2** ⟹ 与 x 是顶点矛盾 ⟹ I₊₁=I₋₁=∅。
（{0,1/2,1} 不能放进 I，否则 y 或 z 不可行——这是采分点。）

**(c) 构造 2-近似解【原】**

套路（**取整**）：LP 最优解 x′ 的分量都在 {0,1/2,1}，把 1/2 **向上取整到 1**：
```
x̂ᵢ = 1, 若 x′ᵢ = 1/2;   否则 x̂ᵢ = x′ᵢ
```
可行性：x′ᵢ+x′ⱼ≥1 ⟹ 至少一个 ≥1/2，取整后仍 ≥1。近似比：Σx̂ᵢ ≤ 2Σx′ᵢ = 2vr\* ≤ 2v\*。

**(d) 取整为何保持可行【补】**

一句话：**xᵢ+xⱼ≥1 ⟹ max(xᵢ,xⱼ)≥1/2**，把 ≥1/2 的那个抬到 1，和仍然 ≥1，且整数约束满足。（这就是 (c) 里「可行性」的完整理由，单独背下来。）

**(e) 为何 LP 不能直接解 IP（gap）【补】**

套路：LP 最优解可能含 1/2，不是整数，不能直接当 IP 解。
示例：**三角形 K3**（3 个顶点两两相连）：x=(1/2,1/2,1/2) 是 LP 最优，值 3/2；但 IP 最优必须选 2 个顶点，值 2。所以松弛解 ≠ IP 解，必须取整。

**(f) 二分图特例 = TU【补·选读】**

套路：图是**二分图**时，顶点覆盖的约束矩阵是**完全幺模（TU）**，LP 松弛的解自动是整数 → 无需取整，vr\*=v\*。连接 L14 的 TU ⟹ 整数解。

## CP 精简公式包（抄到 cheat sheet）

**灵敏度四问法（min 标准形）：**
- 非基 cⱼ→cⱼ+Δ：保持 ⟺ c̄ⱼ+Δ ≥ 0（解、值不变）
- 基 cⱼ→cⱼ+Δ（第 t 基）：c̄_N′ = c̄_N − Δ·(A_B⁻¹A_N 第 t 行) ≥ 0
- bᵢ→bᵢ+λ：x_B′=x_B\*+λ(A_B⁻¹第 i 列) ≥ 0；值 V′=V\*+yᵢλ
- 加变量：c̄ⱼ = cⱼ − y\*ᵀaⱼ；加约束：x\* 代入检查

**读表：** 原单位阵列 = A_B⁻¹；y\* = A_B⁻ᵀc_B。
**互补松弛反解 y\*：** xⱼ\*>0 ⟹ c̄ⱼ=0；原约束不紧 ⟹ yᵢ=0；再验证对偶可行。
**最优证书三条件：** ①原可行 + ②对偶可行 + ③互补松弛。
**对偶不可行 + 原可行 ⟹ 原无界**（弱/强对偶）。
**非退化 ⟺ 基变量全正 ⟺ 最优唯一。**
**顶点覆盖取整：** 半整性(中点矛盾) + 1/2→1 + Σx̂ᵢ≤2Σx′ᵢ=2vr\*≤2v\*。
