二、第 1 章 基础考点 Probability Basics

题型：计数与排列组合

🏆核心决策树：怎么选计数方法？
问自己是否
次序是否重要？排列 (Permutation)组合 (Combination)
是否放回？$n^r$ (有序有放回)$_nP_r$ 或 $\binom{n}{r}$
是否有重复类型？可区分排列 $\frac{n!}{n_1!\cdots n_m!}$普通排列/组合
等可能假设成立？$P(A) = \frac{N(A)}{N(S)}$不能直接用计数法
✎典型例题

Q: 从 52 张扑克牌中抽 5 张，有多少种可能的牌面组合？
A: $\binom{52}{5}$（无序，无放回 → 组合）

Q: 26 个字母组成 4 字母单词（字母可重复），多少种？
A: $26^4$（有序，有放回）

Q: 26 个字母组成 4 字母单词（字母不可重复），多少种？
A: $_{26}P_4 = 26 \times 25 \times 24 \times 23$（有序，无放回）

Q: 抛 10 次硬币，恰好 4 次正面的序列数？
A: $\binom{10}{4}$（可区分排列：10 个中 4 个一类、6 个另一类）

题型：条件概率

🏆两种解法

法 1（直接法）：在缩小的样本空间中直接数。条件 $B$ 发生了，样本空间从 $S$ 缩小到 $B$。在新空间中用等可能计数。

法 2（定义法）：$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$。这是最通用的——即使不是等可能也适用。

✎经典题：两个孩子的三种变体

$S = \{\text{GG, GB, BG, BB}\}$，各 $1/4$。

已知老大是女孩 → 两个都是女孩？ 缩小到 $\{\text{GG, GB}\}$ → $1/2$

已知至少一个是女孩 → 两个都是女孩？ 缩小到 $\{\text{GG, GB, BG}\}$ → $1/3$

随机碰到一个是女孩 → 两个都是女孩？ 相当于"指定了一个孩子" → $1/2$

核心区别：「至少有一个」≠「指定哪一个」——前者只排除 BB，后者排除了一半。

✎郁金香例题 (Lec 2)
早花 (E)晚花 (L)合计
红色 (R)5813
黄色 (Y)347
合计81220

$P(R) = \frac{13}{20}$；$P(R \mid E) = \frac{5}{8}$（样本空间缩小到早花 8 株）

用定义法：$P(R \mid E) = \frac{P(R \cap E)}{P(E)} = \frac{5/20}{8/20} = \frac{5}{8}$ ✓

题型：独立事件判断

🏆三步判断法

1. 算 $P(A)$ 和 $P(B)$
2. 算 $P(A \cap B)$
3. 检查 $P(A \cap B) \stackrel{?}{=} P(A)P(B)$

等价判断（由 Thm 1.4-1）：$P(A \mid B) \stackrel{?}{=} P(A)$ 或 $P(B \mid A) \stackrel{?}{=} P(B)$。

⚠高频陷阱：两两独立 ≠ 相互独立

Lec 3 例 3：瓮中有球 1,2,3,4。$A=\{1,2\}$, $B=\{1,3\}$, $C=\{1,4\}$。

$P(A)=P(B)=P(C)=\frac{1}{2}$；$P(A \cap B) = \frac{1}{4} = P(A)P(B)$ ✓（两两独立）

但 $P(A \cap B \cap C) = \frac{1}{4} \neq \frac{1}{8} = P(A)P(B)P(C)$ ✗（不相互独立）

相互独立 = 两两独立 + 三个同时独立的乘积条件。这个例子常考！

题型：贝叶斯定理

🏆标准解题框架

1. 明确划分：$B_1, B_2, \ldots, B_m$ 互斥且穷尽（先验概率 $P(B_i)$ 已知）

2. 计算全概率：$P(A) = \sum_{i=1}^m P(B_i)P(A \mid B_i)$

3. 计算后验：$P(B_k \mid A) = \dfrac{P(B_k)P(A \mid B_k)}{P(A)}$

✎碗与筹码 (Lec 3 贝叶斯例题)

三个碗：$B_1$(2红4白), $B_2$(1红2白), $B_3$(5红4白)。
先选碗：$P(B_1)=\frac{1}{3}, P(B_2)=\frac{1}{6}, P(B_3)=\frac{1}{2}$。

Q1: 抽出红色的概率？ 全概率:

$P(R) = \frac{1}{3}\cdot\frac{2}{6} + \frac{1}{6}\cdot\frac{1}{3} + \frac{1}{2}\cdot\frac{5}{9} = \frac{4}{9}$

Q2: 已知抽出红色，它最可能来自哪个碗？ 计算后验：

$P(B_1 \mid R) = \frac{\frac{1}{3}\cdot\frac{2}{6}}{\frac{4}{9}} = \frac{1}{4},\; P(B_2 \mid R) = \frac{1}{8},\; P(B_3 \mid R) = \frac{5}{8}$

最可能来自 $B_3$（尽管 $B_3$ 的先验不是最大，但它的红色比例最高）。

💡贝叶斯思维口诀

"先验 × 似然 → 归一化 → 后验"

$P(B_k \mid A) \propto P(B_k) \cdot P(A \mid B_k)$（分母对所有 $k$ 相同，只是归一化常数）

贝叶斯定理本质上就是：用数据 $A$ 来更新对 $B_k$ 的信念。

三、第 2 章 离散分布考点 Discrete Distributions

题型：求 pmf / cdf

🏆pmf 的三个条件（考题中经常要求验证）

(1) $f(x) > 0$ 对所有 $x \in S$（定义域可扩展到 $\mathbb{R}$ 后用 $f(x) = 0$ 填充）

(2) $\sum_{x \in S} f(x) = 1$

(3) $P(X \in A) = \sum_{x \in A} f(x)$

✎例：掷两个四面骰子，$X = \max(d_1, d_2)$ (Lec 4 例 2)

$S_X = \{1,2,3,4\}$。从原样本空间（16个等可能结果）计数：

$f(1) = \frac{1}{16},\; f(2) = \frac{3}{16},\; f(3) = \frac{5}{16},\; f(4) = \frac{7}{16}$

关键技巧：当 $X$ 不是一对一映射时，需要从原样本空间中数出所有映射到同一个 $x$ 的结果。

题型：期望与方差计算

🏆三条计算路线

路线 1（定义）：$E[X] = \sum x f(x)$，然后 $E[X^2] = \sum x^2 f(x)$，$\mathrm{Var} = E[X^2] - (E[X])^2$

路线 2（mgf 求导）：先求 $M(t)$，再 $M'(0) = E[X]$，$M''(0) = E[X^2]$

路线 3（已知分布）：如果你认出了分布，直接查表！$b(n,p)$ → $np$，$\text{Poisson}(\lambda)$ → $\lambda$，等等。

⚠最小化 $E[(X-b)^2]$ 的结论

令 $h(b) = E[(X-b)^2]$，则 $h'(b) = -2E[X] + 2b \overset{!}{=} 0 \Rightarrow b = E[X]$。

结论：均值 $E[X]$ 是使均方误差最小的预测值。这是一个重要性质，考试可能考推导或直接问结论。

题型：mgf 四大问法 重点

🏆mgf 的四种考法
考法典型题目解题方法
1. 给分布求 mgf"求 $X \sim b(n,p)$ 的 mgf"代入定义 $\sum e^{tx}f(x)$，化简级数
2. 给 mgf 求均值和方差"已知 $M(t)$，求 $E[X]$ 和 $\mathrm{Var}$"求导：$M'(0)$ 和 $M''(0)$
3. 给 mgf 识别分布"$M(t) = e^{3(e^t-1)}$ 是什么分布？"对比标准 mgf 形式 → $\text{Poisson}(3)$
4. 用 mgf 证明分布关系"独立二项之和仍是二项"$M_{X+Y}(t) = M_X(t)M_Y(t)$
✎识别分布实例

$M(t) = \left(\frac{1}{4} + \frac{3}{4}e^t\right)^{10}$ → 形如 $[(1-p)+pe^t]^n$ → $b(10, 0.75)$

$M(t) = e^{5(e^t-1)}$ → 形如 $e^{\lambda(e^t-1)}$ → $\text{Poisson}(5)$

$M(t) = \frac{0.3e^t}{1 - 0.7e^t}$ → 形如 $\frac{pe^t}{1-qe^t}$ → $\text{Geom}(0.3)$

$M(t) = \frac{1}{(1-3t)^2}$ → 形如 $\frac{1}{(1-\theta t)^\alpha}$ → $\Gamma(2, 3)$

⚠mgf 收敛条件

几何分布：$t < -\ln q$（$q e^t < 1$ 才能等比求和）。指数分布：$t < 1/\theta$。

考试中可能会问"$M(t)$ 在什么范围内存在？"——要写收敛条件。

题型：分布识别与匹配

🏆场景 → 分布对照表
场景描述关键短语分布

四、第 3 章 连续分布考点 Continuous Distributions 期中范围：Lec 7 (§3.1)

题型：pdf 验证 → 求 cdf → 求概率

🏆标准三步

Step 1（验证 pdf）：检查 $f(x) \ge 0$ 且 $\int_{-\infty}^{\infty} f(x)dx = 1$。

Step 2（求 cdf）：$F(x) = \int_{-\infty}^x f(t)dt$。分段积分，注意上下限。

Step 3（求概率）：$P(a \le X \le b) = F(b) - F(a) = \int_a^b f(x)dx$。

连续型单点概率为零，区间端点包不包含无所谓。

✎例：$f(y)=2y,\;0

cdf: $G(y) = \begin{cases}0,&y\le 0\\y^2,&0

$P(1/2 < Y \le 3/4) = G(3/4) - G(1/2) = 9/16 - 1/4 = 5/16$

题型：正态分布查表 8-9课，期中不考

🏆标准化公式 (Thm 3.3-1)
$$X \sim N(\mu, \sigma^2) \;\Longrightarrow\; Z = \frac{X - \mu}{\sigma} \sim N(0,1)$$ $$P(a \le X \le b) = \Phi\!\left(\frac{b-\mu}{\sigma}\right) - \Phi\!\left(\frac{a-\mu}{\sigma}\right)$$

$\Phi(z)$ 是标准正态的 cdf，查表可得。$\Phi(-z) = 1 - \Phi(z)$。

✎例：$X \sim N(3, 16)$，求 $P(4 \le X \le 8)$ (Lec 9 例 4)

$Z = \frac{X-3}{4}$。$P(4 \le X \le 8) = \Phi(\frac{8-3}{4}) - \Phi(\frac{4-3}{4}) = \Phi(1.25) - \Phi(0.25)$

$= 0.8944 - 0.5987 = 0.2957$

💡常用 $z_\alpha$ 值（上百分位点）
$z_{0.05} = 1.645,\quad z_{0.025} = 1.96,\quad z_{0.0125} = 2.24$

$z_\alpha$ 满足 $P(Z \ge z_\alpha) = \alpha$，所以 $z_\alpha$ 是第 $100(1-\alpha)$ 百分位数。

题型：Gamma/指数/卡方的关系 重点

🏆递进关系
$$\text{Exp}(\theta) = \Gamma(1, \theta) \qquad\qquad \chi^2(r) = \Gamma(r/2, 2)$$ $$\frac{(X-\mu)^2}{\sigma^2} \sim \chi^2(1) \quad\text{其中 } X \sim N(\mu,\sigma^2)$$

伽马函数的阶乘性质：$\Gamma(n) = (n-1)!$（$n$ 正整数），$\Gamma(t) = (t-1)\Gamma(t-1)$。

✎从 PPT 到实际判断

$X \sim \chi^2(5)$ → 这是 $\Gamma(2.5, 2)$。$E[X] = 5,\; \mathrm{Var}(X) = 10$。

$X \sim \text{Exp}(3)$ → 这是 $\Gamma(1, 3)$。$E[X] = 3,\; \mathrm{Var}(X) = 9$。

$X \sim \Gamma(3, 2)$ → $E[X] = 6,\; \mathrm{Var}(X) = 12$。既不是指数也不是卡方。

看到 $\theta=2$ 且 $\alpha$ 是半整数 → 检查是不是卡方；看到 $\alpha=1$ → 检查是不是指数。

技巧 1：指示变量 + 线性期望 高分技巧

🏆三步法

1. 把复杂随机变量 $X$ 拆成简单指示变量之和：$X = I_1 + I_2 + \cdots + I_n$

2. $E[I_j] = P(I_j = 1)$（基本桥梁 Fundamental Bridge）

3. $E[X] = \sum E[I_j]$（线性期望——不需要独立性！）

4. 如果有对称性，所有 $E[I_j]$ 相等，只需算一个乘 $n$。

✎三道经典应用

Putnam 局部极大值：$n$ 个随机排列中极大值个数的期望 = $\frac{n+1}{3}$。

六、高频易错陷阱 Common Pitfalls

35 个高频陷阱清单

⚠概率基础
  1. $P(A \cup B) \neq P(A) + P(B)$（除非互斥）——必须减去 $P(A \cap B)$。
  2. 两两独立 $\neq$ 相互独立——三个事件两两独立不一定相互独立（Lec 3 例 3 是经典反例）。
  3. $P(A \mid B) \neq P(B \mid A)$——条件概率不可随意交换。
  4. $P(A^c \mid B) \neq 1 - P(A \mid B)$ 不对——实际上 $P(A^c \mid B) = 1 - P(A \mid B)$ 是对的（因为 $P(\cdot \mid B)$ 本身是一个概率测度），但要小心 $\cap$ 和 $\mid$ 的区别。
  5. "至少有一个" ≠ "指定某一个"——两孩问题中信息量不同。
  6. 辛普森悖论：分组和合并的结论可能完全相反。
⚠计数方法
  1. 混淆排列与组合：次序重要 → 排列；次序不重要 → 组合。
  2. 可区分排列：$n$ 个中 $r$ 个一类、$n-r$ 个另一类，排列数 = $\binom{n}{r}$，不是 $n!$。
  3. $\binom{n}{x} = \frac{n!}{x!(n-x)!}$，注意 $0! = 1$。
  4. $\binom{n}{0} = \binom{n}{n} = 1$，$\binom{n}{1} = n$。
⚠随机变量与期望
  1. $\mathrm{Var}(X) = E[X^2] - (E[X])^2$，不是 $(E[X])^2 - E[X^2]$。
  2. $\mathrm{Var}(cX) = c^2 \mathrm{Var}(X)$，系数是平方！
  3. $E[g(X)] \neq g(E[X])$，除非 $g$ 是线性的。
  4. 离散求期望用 $\sum$，连续用 $\int$，不要混。
  5. 连续型 $P(X=a) = 0$，单点概率不起作用。
  6. pdf 的值可以大于 1！（如 $U(0.1, 0.2)$ 的 pdf = 10）
  7. cdf：$F(x) = P(X \le x)$ 是非降函数。$f(x) = F'(x)$ 只在可导点成立。
⚠mgf
  1. mgf 求导后必须代入 $t=0$。很多人算了一堆导数忘了最后一步。
  2. $M(0) = 1$ 恒成立，可作为验证 mgf 是否正确的方法。
  3. 有 mgf 收敛区间要求：几何 $t < -\ln q$，指数 $t < 1/\theta$，卡方 $t < 1/2$。
  4. mgf 唯一性：相同 mgf ⇔ 相同分布。这意味着mgf完全刻画了分布。
  5. 正态 mgf 的符号：$e^{\mu t + \sigma^2 t^2/2}$，注意是 $+$ 号。
⚠分布与参数
  1. 二项分布 $X \sim b(n,p)$ 不能写成 $X \sim \text{Binomial}$ 后面不标参数。
  2. 泊松分布的均值和方差相等：$E[X] = \mathrm{Var}(X) = \lambda$。这是一个经常用来识别泊松分布的特征。
  3. 几何分布有两种定义：本课用"直到第一次成功的总试验次数"（$x=1,2,\ldots$），$E[X] = 1/p$。
  4. 负二项中的 $r$ 是成功次数，不是 $n$。
  5. 伯努利是 $n=1$ 的二项：$b(1,p)$。
  6. 指数是 $\alpha=1$ 的伽马：$\Gamma(1, \theta) = \text{Exp}(\theta)$。
  7. 卡方是 $\theta=2, \alpha=r/2$ 的伽马：$\chi^2(r) = \Gamma(r/2, 2)$。
  8. 指数分布的参数：pdf 中 $\frac{1}{\theta}e^{-x/\theta}$，期望 $=\theta$。不要和 $\lambda e^{-\lambda x}$ 搞混——两者只是参数化的差异（$\theta = 1/\lambda$）。
⚠正态分布
  1. 标准化：$Z = \frac{X-\mu}{\sigma} \sim N(0,1)$，不是 $\frac{X-\sigma}{\mu}$。
  2. $\Phi(-z) = 1 - \Phi(z)$（对称性），查表时很常用。
  3. 正态的 mgf 是 $e^{\mu t + \sigma^2 t^2/2}$，指数上是 $\sigma^2 t^2/2$，不是 $-\frac{1}{2}$。
  4. $\frac{(X-\mu)^2}{\sigma^2} \sim \chi^2(1)$（Thm 3.3-2），这个结论在后续课程中很重要。
  5. 查表时先标准化！非标准正态必须变成 $Z$ 后再用 $\Phi$ 表。

3.1-6   西瓜利润优化 重点

✎题目

需求 $X$ 的 pdf 为 $f(x) = \frac{1}{200},\; 0 < x < 200$。进 $n$ 个西瓜：每个卖出赚 \$1.00；不够卖每个缺货损失 \$5.00；卖不完每个亏 \$0.50。求最优 $n$ 最大化期望利润。

★解答

Step 1 — 分段利润函数：

$$\text{profit} = \begin{cases} 1.00 \cdot X + (-0.50)(n-X) = 1.5X - 0.5n, & X \le n \\ 1.00 \cdot n + (-5.00)(X-n) = 6n - 5X, & X > n \end{cases}$$

Step 2 — 期望利润：

$$E[\text{profit}] = \frac{1}{200}\left[\int_0^n (1.5x - 0.5n)dx + \int_n^{200} (6n - 5x)dx\right]$$

第一段积分：$\int_0^n (1.5x - 0.5n)dx = \mathbf{0.25n^2}$

第二段积分：$\int_n^{200} (6n - 5x)dx = \mathbf{1200n - 100000 - 3.5n^2}$

合并：$E = \frac{1}{200}(1200n - 100000 - 3.25n^2) = \mathbf{6n - 500 - \frac{13}{800}n^2}$

Step 3 — 求最大值：

$$\frac{dE}{dn} = 6 - \frac{13}{400}n \overset{!}{=} 0 \;\Rightarrow\; n = \frac{2400}{13} \approx 184.62$$

由于 $n$ 必须是整数，检查 $n=184$ 和 $n=185$：$E(184) = E(185) = 53.84$。

最优进货量：$n = 185$（期望利润 \$53.84）

解题套路：分段函数 → 期望积分 → 二次函数求极值 → 检查整数边界。这种"库存/报童问题"是经典模型，期中很可能出类似题。

3.2-1   mgf 识别分布 必考

✎题目

已知 mgf，求 pdf、均值、方差：
(a) $M(t) = \frac{1}{1-3t},\; t < 1/3$
(b) $M(t) = \frac{3}{3-t},\; t < 3$

★解答

(a) 对比指数分布 mgf 标准形式 $M(t) = \frac{1}{1-\theta t}$ → $\theta = 3$。

pdf: $f(x) = \frac{1}{3}e^{-x/3},\; x>0$；$E[X] = 3$；$\mathrm{Var}(X) = 9$

(b) 改写 $M(t) = \frac{3}{3-t}$。这是指数分布参数化形式：$M(t) = \frac{\lambda}{\lambda - t}$，所以 $\lambda = 3$。

换回 $\theta = 1/\lambda = 1/3$ 的参数化：

pdf: $f(x) = 3e^{-3x},\; x>0$；$E[X] = 1/3$；$\mathrm{Var}(X) = 1/9$

考点：能识别 mgf 的标准形式。指数分布有两种参数化——$\frac{1}{1-\theta t}$（期望=$\theta$）和 $\frac{\lambda}{\lambda-t}$（期望=$1/\lambda$），不要搞混。

3.2-3   指数分布的无记忆性 重要性质

✎题目

$X \sim \text{Exp}(\theta > 0)$。证明：$P(X > x+y \mid X > x) = P(X > y)$，对任意 $x > 0, y > 0$。

★解答

指数分布的生存函数（survival function）为 $P(X > t) = e^{-t/\theta}$。

$$\begin{aligned} P(X > x+y \mid X > x) &= \frac{P(X > x+y)}{P(X > x)} \\ &= \frac{e^{-(x+y)/\theta}}{e^{-x/\theta}} = e^{-y/\theta} \\ &= P(X > y) \quad \blacksquare \end{aligned}$$

直觉：如果已经等了 $x$ 分钟还没等到，那么再多等 $y$ 分钟的概率 = 从头开始等 $y$ 分钟的概率。指数分布"忘记了"已经等了多久——这是它区别于其他连续分布的根本特征。Gamma 分布无此性质。

3.2-7   伽马分布的 mgf 推导 推导题

✎题目

求 Gamma$(\alpha, \theta)$ 的 mgf。Hint: 在积分中令 $y = (1-\theta t)x/\theta$。

★解答

Gamma pdf：$f(x) = \frac{1}{\Gamma(\alpha)\theta^\alpha} x^{\alpha-1} e^{-x/\theta},\; x > 0$。

$$M(t) = \int_0^\infty e^{tx} \cdot \frac{x^{\alpha-1} e^{-x/\theta}}{\Gamma(\alpha)\theta^\alpha} dx = \frac{1}{\Gamma(\alpha)\theta^\alpha} \int_0^\infty x^{\alpha-1} \exp\!\left(-x\cdot\frac{1-\theta t}{\theta}\right)dx$$

令 $y = \frac{(1-\theta t)x}{\theta}$，则 $x = \frac{\theta y}{1-\theta t}$，$dx = \frac{\theta}{1-\theta t}dy$（需 $1-\theta t > 0$，即 $t < 1/\theta$）：

$$\begin{aligned} M(t) &= \frac{1}{\Gamma(\alpha)\theta^\alpha} \int_0^\infty \left(\frac{\theta y}{1-\theta t}\right)^{\alpha-1} e^{-y} \cdot \frac{\theta}{1-\theta t} dy \\ &= \frac{\theta^\alpha}{\Gamma(\alpha)\theta^\alpha (1-\theta t)^\alpha} \int_0^\infty y^{\alpha-1} e^{-y} dy \\ &= \frac{1}{(1-\theta t)^\alpha} \cdot \frac{\Gamma(\alpha)}{\Gamma(\alpha)} \end{aligned}$$
$$M(t) = \frac{1}{(1-\theta t)^\alpha}, \quad t < \frac{1}{\theta}$$

技巧总结：Gamma mgf 的推导套路 = 变量替换把指数凑成 $e^{-y}$ → 提取常数 → 用 $\Gamma(\alpha) = \int y^{\alpha-1}e^{-y}dy$ 吃掉积分。期中考试可能考这个推导过程。

3.2-22   Logistic 分布 → Uniform 变换 技巧题

✎题目

$X$ 服从 Logistic 分布，pdf 为 $f(x) = \frac{e^{-x}}{(1+e^{-x})^2},\; -\infty < x < \infty$。证明 $Y = \frac{1}{1+e^{-X}} \sim U(0,1)$。

★解答

关键第一步：注意到 $\frac{d}{dt}\left[\frac{1}{1+e^{-t}}\right] = \frac{e^{-t}}{(1+e^{-t})^2} = f(t)$，所以 Logistic 的 cdf 恰好是：

$$F_X(x) = \int_{-\infty}^x f(t)dt = \frac{1}{1+e^{-x}}$$

第二步：求 $Y = 1/(1+e^{-X})$ 的 cdf（$0 < y < 1$）：

$$\begin{aligned} G(y) &= P(Y \le y) = P\!\left(\frac{1}{1+e^{-X}} \le y\right) \\ &= P(1 \le y(1+e^{-X})) = P(1-y \le y e^{-X}) \\ &= P\!\left(e^{-X} \ge \frac{1-y}{y}\right) = P\!\left(X \le \ln\frac{y}{1-y}\right) \\ &= F_X\!\left(\ln\frac{y}{1-y}\right) = \frac{1}{1 + \exp(-\ln\frac{y}{1-y})} \\ &= \frac{1}{1 + \frac{1-y}{y}} = \frac{1}{(y+1-y)/y} = \mathbf{y} \end{aligned}$$

$G(y) = y$（$0 < y < 1$）正是 $U(0,1)$ 的 cdf，所以 $Y \sim U(0,1)$。

核心洞察：Logistic 分布的 cdf $1/(1+e^{-x})$ 本身就是 sigmoid 函数。将 cdf 作用在随机变量上，得到的是 Uniform(0,1)——这是概率积分变换（Probability Integral Transform）的一个具体体现，极其重要。

随机变量的独立性 Independence of r.v.s 重要

🏆独立 vs 同分布（四个象限）
同分布 (Same Distribution)不同分布 (Different Distribution)
独立 Independent两个独立骰子的结果骰子结果 & 股票指数
不独立 Dependent$X$=正面次数, $Y$=反面次数 (同一次实验)选举结果 & 民调数据

核心区分："独立"和"同分布"是两个完全独立的概念。同分布 ≠ 相等：$X$ 和 $Y$ 可以都是 Bern(1/2) 但 $P(X=Y)=0$（如 $Y=1-X$）。

★独立 RV 的定义 (Def 3.8.1)

$X$ 和 $Y$ 独立 $\iff P(X \le x, Y \le y) = P(X \le x)P(Y \le y)$ 对所有 $x,y$。

离散等价：$P(X=x, Y=y) = P(X=x)P(Y=y)$ 对所有 $x,y$。

独立 RV 的关键性质：

1. 独立 $\Rightarrow$ 两两独立，但两两独立 $\not\Rightarrow$ 独立（和事件一样！）

2. 若 $X,Y$ 独立，则 $g(X)$ 和 $h(Y)$ 也独立（Thm 3.8.5：函数的独立性保持）

3. i.i.d. = 独立同分布（independent and identically distributed）

✎例 3.8.4：两骰子和与差

两公平骰子，$X$=第一个点数，$Y$=第二个点数。则 $X+Y$ 与 $X-Y$ 不独立：

$$0 = P(X+Y=12, X-Y=1) \neq P(X+Y=12)P(X-Y=1) = \frac{1}{36} \cdot \frac{5}{36}$$

因为 $X+Y=12$ 必然推出 $X-Y=0$，所以它们互相提供信息。

期望的线性性 Linearity of Expectation 核心原理

🏆两种"求平均"的视角（理解线性的关键）

方式一：分组求平均（grouped）——把相同 $x$ 值的样本点归到一起，用 pmf 加权：$E(X) = \sum x P(X=x)$。这就是我们学的定义。

方式二：逐个求平均（ungrouped）——回到原样本空间，每个样本点 $s$ 单独加权：$E(X) = \sum_s X(s) P(\{s\})$。

两种方式算出的期望完全相等。线性的证明就是靠方式二：

$$E(X) + E(Y) = \sum_s X(s)P(\{s\}) + \sum_s Y(s)P(\{s\}) = \sum_s [X+Y](s) P(\{s\}) = E(X+Y)$$

为什么不需要独立也能用？因为方式二中，$X$ 和 $Y$ 用的是同一组样本点 $s$ 和同一组权重 $P(\{s\})$。不管 $X$ 和 $Y$ 之间多相关，加权求和时各项独立相加，相关性不影响。

💡模拟直觉

做 $n$ 次实验，每次记录 $(X_i, Y_i)$。算 $X+Y$ 列的平均有两种方式：

(a) 直接算 $X+Y$ 列的所有数平均 → $E(X+Y)$
(b) 分别算 $X$ 列的平均和 $Y$ 列的平均，然后相加 → $E(X)+E(Y)$

两种方式结果完全一样，相关性完全不影响的——不管 $X$ 和 $Y$ 是什么关系。
