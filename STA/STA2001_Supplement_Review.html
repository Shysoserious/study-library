一、随机变量的函数 Functions of Random Variables

💡核心问题

我们学了很多"有名有姓"的分布（伯努利、二项、泊松……）。但实际问题中，我们往往对随机变量的某个函数感兴趣——比如 $X^2$，$e^X$，$\sin(X)$，或者 $|X|$。

这些东西的分布怎么求？这篇资料回答的就是这个问题。

定义：$g(X)$ 也是随机变量

📖Definition 3.7.1

给定样本空间 $S$，随机变量 $X$，以及函数 $g: \mathbb{R} \to \mathbb{R}$。则 $g(X)$ 也是一个随机变量，它把每个样本点 $s$ 映射到 $g(X(s))$。

$g(x) = \sqrt{x}$ 的例子：先经 $X$ 映射，再经 $g$ 映射。$g(X)$ 本质上是 $g \circ X$（复合函数）。

一句话理解：把 $X$ 的每个可能取值，塞进函数 $g$ 里算出新值，就得到了新随机变量 $g(X)$。如果 $X$ 取值 0, 1, 4 的概率分别是 $p_0, p_1, p_4$，那么 $g(X)$ 取值 $g(0), g(1), g(4)$——概率照搬……但前提是 $g$ 不能把不同值"合并"。

💡实例：篮球七场四胜

$X$ = A 队赢的场数，$X \sim \text{Bin}(7, 1/2)$。

$g(X) = 7 - X$ = B 队赢的场数（一对一，概率照搬）

$h(X) = \begin{cases}1, & X \ge 4 \\ 0, & X < 4\end{cases}$ = A 队是否赢得系列赛（多对一，需要把 $X=4,5,6,7$ 的概率加总）

情形一：$g$ 是一对一函数（简单）

★一对一情形：概率照搬

若 $g$ 是一对一的（每个 $y$ 只对应唯一一个 $x$），则 $Y = g(X)$ 的支撑集就是 $\{g(x) : x \in \text{support}(X)\}$，且：

$$P(Y = g(x)) = P(g(X) = g(x)) = P(X = x)$$

概率表直接翻译过去：

$x$$P(X=x)$$y = g(x)$$P(Y=y)$
$x_1$$p_1$$g(x_1)$$p_1$
$x_2$$p_2$→$g(x_2)$$p_2$
$x_3$$p_3$$g(x_3)$$p_3$

情形二：$g$ 不是一对一的（需要加总）

★Theorem 3.7.3：多对一情形的 PMF

对于任意函数 $g: \mathbb{R} \to \mathbb{R}$，$Y = g(X)$ 的 PMF 为：

$$P(Y = y) = \sum_{x:\, g(x) = y} P(X = x)$$

含义：把所有满足 $g(x) = y$ 的 $x$ 的概率加在一起。因为这些 $x$ 都对应同一个 $y$，是互斥事件，所以概率直接相加。

⚠别搞混

$g(X) = X^2$ 时，$y=4$ 可以来自 $x=2$ 或 $x=-2$：

$$P(X^2 = 4) = P(X = 2) + P(X = -2)$$

对于绝对值 $g(X) = |X|$ 也是一样：$y=3$ 来自 $x=3$ 或 $x=-3$。

例 3.7.2：随机游走（一对一应用）

✎例：$n$ 步随机游走后的位置

粒子从原点出发，每步独立地以概率 $1/2$ 向右或向左移动 1 单位。$n$ 步后位置为 $Y$，求 $Y$ 的 PMF。

解法思路：不直接求 $Y$，而是借助已知分布 $X$。

Step 1：设 $X$ = 向右的步数。则 $X \sim \text{Bin}(n, 1/2)$，这个是已知的。

Step 2：建立 $Y$ 和 $X$ 的一对一关系。若 $X=j$（向右走 $j$ 步），则向左走 $n-j$ 步，最终位置：

$$Y = j - (n-j) = 2j - n = 2X - n$$

$Y = 2X - n$ 是一对一函数（线性，斜率为正）。$X$ 取值 $\{0,1,\ldots,n\}$，则 $Y$ 取值 $\{-n, -n+2, -n+4, \ldots, n\}$。

Step 3：一对一情形下，直接翻译概率：

$$P(Y = k) = P(2X - n = k) = P\left(X = \frac{n+k}{2}\right) = \binom{n}{\frac{n+k}{2}} \left(\frac{1}{2}\right)^n$$

前提：$n+k$ 必须是偶数（即 $k$ 和 $n$ 同奇偶性），否则 $P(Y=k)=0$。

核心技巧：把不熟悉的随机变量 $Y$ 表达为熟悉分布 $X$ 的一对一函数，概率自动照搬。

例 3.7.4：距原点的距离（多对一应用）

✎例：$n$ 步后的距离 $D = |Y|$

仍是上面那个随机游走，$n$ 为偶数。令 $D = |Y|$，求 $D$ 的 PMF。

$D = |Y|$ 不是一对一的：$Y = k$ 和 $Y = -k$ 都映射到 $D = k$（$k > 0$）。

零点：$D = 0 \iff Y = 0$，所以 $P(D = 0) = P(Y = 0) = \binom{n}{n/2} (1/2)^n$。

正点：$k = 2, 4, \ldots, n$：

$$P(D = k) = P(Y = k) + P(Y = -k) = 2 \cdot \binom{n}{\frac{n+k}{2}} \left(\frac{1}{2}\right)^n$$

最后一步利用了对称性 $P(Y = k) = P(Y = -k)$（左右等概率）。

二、配对与生日问题 Matching & Birthday Problems

💡三合一技巧：指示变量 + 线性期望 + 对称性

这几个问题的共同模式：把复杂随机变量 $X$ 拆成简单指示变量之和 $X = I_1 + I_2 + \cdots + I_n$，然后：

  1. Fundamental Bridge（基本桥梁）：$E[I_j] = P(I_j = 1)$，指示变量的期望 = 它对应事件发生的概率
  2. Linearity（线性性）：$E[X] = E[I_1] + E[I_2] + \cdots + E[I_n]$，不需要独立性
  3. Symmetry（对称性）：每个 $E[I_j]$ 通常相等，所以只需算一次然后乘以 $n$

最震撼的一点：线性期望不要求独立！$I_j$ 之间可以乱七八糟地相关（如洗牌问题中每张牌是否配对是高度依赖的），依旧能用。

核心技巧详解：指示变量 + 线性期望

📖指示变量 Indicator Random Variable
$$I_j = \begin{cases} 1, & \text{事件 } A_j \text{ 发生} \\ 0, & \text{事件 } A_j \text{ 不发生} \end{cases}$$

于是 $E[I_j] = 1 \cdot P(A_j) + 0 \cdot P(A_j^c) = P(A_j)$。

如果 $X = I_1 + I_2 + \cdots + I_n$ 计数的是"有多少个事件发生了"，那么 $E[X] = \sum_{j=1}^n P(A_j)$。

这不需要 $A_j$ 之间独立！

三步流程：复杂问题 → 拆指示变量 → 线性期望求和。不需要独立性是最大优势。

例 1：洗牌配对

✎Example 4.4.4：洗牌后有多少张牌位置不变？

$n$ 张牌（标号 $1,2,\ldots,n$），随机排列。$X$ = 位置不变的牌的张数（i.e., 第 $j$ 张牌恰好落在第 $j$ 个位置 ）。求 $E[X]$。

直接求 $X$ 的分布非常困难——配对数是高度依赖的（如果前 $n-1$ 张都配对，第 $n$ 张一定也配对）。但用指示变量：

$I_j = 1$ 若第 $j$ 张牌配对。$X = I_1 + \cdots + I_n$。

$P(I_j = 1) = \frac{1}{n}$（随机排列中，第 $j$ 张牌落在第 $j$ 个位置的概率）。

$$E[X] = \sum_{j=1}^n E[I_j] = \sum_{j=1}^n \frac{1}{n} = 1$$

结论：洗 $n$ 张牌，平均有恰好 1 张留在原位——与 $n$ 无关！10 张牌是 1 张，100 张牌也是 1 张。这个结果用其他方法几乎无法得到。

例 2：不同的生日数

✎Example 4.4.5：$n$ 个人中有多少个不同生日？

$n$ 个人，生日独立均匀分布在 365 天。$X$ = 至少有一个人的生日落在其中的天数。换句话说：365 天中有多少天"被占用了"？求 $E[X]$。

$X = I_1 + \cdots + I_{365}$，其中 $I_j = 1$ 若第 $j$ 天被至少一个人占用。

$P(I_j = 1) = 1 - P($没人这天生日$) = 1 - \left(\frac{364}{365}\right)^n$

$$E[X] = 365 \left[1 - \left(\frac{364}{365}\right)^n\right]$$

比如 $n=23$ 时，$E[X] \approx 365 \cdot (1 - 0.9388) \approx 22.3$。23 个人，大约有 22 个不同的生日（只有约 1 对冲突）。$n=50$ 时 $E[X] \approx 46.8$。

例 3：生日匹配对数

✎有多少对人生日相同？

同样 $n$ 个人。$Y$ = 生日相同的对数（每两个人为一对）。求 $E[Y]$。

$Y = J_1 + \cdots + J_{\binom{n}{2}}$，其中每个 $J_i$ 指示某一对特定的两人是否同生日。

任意两人的生日相同的概率 $P(J_i = 1) = \frac{1}{365}$。

$$E[Y] = \binom{n}{2} \cdot \frac{1}{365}$$

$n=23$ 时：$E[Y] = \frac{23 \cdot 22}{2 \cdot 365} = \frac{253}{365} \approx 0.69$。平均不到 1 对。
$n=50$ 时：$E[Y] = \frac{1225}{365} \approx 3.36$ 对。

例 4：Putnam 竞赛题 — 局部极大值

✎Example 4.4.6：随机排列中局部极大值的期望个数

$1,2,\ldots,n$ 的一个随机排列（$n!$ 种等可能）。位置 $j$ 处是局部极大值当 $a_j$ 比左右邻居都大（$a_{j-1} < a_j > a_{j+1}$）。两端各有一个邻居。求局部极大值的期望个数。

这道题来自 Putnam 竞赛（全美最难的大学数学竞赛，中位数分数经常是 0）。用指示变量几十秒就能解。

$X = I_1 + \cdots + I_n$，$I_j$ 指示位置 $j$ 是否为局部极大值。

中间位置（$2 \le j \le n-1$）：$a_{j-1}, a_j, a_{j+1}$ 三个数中，$a_j$ 最大的概率 = $1/3$（等可能排列，三个位置中任意一个是最大的概率相等）。所以 $E[I_j] = \frac{1}{3}$。

两端位置（$j=1$ 或 $j=n$）：只有一个邻居，$a_j$ 比邻居大的概率 = $1/2$。所以 $E[I_1] = E[I_n] = \frac{1}{2}$。

$$E[X] = 2 \cdot \frac{1}{2} + (n-2) \cdot \frac{1}{3} = \frac{n+1}{3}$$

这就是最终的简洁答案！$n=5$ 时 $E[X]=2$；$n=100$ 时 $E[X] \approx 33.7$。一个 Putnam 竞赛题被三行解法解决，全靠指示变量 + 线性期望 + 对称性。

三、辛普森悖论 Simpson's Paradox

⚠一句话描述

每个子组里都是 B 更好，但合并后反而 A 更好。这不是数学错误——是分组比例不同造成的"统计错觉"。它警告你：不能盲目合并分组数据，否则结论可能完全反转。

数据与设定

📖两种疗法 A 和 B
男性 (Men)女性 (Women)
康复 (R)死亡 (D)康复 (R)死亡 (D)
A2080A4020
B50160B155

分性别计算：B 优于 A

✎男性和女性各自内部——B 都更优

男性：

$$P(\text{康复} \mid \text{男性}, \text{A}) = \frac{20}{100} = \frac{1}{5} = 0.20$$ $$P(\text{康复} \mid \text{男性}, \text{B}) = \frac{50}{210} = \frac{5}{21} \approx 0.238$$

B 的康复率更高：$0.238 > 0.20$。

女性：

$$P(\text{康复} \mid \text{女性}, \text{A}) = \frac{40}{60} = \frac{2}{3} \approx 0.667$$ $$P(\text{康复} \mid \text{女性}, \text{B}) = \frac{15}{20} = \frac{3}{4} = 0.75$$

B 的康复率也更高：$0.75 > 0.667$。

结论（分组）：无论男女，B 都比 A 好。

合并所有数据：A 反而更好

⚠合并后的反转

全部患者合并：

$$P(\text{康复} \mid \text{A}) = \frac{20 + 40}{100 + 60} = \frac{60}{160} = \frac{3}{8} = 0.375$$ $$P(\text{康复} \mid \text{B}) = \frac{50 + 15}{210 + 20} = \frac{65}{230} = \frac{13}{46} \approx 0.283$$

合并后 A 的康复率 37.5% 反而高于 B 的 28.3%！结论完全反转。

$$\text{分组：B > A} \qquad \longrightarrow \qquad \text{合并：A > B}$$

为什么会这样？

🔗本质原因：混淆变量

注意两个关键数字：

• 疗法 B 主要用在男性身上（210 男 vs 20 女），而男性的康复率本身就很低（不管用什么疗法）。

• 疗法 A 更多地用在女性身上（60 女 / 160 总 = 37.5%），而女性的康复率本身很高。

所以合并数据时，性别成为了一个混淆变量（confounding variable）：B 看起来更差，是因为它的患者中"更难治"的男性比例太高，而不是因为疗法本身的效果差。

辛普森悖论的因果结构：性别同时影响疗法分配和治疗结果

现实中有名的例子：1973 年加州大学伯克利分校的录取数据——每个系里女性录取率都不低于男性，但总体女性录取率低于男性。原因：女性更多地申请了录取率本来就低的系。

四、两个孩子问题 Two Children Problem

💡同一个场景，不同条件 → 不同答案

核心谜题：一个家庭有两个孩子。已知的信息不同，会导致"两个都是同性别"的概率不同。这不是数学错误——是条件概率中"条件给得多精确"决定了答案。

问题设定与假设

📖三个简化假设

1. 性别二元（男孩/女孩）

2. $P(\text{男}) = P(\text{女}) = 1/2$

3. 两个孩子性别独立

$$\text{样本空间：} S = \{GG, GB, BG, BB\},\quad \text{各 } 1/4$$

这里 GG 表示老大女孩、老二女孩。GB 表示老大女孩、老二男孩，以此类推。

变体 1：已知"老大是女孩" → 答案 1/2

✎Mr. Jones：大的是女孩，问两个都是女孩的概率？

条件：老大是女孩。

排除掉 BB（老大男）和 BG（老大男），剩下 GG 和 GB。

指定了特定孩子（老大），条件排除了 2/4 的样本点
$$P(\text{两个都女} \mid \text{老大是女}) = \frac{P(GG)}{P(GG) + P(GB)} = \frac{1/4}{1/2} = \frac{1}{2}$$

直觉：指定了老大后，老二独立于老大，所以老二有 50% 概率是女孩。

变体 2：已知"至少有一个女孩" → 答案 1/3

✎Mr. Smith：至少有一个女孩，问两个都是女孩的概率？

条件：至少有一个女孩。

只排除 BB，剩下 GG、GB、BG 三个等可能事件。

不指定具体孩子，条件只排除了 1/4 的样本点
$$P(\text{两个都女} \mid \text{至少一女}) = \frac{P(GG)}{P(GG) + P(GB) + P(BG)} = \frac{1/4}{3/4} = \frac{1}{3}$$

直觉："至少有一个女孩"比"老大是女孩"条件更弱——它只告诉你"不是 BB"，但没告诉你到底是哪一个。三个符合条件的组合中，只有一个（GG）满足"两个都是女孩"。

变体 3：随机遇到一个是女孩 → 答案 1/2

✎你随机碰到其中一个孩子，发现是女孩。问两个都是女孩的概率？

这个版本微妙地不同于前面两个。假设你等可能地遇到两个孩子中的任意一个，且遇到谁与性别独立。

令 $G_3$ = "你随机碰到的孩子是女孩"。$G_1, G_2$ 分别是老大和老二是女孩。

$P(G_1 G_2 G_3) = P(G_1 G_2) = 1/4$（两个都是女孩保证你碰到的是女孩）。$P(G_3) = 1/2$。

$$P(\text{两个都女} \mid \text{随机碰到的是女}) = \frac{P(G_1 G_2 G_3)}{P(G_3)} = \frac{1/4}{1/2} = \frac{1}{2}$$

直觉：随机遇到一个孩子就像"指定了一个具体孩子"。你知道这个特定孩子是女孩，另一个孩子（不管在家的是老大还是老二）有 50% 概率是女孩。这等价于变体 1。

三版本对比总结

🔗为什么答案不同？——条件信息量不同
条件排除的样本点符合条件的答案直觉
老大是女孩BG, BB（2 个）GG, GB1/2指定了具体孩子，另一个独立
至少有一女孩BB（1 个）GG, GB, BG1/3不指定谁，条件更"弱"
随机遇到一女取决于遇到谁等价于"指定"1/2随机采样 = 指定了特定孩子

核心教训：条件概率中，条件怎么给非常重要。"至少有一个"是一种较弱的条件，给的信息比"指定具体哪一个"少。信息越少，能排除的样本点越少，答案就可能越小（1/3 vs 1/2）。这在统计推断中至关重要——要知道你的样本是"怎么收集的"，而不只是盯着数据本身。
