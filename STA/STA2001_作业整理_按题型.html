二、题型 1 · 离散 PMF 归一化（求常数 c）

核心方法

PMF 必须满足 (1) $f(x) \ge 0$；(2) $\sum_x f(x) = 1$。第一点决定 $c$ 的符号，第二点决定 $|c|$。

HW2 2.1-3求下列各 PMF 中的常数 $c$

(a) $f(x) = x/c,\ x=1,2,3,4$
(b) $f(x) = cx,\ x=1,2,\ldots,10$
(c) $f(x) = c(1/4)^x,\ x=1,2,3,\ldots$
(d) $f(x) = c(x+1)^2,\ x=0,1,2,3$
(e) $f(x) = x/c,\ x=1,2,\ldots,n$
(f) $f(x) = \dfrac{c}{(x+1)(x+2)},\ x=0,1,2,\ldots$   提示：部分分式
答案
(a) $\sum_{x=1}^{4} x = 10 = c \Rightarrow c = 1/10$
(b) $\sum_{x=1}^{10} x = 55,\ c \cdot 55 = 1 \Rightarrow c = 1/55$
(c) $\sum_{x=1}^{\infty}(1/4)^x = \frac{1/4}{1-1/4} = 1/3,\ c \cdot 1/3 = 1 \Rightarrow c = 3$
(d) $1^2+2^2+3^2+4^2 = 30,\ c \cdot 30 = 1 \Rightarrow c = 1/30$
(e) $c \cdot \frac{n(n+1)}{2} = 1 \Rightarrow c = \dfrac{2}{n(n+1)}$
(f) $c\sum_{x=0}^{\infty}\Big(\frac{1}{x+1} - \frac{1}{x+2}\Big) = c \cdot 1 = 1 \Rightarrow c = 1$
重点讲解 ⭐ (f) 部分分式
关键思想：把"长尾巴"求和变成逐项相消的 telescoping 级数。 $$\frac{1}{(x+1)(x+2)} = \frac{1}{x+1} - \frac{1}{x+2}$$ 求和后中间项全部相消，只剩首尾： $$\sum_{x=0}^{N-1}\Big(\frac{1}{x+1} - \frac{1}{x+2}\Big) = 1 - \frac{1}{N+1} \xrightarrow{N\to\infty} 1$$ 因此 $c=1$。这个 trick 在 (2.4-7)、(4.4-7) 等涉及"无界离散"求和时反复出现。

三、题型 2 · 期望 / 方差 / 矩计算

核心公式回顾

量定义常用简写

$E(X^2)$$\sum x^2 f(x)$
$\mathrm{Var}(X)$$E(X^2) - \mu^2$$\sigma^2$

HW2 2.2-1求 2.1-3 各 PMF 的 $E(X)$

沿用 2.1-3 各 PMF，求 $\mu = E(X)$。
答案
(a) $E(X) = \sum_{x=1}^{4} x \cdot \frac{x}{10} = \frac{1+4+9+16}{10} = 3$
(b) $E(X) = \frac{1}{55}\sum_{x=1}^{10} x^2 = \frac{385}{55} = 7$
(c) $E(X) = 3 \cdot \sum_{x=1}^{\infty} x(1/4)^x$。用 $\sum x r^x = r/(1-r)^2$ 公式，$r=1/4$，得 $\sum x(1/4)^x = 4/9$，故 $E(X) = 3 \cdot 4/9 = 4/3$
(d) $E(X) = \frac{1}{30}\sum_{x=0}^{3} x(x+1)^2 = \frac{0\cdot 1 + 1\cdot 4 + 2\cdot 9 + 3\cdot 16}{30} = \frac{70}{30} = 7/3$
(e) $E(X) = \frac{2}{n(n+1)}\sum_{x=1}^n x^2 = \frac{2}{n(n+1)}\cdot \frac{n(n+1)(2n+1)}{6} = \frac{2n+1}{3}$
(f) $E(X) = \sum_{x=0}^{\infty} x \cdot \Big(\frac{1}{x+1}-\frac{1}{x+2}\Big)$，利用 telescoping 求得 $= \infty$（无穷均值的重尾分布！）
解析要点
两个关键工具：
1. 几何分布型求和：$\sum_{x=1}^\infty r^x = \frac{r}{1-r}$，$\sum_{x=1}^\infty x r^x = \frac{r}{(1-r)^2}$，$\sum_{x=1}^\infty x^2 r^x = \frac{r(1+r)}{(1-r)^3}$。
2. Telescoping 套路：看到 $\frac{1}{(x+a)(x+b)}$ 形式先做部分分式，再求和。
易错点：(f) 的 PMF 看似温和，其实 $\sum x f(x) = \infty$ —— 它的尾部是 $1/x^2$ 级别，刚好踩在"均值是否存在"的边界上。

HW2 2.3-2用"组合公式"求 $\mu, E[X(X-1)], \sigma^2$

(a) $f(x) = \binom{3}{x}(1/4)^x(3/4)^{3-x},\ x=0,1,2,3$   即 $B(3,1/4)$
(b) $f(x) = \binom{4}{x}(1/2)^4,\ x=0,1,2,3,4$   即 $B(4,1/2)$
答案
(a) $\mu = np = 3/4$，$E[X(X-1)] = n(n-1)p^2 = 3\cdot 2\cdot (1/16) = 3/8$，$\sigma^2 = E[X(X-1)] + \mu - \mu^2 = 3/8 + 3/4 - 9/16 = 15/16 - 9/16 = 6/16 = 3/8$。也可直接 $\sigma^2 = npq = 3\cdot 1/4 \cdot 3/4 = 9/16$。
(b) $\mu = 2$，$E[X(X-1)] = 4\cdot 3\cdot 1/4 = 3$，$\sigma^2 = 3 + 2 - 4 = 1$。直接 $npq = 4\cdot 1/2\cdot 1/2 = 1$，一致。
重点讲解 ⭐ $E[X(X-1)]$ 的组合意义
为什么要先算 $E[X(X-1)]$？因为 $E[X(X-1)] = \sum x(x-1)\binom{n}{x}p^x q^{n-x}$，可以利用 $\binom{n}{x} = \frac{n!}{x!(n-x)!}$ 把 $x!$ 消掉： $$x(x-1)\binom{n}{x} = n(n-1)\binom{n-2}{x-2}$$ 于是 $E[X(X-1)] = n(n-1)p^2$。
用途：配合公式 $\sigma^2 = E[X(X-1)] + E(X) - [E(X)]^2$ 即可推出 $\mathrm{Var}(X) = npq$，绕过冗长的直接求和。这是 Hogg 教材反复强调的"捷径"。

HW2 2.3-4对任意 $X$（均值 $\mu$、方差 $\sigma^2$），求 $E\!\left[\frac{X-\mu}{\sigma}\right]$ 和 $E\!\left[\left(\frac{X-\mu}{\sigma}\right)^2\right]$

答案
$E\!\left[\frac{X-\mu}{\sigma}\right] = \frac{1}{\sigma}(E[X] - \mu) = 0$；
$E\!\left[\left(\frac{X-\mu}{\sigma}\right)^2\right] = \frac{1}{\sigma^2}E[(X-\mu)^2] = \frac{\sigma^2}{\sigma^2} = 1$
解析
标准化变量 $Z = (X-\mu)/\sigma$ 的一阶矩恒为 0、二阶矩恒为 1。这个结论等价于"$Z$ 必是零均值单位方差"，是后续 t 分布、χ² 分布推导的基石。

HW2 2.4-7单位正方形内的 2000 个随机点

从单位正方形 $\{(x,y): 0 \le x \le 1, 0 \le y \le 1\}$ 中独立随机取 2000 个点。$W$ = 落入 $A = \{(x,y): x^2+y^2<1\}$ 的点数（即四分之一单位圆）。
(a) $W$ 的分布？(b) 给出 $\mu, \sigma^2, \sigma$。(c) $E(W/500)$。
答案
每个点落入 $A$ 的概率 $p = \pi/4$（单位圆面积的 $1/4$）。
(a) $W \sim B(2000, \pi/4)$
(b) $\mu = 2000 \cdot \pi/4 = 500\pi \approx 1570.80$，$\sigma^2 = 2000 \cdot \frac{\pi}{4}\Big(1-\frac{\pi}{4}\Big) \approx 1119.78$，$\sigma \approx 33.46$
(c) $E(W/500) = \mu/500 = \pi \approx 3.14$
解析 ⭐
核心思路："几何概率 → 二项分布"映射。点是否落入 $A$ 是 Bernoulli 试验（$p$ = 区域面积 / 总面积 = 圆面积/正方形面积 = $\pi/4$），2000 个独立点 = 2000 次独立 Bernoulli 试验。
易错点：不要把 $W$ 误以为是 Poisson（虽然 $n$ 大、$p$ 小可以用泊松近似，但题目要求的是精确分布）。
延伸：本题是 Monte Carlo 估计 $\pi$ 的原型 —— 统计 $W/500$ 的实测值 × 4 就得到 $\pi$ 的估计。

四、题型 3 · 随机变量函数

核心方法

离散情形：$g(X)$ 的 PMF 通过 $h(z) = P(g(X)=z) = \sum_{x: g(x)=z} f(x)$。
连续情形：用 CDF 法 —— 求 $G(w) = P(g(X) \le w) = P(X \in g^{-1}((-\infty, w]))$，再求导。

HW2 2.2-5Example 2.2-1 中 $Z = X^3$ 的 PMF 与期望

设 $X$ 在 $\{1,2,3,4\}$ 上均匀（$f(x)=1/4$），令 $Z = X^3$。
(a) 求 $Z$ 的 PMF $h(z)$。(b) 求 $E(Z)$。(c) 若该青年每局收费 10 美元，每局平均净赢多少？
答案
(a) $Z$ 取值 $\{1, 8, 27, 64\}$，各概率 $1/4$。$h(z) = 1/4$，$z=1,8,27,64$；其他为 0。
(b) $E(Z) = (1+8+27+64)/4 = 100/4 = 25$ 美元
(c) 每局平均净赢 $= 25 - 10 = 15$ 美元
解析
观察：$g(x)=x^3$ 在 $\{1,2,3,4\}$ 上严格单调，因此是一一映射，$h(z) = f(x)/|g'(x)|$ 在离散情形简化为"取哪个 $x$ 的概率直接挪到 $z=x^3$ 上"。
重要：题目"若按均匀分布 $X$ 收费"场景下, $E(u(X))$ 的计算既可以走 PMF 转换（先求 $h(z)$ 再求和），也可以直接用 LOTUS (Law of the Unconscious Statistician)： $$E(u(X)) = \sum_x u(x)f(x) = \frac{1+8+27+64}{4} = 25$$ 两种方法结果一致。

HW3 3.1-5$Y \sim U(0,1)$，$W = a + (b-a)Y$ 的分布

$Y \sim U(0,1)$，$a < b$，$W = a + (b-a)Y$。求 (a) $W$ 的 CDF；(b) $W$ 的分布。
答案
(a) 对 $a \le w \le b$： $$F_W(w) = P(W \le w) = P\!\left(Y \le \frac{w-a}{b-a}\right) = \frac{w-a}{b-a}$$ 所以 $$F_W(w) = \begin{cases} 0, & w < a \\ \dfrac{w-a}{b-a}, & a \le w \le b \\ 1, & w > b \end{cases}$$ (b) 求导得 $f_W(w) = \dfrac{1}{b-a}$，$a < w < b$ —— 即 $W \sim U(a, b)$。
重点讲解 ⭐ CDF 法的标准范式
步骤：目标随机变量 $W$ → 把 $P(W \le w)$ 翻译成 $Y$ 的事件 → 利用 $Y$ 的已知 CDF → 用 $Y$ 的反函数 $g^{-1}$ 替换 → 求导得 PMF/PDF。
直觉：线性仿射变换 $W = a + (b-a)Y$ 把 $U(0,1)$ 的"区间"线性拉伸到 $(a, b)$，因此仍是均匀分布。这是 Monte Carlo 模拟的基础：用 $U(0,1)$ 生成任意 $U(a,b)$。

HW3 3.2-22Logistic → Uniform 变换

$X$ 服从 logistic 分布，$f(x) = \dfrac{e^{-x}}{(1+e^{-x})^2}$，$-\infty < x < \infty$。证明 $Y = \dfrac{1}{1+e^{-X}}$ 服从 $U(0,1)$。
证明
设 $G(y) = P(Y \le y) = P\!\left(\dfrac{1}{1+e^{-X}} \le y\right)$，其中 $0 < y < 1$。
当 $1/(1+e^{-X}) \le y$ 时，$1+e^{-X} \ge 1/y$，$e^{-X} \ge (1-y)/y$，$-X \ge \ln[(1-y)/y]$，$X \le \ln[y/(1-y)]$。
所以 $G(y) = P(X \le \ln[y/(1-y)]) = F_X(\ln[y/(1-y)])$。
计算 $F_X$：Logistic CDF 为 $F_X(x) = \dfrac{1}{1+e^{-x}}$，代入得： $$G(y) = \frac{1}{1+e^{-\ln[y/(1-y)]}} = \frac{1}{1+(1-y)/y} = \frac{y}{y + (1-y)} = y$$ 因此 $Y \sim U(0,1)$。$\blacksquare$
解析
方法：CDF 法的"反函数"形式：$Y = h(X) = \frac{1}{1+e^{-X}}$ 关于 $X$ 严格单调递增（$h'(x) > 0$），其反函数为 $X = \ln\frac{Y}{1-Y}$（logit 函数）。先解 $Y \le y$ 得 $X \le \ln\frac{y}{1-y}$，再代入 logistic CDF 即得。
延伸：这是 "Probability Integral Transform"（概率积分变换）的经典例子 —— 任何连续随机变量经自身 CDF 变换后都变 $U(0,1)$。此例反着用：从已知的 logistic 生成 $U(0,1)$。

HW3 3.2-3指数分布的无记忆性

$X \sim$ Exponential($\theta$)。证明 $P(X > x+y \mid X > x) = P(X > y)$ 对任意 $x>0$。
证明
$$P(X > x+y \mid X > x) = \frac{P(X > x+y)}{P(X > x)} = \frac{e^{-(x+y)/\theta}}{e^{-x/\theta}} = e^{-y/\theta} = P(X > y) \qquad \blacksquare$$
解析 ⭐
无记忆性的物理意义："已经等了 $x$ 分钟还没来"这一信息对未来等待时间的分布没有任何影响 —— 就像机器刚启动一样，剩余寿命分布与新机器完全相同。
重要事实：在连续分布中，只有Exponential 具有无记忆性。这是它被用于"寿命/排队"建模的根本原因。

HW3 3.2-7推导 Gamma($\alpha, \theta$) 的 MGF

Gamma($\alpha, \theta$) 的 pdf $f(x) = \dfrac{1}{\Gamma(\alpha)\theta^\alpha}x^{\alpha-1}e^{-x/\theta}$，$x>0$。求 $M(t) = E(e^{tX})$。
推导
$$M(t) = \int_0^\infty e^{tx} \frac{x^{\alpha-1}e^{-x/\theta}}{\Gamma(\alpha)\theta^\alpha}\,dx = \frac{1}{\Gamma(\alpha)\theta^\alpha}\int_0^\infty x^{\alpha-1}e^{-x(1/\theta - t)}\,dx$$ 要求 $1/\theta - t > 0$ 即 $t < 1/\theta$。令 $y = x(1-\theta t)/\theta$，则 $x = \theta y/(1-\theta t)$，$dx = \theta\,dy/(1-\theta t)$。代入： $$M(t) = \frac{1}{\Gamma(\alpha)\theta^\alpha} \cdot \frac{\theta^{\alpha}}{(1-\theta t)^\alpha} \int_0^\infty y^{\alpha-1}e^{-y}\,dy = \frac{\Gamma(\alpha)}{\Gamma(\alpha)} \cdot \frac{1}{(1-\theta t)^\alpha} = (1-\theta t)^{-\alpha}$$

HW4 3.2-9$M(t) = (1-7t)^{-20}$ —— Gamma(20, 7)

答案
对照 $(1-\theta t)^{-\alpha}$：$\alpha = 20$，$\theta = 7$。
pdf: $f(w) = \dfrac{1}{\Gamma(20)\cdot 7^{20}} w^{19}e^{-w/7}$，$w>0$。
$\mu = \alpha\theta = 140$，$\sigma^2 = \alpha\theta^2 = 20\cdot 49 = 980$。

(b) 每盒 100 袋，每天 1 袋 → $37.24 \times 100 = 3724$ 天 ≈ 10.2 年。
重点讲解 ⭐ Coupon Collector 套路

渐近：$H_n \approx \ln n + \gamma$，所以 $E(T) \approx n \ln n$。当 $n=12$，$n\ln n = 12\times 2.485 \approx 29.8$（仅粗估）。

统一写为 $\text{Profit}(X) = \min(1.5X - 0.5n,\ 6n - 5X)$。

HW5 4.2-5最小二乘的代数推导

用 $\partial K/\partial a = 0$ 和 $\partial K/\partial b = 0$ 推导最小二乘回归系数。
推导
$K(a,b) = E[(Y - a - bX)^2]$
$\dfrac{\partial K}{\partial a} = -2E(Y - a - bX) = 0 \Rightarrow E(Y) = a + bE(X)$
$\dfrac{\partial K}{\partial b} = -2E[X(Y - a - bX)] = 0 \Rightarrow E(XY) = aE(X) + bE(X^2)$
联立解：
由第一式 $a = \mu_Y - b\mu_X$，代入第二式：$E(XY) = (\mu_Y - b\mu_X)\mu_X + bE(X^2)$
$E(XY) - \mu_X \mu_Y = b[E(X^2) - \mu_X^2] = b\sigma_X^2$
所以 $b = \dfrac{E(XY) - \mu_X \mu_Y}{\sigma_X^2} = \dfrac{\mathrm{Cov}(X,Y)}{\sigma_X^2} = \rho \dfrac{\sigma_Y}{\sigma_X}$，$a = \mu_Y - b\mu_X$。$\blacksquare$
重点讲解 ⭐ 推导背后的几何
核心目标：在 $\{(a,b)\}$ 中找使"残差平方的期望"$E[(Y-a-bX)^2]$ 最小的点。
几何意义：最小二乘线是 $Y$ 在 $X$ 生成的子空间（$1$ 和 $X$ 张成的）上的正交投影。这与 Gram-Schmidt、PCA 思想一脉相承。
物理意义：$\rho$ 描述"线性拟合优度"，$\rho^2$ 是决定系数。

连续性修正：离散分布被连续分布近似时，$P(a \le X \le b) \approx P(a-0.5 < X < b+0.5)$，对结果修正明显（本题差 0.0124）。
三种方法对比：正态近似 0.2417（最接近精确 0.2293，差 0.0124），泊松 0.2196（差 0.0097），精确 0.2293。
结论：$np$ 适中时，正态近似 + 连续性修正 通常最准。

十六、题型 15 · 切比雪夫不等式 ⭐

核心公式

Chebyshev：$P(|X - \mu| \ge k\sigma) \le \dfrac{1}{k^2}$，等价于 $P(|X-\mu| < k\sigma) \ge 1 - \dfrac{1}{k^2}$。
无需知道分布！ 任何均值/方差有限的随机变量都满足。

HW6 5.8-3骰子的切比雪夫界

$X$ 骰子点数，$\mu=7/2, \sigma^2=35/12$。最大偏差 $5/2$。用 $k\sigma = 5/2$ 求 $k$，并用切比雪夫给 $P(|X-3.5|<2.5)$ 下界。
答案
$\sigma = \sqrt{35/12} = \sqrt{2.9167} \approx 1.708$。$k = (5/2)/\sigma = 2.5/1.708 \approx 1.464$。
切比雪夫：$P(|X - 3.5| < 2.5) \ge 1 - 1/k^2 = 1 - 1/2.143 = 1 - 0.4667 = 0.5333$。
(精确值 = 1，因为 $X \in \{1,...,6\}$ 全部落在 $(3.5 \pm 2.5)$ 内。)
解析 ⭐ 切比雪夫界 vs 精确值
切比雪夫的下界很松：0.5333 vs 实际 1.000。
原因：切比雪夫对所有分布都成立，必须考虑最坏情况（如双峰分布）。
若用正态近似（$X$ 接近均匀），$P(|X-3.5|<2.5) \approx 1$。
价值：切比雪夫无需知道分布，是"无信息下界"。

HW6 5.8-6样本均值的切比雪夫界

$\bar X$ 是 $n=15$ 的样本均值，$\mu=80, \sigma^2=60$。用切比雪夫求 $P(75 < \bar X < 85)$ 的下界。
答案
$E(\bar X) = 80$，$\mathrm{Var}(\bar X) = 60/15 = 4$，$\sigma_{\bar X} = 2$。
$P(75 < \bar X < 85) = P(|\bar X - 80| < 5) = P(|\bar X - 80| < 2.5 \sigma_{\bar X})$
由切比雪夫：$P(|\bar X - 80| < k\sigma_{\bar X}) \ge 1 - 1/k^2$，其中 $k = 2.5$。
下界 = $1 - 1/6.25 = 1 - 0.16 = 0.84$。
重点讲解 ⭐ 切比雪夫 + 抽样
关键观察：切比雪夫直接应用于 $\bar X$（不需要 CLT）。
与 CLT 对比：正态近似 $P(75 < \bar X < 85) = P(-2.5 < Z < 2.5) = 0.9876$，比切比雪夫的 0.84 紧很多。
但切比雪夫是精确下界，正态近似是"假设总体正态"后的近似。
一般规律：在不知道总体分布时，切比雪夫给的是"绝对下界"；已知正态时用正态近似（更紧）。

十七、题型 16 · CLT 证明

HW6 5.9-4$\chi^2(n)$ 的 CLT 极限

$Y \sim \chi^2(n)$。用 CLT 证明 $W = (Y - n)/\sqrt{2n}$ 极限分布是 $N(0,1)$。
证明
$Y$ 可以写成独立标准正态的平方和：$Y = Z_1^2 + Z_2^2 + \cdots + Z_n^2$，其中 $Z_i \sim N(0,1)$ 独立。
设 $X_i = Z_i^2$。则 $X_i$ 独立同分布。
$E(X_i) = E(Z_i^2) = 1$，$\mathrm{Var}(X_i) = E(Z_i^4) - 1 = 3 - 1 = 2$。
所以 $Y = \sum_{i=1}^n X_i$，$E(Y) = n$，$\mathrm{Var}(Y) = 2n$。
由 CLT：$\frac{Y - n}{\sqrt{2n}} = \frac{\sum X_i - n \cdot 1}{\sqrt{n \cdot 2}} \xrightarrow{d} N(0,1)$。
即 $W$ 的极限分布是 $N(0,1)$。$\blacksquare$
重点讲解 ⭐ 把"非独立和"转成"独立和"
核心思路：遇到"复杂随机变量"时，先拆成独立同分布之和：
- $\chi^2(n) = \sum_{i=1}^n Z_i^2$，$Z_i^2$ 独立
- Binomial = $\sum$ Bernoulli
- Poisson = $\lim$ Binomial
CLT 的标准形式：$\frac{\sum X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)$。把它套到 $\chi^2$ 上即可。
应用：大 $n$ 时 $\chi^2(n) \approx N(n, 2n)$，可查正态表近似 $\chi^2$ 临界值。
