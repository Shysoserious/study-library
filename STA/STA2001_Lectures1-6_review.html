Lecture 1 | Ch1 概率基础 Basics of Probability

导言：概率论与统计学 Probability & Statistics

📖概率论与统计学

概率论（Probability Theory）是研究随机现象的数学分支。它从给定的总体模型出发，演绎出样本的规律。

统计学（Statistics）是收集、分析、解释和呈现数据的方法论。它从观测到的样本出发，归纳推断总体的特征。

🔗概率论与统计学的互补关系
概率论 Probability统计学 Statistics
方向演绎 (Deductive)归纳 (Inductive)
从...出发总体 (Population) →样本 (Sample) →
推得...样本的性质总体的特征
例子已知硬币有偏(p=0.6)，求10次中7次正面的概率抛10次得7次正面，推断硬币是否有偏
💡形象理解

概率论像是"从原因推结果"：已知骰子各面概率 → 推断掷出特定组合的概率。

统计学像是"从结果推原因"：观测到掷出的结果 → 推断骰子是否公平。

两者互为逆问题（inverse problems），构成了随机数学的完整体系。

§1.1 概率的性质 Properties of Probability

基本概念：试验、样本空间与事件

📖试验、随机试验与样本空间

试验（Experiment）：任何可以观测结果的过程。例如：掷硬币、测量温度、记录寿命。

随机试验（Random Experiment）：在相同条件下重复进行，结果不确定且不可预测的试验。例如：掷骰子、明天股价的涨跌。

样本空间 $S$（Sample Space）：随机试验所有可能结果的集合。

事件 $A$（Event）：样本空间 $S$ 的一个子集。若试验结果落在 $A$ 中，称事件 $A$ 发生。

✎例子

掷一个六面骰子：

$S = \{1, 2, 3, 4, 5, 6\}$

$A = \{2, 4, 6\}$ 是事件"掷出偶数点"

$B = \{5, 6\}$ 是事件"掷出至少5点"

集合代数 Algebra of Sets

📖集合运算

并集（Union）：$A \cup B = \{x : x \in A \text{ 或 } x \in B\}$，事件 $A$ 或 $B$ 至少一个发生。

交集（Intersection）：$A \cap B = \{x : x \in A \text{ 且 } x \in B\}$，事件 $A$ 和 $B$ 同时发生。

补集（Complement）：$A' = \{x : x \notin A\}$，事件 $A$ 不发生。

📖特殊事件关系

互斥（Mutually Exclusive）：$A \cap B = \emptyset$，两个事件不可能同时发生。

穷尽（Exhaustive）：$A_1 \cup A_2 \cup \cdots \cup A_k = S$，事件覆盖了整个样本空间。

★集合运算定律

交换律（Commutative）：$A \cup B = B \cup A$，$A \cap B = B \cap A$

结合律（Associative）：$(A \cup B) \cup C = A \cup (B \cup C)$，$(A \cap B) \cap C = A \cap (B \cap C)$

分配律（Distributive）：

$$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$ $$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$

德摩根律（De Morgan's Law）：

$$(A \cup B)' = A' \cap B'$$ $$(A \cap B)' = A' \cup B'$$
德摩根律的口诀："并的补等于补的交"，"交的补等于补的并"。通俗理解："既不...也不..."。

概率公理 Probability Axioms (Kolmogorov)

★柯尔莫哥洛夫概率公理

设 $S$ 是样本空间，概率函数 $P$ 将 $S$ 的子集映射到 $[0, 1]$，满足：

公理 1（非负性）：$P(A) \ge 0$，对所有事件 $A$。

公理 2（规范性）：$P(S) = 1$，整个样本空间的概率为 1。

公理 3（可数可加性）：若 $A_1, A_2, \ldots$ 两两互斥（$A_i \cap A_j = \emptyset$，$i \neq j$），则：

$$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$$

概率的基本性质 Properties of Probability

★由公理推导的五个基本性质

性质 1：$P(\emptyset) = 0$

证明：$S = S \cup \emptyset \cup \emptyset \cup \cdots$，由公理 3：$1 = 1 + P(\emptyset) + \cdots$，故 $P(\emptyset) = 0$。

性质 2（有限可加性）：若 $A_1, \ldots, A_n$ 两两互斥，则 $P(\bigcup_{i=1}^n A_i) = \sum_{i=1}^n P(A_i)$

性质 3（补事件）：$P(A') = 1 - P(A)$

证明：$A \cup A' = S$ 且 $A \cap A' = \emptyset$，故 $P(S) = P(A) + P(A')$，即 $1 = P(A) + P(A')$。

性质 4（单调性）：若 $A \subseteq B$，则 $P(A) \le P(B)$

证明：$B = A \cup (B \setminus A)$ 且两项互斥，所以 $P(B) = P(A) + P(B \setminus A) \ge P(A)$。

性质 5（加法公式 / 容斥原理）：$P(A \cup B) = P(A) + P(B) - P(A \cap B)$

直观：$A$ 的面积 + $B$ 的面积 = 重叠部分被算了两次，所以要减去一次。

三事件推广：

$$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(A \cap B) - P(A \cap C) - P(B \cap C) + P(A \cap B \cap C)$$

§1.2 计数方法 Method of Enumeration

📖乘法原理 Multiplication Principle

若一个过程分为 $k$ 个步骤：第 1 步有 $n_1$ 种选择，第 2 步有 $n_2$ 种选择，...，第 $k$ 步有 $n_k$ 种选择，且各步选择相互独立，则总共有：

$$n_1 \times n_2 \times \cdots \times n_k$$

种不同的完成方式。

✎例：穿衣选择

有 3 件上衣，4 条裤子，2 双鞋。则不同的穿法有 $3 \times 4 \times 2 = 24$ 种。

排列 Permutation

📖排列的定义

从 $n$ 个不同对象中选取 $r$ 个并按顺序排列，方法数为：

$$_nP_r = n \times (n-1) \times \cdots \times (n-r+1) = \frac{n!}{(n-r)!}$$

特殊情况：$r = n$ 时（$n$ 个对象全排列）：$_nP_n = n! = n \times (n-1) \times \cdots \times 2 \times 1$

✎例：5人中选3人排队

从 5 人中选 3 人排成一列，方法数为 $_5P_3 = 5 \times 4 \times 3 = 60$ 种。

解释：第一个位置 5 人选，第二个位置 4 人选，第三个位置 3 人选。

组合 Combination

📖组合的定义

从 $n$ 个不同对象中选取 $r$ 个（不考虑顺序），方法数为：

$$\binom{n}{r} = _nC_r = \frac{n!}{r!(n-r)!}$$

称为二项式系数（binomial coefficient）。

💡排列与组合的关系

$$\binom{n}{r} = \frac{_nP_r}{r!}$$

排列先选 $r$ 个并排序（$_nP_r$），但如果在每种选法中忽略 $r!$ 种不同的内部排序方式，就得到组合数。

换句话说：$\binom{n}{r} \times r! = _nP_r$。先选 $r$ 个（组合），再对它们排序（$r!$），就得到排列。

✎例：5人中选3人的委员会

5 人中选出 3 人组成委员会，不区分职务（无序），方法数为 $\binom{5}{3} = \frac{5!}{3! \cdot 2!} = 10$ 种。

相比之下，如果区分主席、副主席、秘书（有序），就是 $_5P_3 = 60$ 种。

可区分排列 Distinguishable Permutation

📖有重复元素的排列

$n$ 个对象中有 $n_1$ 个同类（类型 1）、$n_2$ 个同类（类型 2）、...、$n_k$ 个同类（类型 $k$），且 $n_1 + n_2 + \cdots + n_k = n$。可区分的排列数为：

$$\frac{n!}{n_1! \; n_2! \; \cdots \; n_k!}$$
✎例：字母排列

"MISSISSIPPI" 有多少种不同的排列？

$n = 11$（总字母数），$M: 1$，$I: 4$，$S: 4$，$P: 2$

$$\text{排列数} = \frac{11!}{1! \times 4! \times 4! \times 2!} = 34650$$

Lecture 2 | 抽样与条件概率 Sampling & Conditional Probability

有序抽样与组合 Ordered Sample & Combination

有序抽样 Ordered Sample

📖两种抽样方式

有放回抽样（sampling with replacement）：从 $n$ 个对象中抽 $r$ 次，每次抽完放回。总共有：

$$n^r \text{ 种可能的有序样本}$$

解释：每次有 $n$ 种选择，共 $r$ 次，由乘法原理得 $n^r$。

无放回抽样（sampling without replacement）：从 $n$ 个对象中抽 $r$ 次，抽完不放回。总共有：

$$_nP_r = \frac{n!}{(n-r)!} \text{ 种可能的有序样本}$$

解释：第一次 $n$ 种，第二次 $n-1$ 种，...，第 $r$ 次 $n-r+1$ 种。

组合的推导 Derivation of Combination

💡从有序到无序

无放回抽样中，$r$ 个对象有 $_nP_r$ 种有序抽取方式。但每一个大小为 $r$ 的（无序）子集对应 $r!$ 种不同的有序排列。因此：

$$_nC_r = \binom{n}{r} = \frac{_nP_r}{r!} = \frac{n!}{r!(n-r)!}$$

这就是组合公式的"推导"：排列除以 $r!$。

★二项式定理

$$\boxed{(a + b)^n = \sum_{r=0}^{n} \binom{n}{r} a^r b^{n-r}}$$

因此 $\binom{n}{r}$ 也称为二项式系数。特殊情形：

$$\sum_{r=0}^n \binom{n}{r} = 2^n \quad (\text{取 } a = b = 1)$$ $$\sum_{r=0}^n (-1)^r \binom{n}{r} = 0 \quad (\text{取 } a = -1, b = 1)$$

可区分排列的推广 Distinguishable Permutation

📖两类对象的可区分排列

$n$ 个位置中选出 $r$ 个位置放置类型 A，其余 $n-r$ 个位置放置类型 B。

选位置的方法数为 $\binom{n}{r}$。这等同于 $n$ 个对象中 $r$ 个相同（类型 A）、$n-r$ 个相同（类型 B）的可区分排列：

$$\frac{n!}{r! (n-r)!} = \binom{n}{r}$$
📖$m$ 类对象的可区分排列

$n$ 个对象分为 $m$ 类，第 $i$ 类有 $n_i$ 个同类对象（$\sum n_i = n$），可区分的排列数为：

$$\frac{n!}{n_1! \cdot n_2! \cdot \cdots \cdot n_m!}$$

这等价于多步组合：先选 $n_1$ 个位置给类型 1（$\binom{n}{n_1}$），再从剩下的选 $n_2$ 个位置给类型 2（$\binom{n-n_1}{n_2}$），以此类推，最终积恰好化简为上式。

§1.3 条件概率 Conditional Probability

📖条件概率的定义

设 $A$ 和 $B$ 是事件，且 $P(B) > 0$。在事件 $B$ 已发生的条件下，事件 $A$ 发生的条件概率（conditional probability）定义为：

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$

直观理解：条件概率是将样本空间从 $S$"缩小"到 $B$。分母 $P(B)$ 是新的"单位 1"，分子 $P(A \cap B)$ 是在新空间中 $A$ 也发生的部分。

✎郁金香球茎例子 (Tulip Bulb)

一个花房中，种球来自两个供应商：

供应商红色花 (R)黄色花 (Y)合计
A302050
B153550
合计4555100

随机选取一个球茎：

$P(\text{红色} \mid A) = \dfrac{P(R \cap A)}{P(A)} = \dfrac{30/100}{50/100} = \dfrac{30}{50} = 0.6$

$P(\text{红色} \mid B) = \dfrac{P(R \cap B)}{P(B)} = \dfrac{15/100}{50/100} = \dfrac{15}{50} = 0.3$

结论：给定供应商 A，红色花的概率是 0.6（供应商 A 的种球更偏向红色花）。

★条件概率满足概率公理

固定 $B$（$P(B) > 0$），函数 $P(\cdot \mid B)$ 也满足柯尔莫哥洛夫的三条公理：

(1) $P(A \mid B) \ge 0$（非负性）

(2) $P(S \mid B) = \frac{P(S \cap B)}{P(B)} = \frac{P(B)}{P(B)} = 1$（规范性）

(3) 若 $A_1, A_2, \ldots$ 两两互斥，则 $P(\bigcup A_i \mid B) = \sum P(A_i \mid B)$（可数可加性）

这意味着所有从概率公理推导出的性质（如 $P(A' \mid B) = 1 - P(A \mid B)$，$P(\emptyset \mid B) = 0$ 等）对于条件概率也自动成立。

乘法法则 Multiplication Rule

★乘法法则

由条件概率的定义 $P(A \mid B) = \frac{P(A \cap B)}{P(B)}$，两边同乘 $P(B)$：

$$P(A \cap B) = P(A) \cdot P(B \mid A) = P(B) \cdot P(A \mid B)$$

三个事件的推广：

$$P(A \cap B \cap C) = P(A) \cdot P(B \mid A) \cdot P(C \mid A \cap B)$$

一般情形（链式法则）：

$$P(A_1 \cap A_2 \cap \cdots \cap A_n) = P(A_1) \cdot P(A_2 \mid A_1) \cdot P(A_3 \mid A_1 \cap A_2) \cdots P(A_n \mid A_1 \cap \cdots \cap A_{n-1})$$
✎例：无放回抽牌

一副 52 张扑克牌，无放回地抽 3 张，求三张都是 A 的概率。

$P(\text{三张A}) = \frac{4}{52} \times \frac{3}{51} \times \frac{2}{50} = \frac{24}{132600} = \frac{1}{5525}$

也可以写成：$P(\text{三张A}) = \frac{\binom{4}{3}}{\binom{52}{3}} = \frac{4}{22100} = \frac{1}{5525}$

§1.4 独立事件 Independent Events

📖独立事件的定义

事件 $A$ 和 $B$ 称为独立（independent），当且仅当：

$$P(A \cap B) = P(A) P(B)$$

否则称为不独立（dependent）。

💡独立 vs 互斥
独立 Independent互斥 Mutually Exclusive
条件$P(A \cap B) = P(A)P(B)$$A \cap B = \emptyset$
含义A 发生不影响 B 的概率A 发生则 B 不可能发生
交集不为空（一般有重叠）为空
与条件概率的关系$P(A \mid B) = P(A)$$P(A \mid B) = 0$
除非 $P(A)=0$ 或 $P(B)=0$，否则互斥事件一定是不独立的（因为如果 B 发生了，A 一定不发生）。
📖两两独立 vs 相互独立

两两独立（pairwise independence）：$n$ 个事件中任意两个都满足 $P(A_i \cap A_j) = P(A_i)P(A_j)$。

相互独立（mutual independence）：对任意子集 $\{i_1, \ldots, i_k\}$（$2 \le k \le n$）都有 $P(A_{i_1} \cap \cdots \cap A_{i_k}) = P(A_{i_1}) \cdots P(A_{i_k})$。

相互独立 ⇒ 两两独立，但反过来不一定成立！教师可能会举一个两两独立但不相互独立的反例。
★定理 1.4-1：独立性的"对偶"关系

若 $A$ 和 $B$ 独立，则以下各对也独立：

$$A \text{ 和 } B' \text{ 独立}$$ $$A' \text{ 和 } B \text{ 独立}$$ $$A' \text{ 和 } B' \text{ 独立}$$

证明思路：$P(A \cap B') = P(A) - P(A \cap B) = P(A) - P(A)P(B) = P(A)(1 - P(B)) = P(A)P(B')$

直观：如果 A 和 B 独立，那么知道 B 没发生不影响 A 的概率——因为知道 B 发生了也不影响。

✎例：掷两个骰子

掷两个公平六面骰子。设 $A =$ "第一个骰子为偶数"，$B =$ "两个骰子之和为 7"。

$P(A) = \frac{3}{6} = \frac{1}{2}$

$P(B) = \frac{6}{36} = \frac{1}{6}$（和为 7 的组合：(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)）

$P(A \cap B) = P(\text{第一个偶数且和为7}) = \frac{3}{36} = \frac{1}{12}$（(2,5),(4,3),(6,1)）

$P(A)P(B) = \frac{1}{2} \times \frac{1}{6} = \frac{1}{12} = P(A \cap B)$ ⇒ A 和 B 独立！

§1.5 贝叶斯定理 Bayes' Theorem

全概率公式 Total Probability Formula

★全概率公式

设 $B_1, B_2, \ldots, B_k$ 是样本空间 $S$ 的一个划分（partition），即：

(1) $B_i \cap B_j = \emptyset$（$i \neq j$），两两互斥

(2) $B_1 \cup B_2 \cup \cdots \cup B_k = S$，穷尽所有可能

(3) $P(B_i) > 0$，$i = 1, 2, \ldots, k$

则对任意事件 $A$：

$$P(A) = \sum_{i=1}^{k} P(B_i) \cdot P(A \mid B_i)$$

直觉：要求 $A$ 的概率，可以按"原因" $B_i$ 分类，分别算每种原因下 $A$ 发生的概率，再按各原因的概率加权求和。

贝叶斯定理 Bayes' Theorem

★贝叶斯定理

设 $B_1, \ldots, B_k$ 是 $S$ 的一个划分，$A$ 是任意事件（$P(A) > 0$），则：

$$P(B_j \mid A) = \frac{P(B_j) \cdot P(A \mid B_j)}{\sum_{i=1}^{k} P(B_i) \cdot P(A \mid B_i)}$$

其中：

$P(B_j)$ 称为先验概率（prior probability）——在看到 $A$ 发生之前对 $B_j$ 的信念。

$P(B_j \mid A)$ 称为后验概率（posterior probability）——在看到 $A$ 发生之后对 $B_j$ 的更新信念。

💡贝叶斯定理的直觉

$$\text{后验} = \frac{\text{先验} \times \text{似然}}{\text{归一化常数}}$$

看到新证据 $A$ 后，我们把每个原因 $B_j$ 的概率从 $P(B_j)$（先验）更新到 $P(B_j \mid A)$（后验）。更新的权重是 $P(A \mid B_j)$（该原因导致 $A$ 的可能性）。

✎碗与筹码例子 (Bowl-Chip Example)

有两个碗：

碗 B1：3 个红筹码，7 个蓝筹码（共 10 个）

碗 B2：6 个红筹码，4 个蓝筹码（共 10 个）

随机选一个碗（先验：$P(B_1) = P(B_2) = 0.5$），然后从该碗中随机抽一个筹码。

$P(R \mid B_1) = 0.3$，$P(R \mid B_2) = 0.6$

全概率：$P(R) = 0.5 \times 0.3 + 0.5 \times 0.6 = 0.45$

如果抽到红色筹码，来自碗 B1 的概率（贝叶斯）：

$$P(B_1 \mid R) = \frac{P(B_1)P(R \mid B_1)}{P(R)} = \frac{0.5 \times 0.3}{0.45} = \frac{0.15}{0.45} = \frac{1}{3}$$

抽到红色后，来自 B1 的概率从 50% 下降到约 33%（因为 B2 有更多红色筹码）。

§2.1 随机变量 Random Variable

📖随机变量的定义

给定一个样本空间为 $S$ 的随机试验，函数 $X: S \to \mathbb{R}$ 将每个样本点 $s \in S$ 映射到一个实数 $X(s) = x$，称为随机变量（Random Variable, RV）。

通俗理解：随机变量不是"变量"，而是一个函数——它把随机试验的每一个可能结果转化为一个数字。

📖离散随机变量 Discrete Random Variable

$X$ 的取值范围（range）记为 $S$（或 $S_X$）：

$$S = \{x : x = X(s), s \in S_{\text{原}}\}$$

若 $S$ 是有限集或可数无限集（$\mathbb{N}, \mathbb{Z}$ 等），则 $X$ 称为离散随机变量（discrete RV）。

💡RV 定义了新的随机试验

如果 $X$ 是一对一的（one-to-one），则新试验与旧试验等价。

如果 $X$ 不是一对一的，则新试验是旧试验的简化版本（多个旧结果映射到同一个数字，丢失了一些信息）。

概率质量函数 Probability Mass Function (pmf)

📖概率质量函数 pmf

设 $X$ 是离散随机变量，取值范围为 $S$。函数 $f(x): S \to (0, 1]$ 称为 probability mass function（pmf），若满足三个条件：

(1) $f(x) > 0$，对所有 $x \in S$（概率为正）

(2) $\sum_{x \in S} f(x) = 1$（概率之和为 1）

(3) $P(X \in A) = \sum_{x \in A} f(x)$，对所有 $A \subseteq S$（事件概率 = 对应值概率之和）

$f(x)$ 的定义域可以扩展到 $\mathbb{R}$，只需令 $f(x) = 0$ 对所有 $x \notin S$ 即可。
📖支撑集 Support

支撑集（support）即 $S = \{x : f(x) > 0\}$，是 pmf 取值严格为正的 $x$ 的集合。

✎均匀分布 Uniform Distribution 的 pmf

$S = \{1, 2, \ldots, m\}$，$f(x) = \frac{1}{m}$，对所有 $x \in S$。

验证：$\sum_{x=1}^m f(x) = m \times \frac{1}{m} = 1$，满足 pmf 条件。

例如：公平骰子 $f(x) = 1/6$，$x = 1, \ldots, 6$。

pmf 的图形表示

📖线形图与概率直方图

线形图（Line Graph）：在每个 $x$ 处画一条垂直线段，高度等于 $f(x)$。

概率直方图（Probability Histogram）：在每个 $x$ 处画一个宽度为 1 的矩形，面积等于 $f(x)$（即高度 = $f(x)$）。所有矩形面积之和 = 1。

累积分布函数 Cumulative Distribution Function (cdf)

📖累积分布函数 cdf

函数 $F(x): \mathbb{R} \to [0, 1]$ 定义为：

$$F(x) = P(X \le x) = \sum_{x' \le x,\; x' \in S} f(x')$$

称为累积分布函数（cdf）。它表示随机变量取值不超过 $x$ 的概率。

★cdf 的性质

(1) $F(x)$ 是非减函数（单调递增）

(2) $\lim_{x \to -\infty} F(x) = 0$，$\lim_{x \to +\infty} F(x) = 1$

(3) $F(x)$ 是右连续的

(4) $P(a < X \le b) = F(b) - F(a)$

对于离散 RV，$F(x)$ 是一个"阶梯函数"（step function），在 $x \in S$ 处跳跃，跳跃的高度等于 $f(x)$。

§2.2 数学期望 Mathematical Expectation

📖数学期望的定义

设 $X$ 是离散随机变量，取值范围为 $S$，pmf 为 $f(x)$。若 $\sum_{x \in S} g(x)f(x)$ 存在，则称其为 $g(X)$ 的数学期望（mathematical expectation / expected value），记为：

$$E[g(X)] = \sum_{x \in S} g(x) f(x)$$

一句话：期望 = 每个可能取值 $\times$ 该取值的概率，全部加起来。如果 $g(X) = X$，就是随机变量本身的期望（即"平均值"）。

★定理 2.2-1：期望的线性性质

设 $a_1, a_2, \ldots, a_k$ 为常数，则：

$$E\left[\sum_{i=1}^{k} a_i g_i(X)\right] = \sum_{i=1}^{k} a_i E[g_i(X)]$$

特例：$E[aX + b] = aE[X] + b$

证明：由定义直接展开求和即可。因为求和是线性的，常数系数可以提到求和号外面。

★重要例题：最小化 $E[(X-b)^2]$

求 $b$ 使得 $E[(X-b)^2]$ 最小。

解：

$$\begin{aligned} E[(X-b)^2] &= E[X^2 - 2bX + b^2] \\ &= E[X^2] - 2bE[X] + b^2 \end{aligned}$$

将上式视为 $b$ 的二次函数 $h(b)$，求导令导数为零：

$h'(b) = -2E[X] + 2b = 0 \Rightarrow b = E[X]$

二阶导数 $h''(b) = 2 > 0$，确为最小值。

$$b = E[X] \text{ 时，}E[(X-b)^2] \text{ 取最小值 } \mathrm{Var}(X)$$

一个重要结论：均值 $E[X]$ 是使得平方误差期望最小的预测值——这就是为什么我们把均值当作"中心"。

均值与方差 Mean & Variance

📖均值 Mean

$g(X) = X$ 时，定义均值（也即期望值）：

$$\mu = E[X] = \sum_{x \in S} x\, f(x)$$

直觉：$E[X]$ 是 $X$ 在长期重复试验中的平均取值，不是某一次的值。

📖方差 Variance

$g(X) = (X - E[X])^2$ 时，定义方差：

$$\sigma^2 = \mathrm{Var}(X) = E\big[(X - E[X])^2\big] = \sum_{x \in S} (x - \mu)^2 f(x)$$

计算方差最常用公式（展开化简）：

$$\mathrm{Var}(X) = E[X^2] - (E[X])^2$$
📖标准差 Standard Deviation

$$\sigma = \sqrt{\mathrm{Var}(X)}$$

方差的单位是原始单位的平方，标准差与原始数据单位一致，更直观。

★方差的性质
$$\mathrm{Var}(c) = 0, \qquad \mathrm{Var}(cX) = c^2 \mathrm{Var}(X)$$

常数的方差为零——常数没有波动。缩放 $c$ 倍，方差缩放 $c^2$ 倍。

例：六面骰子的均值与方差

✎掷一个公平六面骰子

$S = \{1,2,3,4,5,6\}$，$f(x) = \frac{1}{6}$。

$$E[X] = \frac{1}{6} \sum_{i=1}^{6} i = \frac{21}{6} = 3.5$$ $$E[X^2] = \frac{1}{6} \sum_{i=1}^{6} i^2 = \frac{91}{6}$$ $$\mathrm{Var}(X) = \frac{91}{6} - \left(\frac{7}{2}\right)^2 = \frac{35}{12} \approx 2.92$$
期望值 3.5 不是可能的取值——期望值不必是可能的观测值。

矩母函数 Moment Generating Function (mgf)

📖定义：矩母函数 mgf

设 $X$ 为离散随机变量，取值范围为 $S$，pmf 为 $f(x)$。若存在 $h > 0$ 使得：

$$M(t) = E[e^{tX}] = \sum_{x \in S} e^{tx} f(x)$$

在 $(-h, h)$ 内存在，则 $M(t)$ 称为 $X$ 的矩母函数（moment generating function）。

💡mgf 的设计思想

把所有的矩（$E[X], E[X^2], E[X^3], \ldots$）一次性打包进一个函数 $M(t)$。想要哪个矩，对这个函数求导然后代入 $t = 0$ 即可。

像是一个"快递箱"：$M(t)$ 里面装着所有阶矩，求 $r$ 次导数就是打开第 $r$ 个包裹。

★核心原理：逐次求导生成矩

一阶导数：$M'(t) = \sum x e^{tx} f(x)$，代入 $t=0$：

$$M'(0) = \sum x f(x) = E[X]$$

二阶导数：$M''(t) = \sum x^2 e^{tx} f(x)$，$M''(0) = E[X^2]$

第 $r$ 阶：

$$M^{(r)}(0) = \sum_{x} x^r f(x) = E[X^r]$$
矩母函数工作原理：对 $M(t)$ 求 $r$ 次导后代入 $t=0$，即得第 $r$ 阶矩 $E[X^r]$
★mgf 的三个关键性质

性质 1：$M(0) = \sum f(x) = 1$（所有概率之和为 1）

性质 2（唯一性）：若两个随机变量有相同的 mgf，则它们有相同的概率分布（相同的 pmf）。mgf 完全刻画了一个分布。

性质 3（生成矩）：$M^{(r)}(0) = E[X^r]$

✎几何分布 $X \sim \text{Geometric}(p)$ 的均值与方差

pmf：$f(x) = q^{x-1} p,\; x = 1, 2, 3, \ldots$（$q = 1-p$）

Step 1：求 mgf

$$M(t) = \sum_{x=1}^{\infty} e^{tx} q^{x-1}p = \frac{p}{q} \sum_{x=1}^{\infty} (q e^t)^x = \frac{p e^t}{1 - q e^t}, \quad t < -\ln q$$

§2.4 二项分布 Binomial Distribution

伯努利试验与伯努利分布

📖伯努利试验 Bernoulli Experiment

结果只能分为互斥且穷尽的两类的随机试验：成功 (Success) / 失败 (Failure)。

定义 $X(\text{成功}) = 1$，$X(\text{失败}) = 0$。取值范围 $S = \{0, 1\}$。

📖伯努利分布 Bernoulli Distribution

pmf：

$$f(x) = p^x (1-p)^{1-x}, \quad x \in \{0, 1\}$$

$f(1) = p$（成功概率），$f(0) = 1-p$（失败概率）。

期望、方差、mgf：

$$E[X] = p, \quad \mathrm{Var}(X) = p(1-p), \quad M(t) = (1-p) + p e^t$$

n 重伯努利试验与随机样本

📖n 重伯努利试验 n Bernoulli Trials

一个伯努利试验被独立地重复 $n$ 次，每次成功概率 $p$ 保持不变。两个条件：(1) 独立性，(2) 同分布。

📖随机样本 Random Sample

令 $X_i$ 表示第 $i$ 次试验的伯努利 RV。观测到的一串 $n$ 个 0/1 序列（如 $(0,0,0,1,0)$）称为来自伯努利分布的容量为 $n$ 的随机样本。

二项分布的完整推导

💡核心问题

$n$ 重伯努利试验中，不关心具体是"第几次"成功，只关心成功了"几次"。

$X = n$ 次试验中成功的总次数，$S = \{0, 1, 2, \ldots, n\}$。$X$ 的分布就是二项分布。

★推导二项分布 pmf

设每次试验成功概率为 $p$。

Step 1（选位置）：在 $n$ 次试验中选出 $x$ 个位置作为"成功"，共 $\binom{n}{x}$ 种选法。

Step 2（算概率）：任何一个特定序列（$x$ 次成功，$n-x$ 次失败）的概率为 $p^x (1-p)^{n-x}$。

Step 3（乘起来）：

$$f(x) = P(X = x) = \binom{n}{x} p^x (1-p)^{n-x}, \quad x = 0, 1, 2, \ldots, n$$

记作 $X \sim b(n, p)$。$n$ 和 $p$ 是分布的参数（parameters）。

🔗为什么叫"二项分布"？

$$\sum_{x=0}^n \binom{n}{x} p^x (1-p)^{n-x} = (p + (1-p))^n = 1^n = 1$$

pmf 的各项正是 $(p + (1-p))^n$ 的二项式展开中的各项，因此得名。

从伯努利试验到二项分布：伯努利 -> n次独立重复 -> 数成功次数 -> 二项分布
✎彩票例子

$X \sim b(n=5, p=0.2)$，买 5 张彩票，恰好中 2 张的概率：

$$P(X=2) = \binom{5}{2} (0.2)^2 (0.8)^3 = 10 \times 0.04 \times 0.512 = 0.2048$$

恰好中 2 张的概率为 20.48%。

相比于特定序列 $(0,0,1,0,1)$ 的概率 $p^2(1-p)^3 = 0.02048$，恰好中 2 张的概率大了 10 倍——因为 $\binom{5}{2}=10$ 种方式。

二项分布的 mgf 推导 Mgf of Binomial Distribution

★二项分布 $X \sim b(n,p)$ 的 mgf

pmf：

$$f(x) = \binom{n}{x} p^x (1-p)^{n-x}, \quad x = 0, 1, \ldots, n$$

代入 mgf 定义：

$$M(t) = E[e^{tX}] = \sum_{x=0}^{n} e^{tx} \cdot \binom{n}{x} p^x (1-p)^{n-x}$$

把 $e^{tx}$ 和 $p^x$ 拼在一起，写成 $(p e^t)^x$：

$$M(t) = \sum_{x=0}^{n} \binom{n}{x} (p e^t)^x (1-p)^{n-x}$$

套二项式定理 $(a+b)^n = \sum_{x=0}^{n} \binom{n}{x} a^x b^{n-x}$：

令 $a = p e^t$，$b = 1-p$：

$$M(t) = \big[(1-p) + p e^t\big]^n$$
★从 mgf 求期望和方差

一阶导数（链式法则）：

$$M'(t) = n\big[(1-p) + p e^t\big]^{n-1} \cdot p e^t$$

代入 $t=0$，注意 $(1-p)+p = 1$：

$$M'(0) = n \cdot 1^{n-1} \cdot p = np = E[X]$$

二阶导数（乘积法则）：

$$M''(t) = n(n-1)\big[(1-p) + p e^t\big]^{n-2} (p e^t)^2 + n\big[(1-p) + p e^t\big]^{n-1} p e^t$$

代入 $t=0$：

$$M''(0) = n(n-1)p^2 + np = E[X^2]$$

方差：

$$\mathrm{Var}(X) = E[X^2] - (E[X])^2 = n(n-1)p^2 + np - n^2p^2 = np(1-p)$$
🔗两个视角的统一

视角一（二项式定理）：上面刚推完的，直接套 $(a+b)^n$ 展开。

视角二（独立和）：二项分布是 $n$ 个独立伯努利之和：$X = X_1 + X_2 + \cdots + X_n$，每个 $X_i \sim \text{Bernoulli}(p)$。

伯努利的 mgf 是 $(1-p) + p e^t$，独立和的 mgf = mgf 的乘积，所以：

$$M_X(t) = \big[M_{X_1}(t)\big]^n = \big[(1-p) + p e^t\big]^n$$

两种方法结果一致。视角二还解释了：$E[X] = n \cdot E[X_1] = np$，$\mathrm{Var}(X) = n \cdot \mathrm{Var}(X_1) = np(1-p)$。

💡特例：$n=1$ 时退化为伯努利分布

当 $n=1$ 时，$M(t) = (1-p) + p e^t$，正是伯努利分布的 mgf。二项分布 $b(n,p)$ 包含了伯努利 $b(1,p)$ 作为特例。

Lecture 6 | 负二项分布与泊松分布 Negative Binomial & Poisson

§2.5 负二项分布 Negative Binomial Distribution

动机：试到成功为止

💡从几何到负二项

回顾：几何分布问的是"试到第 1 次成功为止，需要多少次？"

负二项分布问的是推广的问题："试到第 $r$ 次成功为止，需要多少次？"

$r = 1$ 时，负二项分布退化为几何分布。

📖负二项分布的设定

进行一系列独立伯努利试验，每次成功概率为 $p$（失败概率 $q = 1-p$）。

$X =$ 直到获得第 $r$ 次成功所需的试验总次数。

$X$ 的取值范围：$S = \{r, r+1, r+2, \ldots\}$（至少需要 $r$ 次才能获得 $r$ 次成功）。

负二项分布 pmf 的推导

★推导 pmf

$X = x$ 意味着：前 $x-1$ 次试验中恰好有 $r-1$ 次成功，且第 $x$ 次试验一定是成功。

Step 1：前 $x-1$ 次中恰好有 $r-1$ 次成功的概率：

$$\binom{x-1}{r-1} p^{r-1} q^{(x-1)-(r-1)} = \binom{x-1}{r-1} p^{r-1} q^{x-r}$$

Step 2：第 $x$ 次试验成功（概率 $p$）。由独立性，总概率为两者乘积：

$$f(x) = P(X = x) = \binom{x-1}{r-1} p^{r} q^{x-r}, \quad x = r, r+1, r+2, \ldots$$

$X$ 服从负二项分布（negative binomial distribution），记作 $X \sim \text{NB}(r, p)$。

💡理解"负二项"这个名字

$$\binom{x-1}{r-1} = \binom{x-1}{x-r} = (-1)^{x-r} \binom{-r}{x-r}$$

系数 $\binom{-r}{x-r}$ 涉及"负的"二项式系数，因此得名。

🔗几何分布作为特例（$r = 1$）

当 $r = 1$ 时：

$$f(x) = \binom{x-1}{0} p^1 q^{x-1} = p q^{x-1}, \quad x = 1, 2, 3, \ldots$$

这就是几何分布的 pmf：试到首次成功为止的次数。

负二项分布的矩母函数、均值和方差

★负二项分布的 mgf

$$M(t) = \left(\frac{p e^t}{1 - q e^t}\right)^r, \quad t < -\ln q$$

推导思路：负二项分布中 $X = Y_1 + Y_2 + \cdots + Y_r$，其中 $Y_i \sim \text{Geometric}(p)$ 且相互独立。

因此 $M_X(t) = [M_Y(t)]^r = \left(\frac{p e^t}{1 - q e^t}\right)^r$。

★均值和方差

由 $X = Y_1 + \cdots + Y_r$（独立同几何分布的和）：

$$E[X] = r \cdot E[Y_i] = \frac{r}{p}$$ $$\mathrm{Var}(X) = r \cdot \mathrm{Var}(Y_i) = \frac{r q}{p^2} = \frac{r(1-p)}{p^2}$$

特例 $r=1$几何分布：$E[X]=1/p$, $\mathrm{Var}=q/p^2$

§2.6 泊松分布 Poisson Distribution

APP：近似泊松过程

📖APP 的定义 Approximate Poisson Process

考虑一段时间（或区域）内某随机事件发生的次数。假设：

(1) 在互不重叠的时间区间内，事件发生次数相互独立。

(2) 在一个充分短的时间区间 $\Delta t$ 内，事件发生一次的概率约为 $\lambda \Delta t$（$\lambda > 0$ 是常数，称为强度 / rate）。

(3) 在 $\Delta t$ 内，事件发生两次或更多的概率相对于 $\Delta t$ 可忽略（即 $o(\Delta t)$）。

满足以上三条的随机过程称为近似泊松过程（APP）。

从二项分布推导泊松分布

★泊松作为二项分布的极限

将时间区间 $[0, t]$ 分割为 $n$ 个等长子区间（每个长度 $t/n$）。令 $n \to \infty$。

每个子区间内事件发生一次的概率 $\approx \lambda \cdot \frac{t}{n} = p_n$。

$X =$ 在 $n$ 个子区间中事件发生的总次数。每个子区间近似为一个伯努利试验，因此 $X \sim b(n, p_n)$。

极限过程（$n \to \infty$）：

$$P(X = x) = \binom{n}{x} p_n^x (1-p_n)^{n-x}, \quad p_n = \frac{\lambda t}{n}$$

$$\begin{aligned} P(X = x) &= \frac{n!}{x!(n-x)!} \left(\frac{\lambda t}{n}\right)^x \left(1 - \frac{\lambda t}{n}\right)^{n-x} \\ &= \frac{n(n-1)\cdots(n-x+1)}{n^x} \cdot \frac{(\lambda t)^x}{x!} \cdot \left(1 - \frac{\lambda t}{n}\right)^n \left(1 - \frac{\lambda t}{n}\right)^{-x} \end{aligned}$$

当 $n \to \infty$：

$\frac{n(n-1)\cdots(n-x+1)}{n^x} \to 1$

$(1 - \frac{\lambda t}{n})^n \to e^{-\lambda t}$（重要极限 $e = \lim_{n\to\infty}(1+1/n)^n$）

$(1 - \frac{\lambda t}{n})^{-x} \to 1$

$$P(X = x) = \frac{(\lambda t)^x e^{-\lambda t}}{x!}, \quad x = 0, 1, 2, \ldots$$
📖泊松分布的定义

若随机变量 $X$ 的 pmf 为：

$$f(x) = \frac{\lambda^x e^{-\lambda}}{x!}, \quad x = 0, 1, 2, \ldots$$

其中 $\lambda > 0$ 是参数（单位时间/区域内事件发生的平均次数），则称 $X$ 服从泊松分布（Poisson distribution），记作 $X \sim \text{Poisson}(\lambda)$。

（上式中把 $\lambda t$ 简记为 $\lambda$，即固定时间区间后的参数。）

💡泊松分布适用于哪些场景？

在固定时间或空间内"稀有事件"的发生次数：

• 一小时内的来电次数

• 一天内交通事故数

• 一页书上的印刷错误数

• 一块材料上的瑕疵数

只要事件独立且发生率恒定，泊松分布就是合适的模型。

泊松分布的矩母函数、均值和方差

★泊松分布的 mgf

$$M(t) = E[e^{tX}] = \sum_{x=0}^{\infty} e^{tx} \cdot \frac{\lambda^x e^{-\lambda}}{x!} = e^{-\lambda} \sum_{x=0}^{\infty} \frac{(\lambda e^t)^x}{x!}$$

回忆指数函数的泰勒展开：$\sum_{x=0}^{\infty} \frac{a^x}{x!} = e^a$

取 $a = \lambda e^t$：

$$M(t) = e^{-\lambda} \cdot e^{\lambda e^t} = e^{\lambda(e^t - 1)}$$
★均值和方差的推导

求 $E[X]$：

$M'(t) = e^{\lambda(e^t-1)} \cdot \lambda e^t = \lambda e^t e^{\lambda(e^t-1)}$

$$M'(0) = \lambda e^0 \cdot e^{\lambda(1-1)} = \lambda \cdot 1 \cdot 1 = \lambda = E[X]$$

泊松分布的均值就是参数 $\lambda$！

求 $\mathrm{Var}(X)$：

$M''(t) = \lambda e^t e^{\lambda(e^t-1)} (1 + \lambda e^t)$

$M''(0) = \lambda \cdot 1 \cdot 1 \cdot (1 + \lambda) = \lambda(\lambda + 1) = E[X^2]$

$$\mathrm{Var}(X) = E[X^2] - (E[X])^2 = \lambda(\lambda+1) - \lambda^2 = \lambda$$

泊松分布的均值和方差相等，都等于 $\lambda$！这是一个非常重要的性质。

例题：电话呼叫

✎电话呼叫次数

某呼叫中心平均每小时接到 3 通电话。假设通话次数服从泊松分布。求一小时内恰好接到 5 通电话的概率。

$X \sim \text{Poisson}(\lambda = 3)$

$$P(X = 5) = \frac{3^5 e^{-3}}{5!} = \frac{243 \times e^{-3}}{120} = \frac{243 \times 0.0498}{120} \approx 0.1008$$

一小时内恰好 5 通电话的概率约为 10.08%。

⚠Lecture 6 常见易错点

1. 负二项 vs 二项：二项固定试验次数随机成功数，负二项固定成功数随机试验次数！

2. 负二项 pmf 中的组合数：是 $\binom{x-1}{r-1}$，不是 $\binom{x}{r}$。因为最后一次试验一定是成功。

3. 泊松的均值和方差相等：$E[X] = \mathrm{Var}(X) = \lambda$，这是泊松的"名片"特征。

4. 泊松是二项(大n小p)的极限：$n \to \infty$，$p \to 0$，但 $np = \lambda$ 保持恒定。

5. mgf 推导中要用到 $e^a = \sum a^x/x!$：泊松 mgf 的推导依赖于指数函数的泰勒展开。

6. 极限公式：$\lim_{n\to\infty} (1 + a/n)^n = e^a$，泊松推导中的核心。

7. 负二项 mgf：$M(t) = [M_{\text{Geom}}(t)]^r$，这是利用几何分布的独立和。

Lecture 7 | Ch3 连续型随机变量 Continuous Random Variable

§3.1 连续型随机变量 Random Variable of Continuous Type

💡从离散到连续

离散 RV 的取值范围是有限个或可数无限个。但很多实际问题中，变量可以取一个区间上的任意值（如车速、身高、温度），这就是连续型随机变量。

核心变化：求和 $\sum$ 变成积分 $\int$，pmf 变成 pdf。

📖连续型 RV 与概率密度函数 pdf

$X$ 是连续型 RV，如果存在函数 $f(x): S \to (0, \infty)$ 满足：

  1. $f(x) > 0$，对所有 $x \in S$
  2. $\int_S f(x)\,dx = 1$（总面积 = 1）
  3. $P(a \le X \le b) = \int_a^b f(x)\,dx$（区间概率 = 曲线下面积）

$f(x)$ 称为概率密度函数（probability density function, pdf）。

🔗离散 vs 连续 — 对照表
离散 Discrete连续 Continuous
函数名pmf $f(x): S \to (0,1]$pdf $f(x): S \to (0, \infty)$
归一化$\sum_{x \in S} f(x) = 1$$\int_S f(x)dx = 1$
概率$P(X \in A) = \sum_{x \in A} f(x)$$P(X \in A) = \int_A f(x)dx$
单点概率$P(X=a) = f(a)$$P(X=a) = 0$
⚠连续型 RV 的三个重要注意点

1. 单点概率为零：$P(X=a) = \int_a^a f(x)dx = 0$。因此区间端点包含与否不影响概率：

$$P(a \le X \le b) = P(a < X \le b) = P(a \le X < b) = P(a < X < b)$$

2. pdf 可以大于 1：不像 pmf 限制在 $[0,1]$，pdf 只要积分等于 1 即可。例如 $U(0.1, 0.2)$ 的 pdf 值为 10。

3. pdf 不必连续、不必有界：可以有跳跃间断点（如分段函数），也可以发散（如 Gamma 分布在 $x \to 0$ 时）。

📖累积分布函数 cdf（连续版本）

对于连续型 RV $X$：

$$F(x) = P(X \le x) = \int_{-\infty}^x f(t)\,dt$$

关键性质：

• $F(x)$ 是非降函数

• $P(a \le X \le b) = F(b) - F(a)$

• pdf 和 cdf 的关系：$f(x) = F'(x)$（在 $F$ 可导的点处）— 这是微积分基本定理的直接推论

💡pdf 的直观理解

取一个极小区间 $[x, x+\Delta]$：

$$P(x \le X \le x+\Delta) = \int_x^{x+\Delta} f(t)dt \approx f(x)\Delta$$

所以 $f(x)$ 可以理解为单位长度上的概率质量（probability mass per unit length near $x$）。它本身不是概率，但乘以长度 $\Delta$ 后近似等于概率。

均匀分布与例题

📖均匀分布 Uniform Distribution $X \sim U(a,b)$

在 $[a,b]$ 上随机选一个点，每个位置"等可能"。

pdf：

$$f(x) = \frac{1}{b-a}, \quad a \le x \le b$$

cdf：

$$F(x) = \begin{cases} 0, & x < a \\ \frac{x-a}{b-a}, & a \le x \le b \\ 1, & x > b \end{cases}$$

直观：$P(X \le x) = \frac{x-a}{b-a}$，概率与区间长度成正比。

✎例 2（p.96）：$g(y) = 2y, \; 0 < y < 1$

求 cdf $G(y)$：

$G(y) = P(Y \le y) = \int_{-\infty}^y g(t)dt$

$y \le 0$ 时：$G(y) = 0$

$0 < y < 1$ 时：$G(y) = \int_0^y 2t\,dt = y^2$

$y \ge 1$ 时：$G(y) = 1$

求概率：

$P(\frac{1}{2} < Y \le \frac{3}{4}) = G(\frac{3}{4}) - G(\frac{1}{2}) = (\frac{3}{4})^2 - (\frac{1}{2})^2 = \frac{9}{16} - \frac{4}{16} = \frac{5}{16}$

$P(\frac{1}{4} < Y < 2) = G(2) - G(\frac{1}{4}) = 1 - \frac{1}{16} = \frac{15}{16}$

连续型 RV 的数学期望与 mgf

📖数学期望（连续版本）
$$E[g(X)] = \int_S g(x)f(x)\,dx = \int_{-\infty}^{\infty} g(x)f(x)\,dx$$

期望仍然是线性算子：$E[c_1 g_1(X) + c_2 g_2(X)] = c_1 E[g_1(X)] + c_2 E[g_2(X)]$。

特殊期望（与离散完全对应）：

✎例 3（p.98）：$X \sim U(0,100)$

$f(x) = \frac{1}{100}, \; 0 < x < 100$

$$E[X] = \int_0^{100} x \cdot \frac{1}{100} dx = \frac{1}{100} \cdot \frac{x^2}{2}\Big|_0^{100} = 50$$ $$\mathrm{Var}(X) = \int_0^{100} (x-50)^2 \cdot \frac{1}{100} dx = \frac{2500}{3}$$

对于一般 $U(a,b)$：$E[X] = \frac{a+b}{2}$，$\mathrm{Var}(X) = \frac{(b-a)^2}{12}$。

✎例 4（p.99）：$f(x) = xe^{-x}, \; x > 0$

这是 Gamma 分布的特例（$\alpha=2, \theta=1$）。用 mgf 求期望：

$$M(t) = \int_0^\infty e^{tx} \cdot x e^{-x} dx = \int_0^\infty x e^{-(1-t)x} dx = \frac{1}{(1-t)^2}, \quad t < 1$$

$M'(t) = \frac{2}{(1-t)^3}$，$M'(0) = 2 = E[X]$

$M''(t) = \frac{6}{(1-t)^4}$，$M''(0) = 6$

$\mathrm{Var}(X) = 6 - 2^2 = 2$

百分位数 Percentile

📖第 100p 百分位数 (100p)th Percentile

数 $\pi_p$ 使得 pdf 曲线下 $\pi_p$ 左侧的面积恰好为 $p$：

$$p = \int_{-\infty}^{\pi_p} f(x)dx = F(\pi_p)$$

• $\pi_{0.5}$ = 中位数 (median)，也称第二四分位数

• $\pi_{0.25}$ = 第一四分位数 (first quartile)

• $\pi_{0.75}$ = 第三四分位数 (third quartile)

✎例 5（p.99）：求 $\pi_{0.3}$

$f(x) = \frac{3x^2}{4^3} e^{-(x/4)^3}, \; x > 0$

先求 cdf：$F(x) = 1 - e^{-(x/4)^3}$（当 $x \ge 0$）

$F(\pi_{0.3}) = 0.3 \;\Rightarrow\; 1 - e^{-(\pi_{0.3}/4)^3} = 0.3$

$e^{-(\pi_{0.3}/4)^3} = 0.7 \;\Rightarrow\; -(\pi_{0.3}/4)^3 = \ln 0.7$

$\pi_{0.3} = 4(-\ln 0.7)^{1/3} \approx 2.84$

指数分布 Exponential Distribution

📖从泊松过程到指数分布

回忆 APP（近似泊松过程）：单位时间内平均发生 $\lambda$ 次事件。

问题：等到第一次事件发生需要等多久？令 $W$ = 等待时间。

推导 cdf：

$F(w) = P(W \le w) = 1 - P(W > w)$

$P(W > w) = P($在 $[0,w]$ 内没有事件发生$) = e^{-\lambda w}$（泊松分布 $P(Y=0)$）

$F(w) = 1 - e^{-\lambda w}, \; w \ge 0$

pdf = cdf 的导数：

$$f(w) = F'(w) = \lambda e^{-\lambda w} = \frac{1}{\theta} e^{-w/\theta}, \quad w \ge 0$$

其中 $\theta = \frac{1}{\lambda}$。记作 $X \sim \text{Exp}(\theta)$，$\theta > 0$。

★指数分布的期望、方差与 mgf

mgf：

$$M(t) = \int_0^\infty e^{tx} \cdot \frac{1}{\theta} e^{-x/\theta} dx = \frac{1}{\theta}\int_0^\infty e^{-x(1/\theta - t)} dx = \frac{1}{1 - \theta t}, \quad t < \frac{1}{\theta}$$

导数：$M'(t) = \frac{\theta}{(1-\theta t)^2}$，$M''(t) = \frac{2\theta^2}{(1-\theta t)^3}$

代入 $t=0$：

$$E[X] = M'(0) = \theta, \qquad \mathrm{Var}(X) = M''(0) - [M'(0)]^2 = 2\theta^2 - \theta^2 = \theta^2$$

若用参数 $\lambda = 1/\theta$：$E[X] = 1/\lambda$，$\mathrm{Var}(X) = 1/\lambda^2$。

✎例 1（p.105）：商店等待时间

顾客按 APP 到达，平均每小时 20 人。求店主等待第一个顾客超过 5 分钟的概率。

$\lambda = 20/60 = 1/3$（每分钟平均），$\theta = 1/\lambda = 3$ 分钟。

$X \sim \text{Exp}(\theta=3)$，$f(x) = \frac{1}{3} e^{-x/3}$

$$P(X > 5) = \int_5^\infty \frac{1}{3} e^{-x/3} dx = e^{-5/3} \approx 0.18$$

伽马分布 Gamma Distribution

📖从指数到伽马：等到第 $\alpha$ 次事件

指数分布回答"等到第一次要多久"。现在问：等到第 $\alpha$ 次要多久？

令 $W$ = 等到第 $\alpha$ 次事件的等待时间。$\alpha$ 是正整数。

CDF 推导：和指数分布思路一致——

$F(w) = 1 - P(W > w)$，其中 $P(W > w) = P($在 $[0,w]$ 内发生次数 $< \alpha)$

在长度为 $w$ 的区间里，发生次数 $Y$ 服从泊松分布，参数 $\lambda w$：

$$P(W > w) = \sum_{k=0}^{\alpha-1} \frac{(\lambda w)^k e^{-\lambda w}}{k!}$$

对 $w$ 求导得 pdf（令 $\theta = 1/\lambda$）：

$$f(w) = \frac{\lambda^\alpha w^{\alpha-1} e^{-\lambda w}}{(\alpha-1)!} = \frac{1}{\Gamma(\alpha)\theta^\alpha} w^{\alpha-1} e^{-w/\theta}, \quad w \ge 0$$
📖伽马函数 Gamma Function

为了让 $\alpha$ 可以取任意正实数（不限于整数），引入伽马函数：

$$\Gamma(t) = \int_0^\infty y^{t-1} e^{-y} dy, \quad t > 0$$

核心性质：

• $\Gamma(t) = (t-1)\Gamma(t-1)$（分部积分可得）

• 当 $n$ 为正整数时：$\Gamma(n) = (n-1)!$

• $\Gamma(1) = 1$，$\Gamma(\frac{1}{2}) = \sqrt{\pi}$

📖伽马分布 Gamma Distribution $X \sim \Gamma(\alpha, \theta)$

pdf：

$$f(x) = \frac{1}{\Gamma(\alpha)\theta^\alpha} x^{\alpha-1} e^{-x/\theta}, \quad x \ge 0, \;\alpha>0,\;\theta>0$$

mgf：

$$M(t) = \frac{1}{(1-\theta t)^\alpha}, \quad t < \frac{1}{\theta}$$
$$E[X] = \alpha\theta, \qquad \mathrm{Var}(X) = \alpha\theta^2$$

$\alpha=1$ 时退化为指数分布：$f(x) = \frac{1}{\theta} e^{-x/\theta}$，$\Gamma(1,\theta) = \text{Exp}(\theta)$。

🔗伽马分布与独立指数分布之和

刚才用"泊松 + 求导"推导了 Gamma。还有一个更简洁的视角：

$W$ = 等到第 $\alpha$ 次 = 第一次等待 + 第一次到第二次的间隔 + ... + 第 $\alpha-1$ 到第 $\alpha$ 的间隔

即 $W = W_1 + W_2 + \cdots + W_\alpha$，其中每个 $W_i \sim \text{Exp}(\theta)$ 且相互独立。

所以 Gamma mgf = $[\text{Exp mgf}]^\alpha = (\frac{1}{1-\theta t})^\alpha$，与上面公式一致。

卡方分布 Chi-square Distribution

📖卡方分布 $X \sim \chi^2(r)$

卡方分布是 Gamma 分布的特例：取 $\theta = 2$，$\alpha = r/2$（$r$ 为整数，称为自由度）。

pdf：

$$f(x) = \frac{1}{\Gamma(r/2) 2^{r/2}} x^{r/2 - 1} e^{-x/2}, \quad x > 0$$

mgf：

$$M(t) = (1-2t)^{-r/2}, \quad t < \frac{1}{2}$$
$$E[X] = r, \qquad \mathrm{Var}(X) = 2r$$
✎例 2：查卡方分布表

$X \sim \chi^2(5)$（自由度 $r=5$），查表得：

$P(1.145 \le X \le 12.83) = F(12.83) - F(1.145) = 0.975 - 0.05 = 0.925$

💡Gamma 家族关系图
$$\text{Gamma}(\alpha, \theta) \xrightarrow{\alpha=1} \text{Exp}(\theta) \xrightarrow{\theta=2,\;\alpha=r/2} \chi^2(r)$$

指数分布是 $\alpha=1$ 的特例；卡方分布是 $\theta=2$ 且 $\alpha = r/2$ 的特例。三者共享同一个 mgf 形式，只是参数不同。

正态分布 Normal (Gaussian) Distribution

📖定义：正态分布 $X \sim N(\mu, \sigma^2)$

连续 RV $X$ 服从正态分布，若其 pdf 为：

$$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right), \quad -\infty < x < \infty$$

参数：$\mu$（均值），$\sigma^2$（方差）。$\sigma > 0$。

著名的"钟形曲线"（bell-shaped curve）。

★验证 $\int f(x)dx = 1$（经典证明）

令 $z = \frac{x-\mu}{\sigma}$，问题转化为证明 $I = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} e^{-z^2/2} dz = 1$

考虑 $I^2$，并用极坐标变换：

$$I^2 = \frac{1}{2\pi}\int_{-\infty}^{\infty}\int_{-\infty}^{\infty} e^{-(y^2+z^2)/2} dy\,dz = \frac{1}{2\pi}\int_0^{2\pi}\int_0^\infty e^{-r^2/2} r\,dr\,d\theta$$ $$= \frac{1}{2\pi} \cdot 2\pi \cdot \left[-e^{-r^2/2}\right]_0^\infty = 1$$

这个经典证明用到了：直角坐标 → 极坐标，雅可比行列式 $r$。

★正态分布的 mgf、期望与方差

mgf：$M(t) = E[e^{tX}]$，通过配方法化简积分：

$$M(t) = \exp\!\left(\mu t + \frac{\sigma^2 t^2}{2}\right)$$

求导验证：

$M'(t) = (\mu + \sigma^2 t) \exp(\mu t + \frac{\sigma^2 t^2}{2})$，$M'(0) = \mu$

$M''(t) = \sigma^2 \exp(\ldots) + (\mu+\sigma^2 t)^2 \exp(\ldots)$，$M''(0) = \sigma^2 + \mu^2$

$$E[X] = \mu, \qquad \mathrm{Var}(X) = M''(0) - [M'(0)]^2 = (\sigma^2+\mu^2) - \mu^2 = \sigma^2$$

正态分布的两个参数恰好就是均值和方差，这个性质特别优雅。

✎例 1（p.115）：从 pdf 读出参数

$f(x) = \frac{1}{\sqrt{32\pi}} \exp\!\left(-\frac{(x+7)^2}{32}\right)$

对照标准形式 $\frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$：

$2\sigma^2 = 32 \;\Rightarrow\; \sigma^2 = 16$，$\mu = -7$

所以 $X \sim N(-7, 16)$。$E[X] = -7$，$\mathrm{Var}(X) = 16$。

mgf：$M(t) = \exp(-7t + 8t^2)$

标准正态分布 Standard Normal

📖标准正态分布 $Z \sim N(0,1)$

取 $\mu=0, \sigma=1$：

$$\phi(z) = \frac{1}{\sqrt{2\pi}} e^{-z^2/2}, \quad -\infty < z < \infty$$

cdf 记为 $\Phi(z) = P(Z \le z) = \int_{-\infty}^z \phi(t)dt$。

对称性：$\Phi(-z) = 1 - \Phi(z)$。这是因为 $\phi(z)$ 是偶函数。

★Theorem 3.3-1：标准化变换

若 $X \sim N(\mu, \sigma^2)$，则

$$\frac{X - \mu}{\sigma} \sim N(0,1)$$

这意味任何正态分布都可以通过减均值、除标准差转化为标准正态。于是：

$$P(a \le X \le b) = P\!\left(\frac{a-\mu}{\sigma} \le \frac{X-\mu}{\sigma} \le \frac{b-\mu}{\sigma}\right) = \Phi\!\left(\frac{b-\mu}{\sigma}\right) - \Phi\!\left(\frac{a-\mu}{\sigma}\right)$$
✎例 2（p.116）：标准正态查表

$Z \sim N(0,1)$：

$P(Z \le 1.24) = \Phi(1.24) = 0.8925$

$P(1.24 \le Z \le 2.37) = \Phi(2.37) - \Phi(1.24) = 0.9911 - 0.8925 = 0.0986$

$P(-2.37 \le Z \le -1.24) = \Phi(-1.24) - \Phi(-2.37) = [1-\Phi(1.24)] - [1-\Phi(2.37)]$

$= (1-0.8925) - (1-0.9911) = 0.1075 - 0.0089 = 0.0986$（对称性使得此概率与上相同）

✎例 4（p.118）：非标准正态

$X \sim N(3, 16)$，即 $\mu = 3, \sigma = 4$。

$P(4 \le X \le 8) = \Phi(\frac{8-3}{4}) - \Phi(\frac{4-3}{4}) = \Phi(1.25) - \Phi(0.25)$

$= 0.8944 - 0.5987 = 0.2957$

📖上 100$\alpha$ 百分位点 Upper 100α Percent Point

$z_\alpha$ 使得 $P(Z \ge z_\alpha) = \alpha$。

由于 $P(Z < z_\alpha) = 1 - \alpha$，所以 $z_\alpha$ 就是第 $100(1-\alpha)$ 百分位数。

常用值：$z_{0.05} = 1.645$，$z_{0.025} = 1.96$，$z_{0.0125} = 2.24$。

若 $X \sim N(\mu, \sigma^2)$（$\sigma^2 > 0$），则

$$\frac{(X-\mu)^2}{\sigma^2} \sim \chi^2(1)$$

求导得 pdf：$g(v) = \frac{1}{\sqrt{2\pi}} v^{-1/2} e^{-v/2}$，这正是 $\chi^2(1)$ 的 pdf。

二元随机变量与联合 pmf Bivariate RV & Joint pmf

💡从一元到二元

之前我们研究一个随机变量（身高、分数）。但现实中经常需要同时研究两个——身高和体重、语文和数学。这就是二元随机变量 $(X,Y)$。

📖联合 pmf Joint pmf

$f(x,y): S \to (0,1]$ 称为 $(X,Y)$ 的联合 pmf，满足：

  1. $f(x,y) > 0$ 对所有 $(x,y) \in S$
  2. $\sum_{(x,y)\in S} f(x,y) = 1$
  3. $P((X,Y) \in A) = \sum_{(x,y)\in A} f(x,y)$

特别地，$P(X=x, Y=y) = f(x,y)$。

✎例1 (Page 134)：两四面骰子，$X$=较小者，$Y$=较大者

原样本空间 16 个等可能结果。定义 $(X,Y)$ 后：

$$S = \{(1,1),(1,2),(1,3),(1,4),(2,2),(2,3),(2,4),(3,3),(3,4),(4,4)\}$$

$(1,2)$ 对应原样本中的 $(1,2)$ 和 $(2,1)$ → 概率 $2/16$。

$(1,1)$ 只对应 $(1,1)$ → 概率 $1/16$。

$$f(x,y) = \begin{cases} \frac{2}{16}, & 1 \le x \lt y \le 4 \\[4pt] \frac{1}{16}, & 1 \le x = y \le 4 \end{cases}$$

边缘 pmf Marginal pmf

📖从联合到边缘：对另一个变量"积掉"

$X$ 的边缘 pmf（只看 $X$ 自己的分布）：

$$f_X(x) = P(X=x) = \sum_{y: (x,y)\in S} f(x,y)$$

$Y$ 的边缘 pmf：$f_Y(y) = \sum_{x: (x,y)\in S} f(x,y)$。

✎例1 续：边缘 pmf

对例1的联合pmf求边缘：

$x=1$：$f_X(1) = f(1,1)+f(1,2)+f(1,3)+f(1,4) = \frac{1}{16}+\frac{2}{16}+\frac{2}{16}+\frac{2}{16} = \frac{7}{16}$

$x=2$：$f_X(2) = f(2,2)+f(2,3)+f(2,4) = \frac{1+2+2}{16}=\frac{5}{16}$

$x=3$：$f_X(3) = \frac{3}{16}$，$x=4$：$f_X(4) = \frac{1}{16}$。

$f_Y(y)$ 对称得出：$f_Y(1)=\frac{1}{16}, f_Y(2)=\frac{3}{16}, f_Y(3)=\frac{5}{16}, f_Y(4)=\frac{7}{16}$。

三项分布 Trinomial Distribution

📖二项的推广：三种互斥结果

$n$ 次独立重复试验，每次结果有三种："优"（概率 $p_X$）、"良"（$p_Y$）、"差"（$1-p_X-p_Y$）。

$X$ = "优"的次数，$Y$ = "良"的次数。缺陷数 $Z = n-X-Y$。

$$f(x,y) = \frac{n!}{x!\,y!\,(n-x-y)!}\,p_X^x\,p_Y^y\,(1-p_X-p_Y)^{\,n-x-y}$$

支撑集：$S = \{(x,y) \mid x+y \le n,\; x,y = 0,1,\dots,n\}$。

由来：三项式展开 $(a+b+c)^n = \sum_{x=0}^n\sum_{y=0}^{n-x} \frac{n!}{x!y!(n-x-y)!} a^x b^y c^{n-x-y}$。

★边缘分布：$X \sim b(n, p_X)$，$Y \sim b(n, p_Y)$

对 $y$ 求和后：$f_X(x) = \binom{n}{x} p_X^x (1-p_X)^{n-x}$——就是二项分布。

直观理解：不管"良"和"差"怎么分，只看"优"vs"非优"就是伯努利，$n$ 次独立就是二项。

离散 RV 的独立性 Independence

📖二元独立定义

$X$ 和 $Y$ 独立 $\iff$ 对所有 $x \in S_X, y \in S_Y$：

$$f(x,y) = f_X(x) f_Y(y)$$

必要条件：$S = S_X \times S_Y$（支撑集必须是矩形）。如果支撑集不是矩形（如 $x$ 和 $y$ 取值范围互相依赖），则一定不独立。

✎例2 (Page 135)：$f(x,y) = \frac{x+y}{21},\; x=1,2,3,\; y=1,2$

$f_X(x) = \frac{2x+3}{21}$，$f_Y(y) = \frac{3y+6}{21}$。

检查：$\frac{x+y}{21} \stackrel{?}{=} \frac{2x+3}{21} \cdot \frac{3y+6}{21}$ → 不成立，$X$ 和 $Y$ 不独立。

二元期望

📖$E[g(X,Y)]$ 的计算
$$E[g(X,Y)] = \sum_{(x,y)\in S} g(x,y) f(x,y)$$

两种求 $E[X]$ 的方法（等效）：

法1（边缘）：$E[X] = \sum x f_X(x)$

法2（联合）：$E[X] = \sum_{(x,y)} x f(x,y) = \sum_x x \sum_y f(x,y) = \sum_x x f_X(x)$

协方差 Covariance

📖定义
$$\mathrm{Cov}(X,Y) = E\big[(X-E[X])(Y-E[Y])\big] = E[XY] - E[X]E[Y]$$

解释：

• $\mathrm{Cov}(X,Y) > 0$：$X$ 和 $Y$ 正相关——$X$ 偏大时 $Y$ 也偏大

• $\mathrm{Cov}(X,Y) < 0$：$X$ 和 $Y$ 负相关——$X$ 偏大时 $Y$ 偏小

• $\mathrm{Cov}(X,Y) = 0$：$X$ 和 $Y$ 不相关（uncorrelated）

★独立 $\Rightarrow$ 不相关，但反之不然！

若 $X$ 和 $Y$ 独立：$f(x,y) = f_X(x)f_Y(y)$，则

$$E[XY] = \sum_x\sum_y xy\,f_X(x)f_Y(y) = \left(\sum_x x f_X(x)\right)\left(\sum_y y f_Y(y)\right) = E[X]E[Y]$$

$\mathrm{Cov}(X,Y) = E[XY] - E[X]E[Y] = 0$。✓

但反过来不成立！存在不相关但不独立的随机变量（见下例）。

✎例2：不相关但不独立

$(X,Y)$ 均匀取 $(1,0), (0,1), (-1,0), (0,-1)$ 四个点，各 $1/4$。

$f_X(-1)=\frac14, f_X(0)=\frac12, f_X(1)=\frac14$；$f_Y$ 对称相同。

$E[X]=0, E[Y]=0, E[XY]=\frac14(1\cdot0+0\cdot1+(-1)\cdot0+0\cdot(-1))=0 \Rightarrow \mathrm{Cov}=0$（不相关）。

但 $f(0,1) = 1/4 \neq f_X(0)f_Y(1) = \frac12 \cdot \frac14 = \frac18$ → 不独立。

相关系数 Correlation Coefficient

📖定义：协方差的标准化版本
$$\rho(X,Y) = \frac{\mathrm{Cov}(X,Y)}{\sqrt{\mathrm{Var}(X)\,\mathrm{Var}(Y)}}$$

性质：

• $-1 \le \rho \le 1$

• $|\rho| = 1 \iff Y - E[Y] = c(X - E[X])$（完全线性关系）

• $\rho > 0$ → 正相关；$\rho < 0$ → 负相关；$\rho = 0$ → 不相关

★$|\rho| \le 1$ 的证明（利用二次非负性）

令 $V = X - E[X], W = Y - E[Y]$。对任意 $t \in \mathbb{R}$：

$$E[(V + tW)^2] = \mathrm{Var}(X) + 2t\,\mathrm{Cov}(X,Y) + t^2\mathrm{Var}(Y) \ge 0$$

这是关于 $t$ 的二次函数，非负要求判别式 $\le 0$：

$4\mathrm{Cov}^2 - 4\mathrm{Var}(X)\mathrm{Var}(Y) \le 0 \Rightarrow \mathrm{Cov}^2 \le \mathrm{Var}(X)\mathrm{Var}(Y) \Rightarrow |\rho| \le 1$。

✎例：抛 $n$ 次硬币，$X$=正面数，$Y$=反面数

$X+Y=n \Rightarrow X - E[X] = -(Y - E[Y])$，完全负线性关系。

$$\mathrm{Cov}(X,Y) = -\mathrm{Var}(Y),\quad \mathrm{Var}(X)=\mathrm{Var}(Y),\quad \rho = -1$$

条件分布（离散）Conditional Distribution

📖条件 pmf

$Y$ 在 $X=x$ 条件下的 pmf：

$$h(y \mid x) = \frac{f(x,y)}{f_X(x)}, \quad y \in S_Y(x),\quad f_X(x) > 0$$

$X$ 在 $Y=y$ 条件下的 pmf：$g(x \mid y) = \frac{f(x,y)}{f_Y(y)}$。

条件 pmf 是合法的 pmf：非负，且 $\sum_y h(y\mid x) = 1$。

✎例1：$f(x,y)=\frac{x+y}{21},\;x=1,2,3,\;y=1,2$

已知 $f_X(x)=\frac{2x+3}{21}$。给定 $Y=1$ 条件下 $X$ 的 pmf：

$$g(x \mid 1) = \frac{f(x,1)}{f_Y(1)} = \frac{(x+1)/21}{3/7} = \frac{x+1}{9},\quad x=1,2,3$$

$P(1 \le X \le 2 \mid Y=1) = g(1\mid 1) + g(2\mid 1) = \frac{2}{15}+\frac{3}{15} = \frac{5}{15}$

条件期望 Conditional Expectation

📖条件均值与条件方差
$$E[Y \mid X=x] = \sum_y y \cdot h(y \mid x)$$

条件方差：

$$\mathrm{Var}(Y \mid X=x) = E[Y^2 \mid X=x] - (E[Y \mid X=x])^2$$

条件期望 $E[Y \mid X=x]$ 是$x$ 的函数——给不同的 $x$ 值，得到不同的条件均值。这在回归分析中至关重要。

§4.4 联合 pdf 与边缘 pdf Joint & Marginal pdf

📖二元连续 RV 的联合 pdf

$X$ 和 $Y$ 是连续型 RV，$(X,Y)$ 的联合 pdf $f(x,y): S \to (0,\infty)$ 满足：

(1) $f(x,y) > 0$ 对所有 $(x,y) \in S$

(2) $\iint_S f(x,y)\,dx\,dy = 1$（曲面下方总体积 = 1）

(3) $P((X,Y) \in A) = \iint_A f(x,y)\,dx\,dy$

几何解释：$f(x,y)$ 定义一个三维曲面 $z = f(x,y)$。区域 $A$ 上的概率 = 该曲面在 $A$ 上方的体积。

矩形区域上的计算：若 $A = [a,b] \times [c,d]$：

$$P(a \le X \le b,\; c \le Y \le d) = \int_a^b\int_c^d f(x,y)\,dy\,dx = \int_c^d\int_a^b f(x,y)\,dx\,dy$$

一般区域：$P((X,Y)\in A) = \int_{A_X}\int_{A_Y(x)} f(x,y)\,dy\,dx = \int_{A_Y}\int_{A_X(y)} f(x,y)\,dx\,dy$。

📖边缘 pdf — 把另一维积分掉
$$f_X(x) = \int_{S_Y(x)} f(x,y)\,dy,\quad x \in S_X$$ $$f_Y(y) = \int_{S_X(y)} f(x,y)\,dx,\quad y \in S_Y$$

其中 $S_Y(x) = \{y \mid (x,y) \in S\}$（对固定的 $x$，$y$ 能取的范围）。

★数学期望（连续二元版）
$$E[g(X,Y)] = \iint_S g(x,y)\,f(x,y)\,dx\,dy$$

两种求 $E[X]$ 的等效方法：

法1（边缘）：$E[X] = \int_{S_X} x f_X(x)\,dx$

法2（联合）：$E[X] = \iint_S x f(x,y)\,dx\,dy = \int_{S_X} x \left(\int_{S_Y(x)} f(x,y)\,dy\right)dx = \int_{S_X} x f_X(x)\,dx$

方差同样：$\mathrm{Var}(X) = \iint_S (x-E[X])^2 f(x,y)\,dx\,dy = \int_{S_X} (x-E[X])^2 f_X(x)\,dx$。

✎例1 (Page 156)：$f(x,y) = \frac{3}{2}x^2(1-|y|),\; -1 < x < 1,\; -1 < y < 1$

支撑集是正方形 $(-1,1) \times (-1,1)$。$S_X = (-1,1)$，$S_Y = (-1,1)$。

边缘 pdf — $f_X(x)$：对 $y$ 在 $[-1,1]$ 上积分。注意 $1-|y|$ 是关于 $y$ 的偶函数：

$$f_X(x) = \int_{-1}^{1} \frac{3}{2}x^2(1-|y|)\,dy = \frac{3}{2}x^2 \int_{-1}^{1} (1-|y|)\,dy = \frac{3}{2}x^2 \cdot 2\int_0^{1} (1-y)\,dy$$ $$= \frac{3}{2}x^2 \cdot 2 \cdot \left[y - \frac{y^2}{2}\right]_0^1 = \frac{3}{2}x^2 \cdot 2 \cdot \frac{1}{2} = \frac{3}{2}x^2$$

验证：$\int_{-1}^{1} \frac{3}{2}x^2 dx = \frac{3}{2} \cdot \frac{2}{3} = 1$ ✓

边缘 pdf — $f_Y(y)$：$f_Y(y) = \int_{-1}^{1} \frac{3}{2}x^2(1-|y|)\,dx = \frac{3}{2}(1-|y|) \cdot \frac{2}{3} = 1-|y|$。

$E[X] = 0$：$\int_{-1}^{1} x \cdot \frac{3}{2}x^2 dx = 0$（奇函数在对称区间上积分为零）。

区域概率：$A = \{(x,y) \mid 0 < x < 1,\; 0 < y < x\}$：

$$P(A) = \int_0^1\int_0^x \frac{3}{2}x^2(1-y)\,dy\,dx = \int_0^1 \frac{3}{2}x^2\left[x - \frac{x^2}{2}\right]dx = \frac{9}{40}$$
✎例2 (Page 155)：$f(x,y) = \frac{4}{3}(1-xy),\; 0 \le x \le 1,\; 0 \le y \le 1$

支撑集是单位正方形。

边缘 pdf：

$$f_X(x) = \int_0^1 \frac{4}{3}(1-xy)\,dy = \frac{4}{3}\left[y - \frac{x y^2}{2}\right]_0^1 = \frac{4}{3}\left(1 - \frac{x}{2}\right)$$

同理 $f_Y(y) = \frac{4}{3}(1 - \frac{y}{2})$。

$E[X]$：$E[X] = \int_0^1 x \cdot \frac{4}{3}(1-\frac{x}{2})dx = \frac{4}{3}\left[\frac{x^2}{2} - \frac{x^3}{6}\right]_0^1 = \frac{4}{3} \cdot \frac{1}{3} = \frac{4}{9}$。

$\mathrm{Var}(X)$（练习）：$E[X^2] = \int_0^1 x^2 \cdot \frac{4}{3}(1-\frac{x}{2})dx = \frac{4}{3}\left[\frac{1}{3} - \frac{1}{8}\right] = \frac{5}{18}$。

$\mathrm{Var}(X) = \frac{5}{18} - (\frac{4}{9})^2 = \frac{5}{18} - \frac{16}{81} = \frac{13}{162}$。

连续 RV 的独立性 Independent Continuous RVs

📖定义：$X \perp\!\!\!\perp Y \iff f(x,y) = f_X(x)f_Y(y)$

对所有 $x \in S_X, y \in S_Y$ 成立。

必要条件：$S = S_X \times S_Y$（支撑集必须是直角积/矩形）。如果 $S$ 是三角形（如 $0 \le x \le y \le 1$）或圆形，条件本身就让 $X$ 和 $Y$ 依赖——因为知道 $X=x$ 就限定了 $Y$ 的范围。

验证流程：(1) 检查支撑集是否为矩形；(2) 计算边缘 pdf；(3) 检查 $f_X f_Y \stackrel{?}{=} f$。

✎例2续：验证不独立

$f(x,y) = \frac{4}{3}(1-xy)$，$f_X(x) = \frac{4}{3}(1-\frac{x}{2})$，$f_Y(y) = \frac{4}{3}(1-\frac{y}{2})$。

$$f_X(x)f_Y(y) = \frac{16}{9}\left(1 - \frac{x}{2} - \frac{y}{2} + \frac{xy}{4}\right) \neq \frac{4}{3}(1-xy) = f(x,y)$$

乘积的 $xy$ 系数是 $\frac{16}{9} \cdot \frac{1}{4} = \frac{4}{9}$，但 $f(x,y)$ 中 $xy$ 的系数是 $\frac{4}{3}$，两者不相等 → 不独立。

连续情形的协方差与相关系数

📖连续版的协方差
$$\mathrm{Cov}(X,Y) = E[(X-E[X])(Y-E[Y])] = \iint_S (x-\mu_X)(y-\mu_Y) f(x,y)\,dx\,dy = E[XY] - E[X]E[Y]$$

其中 $E[XY] = \iint_S xy\,f(x,y)\,dx\,dy$。

相关系数 $\rho(X,Y) = \frac{\mathrm{Cov}(X,Y)}{\sqrt{\mathrm{Var}(X)\,\mathrm{Var}(Y)}}$，定义与离散完全相同。

所有性质（$|\rho| \le 1$、独立 ⇒ 不相关、不相关 $\not\Rightarrow$ 独立等）全部照搬。

条件 pdf 与条件期望 Conditional pdf & Expectation

📖条件 pdf 的定义

给定 $X=x$（$f_X(x) > 0$）时 $Y$ 的条件 pdf：

$$h(y \mid x) = \frac{f(x,y)}{f_X(x)},\quad y \in S_Y(x)$$

给定 $Y=y$ 时 $X$ 的条件 pdf：$g(x \mid y) = \frac{f(x,y)}{f_Y(y)},\; x \in S_X(y)$。

条件 pdf 是合法的 pdf：$h(y\mid x) \ge 0$ 且 $\int_{S_Y(x)} h(y\mid x)\,dy = 1$。

独立时：$h(y\mid x) = \frac{f_X(x)f_Y(y)}{f_X(x)} = f_Y(y)$——条件不改变分布。

📖条件期望与条件方差

条件均值：

$$E[Y \mid X = x] = \int_{S_Y(x)} y \cdot h(y \mid x)\,dy$$

条件方差：

$$\mathrm{Var}(Y \mid X = x) = E[(Y - E[Y \mid X=x])^2 \mid X = x]$$ $$= \int_{S_Y(x)} (y - E[Y \mid X=x])^2 \, h(y \mid x)\,dy = E[Y^2 \mid X=x] - (E[Y \mid X=x])^2$$

条件概率：$P(Y \in A \mid X=x) = \int_{A} h(y \mid x)\,dy$。

例题3★：$f(x,y) = 2,\; 0 \le x \le y \le 1$（三角形常考题）

✎例3 (Page 157)：全面推导

支撑集 $S = \{(x,y) \mid 0 \le x \le y \le 1\}$ 是直角三角形（面积 $1/2$）。

$f(x,y) = 2$ 是常数——因为体积必须为 1，面积是 $1/2$，所以密度 $= 2$。

Step 1 — 边缘 pdf：

$$f_X(x) = \int_x^1 2\,dy = 2(1-x),\quad 0 \le x \le 1$$ $$f_Y(y) = \int_0^y 2\,dx = 2y,\quad 0 \le y \le 1$$

$S_X = S_Y = [0,1]$ 都是 $[0,1]$——但 $S$ 不是 $S_X \times S_Y$。所以 $X$ 和 $Y$ 必定不独立。

Step 2 — 期望：

$$E[X] = \int_0^1 x \cdot 2(1-x)dx = 2\left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1 = 2\cdot\left(\frac12 - \frac13\right) = \frac13$$ $$E[Y] = \int_0^1 y \cdot 2y\,dy = 2\cdot\left[\frac{y^3}{3}\right]_0^1 = \frac23$$

Step 3 — 条件 pdf $h(y \mid x)$：

$$h(y \mid x) = \frac{f(x,y)}{f_X(x)} = \frac{2}{2(1-x)} = \frac{1}{1-x},\quad x \le y \le 1$$

给定 $X=x$ 时，$Y$ 在 $[x,1]$ 上均匀分布！这是这个例题最美的结论。

Step 4 — 条件期望与条件方差：

$$E[Y \mid X=x] = \int_x^1 y \cdot \frac{1}{1-x}\,dy = \frac{1}{1-x}\left[\frac{y^2}{2}\right]_x^1 = \frac{1-x^2}{2(1-x)} = \frac{1+x}{2}$$ $$\mathrm{Var}(Y \mid X=x) = \frac{(1-x)^2}{12}\quad\text{（$[x,1]$ 上的均匀分布方差）}$$

Step 5 — 条件概率：

$P(\frac{3}{4} \le Y \le \frac{7}{8} \mid X = \frac{1}{4}) = \int_{3/4}^{7/8} \frac{1}{1 - 1/4}\,dy = \frac{4}{3} \cdot \left(\frac{7}{8} - \frac{3}{4}\right) = \frac{4}{3} \cdot \frac{1}{8} = \frac{1}{6}$。

这个例题为什么常考？因为它完美地展示了连续二元分布的全部核心操作：联合 pdf → 边缘 pdf → 条件 pdf → 条件均值 → 条件方差 → 条件概率。三角形支撑集也是最经典的非矩形例子。

⚠Lecture 12 常见易错点

1. 连续版条件分布的公式和离散版完全一样——重要的不是记新公式，是理解"求和变积分"这个统一原则。

2. 支撑集形状是独立的必要条件。三角形/圆形一定不独立，因为 $X$ 的取值会限制 $Y$ 的范围。

3. 边缘 pdf 的积分上下限取决于支撑集。对每个固定的 $x$，$y$ 的范围来自 $S_Y(x)$，不是盲目的 $(-\infty,\infty)$。

4. $E[X]$ 可以走两条路：先求边缘再积分，或直接从联合积分。结果相同，选计算量小的那条。

5. 连续版的协方差和相关系数定义不变——$\rho$ 的所有性质照旧使用。

§4.5 二元正态分布 Bivariate Normal Distribution

📖联合 pdf — 五个参数决定一切
$$f(x,y) = \frac{1}{2\pi\sigma_X\sigma_Y\sqrt{1-\rho^2}} \exp\!\left[-\frac{1}{2}q(x,y)\right],\quad x,y \in \mathbb{R}$$ $$q(x,y) = \frac{1}{1-\rho^2}\left[\left(\frac{x-\mu_X}{\sigma_X}\right)^2 - 2\rho\left(\frac{x-\mu_X}{\sigma_X}\right)\left(\frac{y-\mu_Y}{\sigma_Y}\right) + \left(\frac{y-\mu_Y}{\sigma_Y}\right)^2\right]$$

五个参数：$\mu_X, \mu_Y \in \mathbb{R}$（均值），$\sigma_X, \sigma_Y > 0$（标准差），$|\rho| < 1$（相关系数）。

结构解析：这是"缩放后的指数函数，指数上是 $x$ 和 $y$ 的二次型"。交叉项 $-2\rho(\cdot)(\cdot)$ 包含了 $X$ 和 $Y$ 的全部依赖信息——如果 $\rho=0$，交叉项消失，$f(x,y)$ 就分解成两个独立正态 pdf 的乘积。

★性质 1 — 边缘分布是正态（证明思路）

要证明 $f_X(x) \propto \exp(-\frac{(x-\mu_X)^2}{2\sigma_X^2})$，技巧是把 $f(x,y)$ 改写成：

$$f(x,y) = \underbrace{\frac{1}{\sqrt{2\pi}\sigma_X}\exp\!\left(-\frac{(x-\mu_X)^2}{2\sigma_X^2}\right)}_{f_X(x)} \cdot \underbrace{\frac{1}{\sqrt{2\pi}\sqrt{1-\rho^2}\,\sigma_Y}\exp\!\left[-\frac{\left(y - [\mu_Y + \rho\frac{\sigma_Y}{\sigma_X}(x-\mu_X)]\right)^2}{2(1-\rho^2)\sigma_Y^2}\right]}_{h(y \mid x)}$$

这样就分解为 $f(x,y)=f_X(x)\,h(y\mid x)$。$f_X(x)$ 正是 $N(\mu_X,\sigma_X^2)$ 的 pdf。同理 $f_Y(y) \sim N(\mu_Y,\sigma_Y^2)$。

而 $h(y\mid x)$ 是一个正态 pdf（均值 $\mu_Y+\rho\frac{\sigma_Y}{\sigma_X}(x-\mu_X)$，方差 $(1-\rho^2)\sigma_Y^2$），且 $\int h(y\mid x)dy = 1$，确认了这恰好是条件 pdf。

★性质 2 — 条件分布也是正态
$$Y \mid X=x \;\sim\; N\!\left(\mu_Y + \rho\frac{\sigma_Y}{\sigma_X}(x-\mu_X),\;(1-\rho^2)\sigma_Y^2\right)$$ $$X \mid Y=y \;\sim\; N\!\left(\mu_X + \rho\frac{\sigma_X}{\sigma_Y}(y-\mu_Y),\;(1-\rho^2)\sigma_X^2\right)$$

条件均值的回归解释：$E[Y\mid X=x] = \mu_Y + \rho\frac{\sigma_Y}{\sigma_X}(x-\mu_X)$。若 $x > \mu_X$（$X$ 高于均值），则 $Y$ 的条件均值也在 $\mu_Y$ 基础上向同方向偏移（若 $\rho>0$）。偏移量为 $\rho \cdot \frac{\sigma_Y}{\sigma_X} \cdot (x-\mu_X)$——这就是线性回归的斜率。

条件方差缩小：$\mathrm{Var}(Y\mid X=x) = (1-\rho^2)\sigma_Y^2 \le \sigma_Y^2$。知道 $X$ 总能减少 $Y$ 的不确定性——除非 $\rho=0$。

★性质 3 — 独立 $\iff$ 不相关（二元正态独有的性质）

当 $\rho = 0$ 时，联合 pdf 分解为：

$$f(x,y) = \frac{1}{2\pi\sigma_X\sigma_Y}\exp\!\left[-\frac{(x-\mu_X)^2}{2\sigma_X^2} - \frac{(y-\mu_Y)^2}{2\sigma_Y^2}\right] = f_X(x)f_Y(y)$$

所以 $\rho=0 \iff X$ 和 $Y$ 独立。这在一般分布中不成立（如 Lecture 11 的反例：不相关但不独立），但在二元正态中恰好等价。

$\rho$ 正是 $X$ 和 $Y$ 的相关系数：$\mathrm{Cov}(X,Y) = \rho\sigma_X\sigma_Y$。

💡二元正态的几何理解——等概率线是椭圆

固定 $z = f(x,y) = z_0$（一个常数），截面方程 $q(x,y) = -2\ln(z_0 \cdot 2\pi\sigma_X\sigma_Y\sqrt{1-\rho^2})$，这恰好是中心在 $(\mu_X,\mu_Y)$ 的椭圆。$\rho$ 控制椭圆的旋转方向：

$\rho=0$ → 圆（各向同性）；$\rho>0$ → 右上-左下方向拉长的椭圆（正相关）；$\rho<0$ → 左上-右下方向拉长的椭圆（负相关）。

截面 $x=x_0$（垂直平面）得到一条正态曲线——这就是条件 pdf $h(y\mid x_0)$ 的形状。截面 $y=y_0$ 同理。

§5.1 随机变量的函数：一对一情形 Functions of One RV: One-to-One

📖问题：已知 $X$ 的分布，$Y=u(X)$ 的分布是什么？

我们之前学过离散版的 $g(X)$ 的 pmf：一对一照搬，多对一加总。现在是连续版的系统化方法。

情形一：离散 RV（一对一映射）

★离散公式

$X$ 的 pmf 为 $f(x)$，$Y=u(X)$ 是一对一，反函数 $X=v(Y)$。则：

$$S_Y = \{y \mid y = u(x),\; x \in S_X\}$$ $$g(y) = P(Y=y) = P(u(X)=y) = P(X=v(y)) = f(v(y)),\quad y \in S_Y$$
✎例1 (Page 177)：$X \sim \text{Poisson}(\lambda=4)$，$Y = \sqrt{X}$

pmf of $X$：$f(x) = \frac{4^x e^{-4}}{x!},\; x = 0,1,2,\ldots$

$Y = \sqrt{X}$ 在 $x \ge 0$ 上是严格递增的。反函数：$X = Y^2$。

支撑集：$S_Y = \{0, 1, \sqrt{2}, \sqrt{3}, \sqrt{4}=2, \sqrt{5}, \ldots\}$。

$$g(y) = f(y^2) = \frac{4^{y^2} e^{-4}}{(y^2)!},\quad y \in S_Y$$

情形二：连续 RV 且 $u$ 严格单调

★连续变换公式——通过 CDF 推导

$X$ 的 pdf 为 $f(x)$，支撑集 $[c_1, c_2]$。$Y = u(X)$ 连续且严格单调，反函数 $X = v(Y)$ 可导。

Case 1（$u$ 严格递增）：

$S_Y = [u(c_1), u(c_2)]$。cdf：$G(y) = P(Y \le y) = P(u(X) \le y) = P(X \le v(y)) = \int_{c_1}^{v(y)} f(x)dx$。

求导：$g(y) = G'(y) = f(v(y)) \cdot v'(y)$（链式法则 + 微积分基本定理）。

Case 2（$u$ 严格递减）：

$S_Y = [u(c_2), u(c_1)]$。cdf：$G(y) = P(Y \le y) = P(u(X) \le y) = P(X \ge v(y)) = 1 - \int_{c_1}^{v(y)} f(x)dx$。

求导：$g(y) = G'(y) = -f(v(y)) \cdot v'(y)$。

统一公式（带绝对值）：

$$g(y) = f(v(y)) \cdot \left|\frac{dv(y)}{dy}\right|$$

绝对值是必须的——$v'(y)$ 在递减情形下为负，但 pdf 不能为负。

✎例2 (Page 174)：$f(x)=3(1-x)^2,\;0 < x < 1$，$Y = (1-X)^3$

步骤详解：

Step 1 — 判断单调性：$Y=(1-X)^3$ 在 $x\in(0,1)$ 上严格递减（$1-x$ 递减，三次方保持递减）。

Step 2 — 求反函数：$y = (1-x)^3 \Rightarrow 1-x = y^{1/3} \Rightarrow x = 1 - y^{1/3}$，即 $v(y) = 1 - y^{1/3}$。

Step 3 — 确定新支撑集：$x=0 \Rightarrow y=1$，$x=1 \Rightarrow y=0$。$S_Y = (0, 1)$。

Step 4 — 求导并代公式：$v'(y) = -\frac{1}{3}y^{-2/3}$。$|v'(y)| = \frac{1}{3}y^{-2/3}$。

$$g(y) = f(v(y))|v'(y)| = f(1-y^{1/3}) \cdot \frac{1}{3}y^{-2/3} = 3(y^{1/3})^2 \cdot \frac{1}{3}y^{-2/3} = 1,\; 0 < y < 1$$

$g(y) = 1$ 在 $(0,1)$ 上 → $Y \sim U(0,1)$！

为什么恰好是均匀分布？$X$ 的 cdf 是 $F(x) = 1 - (1-x)^3$。于是 $Y = (1-X)^3 = 1 - F(X)$。因为 $F(X) \sim U(0,1)$，所以 $1-F(X) \sim U(0,1)$。这也引出了下一个定理。

§5.3 多元随机变量 Multivariate Random Variables

📖从一元 → 二元 → 多元

做一次随机实验，得到的结果可以是：

• 一个数（标量） → 一元 RV：$X$，pmf/pdf $f(x)$

• 一对数 → 二元 RV：$(X,Y)$，联合 pmf/pdf $f(x,y)$

• $n$ 个数 → 多元 RV：$(X_1,\ldots,X_n)$，联合 pmf/pdf $f(x_1,\ldots,x_n)$

📖多元联合分布的定义

离散型（$X_1,\ldots,X_n$ 均为离散）：联合 pmf $f(x_1,\ldots,x_n)$。满足 $f>0$，$\sum_{(x_1,\ldots,x_n)\in S} f(x_1,\ldots,x_n)=1$，$P((X_1,\ldots,X_n)\in A)=\sum_A f$。

连续型（$X_1,\ldots,X_n$ 均为连续）：联合 pdf $f(x_1,\ldots,x_n)$。满足 $f>0$，$\iint_S f = 1$，$P((X_1,\ldots,X_n)\in A)=\iint_A f$。

注意：多元 RV 的形成方式很多。最典型的是同一实验独立重复 $n$ 次——每次的结果是 $X_i$，$(X_1,\ldots,X_n)$ 自然形成一个多元 RV。

📖$n$ 个 RV 的相互独立 Mutual Independence
$$X_1,\ldots,X_n \text{ 独立} \iff f(x_1,\ldots,x_n) = f_{X_1}(x_1)\,f_{X_2}(x_2)\,\cdots\,f_{X_n}(x_n)$$

必要条件：支撑集必须是直角积 $S = S_{X_1} \times S_{X_2} \times \cdots \times S_{X_n}$。如果支撑集不是"矩形"（如 $x_1+x_2\le 1$ 这种约束），则必定不独立。

若 $X_1,\ldots,X_n$ 相互独立，则任意两两、任意三个……任意 $n-1$ 个之间也是独立的。

📖i.i.d. — 独立同分布 Independent and Identically Distributed

$X_1,\ldots,X_n$ i.i.d.：

(1) 相互独立；(2) 每个 $X_i$ 服从完全相同的分布（同一个 pmf/pdf）。

此时联合分布简化为：$f(x_1,\ldots,x_n) = f_X(x_1)\,f_X(x_2)\,\cdots\,f_X(x_n)$。

随机样本 $\equiv$ i.i.d.。这二者是同一个概念的两个名字——"随机样本"是统计学的叫法，"i.i.d."是概率论的叫法。

独立 RV 的期望与方差定理 Expectations of Independent RVs

📖多元期望的定义
$$E[u(X_1,\ldots,X_n)] = \sum_{(x_1,\ldots,x_n)} u(x_1,\ldots,x_n) f(x_1,\ldots,x_n) \quad\text{（离散）}$$ $$E[u(X_1,\ldots,X_n)] = \iint_S u(x_1,\ldots,x_n) f(x_1,\ldots,x_n) dx_1\cdots dx_n \quad\text{（连续）}$$

期望仍是线性算子——不需要独立也能拆开加法。

★Thm 5.3-1：独立乘积的期望 = 期望的乘积

若 $X_1,\ldots,X_n$ 独立，则：

$$E[u_1(X_1)\,u_2(X_2)\,\cdots\,u_n(X_n)] = E[u_1(X_1)] \cdot E[u_2(X_2)] \cdots E[u_n(X_n)]$$

证明（离散情形）：

独立 ⇒ $f(x_1,\ldots,x_n) = f_{X_1}(x_1)\cdots f_{X_n}(x_n)$。代入定义：

$$\sum_{x_1}\cdots\sum_{x_n} u_1(x_1)\cdots u_n(x_n) f_{X_1}(x_1)\cdots f_{X_n}(x_n)$$ $$= \left(\sum_{x_1} u_1(x_1)f_{X_1}(x_1)\right)\cdots\left(\sum_{x_n} u_n(x_n)f_{X_n}(x_n)\right) = \prod_{i=1}^n E[u_i(X_i)]$$

关键：独立使得多重求和/积分可以拆成单个求和/积分的乘积。这正是 $E[XY]=E[X]E[Y]$（独立时）的 $n$ 元推广。

★Thm 5.3-2：独立 RV 线性组合的期望与方差

若 $X_1,\ldots,X_n$ 独立，均值分别为 $\mu_i$，方差分别为 $\sigma_i^2$。$Y = \sum_{i=1}^n a_i X_i$（$a_i$ 为常数）。则：

$$E[Y] = \sum_{i=1}^n a_i \mu_i,\qquad \mathrm{Var}(Y) = \sum_{i=1}^n a_i^2 \sigma_i^2$$

期望：直接由期望的线性性得出，不需要独立。

方差的完整推导：

$$\begin{aligned} \mathrm{Var}(Y) &= E[(Y - E[Y])^2] = E\!\left[\left(\sum_{i} a_i (X_i - \mu_i)\right)^2\right] \\ &= E\!\left[\sum_{i}\sum_{j} a_i a_j (X_i - \mu_i)(X_j - \mu_j)\right] \\ &= \sum_{i}\sum_{j} a_i a_j \, E[(X_i - \mu_i)(X_j - \mu_j)] \end{aligned}$$

当 $i = j$：$E[(X_i-\mu_i)^2] = \sigma_i^2$。

当 $i \neq j$：$E[(X_i-\mu_i)(X_j-\mu_j)] = \mathrm{Cov}(X_i, X_j) = 0$（因为独立 ⇒ 协方差为零）。

所有交叉项消失，只剩对角线：$\mathrm{Var}(Y) = \sum_i a_i^2 \sigma_i^2$。$\blacksquare$

方差不需要协方差的唯一情况就是独立。如果不独立，交叉项 $\sum_{i\neq j} a_i a_j \mathrm{Cov}(X_i,X_j)$ 不能忽略。

✎样本均值 $\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$

$X_i$ i.i.d.，$E[X_i] = \mu$，$\mathrm{Var}(X_i) = \sigma^2$。

$$E[\bar{X}] = \frac{1}{n}\sum_{i=1}^n \mu = \mu,\qquad \mathrm{Var}(\bar{X}) = \frac{1}{n^2}\sum_{i=1}^n \sigma^2 = \frac{\sigma^2}{n}$$

样本均值的期望等于总体均值（无偏），方差随 $n$ 增大以 $1/n$ 速率衰减。$n$ 越大，$\bar{X}$ 越精确。

非一对一变换 Non-One-to-One Transformation

⚠$Y = u(X)$ 不是一对一怎么办？

没有通用公式！只能回到定义：先求 cdf $G(y) = P(Y \le y)$，再求导得 pdf $g(y) = G'(y)$。

$P(Y \le y)$ 的计算方法：找出所有满足 $u(x) \le y$ 的 $x$ 的范围，在这个范围上对 $f(x)$ 积分/求和。

✎例4：$f(x) = \frac{1}{\pi(1+x^2)},\; x \in (-\infty,\infty)$（柯西分布），$Y = X^2$

$Y = X^2$ 不是一对一的——$x$ 和 $-x$ 都映射到同一个 $y$。$S_Y = [0, \infty)$。

Step 1 — 求 CDF：$y \ge 0$ 时：

$$G(y) = P(Y \le y) = P(X^2 \le y) = P(-\sqrt{y} \le X \le \sqrt{y})$$ $$= \int_{-\sqrt{y}}^{\sqrt{y}} \frac{dx}{\pi(1+x^2)} = 2\int_0^{\sqrt{y}} \frac{dx}{\pi(1+x^2)}$$

Step 2 — 求导得 PDF：$g(y) = G'(y) = 2 \cdot \frac{1}{\pi(1+y)} \cdot \frac{d}{dy}(\sqrt{y})$（链式法则 + 微积分基本定理）。

$$g(y) = \frac{2}{\pi(1+y)} \cdot \frac{1}{2\sqrt{y}} = \frac{1}{\pi(1+y)\sqrt{y}},\quad y > 0$$

$y=0$ 处 pdf 发散——这是合理的，因为 $X^2$ 在 0 附近"堆积"了很多概率质量。

💡统计量 Statistic

统计量 = 随机样本 $\{X_1,\ldots,X_n\}$ 的不含未知参数的函数。例如 $\bar{X} = \frac{1}{n}\sum X_i$ 和 $S^2 = \frac{1}{n-1}\sum (X_i-\bar{X})^2$ 都是统计量。统计量是我们从数据中提取信息的工具——它是"估计量"的数学表达。

§5.4 mgf 技巧 MGF Technique

💡核心思路：mgf 唯一确定分布 → 求 mgf = 求分布

如果我们能算出 $Y$ 的 mgf，并且这个 mgf 恰好是某个已知分布的标准形式，那么我们就直接证明了 $Y$ 服从该分布——不需要从 pmf/pdf 出发兜圈子。

★Thm 5.4-1：独立 RV 线性组合的 mgf

$X_1,\ldots,X_n$ 独立，各自 mgf 为 $M_{X_i}(t)$（$|t| < h_i$）。$Y = \sum_{i=1}^n a_i X_i$，则：

$$M_Y(t) = \prod_{i=1}^n M_{X_i}(a_i t),\quad |a_i t| < h_i$$

证明：$M_Y(t) = E[e^{t\sum a_i X_i}] = E[\prod e^{a_i t X_i}]$。由独立性和 Thm 5.3-1：$E[\prod e^{a_i t X_i}] = \prod E[e^{a_i t X_i}] = \prod M_{X_i}(a_i t)$。

★Cor 5.4-1：i.i.d. 情形

$X_1,\ldots,X_n$ i.i.d.，共同 mgf 为 $M(t)$。则：

$$M_{\sum X_i}(t) = [M(t)]^n,\qquad M_{\bar{X}}(t) = \left[M\!\left(\frac{t}{n}\right)\right]^n$$
✎例1 (Page 195)：均匀骰子和的分布——mgf 方法

$X_1,X_2$ i.i.d. $\text{Uniform}\{1,2,3,4\}$，$Y = X_1 + X_2$。

单个的 mgf：$M_{X_i}(t) = \frac{1}{4}(e^t + e^{2t} + e^{3t} + e^{4t})$。

$M_Y(t) = [M_{X_i}(t)]^2 = \frac{1}{16}(e^t + e^{2t} + e^{3t} + e^{4t})^2$。

展开多项式——$e^{kt}$ 的系数就是 $P(Y=k)$：

$$M_Y(t) = \frac{1}{16}e^{2t} + \frac{2}{16}e^{3t} + \frac{3}{16}e^{4t} + \frac{4}{16}e^{5t} + \frac{3}{16}e^{6t} + \frac{2}{16}e^{7t} + \frac{1}{16}e^{8t}$$

$P(Y=2)=\frac{1}{16}$（只有 $(1,1)$），$P(Y=3)=\frac{2}{16}$（$(1,2)$ 和 $(2,1)$），……$P(Y=8)=\frac{1}{16}$（只有 $(4,4)$）。

✎例2 (Page 197)：独立伯努利之和 → 二项——mgf 证明

$X_i \sim \text{Bernoulli}(p)$ i.i.d.。$M_{X_i}(t) = (1-p) + p e^t$。$Y = \sum_{i=1}^n X_i$：

卡方分布的可加性 Additivity of Chi-Square

★Thm 5.4-2：独立卡方之和仍是卡方

$X_i \sim \chi^2(r_i)$ 独立。则：

$$Y = \sum_{i=1}^n X_i \;\sim\; \chi^2(r_1 + \cdots + r_n)$$

证明：$M_{X_i}(t) = (1-2t)^{-r_i/2}$（$t < 1/2$）。由 Thm 5.4-1：

$$M_Y(t) = \prod_{i=1}^n (1-2t)^{-r_i/2} = (1-2t)^{-(\sum r_i)/2}$$

这正是 $\chi^2(\sum r_i)$ 的 mgf。由唯一性，$Y \sim \chi^2(\sum r_i)$。

★Cor 5.4-2 & 5.4-3：正态 → 卡方

Cor 5.4-2：$Z_1,\ldots,Z_n$ i.i.d. $N(0,1)$ → $\sum_{i=1}^n Z_i^2 \sim \chi^2(n)$。

证明：Thm 3.3-2 已证 $Z_i^2 \sim \chi^2(1)$。再由 Thm 5.4-2 的卡方可加性，$\sum Z_i^2 \sim \chi^2(n)$。

Cor 5.4-3：$X_i \sim N(\mu_i, \sigma_i^2)$ 独立 → $\sum_{i=1}^n \left(\frac{X_i-\mu_i}{\sigma_i}\right)^2 \sim \chi^2(n)$。

因为标准化后 $\frac{X_i-\mu_i}{\sigma_i} \sim N(0,1)$，然后套 Cor 5.4-2。

正态分布的线性组合 §5.5 Linear Combinations of Normals

★Thm 5.5-1：独立正态线性组合仍是正态

$X_i \sim N(\mu_i, \sigma_i^2)$ 独立，$Y = \sum_{i=1}^n a_i X_i$。则：

$$Y \sim N\!\left(\sum_{i=1}^n a_i \mu_i,\; \sum_{i=1}^n a_i^2 \sigma_i^2\right)$$

证明：$M_{X_i}(t) = \exp(\mu_i t + \frac{1}{2}\sigma_i^2 t^2)$。

$$M_Y(t) = \prod_{i=1}^n M_{X_i}(a_i t) = \prod_{i=1}^n \exp\!\left(\mu_i a_i t + \frac{1}{2}\sigma_i^2 a_i^2 t^2\right) = \exp\!\left(\sum a_i\mu_i \cdot t + \frac{1}{2}\sum a_i^2\sigma_i^2 \cdot t^2\right)$$

这正是 $N(\sum a_i\mu_i,\; \sum a_i^2\sigma_i^2)$ 的 mgf。

$X_1,\ldots,X_n$ i.i.d. $N(\mu,\sigma^2)$。则 $\bar{X} \sim N(\mu, \frac{\sigma^2}{n})$。标准化：$\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$。

样本方差的无偏性 Sample Variance — Unbiasedness

📖样本方差：为什么分母是 $n-1$？
$$S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$$

无偏性：$E[S^2] = \sigma^2$。如果分母用 $n$，期望是 $\frac{n-1}{n}\sigma^2 < \sigma^2$——会系统性低估。

★无偏性的完整证明

关键恒等式：

$$\sum_{i=1}^n (X_i - \mu)^2 = \sum_{i=1}^n (X_i - \bar{X})^2 + n(\bar{X} - \mu)^2$$

推导：$(X_i - \mu) = (X_i - \bar{X}) + (\bar{X} - \mu)$。平方后求和，交叉项 $\sum (X_i - \bar{X})(\bar{X} - \mu) = (\bar{X} - \mu)\sum (X_i - \bar{X}) = 0$（因为 $\sum X_i - n\bar{X} = 0$）。

取期望：

$$\sum_{i=1}^n E[(X_i-\mu)^2] = \sum_{i=1}^n \sigma^2 = n\sigma^2$$ $$E[n(\bar{X}-\mu)^2] = n \cdot \mathrm{Var}(\bar{X}) = n\cdot \frac{\sigma^2}{n} = \sigma^2$$ $$n\sigma^2 = (n-1)E[S^2] + \sigma^2 \;\Rightarrow\; E[S^2] = \sigma^2 \quad\blacksquare$$

直观：$\bar{X}$ 是基于数据算出来的，所以 $\sum (X_i - \bar{X})^2$ 比 $\sum (X_i - \mu)^2$ 要"小"（$\bar{X}$ 总在数据中心，$\mu$ 未必）。这个"损失"恰好对应一个自由度。

§5.5（续）Thm 5.5-2 & Student's t 分布

★Thm 5.5-2：正态样本下 $\bar{X}$ 与 $S^2$ 独立，且 $(n-1)S^2/\sigma^2 \sim \chi^2(n-1)$

$X_1,\ldots,X_n$ i.i.d. $N(\mu,\sigma^2)$。则：

(1) $\bar{X}$ 与 $S^2$ 相互独立（仅在正态分布下成立）。

(2)

$$\frac{(n-1)S^2}{\sigma^2} = \sum_{i=1}^n \left(\frac{X_i - \bar{X}}{\sigma}\right)^2 \sim \chi^2(n-1)$$

证明（第2部分，mgf方法）：

设 $W = \sum_{i=1}^n \left(\frac{X_i-\mu}{\sigma}\right)^2 \sim \chi^2(n)$（Cor 5.4-3）；$Z = \frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$（Cor 5.5-1）。

由样本方差恒等式：$\frac{(n-1)S^2}{\sigma^2} + Z^2 = W$。即 $\frac{(n-1)S^2}{\sigma^2} = W - Z^2$。

利用 $\bar{X}$ 与 $S^2$ 独立（不在此证明），且 $Z^2 \sim \chi^2(1)$，两边取 mgf：

$$M_W(t) = M_{(n-1)S^2/\sigma^2}(t) \cdot M_{Z^2}(t)$$ $$(1-2t)^{-n/2} = M_{(n-1)S^2/\sigma^2}(t) \cdot (1-2t)^{-1/2}$$ $$\Rightarrow M_{(n-1)S^2/\sigma^2}(t) = (1-2t)^{-(n-1)/2}$$

这正是 $\chi^2(n-1)$ 的 mgf。$\blacksquare$

为什么丢了一个自由度？用 $\bar{X}$ 替代 $\mu$ 时，$X_i - \bar{X}$ 满足约束 $\sum (X_i - \bar{X}) = 0$——$n$ 个变量中只有 $n-1$ 个是自由变化的。这和 $E[S^2] = \sigma^2$ 的分母 $n-1$ 是一致的。

🔗Cor 5.4-3 vs Thm 5.5-2 — 自由度从 $n$ 降到 $n-1$

$\sum \left(\frac{X_i - \mu}{\sigma}\right)^2 \sim \chi^2(n)$（用真实均值 $\mu$）

$\sum \left(\frac{X_i - \bar{X}}{\sigma}\right)^2 \sim \chi^2(n-1)$（用样本均值 $\bar{X}$ 替代 $\mu$）

用估计值替代真实参数 → 损失一个自由度。这是统计推断中反复出现的模式。

📖Student's t 分布 — 为什么需要它？

实际中 $\sigma$ 通常是未知的——我们不能用 $\frac{\bar{X}-\mu}{\sigma/\sqrt{n}}$ 因为 $\sigma$ 不知道。自然想到用 $S$ 替代 $\sigma$：$\frac{\bar{X}-\mu}{S/\sqrt{n}}$。但这个量的分布不再是标准正态——因为分母 $S$ 本身也是随机的。t 分布就是为这个场景设计的。

★t 分布的定义 (Thm 5.5-3)

若 $Z \sim N(0,1)$，$U \sim \chi^2(r)$，且 $Z$ 与 $U$ 独立，则：

$$T = \frac{Z}{\sqrt{U/r}} \;\sim\; t(r)$$

pdf：$f(t) = \frac{\Gamma(\frac{r+1}{2})}{\sqrt{\pi r}\,\Gamma(\frac{r}{2})}\left(1 + \frac{t^2}{r}\right)^{-\frac{r+1}{2}},\; t \in (-\infty, \infty)$。

$r$ 是自由度。$r \to \infty$ 时 $t(r) \to N(0,1)$。

关键的"工程实现"：正态样本下，$\bar{X}$ 与 $S^2$ 独立（Thm 5.5-2 第1部分），$Z = \frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$ 只含 $\bar{X}$，$U = \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$ 只含 $S^2$。二者独立 → 可以拼出 $t$：

$$\frac{\bar{X} - \mu}{S/\sqrt{n}} = \frac{Z}{\sqrt{U/(n-1)}} \;\sim\; t(n-1)$$

对比：已知 $\sigma$ 时 $\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$；$\sigma$ 未知时 $\frac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$。后者是实际数据分析中最常用的统计量之一。

💡t 分布 vs 正态分布

$r=1$ 时 $t(1)$ 就是柯西分布（尾巴极重，均值不存在）。$r$ 越大，$t$ 越接近正态。$r \ge 30$ 时二者几乎不可区分。t 分布的尾巴更重——$S$ 的不确定性在小样本下会导致更多的极端偏离。

§5.6 中心极限定理 Central Limit Theorem

📖依分布收敛 Convergence in Distribution

$Z_n \xrightarrow{d} Z$（或 $Z_n \xrightarrow{\mathcal{L}} Z$）若 $\lim_{n\to\infty} F_{Z_n}(z) = F_Z(z)$，对所有 $F_Z$ 的连续点 $z$。

含义：$Z_n$ 的 cdf 逐点趋近于 $Z$ 的 cdf。注意：这是分布层面的收敛，$Z_n$ 和 $Z$ 不必定义在同一概率空间上——收敛的是分布形状，而不是随机变量本身。

★CLT — 中心极限定理 (Page 208)

$X_1,\ldots,X_n$ i.i.d.，均值为 $\mu$，方差为 $\sigma^2$（$0 < \sigma^2 < \infty$）。则：

$$\frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \;\xrightarrow{d}\; N(0,1),\quad n \to \infty$$

三句等价说法（对充分大的 $n$）：

(1) $\frac{\bar{X}-\mu}{\sigma/\sqrt{n}}$ 近似 $N(0,1)$

(2) $\bar{X}$ 近似 $N(\mu, \frac{\sigma^2}{n})$

(3) $\sum_{i=1}^n X_i$ 近似 $N(n\mu, n\sigma^2)$

最重要的结论：不管原始分布是什么形状（二项、泊松、均匀、指数、甚至完全不知名的分布），只要方差有限，样本均值在大样本下都近似正态。CLT 是为什么正态分布在统计学中无处不在的根本原因。

✎例2 (Page 209)：CLT 数值实例

$n=25$，$\mu=15$，$\sigma^2=4$。求 $P(14.4 < \bar{X} < 15.6)$。

CLT：$\bar{X}$ 近似 $N(15,\; \frac{4}{25}) = N(15, 0.4^2)$。

$$P(14.4 < \bar{X} < 15.6) = \Phi\!\left(\frac{15.6-15}{0.4}\right) - \Phi\!\left(\frac{14.4-15}{0.4}\right) = \Phi(1.5) - \Phi(-1.5) = 0.8664$$

$X_1,X_2$ i.i.d. $U(0,1)$。$\mu=\frac12$，$\sigma^2=\frac{1}{12}$。$Y = X_1+X_2$。

精确 pdf（通过 cdf 方法推导）：$g(y) = y$（$0

CLT 近似：$Y$ 近似 $N(2\cdot\frac12, 2\cdot\frac{1}{12}) = N(1, \frac16)$。

$n=2$ 时三角形和正态差距明显。取 $n=4$，$U(0,1)$ 的四次和已经非常接近正态——CLT 说 $n \to \infty$ 时才精确成立，但实际中 $n \ge 30$ 通常就够用了（取决于原始分布的偏度）。

§5.7 离散分布的正态近似 Normal Approximation for Discrete Distributions

💡基本思想：用连续 pdf "贴合"离散直方图

离散 RV $Y$ 的直方图：每个 $k$ 上有一个宽度为 1、高度为 $P(Y=k)$ 的矩形。矩形面积 = 概率。

如果找一个连续 pdf 使它的曲线"穿过"这些矩形的顶部，那么可以用该连续分布来近似计算概率。CLT 告诉我们，当 $Y$ 是很多 i.i.d. RV 之和时，正态 pdf 恰好能做到——这就是正态近似的理论基础。

★半单位修正（连续性修正）Half-Unit Correction

$Y$ 是离散 RV（取值整数），用连续分布近似时：

$$P(Y = k) \;\approx\; P\!\left(k - \tfrac12 < Y_{\text{cont}} < k + \tfrac12\right)$$ $$P(a \le Y \le b) \;\approx\; P\!\left(a - \tfrac12 < Y_{\text{cont}} < b + \tfrac12\right)$$

为什么需要修正？离散的 $P(Y=k)$ 对应直方图中从 $k-0.5$ 到 $k+0.5$ 的矩形面积。如果直接用 $P(Y_{\text{cont}} = k)$，连续分布的单点概率为 0，完全没意义。所以必须用区间来"接住"这个矩形。

✎例1 (Page 216)：$Y \sim b(10, 0.5)$，$P(3 \le Y < 6)$

$E[Y] = 5$，$\mathrm{Var}(Y) = 2.5$。精确概率：$\sum_{k=3}^5 \binom{10}{k}(0.5)^{10} = 0.5683$。

CLT 近似（带半单位修正）：$Y$ 近似 $N(5, 2.5)$。

$$\begin{aligned} P(3 \le Y < 6) &\approx P(2.5 < Y_{\text{normal}} < 5.5) \\ &= \Phi\!\left(\frac{5.5-5}{\sqrt{2.5}}\right) - \Phi\!\left(\frac{2.5-5}{\sqrt{2.5}}\right) \\ &= \Phi(0.316) - \Phi(-1.581) = 0.6240 - 0.0570 = \mathbf{0.5670} \end{aligned}$$

近似值 0.5670 vs 精确值 0.5683——误差仅 0.0013！

✎例2 (Page 217)：泊松和的两种算法对比

$X_1,\ldots,X_{20}$ i.i.d. $\text{Poisson}(1)$。则 $Y = \sum X_i \sim \text{Poisson}(20)$（由 mgf 可证）。

$P(16 < Y \le 21)$。

精确（查泊松表或用公式）：$\sum_{k=17}^{21} \frac{20^k e^{-20}}{k!} = 0.4226$。

CLT 近似（带半单位修正）：$Y$ 近似 $N(20, 20)$。

$$P(16 < Y \le 21) \approx P(16.5 < Y_{\text{normal}} < 21.5) = \Phi(0.335) - \Phi(-0.783) = 0.4142$$

误差约 0.008——可接受。

注意 CLT 用的是 $Y \approx N(20, 20)$，不是 $\text{Poisson}(20)$ 的 pmf。这说明了 CLT 和精确分布（mgf 推出来的）是两个不同层面的事。

§5.8 切比雪夫不等式 Chebyshev's Inequality

★切比雪夫不等式 (Thm 5.8-1)

$X$ 有有限均值 $\mu$ 和有限方差 $\sigma^2$。对任意 $k \ge 1$：

$$P(|X - \mu| \ge k\sigma) \le \frac{1}{k^2}$$

等价形式（取 $\epsilon = k\sigma$）：$P(|X-\mu| \ge \epsilon) \le \frac{\sigma^2}{\epsilon^2}$。

★证明

考虑离散 RV（连续同理，改求和为积分）。$\sigma^2 = \sum_{x}(x-\mu)^2 f(x)$。

将求和拆成两部分：$A = \{x \mid |x-\mu| \ge k\sigma\}$（"偏离大的区域"），$A^c$（"偏离小的区域"）。

$$\sigma^2 = \sum_{x\in A}(x-\mu)^2 f(x) + \sum_{x\in A^c}(x-\mu)^2 f(x) \ge \sum_{x\in A}(x-\mu)^2 f(x)$$

在 $A$ 内，$(x-\mu)^2 \ge k^2\sigma^2$。所以：

$$\sigma^2 \ge \sum_{x\in A} k^2\sigma^2 f(x) = k^2\sigma^2 \sum_{x\in A} f(x) = k^2\sigma^2 \cdot P(A)$$ $$\Rightarrow P(|X-\mu| \ge k\sigma) = P(A) \le \frac{1}{k^2} \quad\blacksquare$$

深刻之处：不需要知道 $X$ 的分布是什么！只要知道 $\mu$ 和 $\sigma^2$，就可以给出一个（保守的）概率上界。代价是上界通常很松——比如正态分布中 $P(|X-\mu|\ge 2\sigma) \approx 0.045$，但切比雪夫只给出 $\le 0.25$。

✎例1 (Page 222)：$\mu=25, \sigma^2=16$

下界（"在均值附近"的概率至少多大）：

$P(17 < X < 33) = P(|X-25| < 8) = 1 - P(|X-25| \ge 2\sigma) \ge 1 - \frac{1}{4} = \frac{3}{4}$。

上界（"偏离太远"的概率至多多大）：

$P(|X-25| \ge 12) = P(|X-25| \ge 3\sigma) \le \frac{1}{9}$。

依概率收敛与大数定律 Convergence in Probability & LLN

📖依概率收敛 Convergence in Probability

$Z_n \xrightarrow{p} Z$ 若对任意 $\epsilon > 0$：$\lim_{n\to\infty} P(|Z_n - Z| \ge \epsilon) = 0$。

含义：随着 $n$ 增大，$Z_n$ 偏离 $Z$ 超过任意小正数 $\epsilon$ 的概率趋于零。$Z_n$ 以越来越高的概率"贴近"$Z$。不同于依分布收敛——这里 $Z_n$ 和 $Z$ 定义在同一个概率空间上。

★大数定律 Law of Large Numbers (LLN)

$X_1,\ldots,X_n$ i.i.d.，$E[X_i] = \mu$（有限）。则：

$$\bar{X} \;\xrightarrow{p}\; \mu$$

证明（用切比雪夫不等式）：

$E[\bar{X}] = \mu$，$\mathrm{Var}(\bar{X}) = \frac{\sigma^2}{n}$。

$$P(|\bar{X} - \mu| \ge \epsilon) \le \frac{\mathrm{Var}(\bar{X})}{\epsilon^2} = \frac{\sigma^2}{n\epsilon^2} \longrightarrow 0,\quad n \to \infty \quad\blacksquare$$

§5.9 极限mgf —— 二项分布的两个归宿 Limiting MGF

★Thm 5.9-1：mgf 点态收敛 ⇒ 依分布收敛

若 $\lim_{n\to\infty} M_{Z_n}(t) = M_Z(t)$ 对 $t$ 在 $0$ 的某个开邻域内成立，且 $M_Z(t)$ 是某个分布的 mgf，则 $Z_n \xrightarrow{d} Z$。

这是从"mgf 唯一确定分布"自然延伸出来的——如果 mgf 收敛，分布也就收敛了。

★应用1：二项 → 泊松（$n$ 大，$p$ 小，$np = \lambda$ 固定）

$Z_n \sim b(n, p = \lambda/n)$。mgf：$M_{Z_n}(t) = [(1-p) + p e^t]^n$。

$$M_{Z_n}(t) = \left[1 - \frac{\lambda}{n} + \frac{\lambda}{n}e^t\right]^n = \left[1 + \frac{\lambda(e^t - 1)}{n}\right]^n$$

取极限，利用 $\lim_{n\to\infty} (1 + \frac{b}{n})^n = e^b$：

$$\lim_{n\to\infty} M_{Z_n}(t) = e^{\lambda(e^t-1)}$$

这正是 $\text{Poisson}(\lambda)$ 的 mgf。由 Thm 5.9-1：$b(n, \lambda/n) \xrightarrow{d} \text{Poisson}(\lambda)$。

这就是 Lecture 6 中学过的"$n \ge 20$，$p \le 0.05$ 时用泊松近似"的数学证明。条件是 $np = \lambda$ 保持常数——$n$ 越大，$p$ 必须越小。

✎例1 (Page 227)：$Y \sim b(50, 1/25)$，$P(Y \le 1)$

$n=50$，$p=0.04$。$np = 2 = \lambda$。精确概率：

$$P(Y\le 1) = \binom{50}{0}(0.96)^{50} + \binom{50}{1}(0.04)(0.96)^{49} = 0.4$$

泊松近似（$\lambda=2$）：$P(Y\le 1) \approx e^{-2} + 2e^{-2} = 3e^{-2} = 0.406$。差异仅 0.006。

🔗二项分布的两种极限——取决于 $p$ 的行为
参数设置$n\to\infty$ 时的极限证明工具典型场景
$p$ 固定（如 $p=0.3$）正态 $N(np, np(1-p))$CLT大量伯努利试验
$np=\lambda$ 固定，$p=\lambda/n \to 0$泊松 $\text{Poisson}(\lambda)$极限 mgf稀有事件

两者不矛盾：当 $p$ 固定时，$np \to \infty$（泊松的 $\lambda$ 趋于无穷），而 $\text{Poisson}(\lambda)$ 中 $\lambda$ 很大时本身就近似正态——所以两种极限路径最终殊途同归。但当 $p$ 很小且 $np$ 适中时，泊松近似远优于正态近似。

CLT 的 mgf 证明 Proof of CLT via MGF

★完整证明步骤（Page 208）

$X_1,\ldots,X_n$ i.i.d.，$E[X_i] = \mu$，$\mathrm{Var}(X_i) = \sigma^2$。我们需要证：

$$W_n = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \xrightarrow{d} N(0,1)$$

Step 1 — 引入标准化变量：令 $Z_i = \frac{X_i - \mu}{\sigma}$。则 $E[Z_i] = 0$，$\mathrm{Var}(Z_i) = 1$。且：

$$W_n = \frac{1}{\sqrt{n}}\sum_{i=1}^n Z_i$$

Step 2 — 写出 $W_n$ 的 mgf：设 $M_Z(t) = E[e^{t Z_i}]$ 是共同 mgf。由独立性：

$$M_{W_n}(t) = \left[M_Z\!\left(\frac{t}{\sqrt{n}}\right)\right]^n$$

Step 3 — $M_Z(s)$ 在 $s=0$ 处的泰勒展开：$M_Z(0) = 1$，$M_Z'(0) = E[Z_i] = 0$，$M_Z''(0) = E[Z_i^2] = 1$。

$$M_Z(s) = M_Z(0) + M_Z'(0)s + \frac{M_Z''(0)}{2}s^2 + o(s^2) = 1 + \frac{s^2}{2} + o(s^2)$$

$o(s^2)$ 表示比 $s^2$ 更高阶的项（$s^3, s^4, \ldots$）。

Step 4 — 代入 $s = t/\sqrt{n}$：

$$M_Z\!\left(\frac{t}{\sqrt{n}}\right) = 1 + \frac{t^2}{2n} + o\!\left(\frac{1}{n}\right)$$

Step 5 — 取 $n$ 次方并求极限：

$$M_{W_n}(t) = \left[1 + \frac{t^2}{2n} + o\!\left(\frac{1}{n}\right)\right]^n$$

利用 $\lim_{n\to\infty} (1 + \frac{b}{n})^n = e^b$：

$$\lim_{n\to\infty} M_{W_n}(t) = e^{t^2/2}$$

$e^{t^2/2}$ 恰好是 $N(0,1)$ 的 mgf。由 Thm 5.9-1，$W_n \xrightarrow{d} N(0,1)$。$\blacksquare$

💡证明的核心洞察

为什么必须是正态？泰勒展开中线性项消失（因为 $E[Z_i]=0$），保留二阶项 $t^2/(2n)$。更高阶项被 $n^{-3/2}$ 压制（$s^3 = t^3/n^{3/2}$），取 $n$ 次方后也趋于 0。所以极限只保留了二阶信息——恰好对应正态分布的方差参数。

如果三阶矩非零（分布有偏斜），展开中有 $s^3$ 项——但在标准化和 $n\to\infty$ 的作用下被淹没。这就是为什么任何分布都收敛到同一个正态——标准化消掉了所有分布的"个性"，只留下均值和方差决定的"共性"。

⚠Lecture 13-18 常见易错点

1. 二元正态：$\rho=0 \iff X \perp Y$。这是二元正态独有——一般分布只有 $\Rightarrow$ 方向。

2. $g(y)=f(v(y))|v'(y)|$ 的绝对值不能丢。$v'(y)$ 在递减情形下为负，不加绝对值 pdf 会变负。

3. 概率积分变换：$F(X) \sim U(0,1)$ 要求 $F$ 连续。离散分布不适用。

4. 样本方差分母是 $n-1$，因为 $E[S^2] = \sigma^2$。这是无偏性的代价。

5. $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$，自由度是 $n-1$。$\bar{X}$ 的约束消耗了一个自由度。

6. $\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$ vs $\frac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$。$\sigma$ 已知用正态，$\sigma$ 未知用 $t$。

7. CLT 不需要正态假设。方差有限就够。但 CLT 告诉的是渐进分布，不是精确分布。

8. 半单位修正：离散 $P(Y=k) \approx P(k-0.5 < Y_{\text{cont}} < k+0.5)$。不做修正直接代会引入偏差。

9. 切比雪夫给的是（很松的）上界，不是近似值。考试中看到"$\le$"和"$\ge$"要分清楚方向。

10. 二项分布两种极限不矛盾：$p$ 固定 → CLT → 正态；$np$ 固定 → 极限mgf → 泊松。前者 $np \to \infty$，后者 $np = \lambda$ 不变。
