★ 超几何分布 Hypergeometric Distribution（Ch2.1 + Ch2.2/2.3，笔记完全未覆盖）
📖设定与 pmf

共有 $N = N_1 + N_2$ 个对象，其中 $N_1$ 个属于"第一类"（如红球），$N_2$ 个属于"第二类"（如蓝球）。

从中无放回随机抽取 $n$ 个，令 $X =$ 抽到的第一类对象个数。

$X$ 服从超几何分布（hypergeometric distribution），其 pmf 为：

$$f(x) = P(X = x) = \frac{\binom{N_1}{x}\binom{N_2}{\,n-x\,}}{\binom{N}{n}}$$

支撑集 $S$ 由以下不等式约束：

$$x \le n,\quad x \le N_1,\quad n - x \le N_2$$
核心区别：无放回抽样 → 超几何；有放回抽样 → 二项。超几何描述的是"不放回地数成功次数"，与二项（独立重复试验）对应但概率不独立。
★均值与方差

记 $p = \dfrac{N_1}{N}$（总体中第一类的比例），则：

$$E[X] = n\cdot\frac{N_1}{N} = np$$
$$\mathrm{Var}(X) = n\cdot\frac{N_1}{N}\cdot\frac{N_2}{N}\cdot\frac{N-n}{N-1} = np(1-p)\cdot\frac{N-n}{N-1}$$

注意方差里多了一个因子 $\dfrac{N-n}{N-1}$（有限总体校正系数，finite population correction）。当 $N$ 很大、$n$ 相对很小时它 $\approx 1$，此时超几何 ≈ 二项。

✎例（教材 Ex 2.1-5）：池塘里的鱼

池塘有 50 条鱼，其中 10 条被标记过。随机无放回地捕 7 条，令 $X$ 为被标记的鱼数。

$N=50,\; N_1=10,\; n=7$。恰好捕到 2 条标记鱼的概率：

$$P(X=2) = \frac{\binom{10}{2}\binom{40}{5}}{\binom{50}{7}}$$

⚠1. 泊松近似二项 —— 实用判据（Ch2.6）

笔记讲了"泊松是二项(大 $n$ 小 $p$)的极限"，但没给教材的实用门槛。教材明确写道：

$$\text{近似相当准，当 } n \ge 20 \text{ 且 } p \le 0.05,\quad \text{或 } n \ge 100 \text{ 且 } p \le 0.10$$

即把 $X\sim b(n,p)$ 近似为 $\mathrm{Poisson}(\lambda=np)$ 时，用上面的经验规则判断"能不能近似"。

⚠2. 无序且可重复抽样（星与棒，Ch1.2 Remark）

笔记覆盖了"有序有/无放回"和"无序无放回(组合数)"。教材还提了无序且可重复的计数（即把 $r$ 个相同对象分到 $n$ 类）：用 $r$ 个 0 和 $n-1$ 个分隔符 | 的可区分排列来数，结果为：

$$\binom{n-1+r}{r} = \frac{(n-1+r)!}{r!\,(n-1)!}$$

例：掷 10 次六面骰（=10 个相同结果分到 6 个面），无序结果数为 $\binom{6-1+10}{10}=\binom{15}{10}=3003$。教材标注"not needed as often"，了解即可。

⚠3. 相互独立在 3 个事件上的推广（Ch1.4）

笔记给了两事件独立时 $A$ 与 $B'$、$A'$ 与 $B$、$A'$ 与 $B'$ 独立。教材还指出：若 $A,B,C$ 相互独立（mutually independent），则进一步有

(a) $A$ 与 $B\cap C$ 独立；  (b) $A$ 与 $B\cup C$ 独立；  (c) $A'$ 与 $B\cap C'$ 独立；

并且 $A', B', C'$ 也相互独立。建议把"相互独立 ⇒ 任意布尔组合仍独立"这条补进笔记的独立性卡片。

⚠4. 零概率事件的独立性（Ch1.4 脚注式说明）

教材提醒：若 $P(A)=0$ 或 $P(B)=0$，则 $P(A\cap B)=0=P(A)P(B)$ 自动成立，即零概率事件与任何事件独立。笔记在"独立 vs 互斥"里强调了"互斥一般 ⇒ 不独立"，可加一句例外：除非其中某事件概率为 0。
