### 第2周: 矩阵运算 + 行列式
**日期**: 7/28 – 8/3 | **对应DS&A**: Stacks & Queues

**你要实现的**（放在 `linalg/matrix.py`）：

```python
# 基础运算
matrix_add(A, B)         # 矩阵加法
matrix_scalar_mul(c, A)  # 标量乘法
matrix_mul(A, B)         # 矩阵乘法 — 三重循环，先写对再想性能
transpose(A)             # 转置 Aᵀ

# 矩阵-向量
matvec_mul(A, v)         # 矩阵乘向量 Ax

# 行列式
determinant(A)           # 递归实现：用Laplace展开（按第一行展开）
                         # 这是 O(n!) 的算法，对 3×3、4×4 可以，大矩阵太慢
                         # 先写对，后面学了LU分解再用LU算行列式
```

**关键挑战 — 矩阵乘法**：

这是你第一个"三层循环"的程序。先写出最直观的版本：
```python
# i行 j列 k累加
for i in range(m):
    for j in range(p):
        for k in range(n):
            C[i][j] += A[i][k] * B[k][j]
```
写完验证正确之后，思考一个问题：循环顺序换成 i-k-j 会有什么不同？不是因为结果不同（结果一样），而是**缓存命中率**不同。这个思考题不用写代码回答，但值得在周末讨论时想一想。

**行列式递归**：
用 Laplace 展开（选第一行）：
```
det(A) = Σⱼ (-1)^(1+j) * a₁ⱼ * det(M₁ⱼ)
```
其中 M₁ⱼ 是去掉第1行第j列的子矩阵。写一个 `minor(A, row, col)` 函数来生成子矩阵。

递归终止条件：1×1 矩阵的行列式就是那个元素；2×2 矩阵直接用公式 ad-bc。

**周末产出**：`matrix.py`，包含矩阵运算 + 行列式，周中测试用小矩阵（3×3、4×4），numpy验证。

### 第3周: 高斯消元
**日期**: 8/4 – 8/10 | **对应DS&A**: Union-Find

**你要实现的**（放 `linalg/solver.py`）：

```python
# 解 Ax = b 的完整流程
forward_elimination(A, b)    # 前向消元 → 上三角形式
backward_substitution(U, c)  # 回代 → 解向量 x
solve(A, b)                  # 组合上述两步，返回 x

# 辅助
is_upper_triangular(U)       # 检查矩阵是否是上三角
is_singular(A)               # 是否奇异（消元后某行全0？）
```

**关键挑战**：

1. **选主元（Partial Pivoting）**：如果当前列的对角元素是 0 或接近 0，需要交换行。具体做法：在当前列、当前行及以下，找绝对值最大的元素所在行，交换到当前行。不选主元会导致除零错误或者严重浮点误差。

2. **浮点零判断**：消元后判断某行是否为全零时，用 `abs(x) < 1e-10` 而不是 `x == 0`。

3. **增广矩阵**：你需要把 A 和 b 拼在一起操作。建议写一个 `augment(A, b)` 函数，返回一个增广矩阵。

**测试建议**：
- 先用你手算过的简单例子（比如课上讲的那些 2×2、3×3 系统）
- 随机生成一个矩阵 A 和向量 x_true，算出 b = A × x_true，然后跑 `solve(A, b)`，看看算出来的 x 和 x_true 是否一致
- 故意构造一个奇异矩阵（比如两行成比例），看程序是否正确报错

**周末产出**：`solver.py`，能正确解任意方阵线性系统（含选主元）。

### 第4周: LU 分解
**日期**: 8/11 – 8/17 | **对应DS&A**: Hash Tables

**你要实现的**（追加到 `solver.py` 或新建 `linalg/decomposition.py`）：

```python
lu_decompose(A)              # 返回 (L, U) — Doolittle算法，L对角线为1
lu_solve(L, U, b)            # 用L和U分两步解：先解Ly=b（前向代入），再解Ux=y（回代）
det_via_lu(A)                # 用LU分解算行列式 — det(A) = det(L)×det(U) = ∏uᵢᵢ
```

**核心思路**：

Doolittle 算法逐行逐列算，不需要做选主元的高斯消元。伪代码：
```
for k = 0 to n-1:
    # 算U的第k行
    for j = k to n-1:
        U[k][j] = A[k][j] - sum(L[k][s] * U[s][j] for s=0..k-1)
    # 算L的第k列
    for i = k+1 to n-1:
        L[i][k] = (A[i][k] - sum(L[i][s] * U[s][k] for s=0..k-1)) / U[k][k]
```

三角形矩阵的行列式就是对角线元素乘积，`det_via_lu` 只需要一两行。

**对比实验**：
用第2周写的递归 `determinant()` 和第4周写的 `det_via_lu()` 分别算同一个 10×10 矩阵的行列式，比较运行时间。感受一下 O(n!) 和 O(n³) 在 n=10 的差距——以及为什么 n=100 时递归版本基本跑不完。

**周末产出**：`decomposition.py`（或追加到 `solver.py`），包含 Doolittle LU 分解。

### 第5周: 特征值 — 幂迭代法
**日期**: 8/18 – 8/24 | **对应DS&A**: Elementary Sorts

**你要实现的**（放在 `linalg/eigen.py`）：

```python
power_iteration(A, max_iters=1000, tol=1e-10)
    # 返回 (eigenvalue, eigenvector) — 最大特征值及其特征向量

rayleigh_quotient(A, v)
    # Rayleigh商: λ ≈ (vᵀAv) / (vᵀv)
    # 幂迭代过程中用这个来估算特征值，比直接用比值更稳定
```

**幂迭代法流程**：

```
1. 随机初始化向量 v（不要用全零）
2. 重复直到收敛：
   a. w = A × v          # 矩阵乘向量
   b. v_new = w / ‖w‖    # 归一化
   c. λ = v_new·(A·v_new) / (v_new·v_new)   # Rayleigh商
   d. 如果 ‖v_new - v‖ < tol，收敛，退出
   e. v = v_new
```

**为什么幂迭代能工作？**

写出 A 的特征分解：A = QΛQᵀ。任意向量 v 可以表示为特征向量的线性组合：v = c₁q₁ + c₂q₂ + ...。那么 A^k v = c₁λ₁^k q₁ + c₂λ₂^k q₂ + ...。当 k → ∞，只要 |λ₁| > |λ₂|，λ₁^k 项会主导，v 会收敛到 q₁ 的方向。

**测试**：构造一个你知道特征值和特征向量的矩阵（比如对角矩阵，或者 3×3 的你手算过的矩阵），跑幂迭代，看结果是否接近。

**周末产出**：`eigen.py`，能做幂迭代求最大特征值和特征向量。

### 第6周: QR 分解（简化版）
**日期**: 8/25 – 8/31 | **对应DS&A**: BST

**你要实现的**（追加到 `decomposition.py`）：

```python
qr_gram_schmidt(A)
    # Gram-Schmidt正交化 → 返回(Q, R)
    # Q是正交矩阵（列向量正交且单位），R是上三角矩阵
    # 要求 A 的列线性无关

qr_algorithm_eigenvalues(A, max_iters=100)
    # QR算法求所有特征值 — 简化版（不要求收敛到全部特征值，理解过程即可）
```

**Gram-Schmidt 流程**：

对 A 的每一列 aⱼ：
1. uⱼ = aⱼ - Σ_{i<j} proj(aⱼ, qᵢ)  ← 减去在前j-1个正交方向上的投影
2. qⱼ = uⱼ / ‖uⱼ‖  ← 单位化
3. R 的第 j 列：rᵢⱼ = qᵢ·aⱼ (对 i≤j)，其余为 0

**QR 算法**（求所有特征值，简化版）：

```
A₀ = A
for k = 1 to max_iters:
    Q_k, R_k = QR分解(A_{k-1})
    A_k = R_k × Q_k     # 反向乘！
    # A_k 会收敛到一个上三角矩阵（或块上三角），对角线就是特征值
```

这是工业上计算特征值的实际方法（numpy 的 `np.linalg.eigvals` 底层就是 QR 算法的变种）。你不用追求它能正确收敛到所有特征值——这个算法有大量工程细节（Hessenberg 约化、双位移策略）——但写一遍会让你理解"课堂上的 det(A-λI)=0 只对 2×2 和 3×3 有用，真正算特征值用的是完全不同的思路"。

**周末产出**：Gram-Schmidt QR 分解，以及一个能跑但可能收敛慢的简化 QR 算法。

### 第7周: SVD（终极项目）
**日期**: 9/1 – 9/7 | **对应DS&A**: Mergesort + 阶段总结
**注意**: 这周可能已经开学，可以适当放宽到10天

**你要实现的**（放在 `linalg/svd.py`）：

```python
svd(A)
    # 返回 (U, S, Vt) 的近似
    # U: m×m 左奇异向量矩阵
    # S: m×n 对角矩阵（非负奇异值递减）
    # Vt: n×n 右奇异向量矩阵的转置

# 内部调用：
# 1. 计算 AᵀA 或 AAᵀ（取较小的那个，节省计算）
# 2. 对那个矩阵做特征分解（用QR算法或者power iteration循环）
# 3. 奇异值 = sqrt(特征值)
# 4. 右奇异向量 = AᵀA 的特征向量
# 5. 左奇异向量 = A × 右奇异向量 / 奇异值（或直接归一化）
```

**简化版 SVD 的实现路径**（不用从头写完整的 Golub-Kahan）：

先做小的 m×n 矩阵（比如 4×3），手工验证。流程：

```
# 假设 A 是 m×n, m ≥ n（如果不是，转置一下）
AᵀA = transpose(A) × A     # n×n 矩阵
# 对 AᵀA 用QR算法求特征值和特征向量
# 或者对每列循环用power iteration + deflation（去掉已找到的成分）
eigenvalues, V = eigen_decompose(AᵀA)   # 特征值 λᵢ, 特征向量 vᵢ

σᵢ = sqrt(λᵢ)               # 奇异值（λᵢ ≥ 0，因为 AᵀA 半正定）
U列 = A × vᵢ / σᵢ            # 左奇异向量（σᵢ ≠ 0时）
                              # σᵢ = 0 的列需要补正交基（可以跳过简化）
Vt = Vᵀ
```

**用真实数据测试**：

做完基础验证后，用一个小型真实矩阵测试。比如：
- 一个 5×3 的"用户-电影评分"矩阵（你自己编的数据）
- 跑 SVD，保留最大的 2 个奇异值
- 用 U₂ S₂ V₂ᵀ 重构原矩阵，看重构误差多大
- 这就是推荐系统中"矩阵补全/降维"的雏形——你已经在做推荐算法最底层的数学了

**最后一步**：用 `np.linalg.svd(A)` 跑同样的矩阵，逐元素对比你的结果和 numpy 的结果。允许符号翻转（特征向量的方向可以相反）。

**周末产出**：`svd.py`，能对 5×3 以内的矩阵做 SVD，并用 numpy 交叉验证。这将成为你简历上"项目经历"的重要素材。

## 工程规范（全程遵守）

这些规范本身就是在为实习做准备——项目代码写得规范，和写得能跑，是两回事。

1. **每个文件开头有 docstring**，写清楚这个模块干什么、依赖什么
2. **每个函数有 docstring**，写清楚输入输出、可能抛什么异常
3. **变量命名**：矩阵用大写 `A, B, L, U`，向量用小写 `v, w, x`，标量用 `c, k, n`。不要用 `a1, a2, temp, thing`
4. **类型标注**（可选但推荐）：`def dot(v1: list[float], v2: list[float]) -> float`
5. **测试写在同一个文件里**：每个文件末尾放一个 `if __name__ == "__main__":` 块，包含 3-5 个测试用例。用 `assert` 做断言，或者自己写简单的 `test_xxx()` 函数
6. **Git 提交**：每周末 push 一次，commit message 用英文（比如 `feat: implement power iteration for eigenvalues`）
7. **不用 numpy 做计算**：只用 numpy 做**验证**——即你写完之后，用 numpy 跑同样的输入，对比结果

## 你可能遇到的困难（提前预警）

**第2周矩阵乘法**：三重循环写错下标是正常的，每个人都卡过。建议先在纸上画出 A (2×3) × B (3×2) → C (2×2)，标注每个维度的名字（m, n, k），然后对应到循环变量上。

**第3周选主元**：最经典的 bug 是交换了行但忘记同时交换 b 向量的对应元素。

**第5周幂迭代**：如果不收敛，检查两件事——矩阵是否有唯一的最大特征值（如果 |λ₁| ≈ |λ₂| 收敛会很慢甚至不收敛），初始向量是否"不幸地"正交于主特征向量（概率极低，但理论上有）

**第6-7周 Gram-Schmidt**：经典 Gram-Schmidt 在浮点运算中会严重失正交性。如果结果和 numpy 差很多，不是你写错了，是算法本身的问题——这个现象本身就值得在周末讨论。

**第7周 SVD**：这是整条线最难的。如果做不到完整的 SVD，做降级版也可以——求 AᵀA 的最大特征值和特征向量，得到一个秩1近似——这也已经是推荐系统的雏形了。
