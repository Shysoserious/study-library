# 常州历史气候数据分析项目（简历对口项目）

## 这个项目是做什么的

用 Python 拉取常州近 15 年的逐日气象数据（气温、降水量），做数据清洗、统计分析、趋势分析和可视化，最后写一份简短的分析结论。

**为什么做它**：你的简历现在有三个项目（贪吃蛇、五子棋、聊天室），但都是游戏/网络方向，和气象局要的"数据/软件/AI"不对口。这个项目补上这个缺口——当你走进常州气象局，简历上写着"用 Python 分析过气象数据"，印象完全不同。而且它练的 pandas、数据清洗、matplotlib，正是数据科学的基本功，对你以后想做的推荐算法/ML 方向同样有用。

**目标完成时间**：2027 年 1 月中旬前（避开 12 月期末考试高峰）。

## 第1步：拉数据（约1-2个晚上）

目标：成功拉到数据，能打印出前 10 行。

`fetch_data.py` 骨架：

```python
from datetime import datetime
from meteostat import Point, Daily

# 常州的坐标（纬度, 经度, 海拔米）
changzhou = Point(31.81, 119.97, 5)

start = datetime(2010, 1, 1)
end = datetime(2024, 12, 31)

# 拉逐日数据
data = Daily(changzhou, start, end)
df = data.fetch()

print(df.head(10))
print("数据行数：", len(df))
print("列名：", df.columns.tolist())

# TODO: 把数据保存成 CSV，方便后面反复使用
# df.to_csv("changzhou_weather.csv")
```

**注意**：meteostat 的 `Point` 用的是"离这个坐标最近的气象站"的数据。如果拉下来发现数据缺失很多，可以换一个更接近常州主城区气象站的坐标，或者改用 `Stations` 手动指定一个站点。这一步踩坑很正常。

**验证成功**：你能看到打印出来的表格，有日期、平均气温（tavg）、最高温（tmax）、最低温（tmin）、降水量（prcp）等列，行数大概 5000+（15年 × 365天）。
