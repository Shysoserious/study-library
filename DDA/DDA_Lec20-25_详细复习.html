Lecture 20 — ML 入门 & KNN

机器学习基础概念 · 分类任务 · KNN 算法

1. 什么是 Machine Learning?

ML 的定义

研究那些通过使用数据来提高自身任务表现的算法，而不是仅靠预先编写好的固定规则。

Statistics vs Machine Learning

统计学机器学习
思路先写模型，再拟合数据让数据告诉我们最好的预测规则
目标理解和解释预测新结果
数据较小、结构化较大、高维
模型简单可解释灵活复杂（黑箱）

ML 四要素

2. 分类任务 (Classification)

目标：将输入分配到若干个类别 (categories) 中的一个。输出是标签 (label)。

例：垃圾邮件检测（spam vs not spam）、图像识别（猫 vs 狗）

分类的挑战

  • 姿势不寻常 / 图片模糊 / 只有部分可见 / 类别长得像
  • Hard cases 是检验分类器好坏的关键

3. 用数字表示对象 (Represent Objects Numerically)

重要理念：表征 (Representation) 是连接现实世界和模型的桥梁——计算机需要数字。

一张图像 → 像素网格 → flatten → $\mathbb{R}^n$ 向量

所有人、商品、事件都可以用多个属性 (attributes) 描述，打包成一个特征向量 (feature vector)。

4. 监督学习 vs 无监督学习

监督学习 Supervised Learning

使用 labeled data（带标签数据）

同时看到输入 $x$ 和期望输出 $y$

典型任务：分类、回归

例：猫狗图像每张标好 y=1(cat) 或 y=0(dog)

无监督学习 Unsupervised Learning

使用 unlabeled data（无标签数据）

自己发现数据中的结构、分组、模式

典型任务：聚类、降维

例：自动把顾客分成不同"人群"

5. KNN 算法 (K-Nearest Neighbors) ⭐⭐⭐

核心思想："物以类聚"

给定一个新数据点，找距离它最近的 K 个训练点，看这 K 个"邻居"中哪一类占多数（majority vote），就把新点归为那一类。

KNN 六步骤（必背！）

  1. Load the labeled data — 加载带标签的训练数据
  2. Choose K — 选择邻居数量 K（超参数）
  3. Compute distances — 算新点到每个训练点的距离
  4. Sort by distance — 按距离从小到大排序
  5. Select K nearest — 取最近的 K 个邻居
  6. Majority vote — 多数投票决定新点的标签

5.1 距离度量：L1 vs L2

L2 距离（欧氏距离）

$$d(x,y) = \sqrt{\sum_{i}(x_i-y_i)^2}$$

直线距离，勾股定理，两点之间线段最短

L1 距离（曼哈顿距离）

$$d(x,y) = \sum_{i}|x_i-y_i|$$

沿坐标轴方向的距离之和，像走街区格子

🌰 例子：A=(0,0), B=(3,4)
  • L2 = $\sqrt{3^2+4^2}=5$（直线飞行）
  • L1 = $|3|+|4|=7$（走街区：先横着走3格再竖着走4格）

5.2 K 值的影响（核心考点）

K=1
边界锯齿状，极易受噪声影响
过拟合 Overfitting
K=3
较平滑，合理选择
K=5
更平滑，常用默认值
K=25
过度平滑，忽略细节
欠拟合 Underfitting
⚠️ K 的选择规则：
  • K 太小 → 噪声影响大 → 过拟合
  • K 太大 → 边界过于平滑 → 欠拟合
  • 极端情况：若 K > 样本总数 N，所有新输入都被预测为训练集中的 majority class，模型完全失去意义

5.3 KNN 例题详解（考试高频题型）

题目：用 KNN（K=1，L1 距离）对新点 (4, 3) 分类。

Pointx₁x₂class
A001
B-311
C522
D332
E503
F4-13

解题步骤：

Step 1：算每个点到 (4,3) 的 L1 距离

  • $d(A) = |0-4|+|0-3| = 7$
  • $d(B) = |-3-4|+|1-3| = 9$
  • $d(C) = |5-4|+|2-3| = 2$
  • $d(D) = |3-4|+|3-3| = \mathbf{1}$ ← 最近
  • $d(E) = |5-4|+|0-3| = 4$
  • $d(F) = |4-4|+|-1-3| = 4$

Step 2：排序 D(1) < C(2) < E(4)=F(4) < A(7) < B(9)

Step 3：K=1，最近邻 D 的 class = 2 → 新点 (4,3) 被分类为 class 2

💡 延伸思考：如果 K=3？取最近三个 D(2)+C(2)+E(3)：两票 class 2、一票 class 3 → 仍然是 class 2。

5.4 KNN 的优缺点

✅ 优点

  • 简单直观，容易理解
  • 容易实现
  • 没有训练阶段（no training phase）

❌ 缺点

  • 预测慢：训练集大时要算很多距离
  • 对 K 值和距离度量敏感
  • 维度灾难：高维空间中"最近"可能没有意义

Lecture 21 — Logistic Regression (逻辑回归)

从"输出标签"到"输出概率" — 参数化的分类模型 — 重中之重 ⭐⭐⭐⭐⭐

输入特征 x → 线性组合 z = θᵀx + b → Sigmoid σ(z) → 概率 P(y=1|x) → 阈值 0.5 判断类别

1. 为什么要用 Logistic Regression？

KNN 的局限性

KNN 输出的是离散的类别标签（如 0 或 1），不输出概率。但很多时候我们需要知道"有多大概率属于这个类"。

Logistic Regression 输出的是概率 $P(y=1 | x)$：

  • 若 $P$ 接近 1 → 预测为正类
  • 若 $P$ 接近 0 → 预测为负类

2. Sigmoid 函数详解（必考 ⭐⭐⭐⭐）

问题：如何把任意实数 z 映射到 (0,1)？

答案：Sigmoid (Logistic) 函数

$$\sigma(z) = \frac{1}{1+e^{-z}}$$

关键性质：

  • $\sigma(0) = \frac{1}{1+1} = \mathbf{0.5}$
  • 当 $z \to +\infty$，$\sigma(z) \to \mathbf{1}$
  • 当 $z \to -\infty$，$\sigma(z) \to \mathbf{0}$
  • 单调递增、处处连续可导
  • 导数：$\sigma'(z) = \sigma(z)[1-\sigma(z)]$（在训练中会用到！）
💡 直觉：Sigmoid 像一个"挤压机"，把整个实数轴压缩到 (0, 1) 之间，方便解释为概率。

3. 模型公式与分类流程 ⭐⭐⭐⭐

三步走

  1. 算得分 (score)：特征的线性组合
    z = θᵀx + b = θ₁x₁ + θ₂x₂ + ... + θ_d x_d + b
  2. Sigmoid 转概率：
    P(y=1 | x) = σ(z) = \frac{1}{1+e^{-(θᵀx+b)}}
  3. 决策规则：若 $P > 0.5$ → 预测 y=1；若 $P \le 0.5$ → 预测 y=0

完整模型公式（二分类）

正类概率：

$$P(y=1|x) = \frac{1}{1+e^{-(θᵀx+b)}}$$

负类概率：

$$P(y=0|x) = 1 - P(y=1|x) = \frac{e^{-(θᵀx+b)}}{1+e^{-(θᵀx+b)}}$$
⚠️ 重要理解：Logistic Regression 的决策边界 $\{x: θᵀx+b=0\}$ 是线性的（超平面）。虽然名字里有 "Regression"，但其实做的是线性分类。

4. MLE 训练：最大似然估计（难点 ⭐⭐⭐⭐⭐）

问题：给定 m 个样本，怎么找到最好的 θ 和 b？

答案：MLE（最大似然估计）——选择能让观察到这些样本的概率最大化的参数。

Log-Likelihood 目标函数

$$\max_{\theta,b} \; l(\theta,b) := \log\prod_{i=1}^{m} P(y^i | x^i, \theta, b) = \sum_{i=1}^{m} \log P(y^i | x^i, \theta, b)$$

好消息：$l(\theta,b)$ 是 凹函数 (concave) → 存在唯一的全局最优解！不会陷入局部最优。

💡 凹性的证明思路（了解即可）：先证 $\log(1+e^{-z})$ 是凸函数 → 取负号变凹 → 凹函数之和还是凹。

坏消息：没有 closed-form solution（闭式解）！令 $\partial l/\partial\theta=0$ 无法解析求解 → 必须用数值方法（梯度下降）。

5. 梯度下降 (Gradient Descent) ⭐⭐⭐⭐⭐

核心思想

从一个初始点出发，不断沿着梯度方向移动来找函数的极值。

最小化（Minimization）

$$x^{(t+1)} = x^{(t)} - \alpha \cdot f'(x^{(t)})$$

沿梯度反方向（下坡）

最大化（Maximization）

$$x^{(t+1)} = x^{(t)} + \alpha \cdot f'(x^{(t)})$$

沿梯度正方向（上坡）

其中 $\alpha$ = 学习率 (learning rate / step size)

5.1 学习率 α 的影响（高频考点）

✅ 理想情况

初期 α 较大 → 快速接近最优；接近最优时 α 变小 → 精细调整。实践中常用衰减学习率：$\alpha^{(t)} = \alpha_0/\sqrt{t}$。

❌ α 太大且固定

可能永远不收敛！

振荡反例（经典考题）

$f(x) = x^2$，$\alpha = 1$，$x^{(0)} = -3$：

$f'(x) = 2x$

$x^{(0)} = -3 \to f'(-3) = -6 \to x^{(1)} = -3 - 1\cdot(-6) = 3$

$x^{(1)} = 3 \to f'(3) = 6 \to x^{(2)} = 3 - 1\cdot6 = -3$

→ 永远在 3 和 -3 之间振荡，无法收敛！

5.2 Logistic Regression 的梯度上升更新

因为 MLE 是最大化问题，用 "+" 号（gradient ascent）：

$$\theta^{t+1} \leftarrow \theta^t + \alpha^{(t)}\cdot\frac{1}{m}\sum_{i=1}^{m}\left[(y^i-1)x^i + \frac{e^{-\theta^Tx^i-b}\cdot x^i}{1+e^{-\theta^Tx^i-b}}\right]$$
$$b^{t+1} \leftarrow b^t + \alpha^{(t)}\cdot\frac{1}{m}\sum_{i=1}^{m}\left[(y^i-1) + \frac{e^{-\theta^Tx^i-b}}{1+e^{-\theta^Tx^i-b}}\right]$$

算法：初始化 $(\theta^0, b^0)$，反复更新直到 $|\theta^{t+1}-\theta^t| \le \varepsilon$ 且 $|b^{t+1}-b^t| \le \varepsilon$。

5.3 SGD (Stochastic Gradient Descent) ⭐⭐⭐

为什么需要 SGD？

如果训练数据 $m$ 非常大（如百万级），每次迭代都要算所有样本的梯度，太慢！

SGD 核心思想：每次迭代只用一个随机的小批量 (mini-batch) 来近似梯度方向。

$$\theta^{t+1} \leftarrow \theta^t + \alpha^{(t)}\cdot\frac{1}{|B|}\sum_{i\in B}[\cdots]$$

$B$ = 随机选的一批样本，$|B|$ = batch size。

💡 GD vs SGD 对比：
  • GD：路径光滑但每步代价高（算全部数据）
  • SGD：路径抖动但每步快很多（算少量数据）

5.5 Gradient Descent 经典练习题

题目：用梯度下降法最大化 $f(x) = -\frac{1}{4}(x-1)^2 + 2$。学习率 α 为常数，初始 $x^{(0)} = 3$。

(a) 以下情况 $x^{(t)}$ 是否收敛到最优解？i. α=0 ii. α=4 iii. α=1

(b) α 在什么范围内能收敛？

分析：最优解 $x^* = 1$（最大值点）。$f'(x) = -\frac{1}{2}(x-1)$

最大化更新：$x^{(t+1)} = x^{(t)} + \alpha f'(x^{(t)}) = x^{(t)} - \frac{\alpha}{2}(x^{(t)}-1)$

令 $u^{(t)} = x^{(t)} - 1$（偏移量），则：$u^{(t+1)} = (1-\frac{\alpha}{2})u^{(t)}$

收敛条件：$|1-\frac{\alpha}{2}| < 1$ → $0 < \alpha < 4$

答案：

  • i. α=0：永不更新，停在 x=3 → 不收敛
  • ii. α=4：u 在 2 和 -2 间振荡 → 不收敛
  • iii. α=1：$u^{(t)} = 2\cdot(0.5)^t \to 0$ → 收敛 ✓
  • (b) $0 < \alpha < 4$ 时收敛

Lecture 22 — K-Means Clustering

无监督学习 · 聚类 · 距离度量 · K-Means 算法

1. 无监督学习 (Unsupervised Learning)

在监督学习中每个样本都有标签 $y$；而在无监督学习中，没有预定义的输出标签，模型自己发现数据中的隐藏模式和结构。

典型应用：客户分群、主题发现、去重、异常检测

监督学习

每个点有标签 (label)

例：标记猫和狗的照片

无监督学习

没有标签，发现结构

例：自动把人分成不同的群组

2. 聚类 (Clustering)

定义：把相似的数据点分到同一组（cluster），组内相似、组间不同。

两种度量：相似度函数 $s(x,y)$（越大越相似）、距离函数 $d(x,y)$（越大越不同）

⚠️ 重要概念："Clustering is subjective"（聚类是主观的）——不同的距离定义、不同的 k 值，可能得到完全不同的分组。没有唯一正确的聚类结果。

3. 距离度量 (Distance Measures) ⭐⭐⭐

距离的性质（三个必要条件）

  1. 对称性 (Symmetry)：$d(x,y) = d(y,x)$
  2. 正定性 (Positive Separability)：$d(x,y) \ge 0$，且 $d(x,y)=0 \iff x=y$
  3. 三角不等式 (Triangle Inequality)：$d(x,z) \le d(x,y) + d(y,z)$
距离公式直觉
Euclidean (L2)$\sqrt{\sum (x_i-y_i)^2}$直线距离，最常用
Manhattan (L1)$\sum |x_i-y_i|$沿坐标轴走的距离
Minkowski (Lp)$(\sum |x_i-y_i|^p)^{1/p}$一般化，p=1→L1，p=2→L2
L∞ (无穷范数)$\max |x_i-y_i|$各维度差值的最大值

4. K-Means 目标函数

K-Means 要解决的问题

给定 $m$ 个数据点 $\{x^1, x^2, \dots, x^m\}$，找到：

  • $k$ 个聚类中心 $\{c^1, c^2, \dots, c^k\}$
  • 每个点的归属 $\pi(i) \in \{1, \dots, k\}$

使总距离最小：

$$\min_{c,\pi} \frac{1}{m} \sum_{i=1}^{m} \|x^i - c^{\pi(i)}\|^2$$

直觉：每个数据点尽量靠近自己所属簇的中心。

5. K-Means 算法流程（必背 ⭐⭐⭐⭐）

  1. 初始化 (Initialize)：随机选择 $k$ 个点作为初始聚类中心 $\{c^1, \dots, c^k\}$
  2. 分配 (Cluster Assignment)：对每个数据点 $x^i$，分配到距离最近的中心
    $\pi(i) = \arg\min_j \|x^i - c^j\|^2$
  3. 更新中心 (Center Adjustment)：每个聚类中心移到该簇所有点的均值
    $c^j = \frac{1}{|\{i:\pi(i)=j\}|} \sum_{i:\pi(i)=j} x^i$
  4. 重复：如果任何中心发生变化，回到第 2 步。否则收敛。

5.1 初始化问题（重要 ⭐⭐⭐）

不同的初始化会导致不同的聚类结果！K-Means 只能保证收敛到局部最优 (local optimum)，而非全局最优 (global optimum)。

实际做法：多次随机初始化，选择目标函数值最小的那次结果。

5.2 K-Means 练习题

使用 K-Means 算法和 L2 范数距离，将 8 个数据点聚成 K=3 簇。

数据点： x¹=(2,8) x²=(2,5) x³=(1,2) x⁴=(5,8) x⁵=(7,3) x⁶=(6,4) x⁷=(8,4) x⁸=(4,7)

初始中心： c¹=x¹=(2,8), c²=x³=(1,2), c³=x⁵=(7,3)

Step 1：计算距离（略去详细计算）

Step 2：分配结果

  • 簇1（c¹）：x¹, x², x⁴, x⁸
  • 簇2（c²）：x³
  • 簇3（c³）：x⁵, x⁶, x⁷

Step 3：更新中心

  • c¹ 新 = ((2+2+5+4)/4, (8+5+8+7)/4) = (13/4, 7)
  • c² 新 = (1, 2)（不变）
  • c³ 新 = ((7+6+8)/3, (3+4+4)/3) = (7, 11/3)

Lecture 23 — Model Selection (模型选择)

过拟合与欠拟合 · 验证集 · K-fold 交叉验证

1. Overfitting & Underfitting（核心概念 ⭐⭐⭐⭐）

过拟合 (Overfitting)

模型学到了训练数据中的特有噪声和模式，在训练集上准确率极高，但在测试集上预测效果很差。

KNN 中 K=1 → 过拟合（决策边界过于复杂）

欠拟合 (Underfitting)

模型过于简单，无法捕捉训练数据和测试数据中的关键模式。

KNN 中 K=101 → 欠拟合（几乎所有点都被投票为多数类）

2. 模型空间 (Model Space)

不同复杂度的模型对应不同大小的假设空间 (Hypothesis Space)：

  • 多项式 degree=1 → 空间 $H_1$（所有一次多项式）
  • 多项式 degree=2 → 空间 $H_2$（所有二次多项式）

关系：$H_1 \subset H_2 \subset H_3 \subset \cdots$（嵌套关系），模型越复杂，空间越大。

3. 模型选择的直觉 ⭐⭐⭐⭐

目标是找到一个模型族，使得测试误差 (Test Error) 最小。

关键规律：

  • Training Error（训练误差）随模型复杂度增加而单调递减
  • Test Error（测试误差）呈 U 形曲线——先降后升
  • 最佳模型就在 U 形曲线的最低点！

4. 验证集方法 (Validation Set）

最简单的模型选择方法

  1. 把数据分成训练集和测试集
  2. 对每个候选模型 $m$：用训练数据训练模型
  3. 在测试数据上计算预测误差 $Err_m$
  4. 选择测试误差最小的模型
⚠️ 问题：选出的模型高度依赖于数据的划分方式！不同的训练/测试拆分可能选出不同的最优模型。

5. K-Fold Cross-Validation（K 折交叉验证 ⭐⭐⭐⭐）

核心方法

把数据分成 K 等份 (folds)，每次用其中 1 份做测试集，剩下 K-1 份做训练集，重复 K 次。

最终误差 = K 次误差的平均值：

$$E = \frac{1}{K}\sum_{i=1}^{K}E_i$$

K 值如何选？

  • 常用 K=5 或 K=10
  • K 越大，计算代价越高
  • K = n（样本数）→ Leave-One-Out (LOO)

为什么比简单验证集好？

  • 每个数据点都既当过训练又当过测试
  • 结果不依赖某次特定的数据划分
  • 误差估计更加稳定可靠

Lecture 24 — Large Language Models (LLM)

从条件概率到推理 — 一条完整的 LLM 构建路线

Token → 条件概率 → Transformer → 预训练 → 后训练 → 推理模型

1. Token 与语言建模

Token：LLM 不直接读整个句子，而是将文本切分为小片段。一个 token 可以是完整单词、词的一部分、或标点符号。

核心思想：语言模型的任务就是预测下一个 token。

2. 条件概率与 Next-Token Prediction

条件概率视角

$$P(x_t \mid x_1, x_2, \dots, x_{t-1})$$

完整句子的概率分解（链式法则）：

$$P(x_1, \dots, x_T) = \prod_{t=1}^{T} P(x_t \mid x_1, \dots, x_{t-1})$$

自回归生成

Context
→

→

3. Transformer 架构 ⭐⭐⭐

Transformer = "条件概率机器"

输入：一串 token 序列；输出：下一个 token 的概率分布。

四个步骤：

  1. Embeddings（词嵌入）：每个 token 变成一个向量。语义相近的 token 在向量空间中距离较近。
  2. Position Information（位置信息）：位置编码告诉模型每个 token 在序列中的位置。"dog bites man" 和 "man bites dog" 不一样。
  3. Masked Self-Attention（掩码自注意力）：每个 token 可以查看它之前的 token。Masked = 看不到未来的 token，这正好符合 next-token prediction。
  4. 最后一层：特征 → 概率：本质上是多类分类器 (multi-class classifier)，从词汇表中选择下一个 token。

Logistic Regression 视角理解 Transformer

= Feature Extractor

最后一层

= Classifier

（多类 Logistic Regression）

4. 自监督训练 (Self-Supervised Learning)

训练文本自己提供标签——前面的 token 是输入，下一个 token 是目标。

损失函数：交叉熵 (cross-entropy loss)

$$\mathcal{L} = -\sum_{t=1}^{T} \log P(x_t \mid x_1, \dots, x_{t-1})$$

这最大化模型对训练数据中每一步"正确下一个 token"的预测概率。

推理时的采样策略：

  • Greedy Decoding：每次取概率最高的 token（简单但多样性差）
  • Beam Search：同时保留多个高分部分序列（质量更好）

5. 预训练 (Pre-training)

在超大规模语料上从零训练一个 base LLM，目标仍是 next-token prediction。变化的是规模：更多数据、更大模型、更多算力。

以 Llama 3 为例的数据管线

  1. Safety Filtering：移除有害内容
  2. Text Extraction & Cleaning：从 HTML 提取纯文本
  3. De-duplication：精确 + 模糊去重
  4. Quality Filtering：规则 + 模型打分过滤低质量文本

6. Scaling Law（规模定律）

在固定算力下，模型大小和训练数据量之间存在最优平衡。

核心思想：用 test error 评估，在给定 FLOPS 预算下找最优配置。

训练配方：AdamW 优化器、学习率逐渐衰减、Batch Size 逐渐增大、Context Length 从 4096 逐步增到 128K。

7. 后训练 (Post-training)

为什么仅靠预训练不够？

预训练模型知识丰富但不听话：可能不遵循指令、回答风格奇怪、不符合人类偏好。

7a. SFT (Supervised Fine-Tuning)

用高质量的 (prompt, response) 数据对模型进行微调，让模型学会遵循指令、按期望格式回答。

7b. DPO (Direct Preference Optimization)

使用三元组数据：(prompt, preferred answer, less preferred answer)

DPO 直接增大 preferred answer 的相对概率，减小 less preferred 的概率，避免了复杂的 RL 管线。

8. 推理模型 (Reasoning Model)

两种常见路径

SFT on 推理 traces

用包含思考步骤的数据做 SFT

RL + Verifiable Rewards

用可验证的奖励信号做强化学习 (GRPO)

3. 统计学速查

MLE (最大似然估计)

$$\hat{\theta}_{MLE} = \arg\max_\theta \prod_{i=1}^{n} f(x_i;\theta) = \arg\max_\theta \sum_{i=1}^{n} \log f(x_i;\theta)$$

线性回归

模型：$y = \beta_0 + \beta_1 x + \varepsilon$，$\varepsilon \sim N(0,\sigma^2)$

MLE 估计等价于最小二乘法 (least squares)。

4. 优化速查

凸集与凸函数

凸集：集合内任意两点的线段都在集合内。

凸函数：$f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y)$

核心定理：凸优化问题的任何局部最小值也是全局最小值。

梯度下降

$$x_{t+1} = x_t - \eta \nabla f(x_t)$$

$\eta$ = 学习率。太大 → 振荡；太小 → 太慢。

Newsvendor (报童问题) 的临界比率公式

最优订货量：$F(q^*) = \frac{c_u}{c_u + c_o}$，其中 $F$ 是需求 CDF，$c_u$ = underage cost，$c_o$ = overage cost。
