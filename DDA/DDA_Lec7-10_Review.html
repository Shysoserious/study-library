Lecture 7 — Continuous Random Variables

连续随机变量 · CDF · PDF · 均匀分布 · 正态分布

1. 连续 vs 离散

Key Difference

核心区别

离散 RV连续 RV
Range可数集合不可数（区间或区间并）
$P(X=x)$$> 0$ 对 range 中的 $x$= 0 对所有 $x$
工具PMF $f(x) = P(X=x)$PDF $f(x)$（概率密度）
Important

关键理解

连续世界中，零概率事件 $\neq$ 不可能事件。

例：$X \sim U[0,1]$，$P(X = 0.5) = 0$，但 $X = 0.5$ 并非不可能！

因为每个点概率为 0，PMF 不再有用 — 我们需要新工具。

2. CDF（累积分布函数）

Formula

CDF 定义与性质（重要考点）

$$F(x) = P(X \le x)$$

性质：

1. $0 \le F(x) \le 1$

2. 单调不减

3. $\lim_{x\to-\infty}F(x) = 0$，$\lim_{x\to+\infty}F(x) = 1$

4. 计算区间概率：$P(a < X \le b) = F(b) - F(a)$

对连续 RV：$P(a \le X \le b) = P(a < X < b) = F(b) - F(a)$（端点无所谓）

3. PDF（概率密度函数）

Formula

PDF 定义（重要考点）

PDF = CDF 的导数 = "单位长度上的概率集中度"：

$$f(x) = F'(x) = \lim_{\Delta x \to 0}\frac{P(x < X \le x+\Delta x)}{\Delta x}$$

关键关系：

$$P(a \le X \le b) = \int_a^b f(x)\,dx$$
$$F(x) = \int_{-\infty}^x f(t)\,dt$$
Properties

PDF 的性质

1. $f(x) \ge 0$ 对所有 $x$

2. $\int_{-\infty}^{+\infty}f(x)\,dx = 1$

3. $f(x)$ 可以 $> 1$！它不是概率，是概率密度。

4. 样本空间 $S = \{x : f(x) > 0\}$

4. 均匀分布 Uniform Distribution

Definition

$X \sim U(a,b)$

PDF

$$f(x) = \begin{cases}\frac{1}{b-a} & a \le x \le b\\0 & \text{otherwise}\end{cases}$$

CDF

$$F(x) = \begin{cases}0 & x < a\\\frac{x-a}{b-a} & a \le x \le b\\1 & x > b\end{cases}$$
$E[X]$$\text{Var}(X)$
$\dfrac{a+b}{2}$$\dfrac{(b-a)^2}{12}$
Example

Monte Carlo 方法直觉

若 $X \sim U(0,1)$，则 $E[g(X)] = \int_0^1 g(x)\,dx$。

抽取大量样本 $x_1,\dots,x_n$ 并计算 $\frac{1}{n}\sum g(x_i)$，即可近似积分值。

这就是 Monte Carlo simulation 的核心思想。

5. 正态分布 Normal Distribution

Formula

$X \sim N(\mu, \sigma^2)$（重要考点）

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$
参数含义影响
$\mu$均值（中心位置）图形左右平移
$\sigma^2$方差（离散程度）$\sigma$ 大 → 图形矮胖；$\sigma$ 小 → 图形尖瘦

$E[X] = \mu$，$\text{Var}(X) = \sigma^2$

CLT

中心极限定理 Central Limit Theorem

大量独立同分布随机变量的和近似服从正态分布（无论原分布是什么）。

这解释了为什么正态分布如此常见（身高、误差、噪声...）。

（不需要证明，只需理解直觉）

6. 连续 RV 的均值与方差

Formulas

从求和到积分

离散（复习）

$$E[X] = \sum_x x\cdot f(x)$$
$$\text{Var}(X) = \sum_x(x-\mu)^2 f(x)$$

连续

$$E[X] = \int_{-\infty}^{+\infty}x\cdot f(x)\,dx$$
$$\text{Var}(X) = \int_{-\infty}^{+\infty}(x-\mu)^2 f(x)\,dx$$

方差恒等式仍成立：$\text{Var}(X) = E[X^2] - (E[X])^2$

Lecture 8 — Conditional Probability (Deep Dive)

条件概率深入 · Monty Hall · Bayes 定理 · 核酸检测

1. 条件概率回顾

Recall

条件概率公式

$$P(Y=y|X=x) = \frac{P(Y=y,\,X=x)}{P(X=x)}, \quad P(X=x) > 0$$

性质：

• $P(Y=y|X=x) \ge 0$

• $\sum_y P(Y=y|X=x) = 1$（固定 $x$，对 $y$ 的条件分布仍是合法概率分布）

Example

NLP 应用

H = 消息中提到"happy"，D = 消息中提到"DDA2001"。

$P(H) = 0.1$，$P(D) = 0.1$，$P(H,D) = 0.08$

$P(H|D) = \frac{P(H,D)}{P(D)} = \frac{0.08}{0.1} = 0.8$

知道消息提到 DDA2001 后，提到 happy 的概率从 10% 飙升到 80%！

2. Monty Hall 问题（经典考题）

Classic Problem

三门问题

三扇门，一扇后有车，两扇后有羊。你选了一扇门后，主持人打开另一扇有羊的门。你要不要换？

门1后面门2后面门3后面不换结果换的结果
羊羊车羊车
羊车羊羊车
车羊羊车羊

结论：$P(\text{不换赢}) = 1/3$，$P(\text{换赢}) = 2/3$

应该换！因为主持人的开门给你提供了额外信息。

3. Bayes 定理

Bayes' Rule

Bayes 公式（重要考点）

$$P(A|B) = \frac{P(B|A)\cdot P(A)}{P(B)}$$

其中全概率公式：$P(B) = P(B|A)P(A) + P(B|A^c)P(A^c)$

核心意义：已知"原因 $\to$ 结果"的概率，反推"结果 $\to$ 原因"的概率。

Warning

$P(B|A) \neq P(A|B)$

两者可能差别巨大！下面的核酸检测例子就是经典案例。

4. 核酸检测经典题（必考）

Must-Know Example

COVID 检测 — Bayes 定理应用

已知：

符号含义数值
$P(\text{Infected})$感染率0.01
$P(+|\text{Infected})$灵敏度（真阳性率）0.99
$P(+|\text{Well})$假阳性率0.01

求：$P(\text{Infected}|+)$ = 检测阳性后真的感染的概率？

Solution

详细解题步骤

  1. 列出联合概率：
    Infected (0.01)Well (0.99)
    $+$$0.01\times0.99 = 0.0099$$0.99\times0.01 = 0.0099$
    $-$$0.01\times0.01 = 0.0001$$0.99\times0.99 = 0.9801$
  2. 计算 $P(+) = 0.0099 + 0.0099 = 0.0198$
  3. 应用 Bayes：
    $$P(\text{Infected}|+) = \frac{0.0099}{0.0198} = 0.50$$

惊人结论：即使检测灵敏度高达 99%，阳性结果仍只有 50% 概率是真感染！

原因：$P(\text{Infected})$ 很低（1%），大量假阳性来自 99% 的健康人群。

这就是 Base Rate Fallacy（基础概率谬误）。

Lecture 9 — Maximum Likelihood Estimation

最大似然估计 · 参数推断的核心方法

1. 统计推断思路

Framework

统计推断三要素

  1. 样本 Samples：从真实世界收集的数据 $X_1, X_2, \dots, X_n$
  2. 模型集合：一组候选模型（参数 $\theta \in \Theta$）
  3. 评价标准：量化模型好坏的函数（Score function）

核心思想：在候选模型中，选择最可能生成观测数据的那个。

2. 似然函数定义 Likelihood Function

Definition

似然函数（重要考点）

给定参数 $\theta$，观测到样本 $X_1,\dots,X_n$（假设独立）的概率：

$$L(\theta) = \prod_{i=1}^n P(X_i|\theta) \quad\text{(离散)}$$
$$L(\theta) = \prod_{i=1}^n f(X_i|\theta) \quad\text{(连续)}$$

对数似然（更好算）：

$$\ell(\theta) = \log L(\theta) = \sum_{i=1}^n \log P(X_i|\theta)$$
Why Log?

为什么取对数？

1. 乘法变加法，计算更简单

2. 对数是单调函数，最大化 $\ell(\theta)$ 等价于最大化 $L(\theta)$

3. 避免数值下溢（很多小概率相乘 → 极小数）

3. MLE 求解步骤

Procedure

MLE 标准流程（必考）

  1. 写出似然函数 $L(\theta)$（样本独立则连乘）
  2. 取对数得 $\ell(\theta) = \sum \log f(X_i|\theta)$
  3. 对 $\theta$ 求导，令 $\frac{d\ell}{d\theta} = 0$
  4. 解方程得 $\hat{\theta}_{MLE}$
  5. 验证是最大值（二阶导 $< 0$）

若 $\Theta$ 是离散集合：直接比较各候选值的似然。

4. 经典例题

Example 1

Bernoulli 分布 MLE

$N$ 次试验，$M$ 次成功。$X_i \sim \text{Bernoulli}(p)$。

$\ell(p) = M\log p + (N-M)\log(1-p)$

$\frac{d\ell}{dp} = \frac{M}{p} - \frac{N-M}{1-p} = 0$

$\hat{p}_{MLE} = \frac{M}{N}$（样本成功率）

Example 2

离散参数空间

药物试验：$p \in \{0.8, 0.9\}$，100 次试验中 81 次成功。

$L(0.8) = \binom{100}{81}(0.8)^{81}(0.2)^{19}$

$L(0.9) = \binom{100}{81}(0.9)^{81}(0.1)^{19}$

比较：$\frac{L(0.8)}{L(0.9)} = \left(\frac{0.8}{0.9}\right)^{81}\left(\frac{0.2}{0.1}\right)^{19} = (0.889)^{81}\cdot 2^{19}$

计算发现 $L(0.8) > L(0.9)$，所以 $\hat{p} = 0.8$。

Example 3

Uniform 分布 MLE

$X \sim U(a,b)$，观测到 175, 185, 190, 155。

$L(a,b) = \prod \frac{1}{b-a}\cdot\mathbf{1}[a\le X_i\le b] = \frac{1}{(b-a)^4}$（当所有样本在 $[a,b]$ 内时）

要最大化 $L$，需最小化 $b-a$，同时保证所有点在 $[a,b]$ 内。

$\hat{a} = \min(X_i) = 155$，$\hat{b} = \max(X_i) = 190$

注意：这里 MLE 不是样本均值！

Lecture 10 — Regression Analysis

相关性 · 线性回归 · MLE视角 · 残差分析

1. 相关性 Correlation

Definition

三种相关关系

类型含义图形
正相关$x$ 增大 → $y$ 倾向增大点云斜向右上
零相关$x$ 与 $y$ 无线性关系点云无方向
负相关$x$ 增大 → $y$ 倾向减小点云斜向右下

问题：当 $x$ 增加某个量时，$y$ 变化多少？→ 用regression回答。

2. 线性回归模型 Linear Regression

Model

简单线性回归（重要考点）

$$Y = \beta_0 + \beta_1 X + \varepsilon, \quad \varepsilon \sim N(0, \sigma^2)$$

$\beta_0$ = 截距，$\beta_1$ = 斜率，$\varepsilon$ = 随机噪声。

假设：

1. 线性关系

2. 误差独立同分布 $N(0,\sigma^2)$

3. 等方差性（homoscedasticity）

Least Squares

最小二乘法 OLS

给定数据 $(x_1,y_1),\dots,(x_n,y_n)$，找 $\hat\beta_0,\hat\beta_1$ 最小化残差平方和：

$$\min_{\beta_0,\beta_1}\sum_{i=1}^n(y_i - \beta_0 - \beta_1 x_i)^2$$

解（令偏导 = 0）：

$$\hat\beta_1 = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2}, \quad \hat\beta_0 = \bar{y} - \hat\beta_1\bar{x}$$

3. MLE 推导回归参数

MLE = OLS

MLE 视角下的回归

在正态误差假设下：$Y_i | X_i \sim N(\beta_0+\beta_1 x_i,\; \sigma^2)$

$$\ell(\beta_0,\beta_1,\sigma^2) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum(y_i-\beta_0-\beta_1 x_i)^2$$

最大化 $\ell$ 关于 $\beta_0,\beta_1$，等价于最小化 $\sum(y_i-\beta_0-\beta_1 x_i)^2$ — 即最小二乘法！

结论：在正态误差假设下，MLE = OLS。

4. 残差分析 Residual Analysis

Model Check

如何检验模型是否正确？

残差 $e_i = y_i - \hat{y}_i$。画 $e_i$ vs $x_i$ 的散点图：

检验线性性

Good：残差随机散布在 0 附近

Bad：残差呈弧形 → 关系非线性

检验等方差

Good：残差带宽均匀

Bad：残差带宽随 $x$ 变化（喇叭形）

Summary Flow

回归分析完整流程

  1. 画散点图，判断是否呈线性趋势
  2. 拟合模型（最小二乘 / MLE）
  3. 残差分析：检验线性性 + 等方差性
  4. 若假设违反：考虑变换或非线性模型
