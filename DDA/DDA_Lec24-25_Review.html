Lecture 24 — Large Language Models (LLM)

从条件概率到推理 — 一条完整的 LLM 构建路线

1. Token 与语言建模

Definition

什么是 Token？

LLM 不直接读取整个句子，而是先将文本切分为小片段，称为 token。

一个 token 可以是：一个完整单词、一个词的一部分、标点符号、或特殊符号。

常见词通常是单个 token；罕见词会被拆分为多个 sub-token。

Core Idea

语言建模的核心句

语言模型的任务就是预测下一个 token。 如果能不断地准确预测，就能生成完整的句子。

"The capital of France is ___"  →  模型预测填空

2. 条件概率与 Next-Token Prediction

Definition

条件概率视角

Conditional probability：给定上下文后的概率。在语言中，下一个词的概率取决于已经看到的所有词。

$$P(x_t \mid x_1, x_2, \dots, x_{t-1})$$

一个完整句子的概率可以分解为：

$$P(x_1, x_2, \dots, x_T) = \prod_{t=1}^{T} P(x_t \mid x_1, \dots, x_{t-1})$$
Key Insight

为什么 Next-Token Prediction 就够了？

一旦我们知道如何预测下一个 token，就可以自回归地生成完整回复：

上下文 Context
→
预测 next token
→
追加到上下文
→
循环直到 <EOS>

所以关键问题不是"一次写出整段话"，而是高效地计算正确的条件概率。

3. Transformer 架构

Definition

Transformer = 条件概率机器

输入：一串 token 序列；输出：下一个 token 的概率分布。
Transformer 就是将上下文转换为这些概率的函数。

Transformer 的四个步骤

  1. Embeddings（词嵌入）
    每个 token 变成一个向量（word embedding）。模型不直接处理原始文字，而是处理数值表示。语义相近的 token 在向量空间中距离较近。
  2. Position Information（位置信息）
    句子不是"词袋"，顺序很重要。位置编码告诉模型每个 token 在序列中的位置。没有位置信息，"dog bites man" 和 "man bites dog" 看起来一样。
  3. Masked Self-Attention（掩码自注意力）
    每个 token 可以查看它之前的 token 来构建更好的表示。Masked 意味着 token 看不到未来的 token — 这正好符合 next-token prediction 的需求。模型学习哪些earlier words最重要。
  4. 最后一层：特征 → 概率
    最后一层本质上是一个大规模的multi-class classifier（多类分类器），从所有词汇中选择下一个 token。
Key Interpretation

Logistic Regression 视角

可以把整个架构理解为：

Transformer 主体

= Feature Extractor

构建强大的 hidden state

最后一层

= Classifier

（多类 Logistic Regression）

Example

Worked Example

Prompt: "The cat sat on the"

Transformer 为最后一个位置构建 hidden state，最后一层（logistic regression）可能输出：

Token概率
"mat"高
"floor"中等
无关词极低

然后选一个 token，追加，重复。

4. 自监督训练

Self-Supervised Learning

训练数据自带标签

训练文本自己提供标签 — 前面的 token 是输入，下一个 token 是目标。

模型看到的输入正确目标
<start>I
<start> Ilove
<start> I lovemachine
<start> I love machinelearning
<start> I love machine learning<EOS>

这就是为什么 LLM 预训练被称为 self-supervised learning。

Training Objective

训练目标

最小化 cross-entropy loss（交叉熵损失）：

$$\mathcal{L} = -\sum_{t=1}^{T}\log P(x_t \mid x_1,\dots,x_{t-1})$$

即最大化模型对训练数据中每一步"正确下一个 token"的预测概率。

Inference

推理（文本生成）

测试时，模型读取当前 prompt，输出 next-token 概率分布，sample 一个 token，追加到 prompt，重复直到 <EOS> 或达到长度限制。

常见采样策略

策略描述
Greedy Decoding每次取概率最高的 token（简单但多样性差）
Beam Search同时保留多个高分部分序列（质量更好）

5. Pre-training 预训练

Definition

什么是预训练？

在超大规模语料上从零训练一个 base LLM，目标仍是 next-token prediction。变化的是规模：更多数据、更大模型、更多算力。

预训练建立广泛的语言能力和通用知识。

Challenge

工程挑战

想法简单，但工程极难：需要大数据集、大模型、分布式训练、精心的系统调优。预训练同时是一个 ML problem 和一个 systems problem。

数据管线（以 Llama 3 为例）

  1. Safety Filtering：移除有害内容（暴力、仇恨言论等）
  2. Text Extraction & Cleaning：从 HTML 提取高质量纯文本，去除导航栏、广告等
  3. De-duplication：精确去重 + 模糊去重，避免过拟合重复内容
  4. Quality Filtering：规则过滤 + 小模型打分，去除低质量文本

6. Scaling Law

Scaling Law

规模定律

更大并不总是更好 — 在固定算力下，模型大小和训练数据量之间存在最优平衡。

Scaling Law 是一组经验公式：给定算力预算 $C$，最优模型大小 $N$ 和训练数据量 $D$ 应该是多少？

核心思想：用 test error 来评估，在给定 FLOPS 预算下找最优配置。

Training Recipe

训练配方示例

超参数策略
OptimizerAdamW（梯度下降变体）
Learning Rate训练过程中逐渐衰减
Batch Size训练过程中逐渐增大（稳定性）
Context Length从 4096 逐步增到 128K

7a. Supervised Fine-Tuning (SFT)

用高质量的 (prompt, response) 数据对模型进行微调，让模型学会遵循指令、按期望格式回答。

7b. Preference Learning 偏好学习

DPO

Direct Preference Optimization

有时两个回答都流畅，但一个明显更好。偏好学习使用三元组数据：

数据说明
Prompt用户输入
Preferred Answer人类标注的较好回答
Less Preferred Answer人类标注的较差回答

DPO 直接增大 preferred answer 的相对概率，减小 less preferred 的概率，避免了复杂的 RL 管线。

8. Reasoning 推理模型

Reasoning Model

什么是推理模型？

有些任务需要多步推理（如数学、逻辑），不只是流畅文本。推理模型建立在预训练 + 后训练的 LLM 之上。

两种常见路径：

SFT on 推理 traces

用包含思考步骤的数据做 SFT

RL + Verifiable Rewards

用可验证的奖励信号做强化学习

GRPO

RL with a Verifier (GRPO-Style)

  1. 让模型对一个问题生成多个候选答案
  2. Verifier（或 ground truth）检查哪些更好
  3. 更好的答案获得更强的训练信号
  4. 模型逐渐学会产生更正确的推理路径

Key Formulas

均值与方差公式

离散 (PMF)

$$E[X] = \sum_x x\cdot P(X=x)$$
$$\text{Var}(X) = E[X^2]-(E[X])^2$$

连续 (PDF)

$$E[X] = \int_{-\infty}^{\infty}x\cdot f(x)\,dx$$
$$\text{Var}(X) = \int(x-\mu)^2 f(x)\,dx$$
CDF

累积分布函数

对离散和连续随机变量均适用：

$$F(x) = P(X \le x)$$

性质：单调递增，$F(-\infty)=0$，$F(+\infty)=1$。

Conditional Probability

条件概率与 Bayes 公式

$$P(A|B) = \frac{P(A\cap B)}{P(B)}$$
$$P(A|B) = \frac{P(B|A)\cdot P(A)}{P(B)}$$

3. 统计学复习 Statistics

MLE

最大似然估计 Maximum Likelihood Estimation

给定数据 $x_1, \dots, x_n$（假设 i.i.d.），找参数 $\theta$ 使数据出现的概率最大：

$$\hat{\theta}_{MLE} = \arg\max_\theta \prod_{i=1}^{n}f(x_i;\theta)$$

实际操作中取对数：

$$\hat{\theta}_{MLE} = \arg\max_\theta \sum_{i=1}^{n}\log f(x_i;\theta)$$

其中：连续 RV 用 PDF $f$，离散 RV 用 PMF $P$。

Linear Regression

线性回归

模型：$y = \beta_0 + \beta_1 x + \varepsilon$，$\varepsilon \sim N(0,\sigma^2)$

MLE 方法得到的参数估计等价于least squares（最小二乘法）。

4. 优化复习 Optimization

Formulation

优化问题的三要素

要素说明
Objective Function要最大化或最小化的目标函数
Decision Variables决策变量
Constraints约束条件
Convex Set

凸集

集合 $S$ 是凸集，若对任意 $\mathbf{x},\mathbf{y}\in S$ 和 $\lambda\in[0,1]$：

$$\lambda\mathbf{x}+(1-\lambda)\mathbf{y}\in S$$

即两点之间的line segment（线段）完全在集合内。

凸集的交集仍是凸集。

Convex Function

凸函数

$f$ 是凸函数，若对任意 $\mathbf{x},\mathbf{y}$ 和 $\lambda\in[0,1]$：

$$f(\lambda\mathbf{x}+(1-\lambda)\mathbf{y})\le\lambda f(\mathbf{x})+(1-\lambda)f(\mathbf{y})$$

二阶条件

一维：$f''(x)\ge 0$  ⇒  $f$ 是凸函数

凹函数：不等号反向。若 $f$ 凹则 $-f$ 凸。

Key Theorem

凸优化问题的核心性质

凸优化问题需要同时满足：

1. 可行域是凸集

2. 目标函数是凸函数

核心定理：任何局部最小值也是全局最小值。

Newsvendor

报童问题 Newsvendor Problem

经典凸优化应用：在需求不确定下确定最优订货量，使期望利润最大（或期望成本最小）。

最优条件：$F(q^*) = \frac{p-c}{p-s}$（临界比率条件），其中 $p$ = 售价，$c$ = 成本，$s$ = 残值。

Gradient Descent

梯度下降

迭代更新公式：

$$\mathbf{x}_{t+1} = \mathbf{x}_t - \eta\nabla f(\mathbf{x}_t)$$

$\eta$ = 学习率 learning rate

Stochastic GD：每次用随机一个或小批量样本估计梯度，速度更快但有噪声。

Warning

学习率太大：振荡不收敛；学习率太小：收敛极慢。

5. 机器学习复习 Machine Learning

监督学习 vs. 无监督学习

Supervised Learning

训练数据有标签 $(x, y)$

目标：学习 $x \to y$ 的映射

例：KNN、Logistic Regression

Unsupervised Learning

训练数据无标签，只有 $x$

目标：发现数据中的结构和模式

例：K-Means Clustering

5a. KNN (K-Nearest Neighbors)

Algorithm

KNN 算法

  1. 计算测试点与所有训练点的距离
  2. 找出距离最近的 $K$ 个邻居
  3. 用这 $K$ 个邻居的多数投票（分类）或平均值（回归）作为预测

K 的影响：K 太小 → overfitting；K 太大 → underfitting

5b. Logistic Regression

Model

Logistic Regression 模型

Logistic function (Sigmoid)：

$$\sigma(z) = \frac{1}{1+e^{-z}}$$

模型：$P(Y=1|\mathbf{x}) = \sigma(\mathbf{w}^T\mathbf{x}+b)$

训练：通过 MLE（等价于最小化 cross-entropy loss），无闭合解，需用梯度下降求解。

5c. K-Means Clustering

Algorithm

K-Means 算法

  1. 随机初始化 $K$ 个聚类中心
  2. 分配：将每个点分配到最近的聚类中心
  3. 更新：重新计算每个聚类的中心（均值）
  4. 重复步骤 2-3 直到收敛

目标函数：$\min \sum_{k}\sum_{x_i \in C_k}\|x_i - \mu_k\|^2$

5d. Overfitting & Underfitting

Key Concepts

Overfitting（过拟合）

模型学到了训练数据的噪声/特异性

训练准确率高，测试准确率低

模型太复杂

Underfitting（欠拟合）

模型未能捕捉数据中的关键模式

训练和测试准确率都低

模型太简单

5e. Model Selection 模型选择

Validation Set

验证集方法

  1. 将数据分为训练集和测试集
  2. 对每个候选模型 $m$（如 KNN 的 $K=1,2,\dots,M$），用训练集训练
  3. 用测试集计算预测误差 $\text{Err}_m$
  4. 选择测试误差最小的模型
K-Fold CV

K-Fold Cross-Validation

  1. 将数据分为 $K$ 份（folds）
  2. 每次用其中 1 份做测试，其余 $K-1$ 份做训练
  3. 重复 $K$ 次，每份都做一次测试集
  4. 用 $K$ 次测试误差的平均值作为模型的预测误差

优点：每个数据点都被用作测试，结果更稳定。
