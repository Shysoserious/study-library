Lecture 11 — Confidence Interval

置信区间 — 用区间量化不确定性

1. 点估计 vs 区间估计

Comparison

两种估计方式

点估计 Point Estimation

用单个值估计参数

例："治愈率 = 70%"

缺点：不反映不确定性

区间估计 Interval Estimation

给出参数可能落入的范围

例："以 90% 概率，治愈率在 [40%, 100%]"

优点：量化了估计的不确定性

Motivation

为什么需要区间估计？

场景1：药物可靠性。患者只有在"以 90% 概率治愈率 > 55%"时才愿意用药。

场景2：算法审计。卖家称盲盒概率 > 50%，你买了 100 个只得 49 个 Harry Potter。点估计 48% < 50%，但区间估计可能显示 50% 仍在置信区间内 — 卖家可能没骗人。

2. 中心极限定理回顾 CLT

CLT

样本均值的分布（置信区间的基础）

设 $X_1,\dots,X_n$ 独立同分布，均值 $\mu$，方差 $\sigma^2$。则当 $n$ 足够大时：

$$\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i \approx N\left(\mu,\;\frac{\sigma^2}{n}\right)$$

标准化：

$$Z = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0,1)$$

样本越多 → $\sigma/\sqrt{n}$ 越小 → 估计越精确

3. 置信区间的构造（重要考点）

Construction

$\mu$ 的 $(1-\alpha)$ 置信区间（$\sigma$ 已知）

由 $P(-z_{\alpha/2} \le Z \le z_{\alpha/2}) = 1-\alpha$，得：

$$\mu \in \left[\bar{X} - z_{\alpha/2}\frac{\sigma}{\sqrt{n}},\;\;\bar{X} + z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right]$$

其中 $z_{\alpha/2}$ 是标准正态分布的上 $\alpha/2$ 分位数。

置信水平 $1-\alpha$$z_{\alpha/2}$
90%1.645
95%1.96
99%2.576
Unknown $\sigma$

$\sigma$ 未知时：用 $t$ 分布

用样本标准差 $S$ 代替 $\sigma$：

$$T = \frac{\bar{X}-\mu}{S/\sqrt{n}} \sim t_{n-1}$$
$$\mu \in \left[\bar{X} - t_{\alpha/2,n-1}\frac{S}{\sqrt{n}},\;\;\bar{X} + t_{\alpha/2,n-1}\frac{S}{\sqrt{n}}\right]$$

$n$ 大时 $t_{n-1} \approx N(0,1)$。

Interpretation

置信区间的正确解读

"95% 置信区间"意味着：若重复实验很多次，约 95% 的区间会包含真值 $\mu$。

不是说"$\mu$ 有 95% 概率在这个特定区间内"（$\mu$ 是固定的，不是随机的）。

4. 例题

Example

盲盒审计

买 100 个盲盒，得到 49 个 Harry Potter。$\hat{p} = 0.49$。卖家说 $p > 0.5$，他在骗人吗？

构造 $p$ 的 95% CI（大样本 Bernoulli 近似正态）：

$\hat{p} \pm z_{0.025}\sqrt{\frac{\hat{p}(1-\hat{p})}{n}} = 0.49 \pm 1.96\sqrt{\frac{0.49\times0.51}{100}}$

$= 0.49 \pm 1.96 \times 0.05 = 0.49 \pm 0.098 = [0.392,\; 0.588]$

结论：0.5 在置信区间内！不能断言卖家在骗人。

Lecture 12 — Low-Rank Approximation & Data Visualization

PCA · SVD · t-SNE · 降维

1. 高维回归与多重共线性

Problem

高维数据的挑战

当特征数 $D$ 很大时（高维回归 $Y = X\beta + \varepsilon$）：

• 多重共线性 Multicollinearity：特征之间高度相关，导致回归不稳定

• 维度灾难：参数过多，过拟合风险

解决方案：降维 — 把高维数据投影到低维空间。

2. PCA 主成分分析 Principal Component Analysis

Goal & Idea

PCA 核心思想（重要考点）

目标：在降维的同时保留尽可能多的方差（信息）。

方法：找到新变量（主成分），它们是原始特征的线性组合，且：

  1. 各主成分之间不相关（正交）
  2. 第一主成分解释最大方差
  3. 第二主成分解释次大方差（在与第一正交的条件下）
  4. 依次类推...

几何直觉：找数据"散布最广"的方向。

Math

PCA 与特征分解

数据矩阵 $X$（$n\times D$），协方差矩阵 $C = \frac{1}{n}X^TX$。

对 $C$ 做特征分解：$C = V\Lambda V^T$

• $V$ 的列 = 主成分方向（特征向量）

• $\Lambda$ 对角线 = 各方向的方差（特征值）

取前 $k$ 个最大特征值对应的特征向量，得到 $k$ 维表示。

3. SVD 奇异值分解

SVD

Singular Value Decomposition

任意 $m\times n$ 矩阵 $A$ 可分解为：

$$A = U\Sigma V^T$$

• $U$：$m\times m$ 正交矩阵（左奇异向量）

• $\Sigma$：$m\times n$ 对角矩阵（奇异值 $\sigma_1\ge\sigma_2\ge\dots$）

• $V$：$n\times n$ 正交矩阵（右奇异向量）

Low-Rank

低秩近似

取前 $k$ 个奇异值（$k \ll \min(m,n)$）：

$$A \approx A_k = U_k\Sigma_k V_k^T$$

应用：图像压缩 — 原始图像 $m\times n$ 需要 $mn$ 存储，秩 $k$ 近似只需 $k(m+n+1)$。

SVD 与 PCA 的联系：对中心化数据矩阵做 SVD，右奇异向量 $V$ 就是 PCA 的主成分方向。

4. 数据可视化 & t-SNE

Data Matrix

数据的表示

• 数据向量：$\mathbf{x} = [x_1, x_2, \dots, x_D]$（$D$ 个特征）

• 数据矩阵：$N$ 个样本排成 $N\times D$ 矩阵

• 高维数据（如人脸 50×320 = 16000 维）无法直接可视化

t-SNE

t-SNE 降维可视化

t-distributed Stochastic Neighbor Embedding：将高维数据映射到 2D/3D。

核心思想：保持点之间的"邻近关系" — 原空间中接近的点在新空间中也应接近。

  1. 在高维空间用高斯分布计算点对的相似度 $p_{ij}$
  2. 在低维空间用 $t$ 分布计算点对的相似度 $q_{ij}$
  3. 最小化 KL 散度：$C = \sum_{i,j} p_{ij}\log\frac{p_{ij}}{q_{ij}}$

特点：$p_{ij}$ 大但 $q_{ij}$ 小 → 惩罚大（原本近的点被拉远了不行）；反过来则惩罚小。

Lecture 14-15 — Optimization

优化问题建模 · 线性规划 · 图解法 · 报童问题

1. 优化问题四要素（重要考点）

Four Ingredients

优化问题的标准形式

要素英文含义
决策变量Decision Variables我们可以选择的量（产量、分配量...）
目标函数Objective Function要最大化或最小化的量（利润、成本...）
约束条件Constraints解必须满足的限制（资源、容量...）
可行域Feasible Set/Region所有满足约束的点的集合
Terminology

关键术语

• Feasible solution：满足所有约束的一个解

• Infeasible solution：违反至少一个约束

• Optimal solution：可行域中使目标最优的点

• Optimal value：最优解对应的目标函数值

• Interior point：可行域内部的点（严格满足所有不等式约束）

• Boundary point：可行域边界上的点（至少一个约束取等号）

2. 线性规划 Linear Programming (LP)

Definition

LP 的定义

当目标函数和所有约束都是决策变量的线性函数时，称为线性规划。

$$\max\; \mathbf{c}^T\mathbf{x} \quad\text{s.t.}\quad A\mathbf{x}\le\mathbf{b},\;\mathbf{x}\ge\mathbf{0}$$

关键性质：若目标是线性的，最优解一定在可行域的边界上（内点不可能是最优）。

Example

面包店问题

做面包（利润 \$3/个）和蛋糕（利润 \$5/个）。面包用面粉 2 单位 + 人工 1 小时；蛋糕用面粉 3 单位 + 人工 2 小时。今天有面粉 100、人工 40 小时。

建模：

决策变量：$x$ = 面包数，$y$ = 蛋糕数

$\max\; 3x + 5y$

s.t. $2x + 3y \le 100$（面粉）

     $x + 2y \le 40$（人工）

     $x,y \ge 0$

3. 图解法（二维 LP）

Method

图解法步骤（重要考点）

  1. 画出每个约束的边界线（令不等式取等号）
  2. 确定每个约束的可行半平面（哪侧满足不等式）
  3. 找到所有约束的交集 = 可行域（多边形）
  4. 画目标函数的等值线（$c^Tx = $ 常数）
  5. 平移等值线到可行域边界最远处 → 最优解在顶点
Example

Flair Furniture 家具公司

桌子利润 \$7，椅子利润 \$5。约束：木工 2400h，喷漆 1000h，椅子 ≤ 450，桌子 ≥ 100。

$\max\; 7T + 5C$

s.t. $3T+4C\le2400$，$2T+C\le1000$，$C\le450$，$T\ge100$，$T,C\ge0$

最优解：$T=320$，$C=360$，利润 = $7(320)+5(360) = \$4040$

4. Newsvendor 报童问题（重要考点）

Model

报童问题

在需求不确定下决定最优订货量。需求 $D$ 是随机变量。

权衡：

• 订太少 → 错失销售机会（underage cost $c_u$）

• 订太多 → 剩余产品亏损（overage cost $c_o$）

$$\min_q\; E[\text{Cost}(q,D)] = c_o\cdot E[\max(q-D,0)] + c_u\cdot E[\max(D-q,0)]$$
Solution

最优订货量（临界比率条件）

$$F(q^*) = \frac{c_u}{c_u + c_o}$$

其中 $F$ 是需求的 CDF。直觉：underage cost 越大 → 比率越大 → 订更多。

Example

GPU 服务器预留

AI 公司预留 GPU 服务器。预留不够 → 紧急采购贵（$c_u = 5$ 元/单位）。预留太多 → 闲置成本（$c_o = 2$ 元/单位）。

$F(q^*) = \frac{c_u}{c_u+c_o} = \frac{5}{5+2} = \frac{5}{7} \approx 0.714$

找需求分布的 71.4% 分位数作为最优预留量。

Example

银行现金储备

储备闲置成本 $c_o = 2$ 分/元，短缺应急成本 $c_u = 5$ 分/元。

同样的临界比率：$F(q^*) = 5/7$

若取款需求 $D \sim N(\mu,\sigma^2)$，则 $q^* = \mu + \sigma\cdot\Phi^{-1}(5/7)$

5. 更多建模例题

Example

吃派比赛

Bob 参加 1 小时吃派比赛。Torte 每个 2 分钟得 4 分；Apple pie 每个 3 分钟得 5 分。

$\max\; 4x+5y$

s.t. $2x+3y\le60$，$x,y\ge0$

可行解：$x=10,y=10$ → $4(10)+5(10)=90$ ✔

不可行：$x=10,y=15$ → $2(10)+3(15)=65>60$ ✘

最优解：$x=30,y=0$ → 得分 $= 120$

Example

MLE 作为优化问题

MLE 本身就是一个优化问题！

$\max_p\; \ell(p) = M\log p + (N-M)\log(1-p)$

决策变量：$p$；目标函数：对数似然；约束：$0\le p\le 1$

这是一个无约束（或简单约束）优化问题。
