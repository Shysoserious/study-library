Lecture 22 — K-Means Clustering

无监督学习、聚类、距离度量、K-Means 算法

1. Unsupervised Learning（无监督学习）

Definition

在 Supervised Learning（监督学习）中，每个样本都有标签 y；而在 Unsupervised Learning（无监督学习）中，没有预定义的输出标签，模型需要自己发现数据中的 隐藏模式和结构。

典型应用场景

🛒
Customer Segmentation
客户分群
📰
Topic Discovery
主题发现
🔍
Deduplication
去重
⚠️
Anomaly Detection
异常检测
监督学习 vs 无监督学习：有无标签的区别

2. Clustering（聚类）

Definition

Clustering（聚类）就是把 相似的数据点分到同一组（cluster），使得同组内的点尽可能相似，不同组的点尽可能不同。

需要定义两种度量：

• Similarity function s(x, y)：值越大 → 越相似
• Dissimilarity function d(x, y)：值越大 → 越不同

注意

"Clustering is subjective"（聚类是主观的）——不同的距离定义、不同的 k 值，可能得到完全不同的分组。没有唯一正确的聚类结果。

聚类的目标：组内相似、组间不同

3. Distance Measures（距离度量）

核心概念

距离函数 d(x, y) 必须满足三个性质：

① Symmetry（对称性）：d(x, y) = d(y, x)
② Positive Separability（正定性）：d(x, y) ≥ 0，且 d(x,y)=0 ⟺ x=y
③ Triangle Inequality（三角不等式）：d(x, z) ≤ d(x, y) + d(y, z)

四种常见距离

距离名称公式直觉理解
Euclidean
(L2 范数)		√(Σ(xᵢ−yᵢ)²)直线距离，最常用
Manhattan
(L1 范数)		Σ|xᵢ−yᵢ|沿坐标轴走的距离
Minkowski
(Lp 范数)		(Σ|xᵢ−yᵢ|ᵖ)^(1/p)一般化形式，p=1→曼哈顿，p=2→欧几里得
L∞ Distance
(无穷范数)		max|xᵢ−yᵢ|各维度差值的最大值
左：Euclidean vs Manhattan 距离 | 右：不同 Lp 范数下的单位球形状

4. K-Means 目标函数

Objective

给定 m 个数据点 {x¹, x², …, xᵐ}，需要找到：

• k 个聚类中心 {c¹, c², …, cᵏ}
• 每个点的归属函数 π(i) ∈ {1, …, k}

使得总距离最小化：

一般形式：  minc,π ∑i=1m d(xi, cπ(i))
平方欧氏距离版本：  minc,π 1m ∑i=1m ‖xi − cj‖²
直觉

目标就是让 每个数据点尽量靠近自己所属簇的中心。用平方欧氏距离可以让数学上更好处理（对 c 求导可以得到均值解）。

5. K-Means Algorithm（算法流程）

Algorithm
  1. 初始化 Initialize：随机选择 k 个点作为初始聚类中心 {c¹, c², …, cᵏ}
  2. 分配 Cluster Assignment：对每个数据点 xi，将其分配到距离最近的中心
    π(i) = argminj=1,…,k ‖xi − cj‖²
  3. 更新 Center Adjustment：将每个聚类中心移到该簇所有点的均值
    cj = 1|{i: π(i)=j}| ∑i:π(i)=j xi
  4. 重复 Repeat：如果任何中心发生变化，回到第 2 步。否则算法收敛。

7. Initialization Matters（初始化的重要性）

关键问题

不同的初始化会导致不同的聚类结果！K-Means 只能保证收敛到局部最优（local optimum），而非全局最优（global optimum）。

实际做法：多次随机初始化，选择目标函数值最小的那次结果。

不同初始化可能导致不同的聚类结果

Lecture 23 — Model Selection

过拟合与欠拟合、模型空间、验证集方法、K-fold 交叉验证

1. Overfitting & Underfitting（过拟合与欠拟合）

核心问题

选择模型时需要回答两个问题：

Q1: 选哪种模型？（KNN 还是 Logistic Regression？）
Q2: 超参数取多少？（KNN 中的 K 取多少？）

Overfitting（过拟合）

模型学到了训练数据中的 特有噪声和模式，在训练集上准确率极高，但在测试集上预测效果很差。

KNN 中 K=1 → 过拟合（决策边界过于复杂）

Underfitting（欠拟合）

模型过于简单，无法捕捉训练数据和测试数据中的关键模式和变量关系。

KNN 中 K=101 → 欠拟合（几乎所有点都被投票为多数类）

三种拟合状态对比：欠拟合 → 合适拟合 → 过拟合

3. Model Space（模型空间）

核心概念

不同复杂度的模型对应不同大小的模型空间 (Hypothesis Space)：

• 多项式 degree=1 对应空间 H₁（所有一次多项式）
• 多项式 degree=2 对应空间 H₂（所有二次多项式）
• …以此类推

关系是 H₁ ⊂ H₂ ⊂ H₃ ⊂ ⋯（嵌套关系），模型越复杂，空间越大。

模型空间的嵌套关系：H₁ ⊂ H₂ ⊂ H₃ ⊂ H₄

4. Intuition of Model Selection

直觉

目标是找到一个模型族，使得测试误差 (Test Error) 最小。

关键规律：

• Training Error（训练误差）随模型复杂度增加而单调递减
• Test Error（测试误差）呈 U 形曲线——先降后升

最佳模型就在 U 形曲线的最低点！

模型选择核心图：Training Error 持续下降，Test Error 呈 U 形，最佳模型在 U 形最低点

5. Validation Set Approach

方法

最直接的方法：把数据分成 训练集 (Training Set) 和 测试集 (Test Set)。

  1. 从候选模型 {1, 2, …, M} 中，对每个模型 m：用训练数据训练模型
  2. 用训练好的模型在测试数据上计算预测误差 Errm
  3. 选择测试误差最小的模型：min Errm
问题

选出的模型 高度依赖于数据的划分方式！不同的训练/测试拆分可能选出不同的最优模型。

解决方案 → K-fold Cross-Validation（K 折交叉验证）

Validation Set Approach：简单地将数据一分为二

6. K-fold Cross-Validation（K 折交叉验证）

核心方法

把数据分成 K 等份（folds），每次用其中 1 份做测试集，剩下 K−1 份做训练集，重复 K 次。

最终误差 = K 次误差的平均值：

E = 1K ∑i=1K Ei
K-fold 交叉验证：每个 fold 轮流做测试集，最终取平均误差

K 值如何选？

• 常用 K = 5 或 K = 10
• K 越大，训练次数越多，计算代价越高
• K = n（样本数）时 → Leave-One-Out（LOO），最精确但最慢

为什么比简单验证集好？

• 每个数据点都既当过训练又当过测试
• 结果不依赖某次特定的数据划分
• 误差估计更加稳定可靠
