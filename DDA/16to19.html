Lecture 16: 优化基础 & 凸集 (Convex Set)

1. 优化问题的标准形式 Standard Form

minimize   f(x)
subject to   gi(x) ≤ 0,   i = 1, …, m   (不等式约束 inequality constraints)
                  hi(x) = 0,   i = 1, …, n   (等式约束 equality constraints)

三大要素：目标函数 Objective Function f(x)、约束 Constraints gi, hi、决策变量 Decision Variables x

2. 关键术语 Terminologies

2.1 可行域 Feasible Set Ω

满足所有 (all) 约束的点的集合：

Ω = { x : gi(x) ≤ 0, i = 1,…,m;   hi(x) = 0, i = 1,…,p }
例1: x(1−x)=0 → Ω = {0, 1}
例2: x(1−x)=0 且 x>0 → Ω = {1}
例3: x>2 且 x≤3 → Ω = (2, 3]

2.2 ε-球 Epsilon-ball

B(x, ε) = { y : ‖y − x‖ ≤ ε }

以 x 为圆心、ε 为半径的所有点的集合，即 x 的"邻域"。

2.3 局部最小值 vs 全局最小值

Local minimizer 局部最小值点

f(x) ≤ f(y) 对所有 y ∈ Ω ∩ B(x, ε) 成立

且存在 某个 (some) ε > 0

只需在"附近一小片区域"最小

Global minimizer 全局最小值点

f(x) ≤ f(y) 对所有 y ∈ Ω ∩ B(x, ε) 成立

且对 任意 (any) ε > 0 成立

无论"圈"多大，都是最小的

考点 some ε vs any ε 的区别是常考点！

2.4 内部点 / 边界点 Interior / Boundary Point

Interior point 内部点: x ∈ C，若存在 ε > 0 使得 B(x, ε) ⊆ C。直觉：完全被集合"包住"。

Boundary point 边界点: x ∈ C，若存在方向 e ≠ 0 和 δ > 0，使得 x + ae ∉ C (∀a ∈ (0,δ))。直觉：站在集合"边缘"。

2.5 鞍点 Saddle Point

在 x* 点，任意方向的一阶导数都为0，但 x* 既不是局部最大值也不是局部最小值。

df(x* + te)dt |t=0 = 0   对任意方向 e 成立

经典例子: f(x,y) = x² − y², 在 (0,0) 沿 x 方向是"碗底"(min)，沿 y 方向是"山顶"(max)。

3. 线性规划命题 Proposition about LP

Proposition 若目标函数是线性的，则 内部点不可能是最优解 (no interior solution can be optimal)。

直觉：等值线 (level line) 是直线，可行域是多面体，把等值线往最优方向推到极限会卡在边界顶点 (boundary/vertex) 上。

4. Convex vs Non-Convex 对比

Convex problem 凸问题

✅ Local min = Global min

✅ 可高效求解 (solved efficiently)

✅ Gradient descent 收敛到全局最优

Non-convex problem 非凸问题

❌ 难找全局最优解

❌ 可能卡在 local min 或 saddle point

❌ 只能用 heuristics 找局部最优

核心 凸优化需同时满足两个条件：① 可行域是凸集 ② 目标函数是凸函数

5. 凸集 Convex Set

5.1 线段 Line Segment

x = θx1 + (1−θ)x2,   θ ∈ [0, 1]

θ 像"滑块"：θ=1 在 x1，θ=0 在 x2，中间值是线段上的点。这叫convex combination（凸组合）。

5.2 凸集定义

Definition 集合 C 是凸集，当且仅当：

∀ x1, x2 ∈ C,   ∀ θ ∈ [0,1]:   θx1 + (1−θ)x2 ∈ C

直觉：集合中任取两点连线段，线段完全在集合内。有凹进去的部分就不是凸集。

5.3 凸集的例子

集合是否凸集说明
空集 ∅、单点集 {x₀}、全空间 R✅平凡情况
区间 [a,b] ⊂ R✅一维凸集
Hyperplane 超平面: a₁x₁+···+aₙxₙ = c✅R² 中是直线，R³ 中是平面
Halfspace 半空间: y ≤ ax + b✅超平面的"一侧"
Disk 圆盘✅圆心和半径确定的区域
Polyhedron 多面体: 有限个半空间的交集✅利用"交集保凸"性质
六边形(凸多边形)✅没有凹进去的部分
月牙形 / 非凸多边形❌有凹入，线段可穿出

5.4 证明凸集的三步法

考试必用 以证明 H = {(x,y): y = ax + b} 是凸集为例：

  1. 利用假设：取任意 (x₁,y₁), (x₂,y₂) ∈ H → y₁ = ax₁+b, y₂ = ax₂+b
  2. 写出线段上的新点 (characterize new point)：θ(x₁,y₁) + (1−θ)(x₂,y₂) = (θx₁+(1−θ)x₂, θy₁+(1−θ)y₂)
  3. 证明新点也在集合中：θy₁+(1−θ)y₂ = θ(ax₁+b)+(1−θ)(ax₂+b) = a(θx₁+(1−θ)x₂)+b ✅

对半空间证明类似，只是 = 变成 ≤，两边乘以非负的 θ 和 (1−θ) 不等号不变。

5.5 凸集的性质

Lemma 若 S₁ 和 S₂ 都是凸集，则 S₁ ∩ S₂ 也是凸集（交集保凸）。

Proof: 取 x₁, x₂ ∈ S₁ ∩ S₂，令 x 是线段上的点。

因 S₁ 凸 → x ∈ S₁; 因 S₂ 凸 → x ∈ S₂。故 x ∈ S₁ ∩ S₂。∎

推广：任意多个凸集的交集仍是凸集。

应用1：Polyhedron = 多个半空间交集 → 凸集。

应用2：直线 y=ax+b = {y≤ax+b} ∩ {y≥ax+b} → 凸集。

注意 两个凸集的并集 (union) 不一定是凸集！ 例：两个不重叠的圆盘各自凸，合并后不凸。

Lecture 17: 凸函数 & 核心定理证明

1. 凸函数定义 Convex Function

Definition 函数 f: Rn → R 是凸函数，当且仅当：

(1) 定义域 dom(f) 是凸集

(2) 对任意 x₁, x₂ ∈ dom(f)，任意 λ ∈ [0,1]：

f(λx1 + (1−λ)x2)   ≤   λf(x1) + (1−λ)f(x2)

几何直觉：任取两点连弦 (chord)，弦总在曲线上方。

左边 = 函数在"组合点"的值，右边 = 函数值的"同样组合"。函数值在组合点 ≤ 弦上对应点。

2. 凸函数与凸集的关系

Sublevel set 下水平集

C = {x: f(x) ≤ r}

若 f 是凸函数 → C 是凸集

f(λx₁+(1−λ)x₂) ≤ λf(x₁)+(1−λ)f(x₂) ≤ λr+(1−λ)r = r ✅

Epigraph 上方图

C = {(x,y): y ≥ f(x)}

若 f 是凸函数 → 曲线上方区域是凸集

几何直觉："碗的外部"是凸的

⚠️ 反过来不成立！sublevel set 是凸集 ≠ f 是凸函数。反例：f(x)=-x² 的下水平集可以是 R，但 f 是 concave 的。

3. 凹函数 Concave Function

不等号反过来: f(z) ≥ λf(x) + (1−λ)f(y)。弦在曲线下方。

凹函数下方的区域是凸集。

关键 f concave ⟺ −f convex
关键 f convex ⟺ −f concave

实用意义：最大化 concave 函数 = 最小化其负值 (convex)，也能用凸优化！

4. 核心定理 The Fundamental Theorem

Theorem 对凸优化问题（f 凸 + Ω 凸），任何局部最小值 = 全局最小值。

Local minimizer = Global minimizer

反证法证明 Proof by Contradiction

设 x̄ 是局部最小值 → x̄ ∈ Ω，∃ε > 0 使得 f(x̄) ≤ f(x) ∀x ∈ B(x̄,ε) ∩ Ω

反设：∃z ∈ Ω 使得 f(z) < f(x̄)

利用凸集：x̄, z ∈ Ω (凸), 所以 λx̄ + (1−λ)z ∈ Ω, ∀λ ∈ [0,1]

利用凸函数：

   f(λx̄ + (1−λ)z) ≤ λf(x̄) + (1−λ)f(z) < λf(x̄) + (1−λ)f(x̄) = f(x̄)

矛盾：当 λ→1 时，λx̄+(1−λ)z → x̄，此点进入 B(x̄,ε)，但函数值 < f(x̄)，与局部最小性矛盾！∎

Lecture 18: 证明函数的凸性 Prove Convexity

1. 二阶条件 Second Order Condition (SOC)

Theorem (SOC) 设 f 是二阶连续可微 (twice continuously differentiable) 函数。

f 是 convex ⟺ (1) dom(f) 是凸集; (2) 对任意 x ∈ dom(f)、任意单位向量 e、任意 θ:

d²f(x + θe)dθ²   ≥   0

一维简化： f''(x) ≥ 0 对所有 x ∈ dom(f)。 (二阶导非负 → 凸)

对 Concave: f 是 concave ⟺ 同样条件但 ≤ 0。一维: f''(x) ≤ 0。

2. 高维凸函数证明步骤 General Procedure

考试必用 证明多维函数 f(x) 是凸的：

  1. 选任意点 y、任意单位向量 e、任意标量 θ
  2. 定义一维函数 g(θ) = f(y + θe)
  3. 证明 g''(θ) ≥ 0

核心思想：把多维问题沿任意方向"切一刀"，变成一维问题用 SOC 判断。

3. 经典凸/凹函数例子

Convex 凸函数

f(x) = ax + b (同时也是 concave!)

f(x) = x²   (f''=2>0)

f(x) = ex   (f''=ex>0)

f(x) = Σᵢ aᵢxᵢ²   (aᵢ>0时)

f(x) = (Σᵢ aᵢxᵢ)²   (任意 aᵢ)

Concave 凹函数

f(x) = −x²   (f''=−2<0)

f(x) = log(x) on (0,+∞)   (f''=−1/x²<0)

f(x) = sin(x) on [0,π]   (f''=−sin(x)≤0)

高维例子详解

Example 1: f(x) = Σᵢ aᵢxᵢ² (aᵢ > 0)

g(θ) = f(y+θe) = Σᵢ aᵢ(yᵢ+θeᵢ)²，g''(θ) = Σᵢ 2aᵢeᵢ² ≥ 0 ✅ → 凸函数

其 sublevel set {x: f(x) ≤ r} 形成球或椭球 (ball/ellipsoid)。

Example 2: f(x) = (Σᵢ aᵢxᵢ)² (对 aᵢ 无要求)

g(θ) = (Σᵢ aᵢ(yᵢ+θeᵢ))²，g''(θ) = 2(Σᵢ aᵢeᵢ)² ≥ 0 ✅ → 凸函数

4. 凸函数能否不连续？

定义在闭区间 [a,b] 上的一维凸函数 可以在边界点 (boundary) 不连续，但在内部 (interior) 一定连续。

条件：f(a) > limx→a⁺ f(x) 和 f(b) > limx→b⁻ f(x)

即边界点的函数值可以"跳高"，但只能往上跳，不能往下跳。

5. 保凸运算 Operations that Preserve Convexity

5.1 Composition 复合

若 ‖x‖ = √(Σᵢxᵢ²) 是凸函数，则对任意固定的 y，L2 距离 ‖x−y‖ 也是关于 x 的凸函数。

5.2 Maximum of convex functions 凸函数的最大值

Theorem 若 f₁, …, fm 都是凸函数，则 f(x) = max{f₁(x), …, fm(x)} 也是凸函数。

Proof: 取任意 x, y ∈ dom(f), λ ∈ [0,1]。

f(λx+(1−λ)y) = fj(λx+(1−λ)y) (某个 j 取到最大值)

  ≤ λfj(x) + (1−λ)fj(y)   (因为 fj 是凸的)

  ≤ λ max{f₁(x),...} + (1−λ) max{f₁(y),...} = λf(x) + (1−λ)f(y) ∎

应用1: Piecewise-linear function 分段线性函数 f(x) = max{a₁ᵀx+b₁, …, aₗᵀx+bₗ} 是凸的。

应用2: 到集合 C 中最远点的距离 f(x) = supy∈C ‖x−y‖ 是凸的。

5.3 Nonnegative weighted sums 非负加权和

Theorem 若 f₁, …, fm 凸，w₁, …, wm ≥ 0，则 Σᵢ wᵢfᵢ(x) 也是凸函数。

推广到积分：若 f(x,y) 关于 x 凸（对每个 y ∈ A），w(y) ≥ 0，则：

g(x) = ∫A w(y) f(x,y) dy   关于 x 凸

6. 应用例子

Regression Analysis 回归分析

最小化 Σᵢ(Yᵢ − β₁Xᵢ − β₀)²。每个 (Yᵢ − β₁Xᵢ − β₀)² 是关于 (β₀,β₁) 的凸函数 → 非负加权和 → 整体凸。

Blind Box Problem 盲盒问题

目标函数 = (p−c)(−Q) + (p−s)E[max(Q−D, 0)]

其中 −Q 是凸的 (线性)，max(Q−D, 0) 是凸函数的 maximum → 凸

所以整体是 nonnegative weighted sums of convex functions → 凸！

Lecture 19: 最优性条件 & 应用 Optimality Condition

1. 最优性条件 Optimality Condition

Theorem 若 f 二阶可微且凸 (convex)，x* 是内部 (interior) 全局最小值点，则：

∇f(x*) = 0

即梯度 (gradient) 为零向量。(Proof not required)

Theorem 若 f 二阶可微且凹 (concave)，x* 是内部全局最大值点，则同样 ∇f(x*) = 0。

∇f(p) = ∂f/∂x₁(p) ⋮ ∂f/∂xₙ(p)

最优解的位置 最优解可能在内部 (interior) 或边界 (boundary)：

— 内部最优：∇f = 0 (一阶条件)

— 边界最优：需要检查约束边界上的点

— 混合情况：min 可能在内部，max 可能在边界（或反过来）

2. 应用：Regression Analysis 回归分析

最小化 Σᵢ(Yᵢ − β₁Xᵢ − β₀)²。用 SOC 验证凸性，可行域 R² 也是凸的 → 凸优化问题。

用 optimality condition ∇f = 0，对 β₀ 和 β₁ 分别求偏导令其为零：

Σᵢ(Yᵢ − β₁Xᵢ − β₀) = 0     (对 β₀ 求导)
Σᵢ(Yᵢ − β₁Xᵢ − β₀)Xᵢ = 0     (对 β₁ 求导)

解得：

β̂₁  = Σᵢ(Xᵢ − X̄)(Yᵢ − Ȳ)Σᵢ(Xᵢ − X̄)²       β̂₀ = Ȳ − β̂₁X̄

3. 应用：MLE for Bernoulli RV

最小化 negative log-likelihood: −M·log p − (N−M)·log(1−p),   s.t. p ∈ [0,1]

验证凸性: d²dp² = Mp² + N−M(1−p)² > 0 ✅ 凸！

可行域 [0,1] 凸 → 凸优化 → 用一阶条件求解 → p̂ = M/N

4. 应用：MLE for Exponential RV

灯泡寿命服从指数分布, pdf: f(x) = λe−λx

Log-likelihood: l(λ) = n·log λ − λ·Σᵢ Xᵢ

l''(λ) = −n/λ² < 0 → concave! (所以要最大化它)

用一阶条件: l'(λ) = n/λ − Σᵢ Xᵢ = 0 → λ̂ = n / Σᵢ Xᵢ = 1/X̄

5. 重要提醒 Remark

考试要求 从现在起，任何时候被要求求最优解或 MLE，都必须先证明凸性/凹性，然后才能使用一阶条件！

答题步骤：① 写出目标函数 → ② 证明 convex/concave (SOC) → ③ 确认可行域凸 → ④ 用 ∇f = 0 求解

6. Blind Box Problem 盲盒问题

凸优化问题: min −(pE[min(Q,D)] + sE[(Q−D)⁺] − cQ),   s.t. −Q ≤ 0

定义 π(Q) = pE[min(Q,D)] + sE[(Q−D)⁺] − cQ

求导令 π'(Q) = 0：

p·∫Q∞ h(x)dx + s·∫0Q h(x)dx − c = 0

整理得 F(Q) = (p−c)/(p−s)，所以：

Q* = F−1( (p−c)/(p−s) )

当 p > c > s 时，Q* 是内部解 (interior solution)，因此是全局最优。
