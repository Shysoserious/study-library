S1 🔥 Logistic Regression MLE 2024 Q2 (14分) + 2025 Q3 (15分)

Log-likelihood 推导 —— 完整流程

📌 题目特征

给数据 $(x_i, y_i)$, $y_i \in \{0,1\}$, 模型 $P(y=1|x,\theta) = \sigma(\theta^\top x)$。要求：

  1. 写 log-likelihood $\ell(\theta)$
  2. 证明 $-\ell(\theta)$ 是 convex（或 $\ell(\theta)$ 是 concave）
  3. 写梯度上升/下降的更新公式
  4. 可能涉及多项式特征（2025 加了 $\phi(x)$）

✅ Solution Template

Step 1 — 单个样本的似然（Bernoulli trick）

$$P(y_i | x_i, \theta) = \sigma(\theta^\top x_i)^{y_i} \cdot (1-\sigma(\theta^\top x_i))^{1-y_i}$$

Step 2 — 所有样本的似然（独立→连乘）

$$L(\theta) = \prod_{i=1}^n \sigma(\theta^\top x_i)^{y_i} (1-\sigma(\theta^\top x_i))^{1-y_i}$$

Step 3 — 取对数 → 乘法变加法

$$\ell(\theta) = \sum_{i=1}^n \big[ y_i \log\sigma(z_i) + (1-y_i)\log(1-\sigma(z_i)) \big], \quad z_i = \theta^\top x_i$$

Step 4 — 化简 $\log\sigma(z)$ 和 $\log(1-\sigma(z))$

$$\sigma(z) = \frac{1}{1+e^{-z}} \;\Rightarrow\; \log\sigma(z) = -\log(1+e^{-z})$$ $$1-\sigma(z) = \frac{e^{-z}}{1+e^{-z}} \;\Rightarrow\; \log(1-\sigma(z)) = -z - \log(1+e^{-z})$$

Step 5 — 代入，化简

$$ \begin{aligned} \ell(\theta) &= \sum_{i=1}^n \big[ y_i(-\log(1+e^{-z_i})) + (1-y_i)(-z_i - \log(1+e^{-z_i})) \big] \\ &= \sum_{i=1}^n \big[ y_i z_i - \log(1+e^{z_i}) \big] \quad (\text{用 } \log(1+e^{-z}) = \log(1+e^{z}) - z) \end{aligned} $$
$$\boxed{\ell(\theta) = \sum_{i=1}^n \big[ y_i \theta^\top x_i - \log(1 + e^{\theta^\top x_i}) \big]}$$

Step 6 — 证明凸性（SOC 方法）

取方向 $e$，定义 $h(t) = \log(1+e^{(\theta_0+te)^\top x})$：

$$h'(t) = \sigma((\theta_0+te)^\top x) \cdot (e^\top x)$$ $$h''(t) = \sigma(1-\sigma) \cdot (e^\top x)^2 \ge 0$$

所以 $\log(1+e^{z})$ 是 convex → $-\log(1+e^{z})$ 是 concave → 加上线性项 $y_i z_i$ 后 $\ell(\theta)$ 是 concave。等价地 $-\ell(\theta)$ 是 convex。

Step 7 — 梯度公式

$$\frac{\partial \ell}{\partial \theta} = \sum_{i=1}^n (y_i - \sigma(\theta^\top x_i)) \cdot x_i$$

梯度上升（最大化 concave）：$\theta^{(t+1)} = \theta^{(t)} + \eta \nabla \ell(\theta^{(t)})$

SGD：每次随机取一个 mini-batch $B$，$\theta^{(t+1)} = \theta^{(t)} + \frac{\eta}{|B|} \sum_{i\in B} (y_i - \sigma(\theta^\top x_i))x_i$

📖 考试必记

  • Log-likelihood 最终形式：$\ell(\theta) = \sum [y_i \theta^\top x_i - \log(1+e^{\theta^\top x_i})]$ —— 直接背，不需要再推导
  • 凸性证明套路：取方向 $e$ → 算 $h''(t) \ge 0$ → 引用 affine composition 保凸 → 结论
  • 多项式特征：把 $x$ 换成 $\phi(x)$ 即可，所有推导完全相同
  • Gradient Ascent vs Descent：$\ell$ 是 concave → 最大化 → 用 Ascent（正梯度）；$-\ell$ 是 convex → 最小化 → 用 Descent（负梯度）

S2 🔥 Gradient Descent 收敛分析 2024 Q3 (10分) + 2025 Q4 (10分)

核心套路：误差递推 → 等比数列 → 收敛条件

📌 题目特征

给一个 quadratic 函数 $f$（concave），初始点 $x^{(0)}$，固定学习率 $\alpha$，问：

  • 特定 $\alpha$ 值下能否收敛到最优解？
  • $\alpha$ 取何值时 $\lim x^{(t)} \to x^*$？

✅ Solution Template

Step 1 — 求最优解：令 $f'(x) = 0$，得 $x^*$

Step 2 — 写梯度上升更新公式（因为 $f$ 是 concave，要最大化）

$$x^{(t+1)} = x^{(t)} + \alpha f'(x^{(t)})$$

Step 3 — 定义误差，找递推关系

令 $e^{(t)} = x^{(t)} - x^*$（当前到最优解的距离），把更新公式代入：

$$e^{(t+1)} = x^{(t+1)} - x^* = x^{(t)} + \alpha f'(x^{(t)}) - x^*$$

因为 $f$ 是二次函数 $\Rightarrow f'(x)$ 是线性函数 $\Rightarrow$ 一定会化到 $e^{(t+1)} = (1 - k\alpha) e^{(t)}$ 的形式，其中 $k = -f''(x)$（正数）。

Step 4 — 解封闭形式

$$e^{(t)} = (1 - k\alpha)^t \cdot e^{(0)}$$

Step 5 — 收敛条件

$$|1 - k\alpha| < 1 \quad\Longrightarrow\quad 0 < \alpha < \frac{2}{k}$$
  • $|1 - k\alpha| < 1$：指数衰减到 0 ✅
  • $|1 - k\alpha| = 1$：振荡（$\alpha=0$ 或 $\alpha=2/k$）❌
  • $|1 - k\alpha| > 1$：发散 ❌

$f''(x)$$-1$$-1/2$

📖 考试必记

  • 先确认 convex 还是 concave：$f''(x) < 0$ → concave → 最大化 → 梯度上升
  • $k$ 值 = $-f''(x)$ 的绝对值。对于 $f(x) = -a(x-b)^2 + c$，$k = 2a$
  • 收敛范围：$0 < \alpha < 2/k$。注意是开区间！$\alpha = 0$ 不收敛到最优，$\alpha = 2/k$ 振荡不收敛
  • 2024 官方答案给 $(0,1]$ 是错的，正确是 $(0,2)$。考场上按 $(0,2/k)$ 公式写就行
  • 2025 收敛到最优的条件是 $0 < \alpha < 4$，$\alpha=1$ 肯定收敛 ✅

S3 Convex Sets 2024 Q4 (15分) + 2025 Q2 (10分)

三大题型

✅ 题型 A：用定义直接证（Simplex / 凸集的和）

三步法：取任意两点 $x,y \in C$ → 凸组合 $z = \lambda x + (1-\lambda)y$ → 验证 $z \in C$

Simplex $\Delta_n = \{p \ge 0, \sum p_i = 1\}$（2025 Q2a）：
$z_i = \lambda p_i + (1-\lambda)q_i \ge 0$ ✓
$\sum z_i = \lambda\sum p_i + (1-\lambda)\sum q_i = \lambda\cdot 1 + (1-\lambda)\cdot 1 = 1$ ✓
凸集的和 $S_1+S_2$（2024 Q4c）：
$\lambda(x_1+y_1) + (1-\lambda)(x_2+y_2) = \underbrace{[\lambda x_1+(1-\lambda)x_2]}_{\in S_1} + \underbrace{[\lambda y_1+(1-\lambda)y_2]}_{\in S_2}$ ✓

✅ 题型 B：Sublevel Set + 凸函数（2024 Q4b / 2025 Q2b）

定理：若 $f$ 是凸函数，则 $\{x \mid f(x) \le r\}$ 是凸集。

套路：先把约束写成 $f(x) \le r$ 的形式 → 证明 $f$ 凸 → 引用 sublevel set 定理

例：$x^2 \le 5 - 2y^2$（2024 Q4b）
改写为 $x^2 + 2y^2 \le 5$
$g(x,y) = x^2 + 2y^2$，$g''(t) = 2e_1^2 + 4e_2^2 \ge 0$ → $g$ 凸
$\therefore S = \{g(x,y) \le 5\}$ 是凸集 ✓
例：熵约束（2025 Q2b）
$S = \Delta_n \cap \{-\sum p_i\ln p_i \ge C\} = \Delta_n \cap \{\sum p_i\ln p_i \le -C\}$
$h(p) = \sum p_i\ln p_i$ 是凸函数（$p_i\ln p_i$ 二阶导 $1/p_i > 0$）
所以 $\{h(p) \le -C\}$ 是凸集。$\Delta_n \cap$ 凸集 = 凸集 ✓

✅ 题型 C：最优解集是凸集（2024 Q4a）

凸优化问题 $\min_{x\in S} f(x)$，$C$ 是最优解集。取 $x,y \in C$（即 $f(x)=f(y)=f^*$）：

$f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y) = f^*$
又 $f^*$ 是全局最小值 → $f(\lambda x + (1-\lambda)y) \ge f^*$
$\therefore f(\lambda x + (1-\lambda)y) = f^*$ → $\lambda x + (1-\lambda)y \in C$ ✓

📖 考试必记

  • 凸集定义：任意两点连线上的点都在集合内
  • 三种凸集证明方法：① 直接定义 ② Sublevel set ③ 交集/并集/和保凸
  • 注意：sublevel set 是凸集 $\nRightarrow$ $f$ 凸（反例：$f(x)=-x^2$）
  • 熵的凸性：$-x\ln x$ 是 concave（二阶导 $=-1/x < 0$），$x\ln x$ 是 convex

S4 Convex / Concave Functions 2024 Q5 (10分) + 2025 Q5 (10分)

三种证明方法

✅ 方法一：SOC（二阶导 ≥ 0）

一维函数：$f''(x) \ge 0$ 对所有 $x$ 成立 → $f$ 凸

多维函数：沿任意方向 $e$ 的 $g''(t) \ge 0$ → $f$ 凸

例：$f(x) = x^{a^2-a} + ax$ 的凸/凹性（2025 Q5b）
$f''(x) = (a^2-a)(a^2-a-1)x^{a^2-a-2}$
$x > a^2 > 0$，所以 $x^{a^2-a-2} > 0$
concave 要求 $f''(x) \le 0$ → $(a^2-a)(a^2-a-1) \le 0$ → $0 \le a^2-a \le 1$
解得 $a \in [\frac{1-\sqrt{5}}{2}, 0] \cup [1, \frac{1+\sqrt{5}}{2}]$
例：$f(x) = ax^3 + 6\ln x$ 的凸性（2024 Q5b）
$f''(x) = 6ax - 6/x^2$。在 $(a^2,\infty)$ 上要求 ≥ 0 → $a \ge 1$

✅ 方法二：排序统计量凸性（2024 Q5a）

$f(x) = \sum_{i=1}^r \alpha_i |x|_{[i]}$，$|x|_{[i]}$ 是 $|x|$ 的第 $i$ 大分量。

定理：若 $\alpha_1 \ge \alpha_2 \ge \cdots \ge \alpha_n \ge 0$，则 $f$ 是凸函数。

证明思路：

  1. $s_k(x) = \sum_{i=1}^k |x|_{[i]}$ 是凸函数（Ky Fan $k$-范数，等价于 $\max_{I:|I|=k} \sum_{i\in I} |x_i|$）
  2. 递减系数 $\alpha_i$ 可分解为 $\alpha_i = \sum_{j=i}^n \beta_j$，其中 $\beta_j = \alpha_j - \alpha_{j+1} \ge 0$
  3. 代入并交换求和顺序：$f(x) = \sum_{j=1}^n \beta_j s_j(x)$
  4. 凸函数的非负线性组合仍凸 ✓

✅ 方法三：反证法（2025 Q5a）

题目：$f$ 是 $\mathbb{R}^n$ 上的 concave 函数且有下界，证明 $f$ 是常数。

证明：假设 $f$ 不是常数，存在 $x,y$ 使 $f(x) < f(y)$。

令 $z_t = y + t(y-x)$，$t > 0$。由 concavity：

$f(y) \ge \frac{1}{1+t}f(z_t) + \frac{t}{1+t}f(x)$
$\Rightarrow f(z_t) \le f(y) + t(f(y) - f(x))$
当 $t \to \infty$ 时 $f(z_t) \to -\infty$，与 $f$ 有下界矛盾！∴ $f$ 必为常数。

📖 考试必记

  • SOC 步骤：确认定义域是凸集 → 算 $f''$ → 判断 $f'' \ge 0$（或 $\le 0$）→ 结论
  • 单调性技巧：若 $f''(x)$ 在区间上单调，只需检查端点处的 $f''$ 符号
  • 排序统计量记忆：系数递减且非负 → 凸。证明用 Ky Fan 范数 + 分解技巧
  • 凹函数 + 有下界 → 常数：反证法，构造沿方向延伸到无穷远，利用凹性得矛盾

S5 🔥 均匀分布 MLE 2024 Q7a (4分) + 2025 Q7c (4分)

⚠️ 不要用求导！

📌 题目特征

$D \sim U[\theta, g(\theta)]$（如 $U[\theta, 2\theta]$ 或 $U[\theta, \theta^2]$），给几个样本，求 $\hat\theta_{MLE}$。

关键区别：均匀分布的 MLE 不是令 $\frac{dL}{d\theta}=0$！因为似然函数在可行域边界取最大值。

✅ Solution Template

Step 1 — 写 PDF

$$f(x) = \frac{1}{g(\theta) - \theta} \cdot \mathbf{1}[\theta \le x \le g(\theta)]$$

Step 2 — 写似然函数

$$L(\theta) = \prod_{i=1}^n \frac{1}{g(\theta)-\theta} \cdot \mathbf{1}[\theta \le D_i \le g(\theta)] = \frac{1}{(g(\theta)-\theta)^n} \quad \text{(当所有样本在区间内)}$$

Step 3 — 写出可行条件

  • $\theta \le \min(D_i)$（下界须 ≤ 所有样本）
  • $g(\theta) \ge \max(D_i)$（上界须 ≥ 所有样本）

Step 4 — 在可行域内最大化 $L(\theta)$

$L(\theta) = 1/(g(\theta)-\theta)^n$，最大化 $L$ 等价于 最小化 $g(\theta)-\theta$（区间长度）。

Step 5 — 判断 $g(\theta)-\theta$ 的单调性

  • 若 $g(\theta)-\theta$ 递增 → 取可行域下界
  • 若 $g(\theta)-\theta$ 递减 → 取可行域上界

  • 均匀分布的 MLE 永远在边界上！不要用求导！
  • 两步走：① 找 $\theta$ 的可行域（所有样本必须在区间内）② 在可行域内最小化区间长度
  • 常见变形：$U[0, \theta]$ 的 MLE 是 $\max(D_i)$；$U[\theta, 2\theta]$ 的 MLE 取 $\min(D_i)/2$ 和 $\max(D_i)$ 的大值

S6 🔥 Newsvendor / 生产问题 2024 Q7 (16分) + 2025 Q7 (19分)

核心框架：利润 = 收入 − 成本 − 缺货损失

📌 题目特征

决策者在需求不确定的情况下决定生产/订购量 $Q$。成本可能有分段结构或两种生产方式，要求：

  • 写利润函数 $\pi(Q)$
  • 求最优 $Q$（允许非整数）
  • 求整数约束下的最优 $Q$

✅ Solution Template

Step 1 — 写出利润函数的通用形式

$$\pi(Q) = \underbrace{p \cdot E[\min(Q, D)]}_{\text{销售收入}} + \underbrace{s \cdot E[(Q-D)^+]}_{\text{残值（未卖出）}} - \underbrace{c(Q)}_{\text{生产成本}} - \underbrace{c_r \cdot E[(D-Q)^+]}_{\text{加急成本（缺货）}}$$

其中 $(x)^+ = \max(x, 0)$。
若没有残值则 $s=0$；若没有加急则 $c_r=0$。

Step 2 — 展开 $E[\min(Q,D)]$ 和 $E[(D-Q)^+]$

对于 $D \sim U[a,b]$，PDF $= 1/(b-a)$：

$$E[\min(Q, D)] = \frac{Q^2 - a^2}{2(b-a)} + Q \cdot \frac{b-Q}{b-a} = \frac{2bQ - Q^2 - a^2}{2(b-a)} \quad (\text{当 } a \le Q \le b)$$ $$E[(D-Q)^+] = \int_Q^b (x-Q) \cdot \frac{1}{b-a} dx = \frac{(b-Q)^2}{2(b-a)}$$

关键公式（试卷开头会给）：$\frac{d}{dQ} E[\min(Q, D)] = P(D \ge Q)$

Step 3 — 若成本分段，分区间讨论

如 2024 年版：前 12 份成本 $8$，之后 $5$。分别对 $Q \le 12$ 和 $Q \ge 12$ 求 $\pi(Q)$ 和 $\pi'(Q)=0$。

Step 4 — 验证解在区间内部

解出的 $Q^*$ 必须属于当前讨论的区间。如果不是，则在边界取最优。

Step 5 — 整数约束

比较相邻两个整数 $Q$ 的利润大小，选利润更大的。

📖 考试必记

  • 理解收入项：若所有需求都能被满足（有加急渠道），总收入 = $pE[D]$（2025 Q7b 考了）
  • 核心公式：$\frac{d}{dQ}E[\min(Q,D)] = P(D \ge Q)$——试卷会给，直接用
  • 分区间要点：每段写出不同的 $\pi(Q)$，分别求导，验证解是否在区间内
  • 整数最优：比较 $Q^*$ 左右两边的整数，取利润大的
  • 注意符号：$E[(D-Q)^+]$ 是"期望缺货量"，$E[(Q-D)^+]$ 是"期望剩余量"

S7 🔥 综合定价题 2024 Q6 (26分) + 2025 Q6 (26分)

概率 + 统计 + 凸优化 + ML 混合

📌 题目特征

以一个商业场景（航空定价 / 网约车定价）为主线，串起：

  1. 概率（二项分布、均匀分布）
  2. 期望模型（$d(p) = n(1-F(p))$）
  3. 利润优化（写目标函数、证 concavity、求最优解）
  4. MLE（写 log-likelihood）
  5. K-Means（数值计算）

✅ 各子题模板

📌 概率子题（2-3分）：

顾客购买概率 = $P(X > p) = 1 - F(p)$
$n$ 个独立顾客 → $D \sim \text{Binomial}(n, 1-F(p))$
$E[D] = n(1-F(p))$，$\text{Var}[D] = n(1-F(p))F(p)$

📌 利润优化子题（3-4分）：

决策变量：$p$（价格）
目标：$\max \pi(p) = E[D](p-c) = n(1-F(p))(p-c)$
约束：$p \ge 1$（或 $p \in [a,b]$）

📌 证明 Concavity 子题（3分）：

如 2025 Q6bi：$R(p) = p e^{-\lambda p}$，证 $p \in [0, 2/\lambda]$ 上 concave

$R'(p) = e^{-\lambda p}(1 - \lambda p)$
$R''(p) = -\lambda e^{-\lambda p}(2 - \lambda p)$
当 $p \le 2/\lambda$ 时 $2-\lambda p \ge 0$ → $R''(p) \le 0$ → concave ✓

📌 MLE 子题（3-4分，常见于回归参数估计）：

$D_i \sim N(ap_i^b, \sigma^2)$ 的 log-likelihood：
$\ell(a,b) = -\frac{m}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^m (D_i - ap_i^b)^2$
最大化 $\ell$ 等价于最小化 $\sum (D_i - ap_i^b)^2$（非线性最小二乘）

📖 考试必记

  • Concavity 证明步骤：算 $R''(p)$ → 判断符号 → 检查区间
  • 最优解公式：$R'(p^*) = 0 \Rightarrow p^* = 1/\lambda$（对 $R(p)=pe^{-\lambda p}$）
  • K-Means 数值题：算欧氏距离 → 分配 → 求均值 = 新中心。答案用分数保留
  • 二项分布均值和方差：$E[S] = np$，$\text{Var}[S] = np(1-p)$ 必须背
  • $U[a,b]$ 均值和方差：$E = (a+b)/2$，$\text{Var} = (b-a)^2/12$

S8 KNN / K-Means 2024 Q1 (9分) + 2025 Q1 (10分) + Q6c (8分)

✅ KNN（2024 Q1）

流程：

  1. 计算新点到所有训练点的距离
  2. 选 K 个最近的邻居
  3. 多数投票决定类别

K 的影响：
小 K → 过拟合（高 variance）
大 K → 欠拟合（高 bias）

选 K 的方法：Cross-validation

距离三性质：对称性、正定性、三角不等式

✅ K-Means（2025 Q1 / Q6c）

流程：

  1. 初始化 K 个中心
  2. 分配：每个点分到最近的中心
  3. 更新：新中心 = 簇内点的均值
  4. 重复 2-3 直到收敛

距离三性质：对称性、正定性、三角不等式（同 KNN）

数值计算注意：用欧氏距离 $\sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$，新中心是算术平均

⚠️ KNN vs K-Means 考试区分

KNNK-Means

K 含义邻居数量聚类数量
"训练"懒惰学习（只存数据）迭代优化（找中心）
输出类别预测簇中心 + 分配

核心公式速查卡

📐 Convex Sets

定义：$\lambda x + (1-\lambda)y \in C$
Sublevel set：$f$ 凸 ⇒ $\{f \le r\}$ 凸
Simplex：$p_i \ge 0, \sum p_i = 1$ 是凸集
凸集的和是凸集
最优解集是凸集

📐 Convex Functions

SOC：$f''(x) \ge 0$（一维）// $g''(t) \ge 0$（多维）
Affine composition 保凸：$f(Ax+b)$ 凸
凸函数非负和 → 凸
排序统计量：$\alpha_i$ 递减非负 → 凸
凹 + 有下界 → 常数

📐 Gradient Descent

$f(x) = -k(x-b)^2/2 + c$
$e^{(t+1)} = (1 - k\alpha)e^{(t)}$
收敛条件：$0 < \alpha < 2/k$
$e^{(t)} = (1-k\alpha)^t e^{(0)}$

📐 Logistic Regression

$\ell(\theta) = \sum [y_i\theta^\top x_i - \log(1+e^{\theta^\top x_i})]$
$\nabla \ell(\theta) = \sum (y_i - \sigma(\theta^\top x_i))x_i$
$-\ell$ 是 convex → 可用梯度下降
决策边界：$\theta^\top x = 0$

📐 Uniform MLE

$U[\theta, g(\theta)]$：
① $\theta \le \min$, $g(\theta) \ge \max$
② 最小化 $g(\theta) - \theta$
③ 检查单调性取边界

📐 Newsvendor

$\pi(Q) = pE[\min(Q,D)] + sE[(Q-D)^+]$
$\hphantom{\pi(Q)} - c(Q) - c_rE[(D-Q)^+]$
$\frac{d}{dQ}E[\min(Q,D)] = P(D \ge Q)$
$E[(D-Q)^+] = \frac{(b-Q)^2}{2(b-a)}$

📐 概率分布

$X \sim \text{Bin}(n,p)$：$E = np$, Var $= np(1-p)$
$X \sim U[a,b]$：$E = (a+b)/2$, Var $= (b-a)^2/12$
$X \sim N(\mu,\sigma^2)$：$E = \mu$, Var $= \sigma^2$
KL Divergence：$D_{KL}(P\|Q) = \sum p_i \log(p_i/q_i)$

📐 K-Means

欧氏距离：$\sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$
新中心 = 簇内所有点的算术平均
目标：最小化簇内平方距离和

📖 答题规范（Lecture 19+ 硬性要求）

  1. 写目标函数和可行域
  2. 证明目标函数是 convex/concave（用 SOC 或保凸运算）
  3. 确认可行域是凸集
  4. 用最优性条件 $\nabla f = 0$ 求解
  5. 验证解在可行域内部（interior solution → global optimal）
