1. What is Machine Learning?

1.1 数据驱动的决策流程

数据科学完整流程：从原始数据到最终决策

Machine Learning 的定义：研究那些通过使用数据来提高自身任务表现的算法，而不是仅仅依赖预先编写好的固定规则。

ML 通常使用 black boxes（黑箱模型）如 Neural Network（神经网络）、Support Vector Machine（支持向量机），通过优化参数让模型自动学习。深层参数优化即 Deep Learning。

• Machine Learning：让数据告诉我们什么预测规则最好（let data tell us what prediction rule works best）

5. KNN 算法（K-Nearest Neighbors）

核心思想

给定一个新数据点，找距离它最近的 K 个训练点，看这 K 个"邻居"中哪一类占多数（majority vote），就把新点归为那一类。

物以类聚——你的邻居是什么类，你大概率就是什么类。

5.1 KNN 六步骤（必背！）

  1. Load the labeled data — 加载带标签的训练数据
  2. Choose the number of neighbors K — 选择邻居数量 K（超参数）
  3. Compute distances — 算新点到每个训练点的距离
  4. Sort by distance — 按距离从小到大排序
  5. Select K nearest — 取最近的 K 个邻居
  6. Majority vote — 多数投票决定新点的标签

5.2 距离度量 Distance Metrics

L2 距离 Euclidean Distance（欧氏距离）

d(x, y) = √[ (x₁−y₁)² + (x₂−y₂)² + ... ]

两点之间的直线距离，最常用

L1 距离 Manhattan Distance（曼哈顿距离）

d(x, y) = |x₁−y₁| + |x₂−y₂| + ...

沿坐标轴方向的距离之和，像在街区里走

L2 是"空中直飞"，L1 是"走街区格子"

K 值选择规则

• K 太小：噪声影响大 → 过拟合（overfitting）

• K 太大：边界过于平滑 → 欠拟合（underfitting）

• 极端：若 K 大于样本总数 N，所有新输入都被预测为训练集中majority class，模型完全失去意义

6.2 例题详解（考试高频题型）

题目：用 KNN（K=1，L1 距离）对新点 (4, 3) 分类。训练数据如下：

Pointx₁x₂class
A001
B-311
C522
D332
E503
F4-13

Step 1 — 计算每个训练点到 (4, 3) 的 L1 距离：

d(A) = |0−4| + |0−3| = 4 + 3 = 7

d(B) = |−3−4| + |1−3| = 7 + 2 = 9

d(C) = |5−4| + |2−3| = 1 + 1 = 2

d(D) = |3−4| + |3−3| = 1 + 0 = 1 ← 最近!

d(E) = |5−4| + |0−3| = 1 + 3 = 4

d(F) = |4−4| + |−1−3| = 0 + 4 = 4

Step 2 — 排序： D(1) < C(2) < E(4) = F(4) < A(7) < B(9)

Step 3 — K=1，最近邻为 D（class 2）：

新点 (4, 3) 被分类为 class 2

思考延伸：如果 K=3？取 D(2) + C(2) + E(3)：两票 class 2、一票 class 3 → 仍然是 class 2。

Lecture 21 — Logistic Regression（逻辑回归）

从"输出标签"到"输出概率"——参数化的分类模型

1. KNN 优缺点回顾

KNN 是一种 instance-based / memory-based learning（基于实例/记忆的学习）方法。

本质：不学"参数"，只是记住所有训练数据，预测时找最近邻。

优点 Advantages

✓ 简单直观，容易理解

✓ 容易实现

✓ 没有训练阶段（no training phase）

缺点 Disadvantages

✗ 预测慢：训练集大时要算很多距离

✗ 对 K 值和距离度量敏感

✗ Curse of dimensionality（维度灾难）：高维空间中"最近"可能没有意义

KNN 的 trade-off（权衡）：

• 小 K → flexible（灵活）但 noisy（有噪声）

• 大 K → stable（稳定）但可能 smooth too much（过度平滑）

2. Logistic Regression 核心思想

关键转变

与 KNN 输出 {0, 1} 不同，Logistic Regression 输出的是概率：

P(y = 1 | x) = ?

• 若 P 接近 1 → 预测为正类（例如狗）

• 若 P 接近 0 → 预测为负类（例如猫）

主要思想：学习一个公式，输入特征（像素值、属性）→ 输出"属于某类的概率"。

决策规则：以 0.5 为阈值，p > 0.5 → 预测正类；p ≤ 0.5 → 预测负类。

3. Sigmoid Function（S 形函数）

问题：我们希望输出是 0 到 1 之间的数（可以解释为概率）。但如何把任意实数 z 映射到 (0, 1) 呢？

答案：Sigmoid (Logistic) Function。

σ(z) = 11 + e−z
Sigmoid 函数：把任意实数 z 压缩到 (0, 1) 之间，中心点 σ(0) = 0.5

关键性质：

• σ(0) = 1/(1+1) = 0.5

• 当 z → +∞ 时，σ(z) → 1

• 当 z → −∞ 时，σ(z) → 0

• 单调递增、处处连续可导，导数 σ'(z) = σ(z)(1−σ(z)) —— 这会在后面训练时很有用！

4. 模型公式 & 分类流程

4.1 分类流程三步走

  1. 计算 score（得分）：特征的线性组合
    z = θTx + b = θ₁x₁ + θ₂x₂ + ... + θdxd + b
  2. 通过 Sigmoid 转为概率：
    p(y=1 | x) = σ(z) = 11 + e−(θTx+b)
  3. Decision rule（决策规则）：
    若 p > 0.5 → 预测为正类（y=1）
    若 p ≤ 0.5 → 预测为负类（y=0）
结构本质上就是一个 单层感知机 / 最简单的神经网络

4.2 完整模型公式

二分类情况：y ∈ {0, 1}

p(y=1 | x, θ, b) = 11 + exp(−(θTx + b))
p(y=0 | x, θ, b) = 1 − p(y=1) = exp(−(θTx + b))1 + exp(−(θTx + b))

其中 x = 输入特征向量，θ = 权重向量，b = 偏置（bias）；z = θTx + b 是 Sigmoid 的输入。

Key idea 特征的线性组合 → 通过 Sigmoid → 0 到 1 之间的概率。

这也意味着 Logistic Regression 的决策边界 {x : θTx + b = 0} 是线性的（超平面）。所以它叫"regression"但其实做的是线性分类。

5. 训练模型 — MLE（最大似然估计）

问题：给定 m 个标注样本 (xi, yi)，如何找到最好的 θ 和 b？

答案：Maximum Likelihood Estimation (MLE)——选择能让观察到这些样本的概率最大化的参数。

5.1 Log-Likelihood 目标函数

maxθ, b   l(θ, b) := log ∏i=1m P(yi | xi, θ, b) = Σi=1m log P(yi | xi, θ, b)

通常等价地最大化平均（averaged）log-likelihood：

maxθ, b   1m Σi=1m log P(yi | xi, θ, b)

展开后，单样本的 log P 可以写成：

log P(yi|xi, θ, b) = (yi − 1)(θTxi + b) − log(1 + exp(−θTxi − b))

5.2 凹性与全局最优

Good News 好消息

l(θ, b) 关于 (θ, b) 是凹函数（concave），这意味着：

存在唯一的全局最优解 (θ*, b*)！

不用担心陷入局部最优。

证明思路：

• 先证 log(1 + exp(−θTx − b)) 关于 (θ, b) 是凸函数（convex）

  考虑任意点 (θ₀, b₀) 和方向 e = (θ₁, b₁)。定义 h(t) = log{1 + exp[(−θ₀Tx − b₀) + t(−θ₁Tx − b₁)]}

  = log{1 + exp[C₁ + tC₂]}

  算二阶导：h''(t) = C₂²·exp[C₁+tC₂] / (1+exp[C₁+tC₂])² ≥ 0

  对任意方向 e，h''(t) ≥ 0 → 凸函数 ✓

• 凸函数取负号 → 凹函数。凹函数之和 → 凹函数 → l(θ, b) 凹 ✓

Bad News 坏消息

没有 closed-form solution（闭式解）！

令 ∂l/∂θ = 0 和 ∂l/∂b = 0 得到的方程组无法解析求解：

∂l/∂θ = Σi [(yi−1)xi + exp(−θxi−b)·xi1+exp(−θxi−b)] = 0

→ 必须使用数值方法（numerical methods），如 Gradient Descent。

6. Gradient Descent（梯度下降）

核心思想：从一个初始点出发，不断沿着梯度方向移动来找函数的极值。

6.1 更新规则

最小化（Minimization）

x(t+1) = x(t) − α(t) · f'(x(t))

沿梯度反方向（下坡）

最大化（Maximization）

x(t+1) = x(t) + α(t) · f'(x(t))

沿梯度正方向（上坡）

其中 α(t) 是 step size / learning rate（步长/学习率）。

停止条件（Stopping criteria）：

• |x(t+1) − x(t)| ≤ ε（参数变化很小）

• 或 |f'(x(t))| ≤ ε（梯度接近 0）

梯度下降：从随机起点逐步走到最小值

6.2 学习率 α 的影响（重要！）

理想情况

初期 α 较大 → 快速接近最优；
接近最优时 α 变小 → 精细调整。

实践中常用 衰减学习率：α(t) = α₀ / √t 等

坏情况：α 太大且固定

可能永远不收敛！反例：f(x) = x²，α = 1。

振荡反例：f(x) = x², α = 1

f'(x) = 2x

x(0) = −3 → f'(−3) = −6 → x(1) = −3 − 1·(−6) = 3

x(1) = 3 → f'(3) = 6 → x(2) = 3 − 1·6 = −3

→ 永远在 3 和 −3 之间振荡，无法收敛！

6.3 Logistic Regression 的 Gradient Ascent 更新

因为 MLE 是最大化问题，用 "+" 号：

θt+1 ← θt + α(t)·(1/m)·Σi[(yi−1)xi + exp(−θTxi−b)·xi1+exp(−θTxi−b)]
bt+1 ← bt + α(t)·(1/m)·Σi[(yi−1) + exp(−θTxi−b)1+exp(−θTxi−b)]

算法：初始化 (θ⁰, b⁰)，反复更新直到 |θt+1−θt| ≤ ε 且 |bt+1−bt| ≤ ε。

7. Stochastic Gradient Descent (SGD)

问题：如果训练数据 m 非常大（如百万级），每次迭代都要算 Σi=1..m 的完整梯度，太慢！

SGD 核心思想

每次迭代只用一个随机子集（random subset）来 approximate（近似）梯度方向。

θt+1 ← θt + α(t)·(1/|B|)·Σi∈B [(yi−1)xi + exp(−θTxi−b)·xi1+exp(−θTxi−b)]

其中 B = 随机选择的一批样本（batch），|B| = batch size（批大小）。

9. 典型练习题

Exercise（10分） Gradient Descent 收敛分析

用梯度下降法最大化 f(x) = −(1/4)(x−1)² + 2。学习率 α 为常数，初始 x(0) = 3。

(a) 以下情况 x(t) 是否收敛到最优解？

i. α = 0　　ii. α = 4　　iii. α = 1

(b) α 在什么范围内能收敛？

分析：最优解 x* = 1（f 的最大值点）。f'(x) = −(1/2)(x−1)。

最大化更新规则：

x(t+1) = x(t) + α·f'(x(t)) = x(t) − (α/2)(x(t) − 1)

令 u(t) = x(t) − 1（偏移量），则：

u(t+1) = (1 − α/2) u(t)

收敛条件：|1 − α/2| < 1 即 0 < α < 4

(a) 分析：

• i. α = 0：x 永远不更新 → 停在 x=3，不收敛。

• ii. α = 4：1 − 2 = −1，u 在 2 和 −2 之间振荡（x 在 3 和 −1 之间），不收敛。

• iii. α = 1：1 − 1/2 = 0.5，u(t) = 2·(0.5)t → 0，收敛到 x* = 1 ✓

(b) 答：当且仅当 0 < α < 4 时收敛。

📋 整体速查卡

Lec 20 (KNN) 核心

① 物以类聚：找 K 个最近邻 → 多数投票

② 6 步骤：Load → Choose K → Compute distance → Sort → Select K → Vote

③ 两种距离：L1（Manhattan）| L2（Euclidean）

④ K 小→过拟合，K 大→欠拟合，K > N → 永远输出 majority class

⑤ 无显式训练，但预测慢；受 curse of dimensionality 影响

Lec 21 (Logistic Regression) 核心

① 输出概率而非标签：P(y=1 | x) = σ(θTx + b)

② Sigmoid：σ(z) = 1/(1+e−z)，把 ℝ 映到 (0, 1)

③ 决策规则：p > 0.5 → 正类；否则负类

④ 训练用 MLE：最大化 log-likelihood；目标函数凹 → 单一全局最优

⑤ 无闭式解 → 用 Gradient Ascent：xt+1 = xt + α · f'

⑥ 学习率太大会振荡；对 f(x) = (1/2)x²-like 问题，α 需在合理范围内

⑦ SGD：用随机小批量代替全部数据，适合大数据

⑧ 决策边界是线性的（super plane θTx + b = 0）
