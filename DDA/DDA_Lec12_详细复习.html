1. 高维回归的问题：为什么要降维？

动机

高维数据的挑战

考虑高维线性回归模型：

$$Y = X\beta + \varepsilon$$

其中 $X$ 有 $D$ 个特征（列）。当 $D$ 很大时，出现以下问题：

(1) 多重共线性 (Multicollinearity) ⭐⭐⭐

是什么：特征之间高度相关（例如：身高和腿长；温度和冰激凌销量）。

为什么不好：回归系数 $\beta$ 的估计变得非常不稳定——特征间相关性高意味着信息重复，数据中的微小变化会导致 $\beta$ 的剧烈波动。

直观理解：假如你同时用"身高"和"腿长"来预测体重，这两个变量高度相关。回归不知道把权重分给谁——可能这次分给"身高"，下次分给"腿长"。这就是不稳定。

(2) 维度灾难 (Curse of Dimensionality)

特征太多 → 参数过多 → 过拟合风险大 → 模型泛化能力差

💡 解决办法：降维 (Dimensionality Reduction) —— 把高维数据投影到低维空间，同时尽量保留原始信息。

2. PCA 主成分分析（重中之重 ⭐⭐⭐⭐⭐）

原始高维数据 → 找最大方差方向 → 投影到低维空间 → 保留最多信息的低维表示

2.1 PCA 的核心思想与直觉

Goal

PCA 的目标是什么？

一句话：在降维的同时，保留尽可能多的方差（信息）。

直觉理解（非常重要）

想象数据是二维平面上的一堆点，形状像一根拉长的"香肠"（椭球形）：

  • 长轴方向：数据"散布"得最广 → 方差最大 → 包含最多信息
  • 短轴方向：数据"散布"得窄 → 方差小 → 包含信息少
  • PCA 做的事：找到"长轴"方向（第一主成分），然后找到与长轴垂直的次长轴方向（第二主成分），依此类推。
🌰 类比：一本 500 页的小说，你想用 3 页总结它。
  • 你要选最重要的情节（最大方差的方向）
  • 但不是简单地选前 3 页（这相当于选前 3 个特征）
  • 而是要提炼精华（创造新的复合变量 = 主成分）
⚠️ 易错点：PCA 不是选原始特征中的某几个，而是创建新的特征（原始特征的线性组合）。新特征叫"主成分"。

2.2 PCA 的数学推导（考试重点 ⭐⭐⭐⭐⭐）

Math

PCA 的数学过程

第①步：数据中心化

对数据矩阵 $X$（$n$ 个样本，$D$ 个特征），先减去每个特征的均值：

$$X_{\text{centered}} = X - \bar{X}$$

使得每个特征的均值为 0。这一步至关重要——不然第一个主成分会被均值位置影响，而不是方差方向。

第②步：计算协方差矩阵

$$C = \frac{1}{n}X^TX \quad (\text{维度：} D \times D)$$

协方差矩阵 $C$ 的 $(i,j)$ 元素 = 第 $i$ 个特征与第 $j$ 个特征的协方差。

$C$ 告诉我们：

  • 对角线上：每个特征自己的方差（数值越大，该特征越"有信息"）
  • 非对角线上：特征间的相关性（绝对值越大，相关性越强）

第③步：特征分解（最关键的一步）

$$C = V\Lambda V^T$$

其中：

  • $V$ 是 $D \times D$ 矩阵，每一列是一个特征向量 (eigenvector)
  • $\Lambda$ 是对角矩阵，对角线上是特征值 (eigenvalues) $\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_D$

第④步：理解特征值和特征向量

符号叫什么含义PCA 中对应
$V$ 的列特征向量一个"方向"主成分的方向
$\lambda_i$特征值该方向上的"伸展量"该主成分解释的方差大小
💡 关键直觉：
  • 特征向量告诉你"方向"，特征值告诉你"这个方向有多重要"
  • $\lambda_1$ 最大 → 第一主成分方向 $v_1$ 是最重要的方向
  • $\lambda_2$ 第二 → 第二主成分方向 $v_2$ 是次重要的方向，且 $v_2 \perp v_1$（正交）
  • 主成分之间互不相关（正交的）——这解决了多重共线性问题！

第⑤步：选择前 $k$ 个主成分

取前 $k$ 个最大的特征值对应的特征向量 $V_k = [v_1, v_2, \dots, v_k]$。

将数据投影到 $k$ 维空间：

$$X_{\text{new}} = X_{\text{centered}} \cdot V_k \quad (n \times k)$$
Explained Variance

方差解释率 (重要概念)

第 $i$ 个主成分解释的方差比例：

$$\frac{\lambda_i}{\sum_{j=1}^D \lambda_j}$$

前 $k$ 个主成分解释的总方差比例：

$$\frac{\sum_{i=1}^k \lambda_i}{\sum_{j=1}^D \lambda_j}$$

如何选择 $k$？

  • 看累计方差解释率——通常选到 80%-90% 以上
  • 看"碎石图" (Scree plot)——找"拐点"
🌰 例子：人脸图像（16000 维），可能前 100 个主成分就解释了 95% 的方差。意味着用 100 维代替 16000 维，保留了 95% 的信息！

2.3 PCA 算法完整步骤（考试默写级 ⭐⭐⭐⭐）

Algorithm

PCA 六步法

  1. 标准化/中心化：对每个特征减去均值（有时也除以标准差，使量纲统一）
  2. 计算协方差矩阵：$C = \frac{1}{n}X^TX$
  3. 特征分解：$C = V\Lambda V^T$
  4. 排序：按特征值 $\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_D$ 排序
  5. 选前 $k$ 个：取前 $k$ 个特征向量组成 $V_k$
  6. 投影：$X_{\text{new}} = X_{\text{centered}} V_k$

3. SVD 奇异值分解（难点 ⭐⭐⭐⭐⭐）

Why SVD?

为什么需要 SVD？

PCA 需要计算协方差矩阵 $C = \frac{1}{n}X^TX$ 并做特征分解。但有两个问题：

  1. $C$ 是 $D \times D$ 矩阵，当 $D$ 很大时（例如图像有 16000 维），计算 $C$ 和其特征分解非常慢
  2. 数值上，直接计算 $X^TX$ 会损失精度（数值不稳定）

SVD 直接对原始数据 $X$ 做分解，不需要计算 $X^TX$，更高效且更稳定。

3.1 SVD 的定义

Theorem

SVD：任意矩阵都可分解

任意 $m \times n$ 矩阵 $A$ 都可以分解为：

$$A = U\Sigma V^T$$

三个矩阵的详细解释：

矩阵维度名称含义
$U$$m \times m$左奇异向量列是 $AA^T$ 的特征向量，正交矩阵（$U^TU=I$）
$\Sigma$$m \times n$奇异值矩阵对角线上是奇异值 $\sigma_1 \ge \sigma_2 \ge \dots \ge 0$，其余为 0
$V$$n \times n$右奇异向量列是 $A^TA$ 的特征向量，正交矩阵（$V^TV=I$）
📐 几何意义：SVD 把一次线性变换拆成三步：
  1. $V^T$：先在标准坐标系中"旋转"
  2. $\Sigma$：沿坐标轴方向"缩放"（拉长或压缩）
  3. $U$：再"旋转"到新的坐标系
Key Difference

特征分解 vs SVD：对比理解

特征分解 (Eigendecomposition)SVD
适用对象仅方阵 ($n\times n$)任意矩阵 ($m\times n$)
分解形式$A = V\Lambda V^{-1}$$A = U\Sigma V^T$
正交性不一定正交（除非对称）$U,V$ 总是正交
数值稳定性一般更稳定

3.2 SVD 与 PCA 的关系（必考 ⭐⭐⭐⭐⭐）

Key Connection

SVD ↔ PCA 的核心联系

对中心化的数据矩阵 $X$（$n \times D$）做 SVD：

$$X = U\Sigma V^T$$

则：

  • $V$ 的列 = PCA 的主成分方向（即协方差矩阵 $C = \frac{1}{n}X^TX$ 的特征向量）
  • 奇异值 $\sigma_i$ 与 PCA 的特征值 $\lambda_i$ 的关系：$\sigma_i^2 = n\lambda_i$
  • 主成分得分 (PCA 投影后的数据) = $XV = U\Sigma$
💡 为什么这个关系重要？
PCA 需要：计算 $C$（$D\times D$）→ 特征分解
SVD 可以：直接对 $X$（$n\times D$）做分解 → $V$ 就是主成分方向
→ 当 $D$ 很大时，SVD 更高效
🌰 数值例子帮助理解
假设 $X$ 是 $100\times 5$ 的数据（100 个样本，5 个特征）。

PCA 路径：$X^TX$ = $5\times 5$ → 特征分解 → 得到 5 个特征向量和特征值

SVD 路径：$X = U\Sigma V^T$ → $V$ 直接给出主成分方向，$\sigma_i^2$ 给出方差信息

两种方法得到的主成分方向是一样的！

Summary Table

SVD–PCA 对应关系速查表

SVD 中的量PCA 中的对应
右奇异向量 $V$主成分方向（特征向量）
奇异值平方 $\sigma_i^2$$n$ 倍特征值（$n\lambda_i$）

3.3 低秩近似与图像压缩

Low-Rank Approximation

低秩近似：截断 SVD (Truncated SVD)

取前 $k$ 个最大的奇异值（$k \ll \min(m,n)$），其余设为 0：

$$A \approx A_k = U_k\Sigma_k V_k^T$$

原始矩阵需要存储 $m \times n$ 个数，低秩近似只需：

$$\text{存储量} = k(m + n + 1) \quad \text{vs} \quad mn$$
🌰 图像压缩例子
一张 $1000\times 800$ 的灰度图：
  • 原始存储：$1000 \times 800 = 800,000$ 个数
  • 取 $k=50$ 的低秩近似：$50 \times (1000 + 800 + 1) = 90,050$ 个数
  • 压缩比 ≈ 8.9 倍！

而且如果奇异值衰减很快（前几个就占了大部分方差），图像质量损失不大。

⚠️ 易错点：
  • "低秩"中的"秩" (rank) 是指矩阵的秩——即线性无关的行/列的最大数量
  • 截断 SVD (取 $k$ 个奇异值) = 用秩为 $k$ 的矩阵近似原矩阵
  • SVD 给出的低秩近似是"最优"的——在所有秩 $k$ 的矩阵中，$A_k$ 与 $A$ 的误差最小（Eckart-Young 定理）

4. 数据可视化 & t-SNE

Problem

高维数据无法直接可视化

一个 $D$ 维数据点：$\mathbf{x} = [x_1, x_2, \dots, x_D]$

当 $D > 3$ 时，人类无法直接看图理解数据。

比如人脸图像：50×64 = 3200 维 → 需要降维到 2D 或 3D 才能画出来。

t-SNE

t-SNE（考试重点 ⭐⭐⭐⭐）

全称：t-distributed Stochastic Neighbor Embedding

核心思想

"物以类聚，人以群分"——在高维空间中相近的点，在低维空间中也要相近。

算法三步骤（理解逻辑即可）

  1. 高维空间算相似度：用高斯分布计算每两个点之间的"相似度" $p_{ij}$。
    如果点 $i$ 和 $j$ 距离近，$p_{ij}$ 大；距离远，$p_{ij}$ 小。
  2. 低维空间算相似度：在低维（2D/3D）空间中用 $t$ 分布计算点对相似度 $q_{ij}$。
    为什么用 $t$ 分布？$t$ 分布尾部更厚，允许低维空间中相距较远的点有更大的相似度 → 防止"拥挤"问题。
  3. 最小化差距：用 KL 散度衡量两个相似度分布的差距，最小化它：
    $$C = \sum_{i,j} p_{ij}\log\frac{p_{ij}}{q_{ij}}$$
Interpretation

t-SNE 的 Loss 函数详解（重点 ⭐⭐⭐）

$$C = \sum_{i,j} p_{ij}\log\frac{p_{ij}}{q_{ij}}$$
情况$p_{ij}$$q_{ij}$损失 $\log(p/q)$惩罚
本来很近，投影也很近大大小✅ 正确，小惩罚
本来很近，投影却被拉远了大小大❌ 严重惩罚
本来很远，投影却被拉近了小大负数✅ 惩罚很小（允许）
💡 记忆口诀："近点拉远使劲罚，远点拉近无所谓"
→ t-SNE 优先保留局部结构（近邻关系），全局距离不一定要准确。

5. 快速对比与易混淆点总结

⚠️ 考试易混淆概念

常见混淆与澄清

混淆点澄清
特征向量 vs 主成分特征向量 = 主成分的方向；主成分 = 原始数据投影到这个方向后的结果
特征值 vs 奇异值特征值 $\lambda$ 来自 $X^TX$ 的特征分解；奇异值 $\sigma$ 来自 $X$ 的 SVD。关系：$\sigma_i^2 = n\lambda_i$
PCA 降维 vs 特征选择PCA 创造新特征（线性组合）；特征选择是挑原有的几个特征
$U$ vs $V$ 的作用$V$ 的列是主成分方向（右奇异向量）；$U\Sigma$ 是主成分得分
SVD 和特征分解的关系SVD 是对 $X$ 分解；特征分解是对 $X^TX$ 分解。两者通过 $X = U\Sigma V^T$ 联系
PCA 需要中心化吗？必须中心化！否则第一个主成分可能被均值方向带走
t-SNE 的困惑在哪里？它的损失函数不对称：近点拉远惩罚大，远点拉近惩罚小 → 优先保持局部结构
