Lecture 01 — 线性代数与数据科学简介

什么是线性代数 (What is Linear Algebra)

📚线性代数的定义

代数(Algebra)是用数学符号表示对象(subjects)和运算(operations)的一门学科。

线性(Linear)表示只涉及加法、减法和数乘，不涉及非线性运算（如乘积、次方、指数等）。

线性代数就是研究向量、矩阵和线性变换的数学分支。

🔗为什么要学线性代数？

线性代数在现代应用中无处不在：

  • 机器学习(Machine Learning)：所有ML算法的数学基础
  • 计算机视觉(Computer Vision)：图像处理、特征提取
  • 密码学(Cryptography)：加密算法
  • 网络系统(Network Systems)：图论、路由算法
  • 数据科学(Data Science)：数据表示、降维、回归

向量 (Vectors)

📐向量的定义

向量(Vector)是一个有序的数字列表，通常写成列的形式。我们用粗体小写字母表示向量：v, u, x, y。

v =
v₁
v₂
⋮
vₙ

向量中的数字叫做元素(entries/elements/coefficients/components)。

元素个数叫做维度(dimension/size/length)，n维向量记为 n-vector。

第i个元素记为 vi，其中i叫做下标(index)，从1到n。

📋向量相等与特殊向量

两个向量相等 iff (当且仅当) u - v = 0（零向量）

特殊向量：

  • 零向量 0：所有元素都是0
  • 全1向量 1：所有元素都是1
  • 非零向量：至少有一个元素不为0
💡标量的概念

标量(Scalar)是一个单个的实数。我们用普通小写字母表示：a, b, c, α, β。

标量与向量的主要区别：向量是有序列表，标量是单个数字。

⚠️注意："length"的含义

在某些教材（如Gilbert Strang的著作）中，"length"指的是向量的范数(norm)（即向量的"长度"），而不是维度。为了避免混淆，我们优先使用"dimension"表示维度，"norm"表示范数。

向量运算 (Vector Operations)

➕向量加法 (Vector Addition)

两个维度相同的向量可以相加，结果是对应元素相加：

u + v = (u₁ + v₁, u₂ + v₂, ..., uₙ + vₙ)

⚠️ 维度必须相同！不能将3维向量和4维向量相加。

✖️标量乘法 (Scalar Multiplication)

向量可以乘以一个标量，结果是每个元素都乘以该标量：

cv = (cv₁, cv₂, ..., cvₙ)

其中c是标量，v是向量。

🔄线性组合 (Linear Combination)

线性组合是向量加法和标量乘法的组合：

c₁v₁ + c₂v₂ + ... + cₖvₖ

其中c₁, c₂, ..., cₖ是标量系数(coefficients/weights)，v₁, v₂, ..., vₖ是向量。

📝例题：向量运算

给定向量：

v₁ = (1, 1), v₂ = (1, -1)

计算：

  • v₁ + v₂ = (1+1, 1+(-1)) = (2, 0)
  • 2v₁ - v₂ = 2(1,1) - (1,-1) = (2,2) - (1,-1) = (1, 3)

Lecture 02 — 向量范数与内积

向量范数 (Vector Norm)

📏欧几里得范数 (Euclidean Norm)

向量的ℓ₂范数(Euclidean Norm)定义为：

‖v‖₂ = √(v₁² + v₂² + ... + vₙ²)

简写为 ‖v‖（不带下标2）

几何意义：向量的"长度"，即从原点到该向量所指向的点的距离。

在不同的上下文中可能使用不同的范数，例如ℓ₁范数和ℓ∞范数，但在本课程中，我们主要关注ℓ₂范数。
🏆范数的性质 (Properties of Norm)

性质1（非负性）：‖v‖ ≥ 0，且 ‖v‖ = 0 iff v = 0

性质2（标量乘法）：‖cv‖ = |c|·‖v‖

性质3（三角不等式）：‖u + v‖ ≤ ‖u‖ + ‖v‖

单位向量 (Unit Vector)

⭕单位向量的定义

单位向量(Unit Vector)是范数为1的向量，即 ‖v‖ = 1

对任意非零向量 v，向量

v‖v‖

是单位向量。这个过程叫做归一化(normalization)。

🎯标准单位向量 (Standard Unit Vectors)

在ℝ³中，标准单位向量为：

e₁ = (1, 0, 0), e₂ = (0, 1, 0), e₃ = (0, 0, 1)

更一般地，在ℝⁿ中，eᵢ是第i个位置为1，其余为0的向量。

内积 (Inner Product / Dot Product)

⋅内积的定义

两个维度相同的向量 v, w 的点积(Dot Product)或内积(Inner Product)定义为：

⟨v, w⟩ = Σᵢ vᵢwᵢ = v₁w₁ + v₂w₂ + ... + vₙwₙ

也可以写成 v·w 或 vᵀw

我们推荐使用 ⟨v, w⟩ 的记号，以避免与其他运算混淆。

🏆内积的性质 (Properties of Inner Product)

性质1（线性性）：⟨av + bu, w⟩ = a⟨v, w⟩ + b⟨u, w⟩

性质2（对称性）：⟨v, w⟩ = ⟨w, v⟩

性质3（正定性）：⟨v, v⟩ ≥ 0，且 ⟨v, v⟩ = 0 iff v = 0

🔗范数与内积的关系

向量的范数的平方等于向量自身的内积：

‖v‖² = ⟨v, v⟩

即：‖v‖ = √(⟨v, v⟩)

🏆Cauchy-Schwarz 不等式

对任意向量 u, v，有：

|⟨u, v⟩| ≤ ‖u‖ · ‖v‖

等号成立 iff u 和 v 线性相关。

🏆三角不等式（内积版本）

对任意向量 u, v，有：

‖u + v‖ ≤ ‖u‖ + ‖v‖

Lecture 03 — 线性方程与矩阵

线性方程的定义 (Linear Equation)

🧮什么是线性方程

线性方程的标量形式为：

a₁x₁ + a₂x₂ + ... + aₙxₙ = b

其中：

  • a₁, a₂, ..., aₙ 和 b 是已知的常数
  • x₁, x₂, ..., xₙ 是未知数

向量形式（更紧凑）：

⟨a, x⟩ = b
📝线性 vs 非线性方程
方程 类型 理由
x₁ + x₂ = 1 ✓ 线性 只有一次项和常数项
x₁x₂ = 1 ✗ 非线性 包含乘积项
sin(x₁) = 0 ✗ 非线性 包含非线性函数
2x₁ - 3x₂ + 5 = 0 ✓ 线性 只有一次项和常数项

线性方程组 (System of Linear Equations)

📊线性方程组

m个方程，n个未知数的线性方程组称为 m×n system：

a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁
a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = b₂
⋮
aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ = bₘ

四种表示形式：

  • F1（标量形式）：上面显示的形式
  • F2（行向量形式）：⟨aⁱ, x⟩ = bᵢ，其中 aⁱ 是第i行
  • F3（列向量形式）：x₁a₁ + x₂a₂ + ... + xₙaₙ = b，其中 aⱼ 是第j列
  • F0（矩阵形式）：Ax = b（最紧凑的形式）

矩阵的定义 (Matrix)

📋什么是矩阵

矩阵(Matrix)是一个由m行n列数字组成的矩形阵列，记为 A ∈ ℝm×n：

A =
a₁₁ a₁₂ ⋯ a₁ₙ
a₂₁ a₂₂ ⋯ a₂ₙ
⋮ ⋮ ⋱ ⋮
aₘ₁ aₘ₂ ⋯ aₘₙ

元素 aij 位于第i行第j列，其中 1 ≤ i ≤ m，1 ≤ j ≤ n。

⚠️编程中的下标从0开始

在数学中，矩阵下标通常从1开始。但在编程（如Python、Java）中，下标从0开始。

在代码中，第(i,j)个元素对应数学中的第(i+1, j+1)个元素。

矩阵-向量乘积 (Matrix-Vector Product)

✖️矩阵-向量乘法

设 A ∈ ℝm×n，x ∈ ℝn，则 y = Ax ∈ ℝm，其中：

yᵢ = Σⱼ aᵢⱼxⱼ = aᵢ₁x₁ + aᵢ₂x₂ + ... + aᵢₙxₙ

维度检查：

A (m×n) × x (n×1) = y (m×1)

矩阵的列数必须等于向量的维度！

行形式与列形式 (Row and Column Form)

↔️行形式（Row Form）

将矩阵-向量乘法从行

yᵢ = ⟨aⁱ, x⟩

其中 aⁱ 是 A 的第i行向量。即，y的第i个元素是矩阵第i行与向量x的内积。

↕️列形式（Column Form）

将矩阵-向量乘法从列

Ax = x₁a₁ + x₂a₂ + ... + xₙaₙ

其中 aⱼ 是 A 的第j列向量。即，Ax是A的列向量以x的分量为权重的线性组合。

🔗列形式的核心意义

列形式揭示了一个关键的思想：

Ax是矩阵A的列向量的线性组合，其中系数由向量x给出。

这个观点对理解线性代数的许多概念至关重要，包括列空间、秩等。

Lecture 04 — 线性方程组求解与高斯消元

系数矩阵与增广矩阵 (Coefficient and Augmented Matrix)

📋两种矩阵表示

对于线性方程组 Ax = b：

系数矩阵(Coefficient Matrix) A：只包含方程组的系数

A ∈ ℝm×n

增广矩阵(Augmented Matrix) [A|b]：在A的右边添加常数项向量b

[A|b] ∈ ℝm×(n+1)

增广矩阵包含了求解方程组所需的所有信息。

超定/欠定/方阵系统 (Overdetermined/Underdetermined/Square Systems)

⚖️系统的分类

根据方程数m和未知数个数n的关系：

  • 超定系统(Overdetermined)：m > n（方程数多于未知数）— 通常无解
  • 欠定系统(Underdetermined)：m < n（方程数少于未知数）— 通常有无穷多解
  • 方阵系统(Square System)：m = n（方程数等于未知数）— 可能有唯一解

注意：这只是一般规律。具体是否有解取决于矩阵的秩等因素。

特殊矩阵 (Special Matrices)

📐对角线与对角矩阵

对角线元素(Diagonal Entry)：aii（行号和列号相同的元素）

对角矩阵(Diagonal Matrix)：只有对角线元素非零，其他元素都是0

D =
d₁ 0 ⋯ 0
0 d₂ ⋯ 0
⋮ ⋮ ⋱ ⋮
0 0 ⋯ dₙ
📐三角矩阵

下三角矩阵(Lower Triangular)：当 i < j 时，aᵢⱼ = 0（上三角全为0）

上三角矩阵(Upper Triangular)：当 i > j 时，aᵢⱼ = 0（下三角全为0）

下三角：
* 0 0
* * 0
* * *
    上三角：
* * *
0 * *
0 0 *

初等行变换 (Elementary Row Operations)

🔄三种初等行变换

初等行变换(Elementary Row Operations)是对矩阵的行进行的三种操作：

  1. 行倍加(Scaling)：将某一行乘以一个非零常数
  2. 行相加(Addition)：将某一行加上另一行的倍数
  3. 行交换(Swap)：交换两行
⚠️重要性质

初等行变换不改变线性方程组的解！

这是因为初等行变换对应于改变方程的顺序或改变方程的形式，但不改变本质。

警告：不能使用列变换！列变换会改变变量的含义，从而改变解。

Gauss-Jordan 消元法 (Gaussian-Jordan Elimination)

🔢消元法的两个阶段

第一阶段 - 前向消元(Forward Elimination)：

使用初等行变换将增广矩阵 [A|b] 转化为上三角形式。

第二阶段 - 回代(Backward Substitution)：

继续使用初等行变换将上三角形式转化为对角形式（或行简化阶梯形式），然后求解。

🎯主元(Pivot)

主元(Pivot)是用于消元的非零元素，通常选择在对角线位置。

在消元过程中，如果主元为0，需要进行行交换找到非零主元。

假设所有主元非零，则方程组有唯一解。

📝消元法求解示例

对增广矩阵进行初等行变换，最终得到：

[I|x] =
1 0 | x₁
0 1 | x₂

此时x就是解。

Lecture 05 — 矩阵运算：乘法与转置

矩阵乘法定义 (Matrix Multiplication)

✖️矩阵乘法的定义

设 A ∈ ℝm×n，B ∈ ℝn×k，则 C = AB ∈ ℝm×k，其中：

cij = Σℓ aiℓbℓj = ai1b1j + ai2b2j + ... + ainbnj

维度匹配规则：

A (m×n) × B (n×k) = C (m×k)

关键：A的列数必须等于B的行数！

↕️列视角的矩阵乘法

将B按列分块为 B = [b₁, b₂, ..., bₖ]，则：

AB = [Ab₁, Ab₂, ..., Abₖ]

即，AB的第j列是A乘以B的第j列。

✨单位矩阵与零矩阵

单位矩阵(Identity Matrix) In：对角线全为1，其他为0。

In A = A, A In = A

零矩阵(Zero Matrix)：所有元素都为0。

0 A = 0, A 0 = 0

矩阵乘法性质 (Properties of Matrix Multiplication)

🏆矩阵乘法的四个性质

性质1（左分配律）：A(B + C) = AB + AC

性质2（右分配律）：(A + B)C = AC + BC

性质3（标量结合律）：α(AB) = (αA)B = A(αB)

性质4（结合律）：(AB)C = A(BC)

⚠️矩阵乘法不满足交换律！

重要：矩阵乘法不可交换，即 AB ≠ BA（通常）

原因：

  1. AB存在不代表BA存在（维度不匹配）
  2. 即使两者都存在，结果通常也不相等
📝矩阵乘法不可交换的例子

设：

A =
1 1
0 0
, B =
0 0
0 1

计算：

AB =
0 1
0 0
, BA =
0 0
0 0

显然 AB ≠ BA

转置 (Transpose)

🔄转置的定义

矩阵 A = (aij)m×n 的转置(Transpose) Aᵀ = (bji)n×m，其中 bji = aij

简单说：行列互换。

例：A =
1 2
3 4
, Aᵀ =
1 3
2 4

列向量转置变成行向量，反之亦然：

v = [1, 2, 3]ᵀ (列向量), vᵀ = [1, 2, 3] (行向量)
🏆转置的性质

性质1：(A + B)ᵀ = Aᵀ + Bᵀ

性质2：(αA)ᵀ = αAᵀ

性质3：(Aᵀ)ᵀ = A

性质4（重要！）：(AB)ᵀ = BᵀAᵀ

注意：性质4中顺序反转了！这是一个常见的错误点。不是 AᵀBᵀ，而是 BᵀAᵀ。

对称矩阵 (Symmetric Matrix)

🔄对称矩阵的定义

一个方阵 A 称为对称矩阵(Symmetric Matrix)，如果：

A = Aᵀ

即，矩阵等于其转置。

📝对称矩阵的例子

单位矩阵是对称的：

I =
1 0
0 1
= Iᵀ

另一个例子：

A =
0 -1
-1 0
= Aᵀ

矩阵幂 (Matrix Power)

↑矩阵幂的定义

对于方阵 A ∈ ℝn×n，定义：

Aᵖ = A · A · ... · A (p个A相乘)

例如：A² = AA，A³ = AAA

约定：A⁰ = I

🔢矩阵幂的指数规则

Aᵖ · Aᵍ = Ap+q

(Aᵖ)ᵍ = Apq

注意：这些规则与普通指数相同。

⚠️非方阵的幂

非方阵 A 不能计算 A²！因为A的列数不等于行数，无法相乘。

但是，对于非方阵 A ∈ ℝm×n（m ≠ n），可以计算：

  • AᵀA ∈ ℝn×n（方阵）
  • AAᵀ ∈ ℝm×m（方阵）

向量积 (Vector-Vector Products)

⋅向量的三种"乘法"

对两个同维度的列向量 u, v ∈ ℝn：

  • uv — 无意义（无法计算）
  • uᵀv — 有效，得到标量（内积）
  • uvᵀ — 有效，得到矩阵（外积）
📊外积 (Outer Product)

外积(Outer Product) uvᵀ 是一个 m×n 矩阵，其(i,j)元素为：

(uvᵀ)ij = uivj

例如，对于 u = (1, 2), v = (3, 4)：

uvᵀ =
1·3 1·4
2·3 2·4
=
3 4
6 8
🔗内积与外积的联系

内积(Inner Product)： ⟨u, v⟩ = uᵀv (标量)

外积(Outer Product)： uvᵀ (矩阵)

核心区别：

  • 内积：uᵀ乘以v → 标量
  • 外积：u乘以vᵀ → 矩阵
⚠️外积的不可交换性

外积不满足交换律：uvᵀ ≠ vuᵀ

但是，两者有转置关系：

(uvᵀ)ᵀ = vuᵀ

Lecture 06 — 分块矩阵与矩阵乘积形式

行列向量记号 (Row/Column Vector Notation)

📚两种行向量记号

对于矩阵 A，表示其行向量有两种方式：

Notation 1: 用 a(i) 表示第 i 个行向量（行向量本身）

Notation 2（推荐）: 用 a(i)T 表示第 i 个行向量，其中 a(i) 是列向量

推荐使用 Notation 2，即统一使用列向量，好处是方便判断乘积是否合法。

乘法有效性判断 (Valid Product Check)

⚠️向量与矩阵乘积合法性速查

设 u, v 为 n 维列向量，A 为 n×n 矩阵：

表达式uvuvTvTu
合法？ ✗ ✓ 外积 ✓ 内积
表达式AvAvTvAvTA
合法？ ✓ ✗ ✗ ✓
记忆技巧：列向量 u 是 n×1，uT 是 1×n。检查相邻维度是否匹配即可。例如 uv = (n×1)(n×1)，内侧 1≠n，不合法。
💡复合表达式判断

设 u, v 为 n 维列向量，A, B, C 为 n×n 矩阵：

uAv → ✗ （u 是 n×1，A 是 n×n，内侧 1≠n）

uTAv → ✓，结果 ∈ ℝ（标量）

uTAv · uTBCv → ✓（标量 × 标量）

分块矩阵乘积 (Partitioned Matrix Multiplication)

📚分块乘法三步检验法

设 A ∈ ℝm×n，B ∈ ℝn×k，A 和 B 各可以用三种形式表示：整体矩阵、行分块、列分块。共 9 种组合。

Step 1: 检查块结构 (Block Structure, Rule 1)：A 的块列数 = B 的块行数

Step 2: 进行Level-1 乘法，按块展开

Step 3: 检查块尺寸 (Rule 2, Level-2)：每个子块乘积维度匹配

📐四种有效的分块乘积形式
Level-1 类型A 的形式B 的形式结果
整体 × 整体ABAB
整体 × 列分块A[b₁, ..., bk][Ab₁, ..., Abk]
行分块 × 整体 [aT(1); ...; aT(m)] B [aT(1)B; ...; aT(m)B]
行分块 × 列分块 [aT(1); ...; aT(m)] [b₁, ..., bk] (aT(i)bj)m×k
列分块 × 行分块 [a₁, ..., an] [bT(1); ...; bT(n)] Σ aᵢbT(i)
⚠️列分块 × 整体矩阵 是无效的！

尝试 [a₁, a₂, a₃] · B：

Step 1: A 有 3 个块列，B 有 1 个块行 → 不匹配！

即使强行展开为 [a₁B, a₂B, a₃B]，每个 aᵢ 是 m×1，B 是 n×k，内侧 1≠n，Level-2 也不合法。

两种重要的特殊乘积形式

📐行×列 vs 列×行
形式公式计算方式解释
行 × 列
(Definition)		 [aT(i)] · [b₁,...,bk] m×k 个内积 Collection of inner products
列 × 行
(Sum of outer)		 [a₁,...,an] · [bT(i)] n 个外积之和 Sum of outer products
💡列×行（外积之和）计算示例

设 X 为 3×2 矩阵，Y 为 2×3 矩阵，则：

XY = x₁ · yT(1) + x₂ · yT(2)（两个外积之和）

每个 xᵢ · yT(i) 是一个 3×3 矩阵，最终结果也是 3×3 矩阵。

Lecture 07 — 方程组求解 II：崩溃情况与 REF/RREF

方程组的三种崩溃情况 (Breakdown Cases)

📚三种崩溃类型

在对方阵系统进行 Gauss-Jordan Elimination 时，如果对角线位置出现 0：

类型现象含义
Type 1 出现 0 = 1 无解 (No Solution)
Type 2 出现 0 = 0 无穷多解 (Infinitely Many)
Type 3 对角线为0但下方有非零 行交换可修复 (Row Swap)
🔗2×2 系统的几何直观

两个方程对应平面上两条直线：

✓ 唯一解：两条线相交于一点

✗ 无解：两条平行线（矛盾方程）

∞ 无穷解：两条线完全重合

解与解集 (Solution & Solution Set)

📚解集的定义

Solution（解）：满足 Ax = b 的向量 x。

Solution Set（解集）：所有解的集合 S = {x : Ax = b}。

解集的三种可能：空集（无解）、单点（唯一解）、无穷集（无穷多解）。

GJ-E 一般流程 (General GJ-E Process)

📚方阵的 GJ-E 过程

对方阵系统 A → A₁ → ... → U → B₁ → ... → D

Case 1：U 的对角线全非零 → D 是对角矩阵（唯一解）

Case 2：U 的某些对角线为零 → D 不是对角矩阵，呈现 [I | *; 0 | 0] 的块结构

📐遇到 0 主元的处理步骤

当第 k 步的候选主元 (k,k) 位置为 0 时：

Step 1：在 (k,k) 下方寻找非零元素，找到则行交换 (Row Exchange)

Step 2：若下方全为零，检查第 (k+1) 列

Step 2.1：若 (k, k+1) 位置非零，用它作为主元消去下方

Step 2.2：若 (k, k+1) 位置为零，继续在该列下方找非零元素并行交换

继续：若所有列都找不到非零元素 → 第 k 行及以下全为零，形成零块 (Zero Block)

规则：如果行交换无法产生主元，则移动到下一列寻找主元。每行最多一个主元。

REF 行阶梯形 (Row-Echelon Form)

📚REF 的定义

矩阵满足 Row-Echelon Form (REF) 需要三个条件：

i) Leading 1s：每个非零行的第一个非零元素是 1（称为主元 pivot）

ii) Leading 1s Moving Right：下一行的 leading 1 在更靠右的列

iii) Zero Rows at Bottom：全零行在矩阵底部

💡REF 示例

以下是 REF 矩阵的例子（主元用 红色 标注）：

1***
01**
001*
0000

主元位置逐行右移，零行在底部。

RREF 简化行阶梯形 (Reduced Row-Echelon Form)

📚RREF 的定义

Reduced Row-Echelon Form (RREF) = REF + 额外条件：

iv) Zeros in pivot columns：每个 leading 1 是该列中唯一的非零元素（即主元列中其他元素全为 0）

💡RREF 示例对比

这是 RREF：

10*00
01*00
00010
00000

这不是 RREF（但是 REF）：

10002
00101
00011
00001
00000

第四行的 (4,5) 位置的 1 不满足"leading 1 下方/上方行的对应列为零"的条件。
实际上它满足 REF 但不满足 RREF（因为 pivot 列中存在非零元素 2, 1, 1）。

📐RREF 的简化表示

如果矩阵 A 是 RREF，通过列交换 (Column Exchange)可以变成：

[Ik | F]
[0   | 0]

其中 Ik 是 k×k 单位矩阵，k 是主元数。

注意：标准 GJ-E 不使用列交换，这里的列交换仅用于理解 RREF 结构。
📐Proposition 7.1

对 n×n 线性方程组进行 Gauss-Jordan Elimination：

• 前向消元结束时，得到 REF（上三角形式）

• 反向消元结束时，得到 RREF
