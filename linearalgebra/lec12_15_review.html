Lecture 12：一般线性系统理论 II — 线性无关、零空间与张成

线性无关与线性相关

📘线性相关 Linear Dependence

设 $V$ 为线性空间，$\mathbf{u}_1, \ldots, \mathbf{u}_k \in V$。若存在不全为零的系数 $c_1, \ldots, c_k$ 使得：

$$c_1\mathbf{u}_1 + c_2\mathbf{u}_2 + \cdots + c_k\mathbf{u}_k = \mathbf{0}, \quad (c_1, \ldots, c_k) \neq (0, \ldots, 0)$$

则称 $\mathbf{u}_1, \ldots, \mathbf{u}_k$ 线性相关。

📘线性无关 Linear Independence

若 $c_1\mathbf{u}_1 + \cdots + c_k\mathbf{u}_k = \mathbf{0}$ 仅当 $c_1 = c_2 = \cdots = c_k = 0$ 时成立，则称这些向量线性无关。

等价表述：不存在非平凡的线性组合等于零向量。

✅快速判断练习
向量集相关/无关理由
$\mathbf{u}, 2\mathbf{u}$相关$2\mathbf{u} - 2\cdot\mathbf{u} = \mathbf{0}$
$\mathbf{u}, \mathbf{v}, \mathbf{u}+\mathbf{v}$相关$1\cdot\mathbf{u} + 1\cdot\mathbf{v} + (-1)(\mathbf{u}+\mathbf{v}) = \mathbf{0}$
$\mathbf{e}_1, \mathbf{e}_2, \mathbf{e}_3$（标准基）无关唯一解为全零
$\mathbf{u}, \mathbf{v}, \mathbf{0}$相关含零向量一定相关

线性无关与线性系统的关系

🔴Claim 12.1：列向量相关性 ↔ 齐次方程

矩阵 $A$ 的列向量线性相关 $\iff$ $A\mathbf{x} = \mathbf{0}$ 有非零解。

证明关键：$c_1\mathbf{a}_1 + \cdots + c_n\mathbf{a}_n = \mathbf{0}$ 就是 $A\mathbf{c} = \mathbf{0}$（矩阵-向量乘法的列形式）。

🔴Corollary 12.1：方阵特殊情形
$$n \times n \text{ 方阵 } A \text{ 可逆} \iff A \text{ 的列向量线性无关}$$
💡如何检验线性无关？

对 $\mathbb{R}^n$ 中的向量：将它们排成矩阵 $A$ 的列，解 $A\mathbf{x} = \mathbf{0}$。

若唯一解为 $\mathbf{x} = \mathbf{0}$ → 无关；若有非零解 → 相关。

零空间 Null Space

📘零空间的定义（Definition 12.3）

矩阵 $A$ 的零空间（Null Space）定义为齐次方程 $A\mathbf{x} = \mathbf{0}$ 的解集：

$$N(A) = \{\mathbf{x} \in \mathbb{R}^n \mid A\mathbf{x} = \mathbf{0}\}$$
🔴Theorem 12.1：零空间是线性空间

$N(A)$ 是 $\mathbb{R}^n$ 的子空间。

证明三步：

  1. 非空：$A\mathbf{0} = \mathbf{0}$，故 $\mathbf{0} \in N(A)$
  2. 数乘封闭：若 $A\mathbf{x} = \mathbf{0}$，则 $A(\alpha\mathbf{x}) = \alpha(A\mathbf{x}) = \mathbf{0}$
  3. 加法封闭：若 $A\mathbf{x} = \mathbf{0}$ 且 $A\mathbf{y} = \mathbf{0}$，则 $A(\mathbf{x}+\mathbf{y}) = A\mathbf{x} + A\mathbf{y} = \mathbf{0}$
✅例：将零空间写成 Span

解 $A\mathbf{x} = \mathbf{0}$ 得到通解 $\mathbf{x} = s\begin{pmatrix}1\\-3\\-2\\1\\0\end{pmatrix} + t\begin{pmatrix}-4\\-1\\-2\\0\\1\end{pmatrix}$，则

$$N(A) = \text{span}\left\{\begin{pmatrix}1\\-3\\-2\\1\\0\end{pmatrix}, \begin{pmatrix}-4\\-1\\-2\\0\\1\end{pmatrix}\right\}$$

张成 Span

📘Span 的定义（Definition 12.4）

设 $V$ 为线性空间，$\mathcal{U} = \{\mathbf{u}_1, \ldots, \mathbf{u}_k\} \subseteq V$，定义：

$$\text{span}(\mathcal{U}) = \{a_1\mathbf{u}_1 + \cdots + a_k\mathbf{u}_k \mid a_1, \ldots, a_k \in \mathbb{R}\}$$

即所有线性组合的集合。Span 一定是子空间。

💡核心性质：线性组合的线性组合仍是线性组合

若 $\mathbf{x} = \alpha_1\mathbf{u} + \beta_1\mathbf{v}$ 且 $\mathbf{y} = \alpha_2\mathbf{u} + \beta_2\mathbf{v}$，则

$a\mathbf{x} + b\mathbf{y} = (a\alpha_1 + b\alpha_2)\mathbf{u} + (a\beta_1 + b\beta_2)\mathbf{v} \in \text{span}\{\mathbf{u}, \mathbf{v}\}$

这就是为什么 Span 自动满足线性空间公理。

Lecture 13：一般线性系统理论 III — 列空间、Ax=b 的解与基

列空间 Column Space

📘列空间的定义

设 $A = [\mathbf{a}_1, \ldots, \mathbf{a}_n] \in \mathbb{R}^{m \times n}$，$A$ 的列空间定义为：

$$C(A) = \text{span}\{\mathbf{a}_1, \ldots, \mathbf{a}_n\} = \{A\mathbf{x} \mid \mathbf{x} \in \mathbb{R}^n\}$$

列空间是 $\mathbb{R}^m$ 的子空间。

🔴Proposition 12.1：列空间与可解性
$$A\mathbf{x} = \mathbf{b} \text{ 有解} \iff \mathbf{b} \in C(A)$$

证明：$A\mathbf{x} = \mathbf{b}$ 有解 $\iff$ 存在 $\mathbf{x}$ 使得 $x_1\mathbf{a}_1 + \cdots + x_n\mathbf{a}_n = \mathbf{b}$ $\iff$ $\mathbf{b}$ 是列的线性组合 $\iff$ $\mathbf{b} \in C(A)$。

$A\mathbf{x} = \mathbf{b}$ 的解集结构

🔴Proposition 13.1：解集 = 特解 + 零空间

$A\mathbf{x} = \mathbf{b}$ 的解集为：

$$\text{解集} = \begin{cases} \emptyset & \text{（无解）} \\ \mathbf{x}_p + N(A) & \text{（有解时）} \end{cases}$$

其中 $\mathbf{x}_p$ 是任意一个特解，$\mathbf{x}_p + N(A) = \{\mathbf{x}_p + \mathbf{x}_n \mid \mathbf{x}_n \in N(A)\}$。

💡几何理解

$N(A)$ 是过原点的线性空间；$\mathbf{x}_p + N(A)$ 是将 $N(A)$ 平移到特解 $\mathbf{x}_p$ 处的"仿射子空间"。

注意：$\mathbf{x}_p + N(A)$ 本身不是线性空间（不过原点，除非 $\mathbf{b} = \mathbf{0}$）。

✅例题：写出 Ax=b 的完整解集

设已求得 $A\mathbf{x} = \mathbf{b}$ 的一个特解 $\mathbf{x}_p = (1, 6, 7, 0, 0)^T$，且

$N(A) = \text{span}\{\mathbf{u}, \mathbf{v}\}$ 其中 $\mathbf{u} = (1,-3,-2,1,0)^T$，$\mathbf{v} = (-4,-1,-2,0,1)^T$

则通解为：

$$\mathbf{x} = \begin{pmatrix}1\\6\\7\\0\\0\end{pmatrix} + \alpha\begin{pmatrix}1\\-3\\-2\\1\\0\end{pmatrix} + \beta\begin{pmatrix}-4\\-1\\-2\\0\\1\end{pmatrix}, \quad \alpha, \beta \in \mathbb{R}$$

基 Basis

📘基的定义（Definition 13.1）

设 $V$ 为线性空间，$\mathcal{U} = \{\mathbf{u}_1, \ldots, \mathbf{u}_k\} \subseteq V$。若同时满足：

  1. $\mathcal{U}$ 是线性无关的
  2. $\text{span}(\mathcal{U}) = V$（$\mathcal{U}$ 张成整个空间 $V$）

则称 $\mathcal{U}$ 为 $V$ 的一组基。

直觉：基 = "刚好够用"的向量集（不冗余、不遗漏）。

✅常见基的例子
空间标准基
$\mathbb{R}^n$$\{\mathbf{e}_1, \ldots, \mathbf{e}_n\}$
$\mathbb{R}^{m \times n}$$\{E_{ij} \mid i=1,\ldots,m;\ j=1,\ldots,n\}$（单位矩阵基）
$P_n$（$\le n$ 次多项式）$\{1, x, x^2, \ldots, x^n\}$
🔗可逆性等价条件更新

$n \times n$ 方阵 $A$ 可逆等价于：1. $A\mathbf{x}=\mathbf{0}$ 唯一解 $\mathbf{0}$；2. $n$ 个 pivot；3. 初等矩阵乘积；4. 列线性无关；5. （即将加入更多...）

Lecture 14：一般线性系统理论 IV — 维数与秩

维数 Dimension

🔴Theorem 14.1：基的大小唯一（本课程第一个"大"定理）

若 $\{\mathbf{u}_1, \ldots, \mathbf{u}_m\}$ 和 $\{\mathbf{v}_1, \ldots, \mathbf{v}_n\}$ 都是线性空间 $V$ 的基，则 $m = n$。

所有基的元素个数相同！

📘维数的定义（Definition 14.1）

若线性空间 $V$ 有一组含 $n$ 个元素的基，则称 $V$ 的维数为 $n$：

$$\dim(V) = n$$

特殊情况：$\dim(\{\mathbf{0}\}) = 0$；若无有限基则 $V$ 为无穷维。

🔴Lemma 14.1（支撑定理14.1的引理）

设 $m > n$。若 $\{\mathbf{v}_1, \ldots, \mathbf{v}_n\}$ 是 $V$ 的基，则 $V$ 中任意 $m$ 个向量必线性相关。

推论（Lemma 14.1E）：$\mathbb{R}^n$ 中任意 $n+1$ 个向量必线性相关。

逻辑链：$m > n$ 行 → "宽矩阵" → pivot 数 $\le n < m$ 列 → 存在自由变量 → $A\mathbf{x}=\mathbf{0}$ 有非零解。

💡Proposition 14.2：快速判定基

设 $\dim(V) = n$，对 $V$ 中 $n$ 个向量 $\mathbf{u}_1, \ldots, \mathbf{u}_n$：

(a) 若线性无关 → 自动是基（不需要再验证张成）

(b) 若能张成 $V$ → 自动是基（不需要再验证无关）

前提：必须恰好 $n$ 个向量。

秩 Rank

📘行空间、列秩、行秩

行空间：$\text{Row}(A) = $ $A$ 的行向量的 Span = $C(A^T)$

行秩：$r_R(A) = \dim(\text{Row}(A))$

列秩：$r_C(A) = \dim(C(A))$

🔴Theorem 14.3：行秩 = 列秩（第二个"大"定理）
$$r_R(A) = r_C(A) = \text{rank}(A) = \text{pivot 的个数}$$

证明思路：初等行变换不改变行秩也不改变列秩；对 RREF 矩阵直接验证行秩 = 列秩 = pivot 数。

🔗秩的性质

对 $m \times n$ 矩阵 $A$：$\text{rank}(A) \le \min\{m, n\}$

$\dim(N(A)) = n - \text{rank}(A)$（零空间维数 = 列数 - 秩）

解的个数 vs 秩

🔴解的个数与 $r, m, n$ 的关系
Case条件解的个数说明
1$r = m = n$恰好 1 个方阵满秩，可逆
2$r = m < n$$\infty$ 个行满秩，存在自由变量
3$r = n < m$0 或 1 个列满秩，无自由变量
4$r < m$ 且 $r < n$0 或 $\infty$ 个既有冗余方程又有自由变量
🔴Theorem 14.2a：可逆性等价条件完整版

设 $A \in \mathbb{R}^{n \times n}$，以下等价：

  1. $A$ 可逆
  2. $A\mathbf{x} = \mathbf{0}$ 仅有唯一解 $\mathbf{x} = \mathbf{0}$
  3. $A$ 是初等矩阵的乘积
  4. $A$ 有 $n$ 个 pivot
  5. $A$ 的列线性无关
  6. $A$ 的列张成 $\mathbb{R}^n$
  7. $A$ 的列构成 $\mathbb{R}^n$ 的基
  8. $\dim(C(A)) = n$，即 $\text{rank}(A) = n$
  9. $A\mathbf{x} = \mathbf{b}$ 对任意 $\mathbf{b}$ 有解

Lecture 15：满秩矩阵、正交性与四个基本子空间

满秩矩阵 Full Rank

📘满秩的定义（Definition 14.4）

设 $A \in \mathbb{R}^{m \times n}$：

术语条件含义
行满秩（full row rank）$\text{rank}(A) = m$无冗余方程
列满秩（full column rank）$\text{rank}(A) = n$无自由变量
满秩（full rank）$\text{rank}(A) = \min\{m,n\}$两者中较小的
🔴Proposition 15.1 & 15.2：满秩与解的存在性

行满秩（$r = m$）：$A\mathbf{x} = \mathbf{b}$ 对任意 $\mathbf{b}$至少有一个解（排除"无解"可能）。

RREF 视角：没有全零行 → 不会出现 "$0 = \text{非零}$" 的矛盾。

列满秩（$r = n$）：$A\mathbf{x} = \mathbf{b}$ 对任意 $\mathbf{b}$至多有一个解（排除"无穷多解"可能）。

RREF 视角：没有自由列 → 没有自由变量 → 解唯一（若存在）。

💡Corollary 15.1：无关向量的唯一表示

若 $\mathbf{u}_1, \ldots, \mathbf{u}_n$ 线性无关，则 $\text{span}\{\mathbf{u}_1, \ldots, \mathbf{u}_n\}$ 中任何向量有唯一的表示方式：

$\mathbf{v} = \alpha_1\mathbf{u}_1 + \cdots + \alpha_n\mathbf{u}_n$，系数 $\alpha_i$ 唯一确定。

正交性 Orthogonality

📘正交的定义

向量正交：$\mathbf{u} \perp \mathbf{v} \iff \mathbf{u}^T\mathbf{v} = 0$

向量与子空间正交：$\mathbf{u} \perp V \iff \mathbf{u}^T\mathbf{v} = 0, \forall \mathbf{v} \in V$

子空间正交：$U \perp V \iff \mathbf{u}^T\mathbf{v} = 0, \forall \mathbf{u} \in U, \forall \mathbf{v} \in V$

🔴Claim 15.1：正交性只需检验基

若 $\mathbf{u} \perp \mathbf{v}_j$ 对所有 $j = 1, \ldots, n$ 成立，则 $\mathbf{u} \perp \text{span}\{\mathbf{v}_1, \ldots, \mathbf{v}_n\}$。

（类似高中"线面垂直判定"：只需垂直于平面内两条相交直线。）

📘正交补 Orthogonal Complement

子空间 $V \subseteq \mathbb{R}^n$ 的正交补为：

$$V^\perp = \{\mathbf{u} \in \mathbb{R}^n \mid \mathbf{u}^T\mathbf{v} = 0, \forall \mathbf{v} \in V\}$$

性质：$\dim(V) + \dim(V^\perp) = n$，$(V^\perp)^\perp = V$

四个基本子空间 Four Fundamental Subspaces

🔴四个基本子空间及其关系

设 $A \in \mathbb{R}^{m \times n}$，$\text{rank}(A) = r$：

子空间记号所在空间维数
列空间$C(A)$$\mathbb{R}^m$$r$
零空间$N(A)$$\mathbb{R}^n$$n - r$
行空间$\text{Row}(A) = C(A^T)$$\mathbb{R}^n$$r$
左零空间$N(A^T)$$\mathbb{R}^m$$m - r$
🔗正交补关系（核心！）
$$\text{Row}(A) \perp N(A) \quad \text{且} \quad C(A) \perp N(A^T)$$

在 $\mathbb{R}^n$ 中：$\text{Row}(A)$ 与 $N(A)$ 互为正交补，维数之和 = $r + (n-r) = n$

在 $\mathbb{R}^m$ 中：$C(A)$ 与 $N(A^T)$ 互为正交补，维数之和 = $r + (m-r) = m$

⚠️考试常考

理解 $A\mathbf{x} = \mathbf{0}$ 的几何意义：每一行 $\mathbf{a}_i^T\mathbf{x} = 0$ 表示 $\mathbf{x}$ 与第 $i$ 行正交。所以 $N(A)$ 中的向量与 $A$ 的每一行都正交 → $N(A) \perp \text{Row}(A)$。
