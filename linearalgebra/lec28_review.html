Segment 1 快速回顾：线性系统

Matrix × Vector 的四形式（贯穿全课程！）

$F_0$: $Ax = b$（矩阵形式）  |  $F_1$: 标量方程   |  $F_2$: 行向量内积   |  $F_3$: 列的线性组合

考试中每道题几乎都要用到其中一种形式，尤其是 $F_3$（列的线性组合），它直接联系到列空间 $C(A)$。

分块乘法：合法分块 + 结果形式

$A$ 的分块形式$B$ 的分块形式结果
整体矩阵整体矩阵$AB$
整体矩阵$[b_1, b_2, \dots, b_k]$$[Ab_1, Ab_2, \dots, Ab_k]$
$[a^1; a^2; \dots; a^m]$（行分块）整体矩阵$[a^1 B; a^2 B; \dots; a^m B]$
$[a_1, a_2, \dots, a_n]$（列分块）$[b^{1T}; b^{2T}; \dots; b^{nT}]$（行分块）$\sum a_i b^{iT}$（外积和）

RREF 揭示的结构

  • Pivot 列 → 基本变量（$r$ 个）
  • 非 pivot 列 → 自由变量（$n - r$ 个）
  • $r = m = n$ → 唯一解；$r < n$ → 无穷多解；矛盾行 → 无解
  • 解集 = 特解 $+$ 零空间：$S = x_p + N(A)$

四个基本子空间（必考！）

零空间$N(A)$$\mathbb{R}^n$$n-r$$C(A^T)$
行空间$C(A^T)$$\mathbb{R}^n$$r$$N(A)$
左零空间$N(A^T)$$\mathbb{R}^m$$m-r$$C(A)$

Segment 2 快速回顾：中间篇章

投影与最小二乘（Lec 16-17）

三个等价条件：

  1. $b - Ay \perp C(A)$（几何：残差垂直于列空间）
  2. $A^T A y = A^T b$（代数：正规方程）
  3. $Ay$ 是 $b$ 在 $C(A)$ 上的投影

列满秩时 $y = (A^T A)^{-1} A^T b$，解唯一。

正交矩阵（Lec 17-18）

$Q^T Q = I$，即 $Q^{-1} = Q^T$

为什么重要？正交矩阵让计算变简单。投影到正交基上直接是各分量之和：$\text{proj}(b) = \sum (q_i^T b) q_i$

行列式（Lec 18-20）——重要工具

  • 几何： $\det(A)$ = 列向量构成的平行体体积
  • 线性变换： $\det(A)$ = 体积缩放比率
  • $\det(AB) = \det(A) \det(B)$
  • $\det(A) \neq 0 \iff A$ 可逆
  • 行列式在后半段大量出现：特征多项式、正定性判定

线性变换（Lec 20-21）：把矩阵看作变换

  • $A$ 的列 = 标准基变换后的像
  • 行列式 = 体积缩放比
  • 特征向量 = 方向不变的向量
  • 奇异向量 = 伸缩到正交输出方向的向量

Segment 3 快速回顾：特征值与相关

特征值与特征向量（Lec 22-24）

$AV = DV \iff Av_i = \lambda_i v_i,\quad i=1,\dots,n$

$A$ 可对角化 ⟺ 存在特征基（$n$ 个线性无关的特征向量）。不是所有方阵都可对角化！

工具链： 特征多项式 $\det(\lambda I - A) = 0$ → 求根 → 解 $(\lambda_i I - A)x = 0$

对称矩阵的 EVD（谱定理）

$A^T = A \Longrightarrow A = V D V^T = \sum \lambda_i v_i v_i^T$

$V$ 正交矩阵（$V^T V = I$），$D$ 实对角阵。特征值全为实数，特征向量可正交归一化。

SVD：最通用的分解

$A = U \Sigma V^T = \sum_{i=1}^r \sigma_i u_i v_i^T$

适用任意矩阵（不必方阵、不必对称）。$A v_i = \sigma_i u_i$（右奇异向量 $v_i$ 通过 $A$ 变成 $u_i$，伸缩 $\sigma_i$ 倍）。

三种分解对比（必考！）

对角化 EVD Full SVD
形式 $A = S D S^{-1}$ $A = V D V^T$ $A = U \Sigma V^T$
适用矩阵 部分方阵 对称矩阵 任意矩阵
中间 对角 对角 矩形对角
左右 可逆矩阵 正交矩阵 正交矩阵
向量形式 — $\sum \lambda_i v_i v_i^T$ $\sum \sigma_i u_i v_i^T$

记忆诀窍：条件越松 → 分解形式越复杂。对称矩阵条件最强 → 左右都是正交阵。任意矩阵条件最松 → 需要两个正交阵 + 矩形对角阵。

SVD 内部的对映关系

$A v_1 = \sigma_1 u_1, \dots, A v_r = \sigma_r u_r$
$A v_{r+1} = \dots = A v_n = 0$
$A^T u_{r+1} = \dots = A^T u_m = 0$

Part II：计算流程速查

1. 解线性系统 $Ax = b$

增广矩阵 $[A \mid b]$ → GJ-E → RREF → 判断解的情况 → 写出解集

2. 求 $N(A)$

解 $Ax = 0$ → RREF → 自由变量参数化 → 写成 Span 形式

3. 求逆矩阵

$[A \mid I] \xrightarrow{\text{GJ-E}} [I \mid A^{-1}]$

验证：$A A^{-1} = I$

4. 计算正交基与投影

从一组基出发 → Gram-Schmidt（逐步减投影 → 归一化）

有了正交基 $Q = [q_1,\dots,q_k]$，投影公式：$\text{proj}(b) = \sum (q_i^T b) q_i = Q Q^T b$

5. 最小二乘解

列满秩：直接正规方程 $A^T A y = A^T b$，唯一解
列不满秩：正规方程 + 通解。若已知 SVD，LS 解更容易算。

6. 求特征值/特征向量

Step 1: 特征多项式 $\det(\lambda I - A) = 0$，求根
Step 2: 对每个 $\lambda_i$，解 $(\lambda_i I - A)x = 0$，写特征空间

常见错误：把 0 写成特征向量（不允许）；只写一个特征向量而不写整个特征空间

7. 矩阵动力学（计算 $A^k$）

Step 1: 对角化 $A = S D S^{-1}$
Step 2: 求 $S^{-1}$
Step 3: $A^k = S D^k S^{-1}$
Step 4: $z_k = A^k z_0$

若 $A$ 有 $n$ 个互异特征值 → 一定可对角化 → $S$ 可逆。

8. 计算 Full SVD

Step 1: 求 $A^T A$ 的特征值 → $\sigma_i = \sqrt{\lambda_i}$
Step 2: 求右奇异向量 $v_i$（$A^T A$ 的特征向量 + $N(A)$ 的正交基）
Step 3: 求左奇异向量 $u_i = A v_i / \sigma_i$（$i=1,\dots,r$）+ $N(A^T)$ 的正交基

Part III：证明题技巧

通用策略

  1. 改写为"条件 ⇒ 结论"：列出所有已知条件，明确要证明的结论
  2. 写出定义和性质：先把牵扯到的定义写出来（如"子空间需要满足三条"）
  3. 用简单例子试：比如先证 $n=2$ 的情况，找感觉
  4. 标出维度：如果公式看起来复杂，给每个分量写上维度

子空间证明套路

三步法：(1) 零向量在集合中；(2) 加法封闭；(3) 数乘封闭。
经典例子：证明 $N(A)$ 是子空间、证明 $C(A)$ 是子空间。

线性无关和基的证明

要证基，需要证明：线性无关 + 张成空间。
若 $\dim(V) = n$，$n$ 个向量只需验证其中一条（Prop 14.2）。

特征值证明三工具

  1. 定义：$Ax = \lambda x$
  2. 特征多项式：$\det(\lambda I - A)$
  3. 对对称矩阵：EVD $A = V D V^T$

经典证明：(a) $0$ 是特征值 ⟺ $A$ 不可逆；(b) 相似矩阵有相同特征值；(c) 对称矩阵不同特征值的特征向量正交。

正定性证明

对对称矩阵，最常用的技巧：令 $y = Q^T x$，则 $x^T A x = x^T V D V^T x = y^T D y = \sum \lambda_i y_i^2$。
其他工具：定义、特征值判定、$A = R^T R$ 判定。

Part IV：常见错误（来自 Lecture 28）

维度错误

  • $uv$（两个列向量直接乘）——维度不匹配，无效
  • 必须熟悉：$Av$（矩阵乘向量）、$u^T B$（行向量乘矩阵）的维度
  • 行空间是输入空间，对应 $n$（后一个维度）

乘积顺序错误

  • $AB$ 存在 $\not\Rightarrow$ $BA$ 存在
  • 一般 $AB \neq BA$（极少情况才相等）
  • $(AB)^T \neq A^T B^T$（正确的是 $B^T A^T$）
  • $(AB)^{-1} \neq A^{-1} B^{-1}$（正确的是 $B^{-1} A^{-1}$）
  • $(Au)^T \neq A^T u^T$

不检查前提条件就用公式

  • $A^{-1}$ 存在才可以用
  • 谱定理只适用于实对称矩阵（$A = V D V^T$ 中的 $V$ 是正交矩阵，一般对角化是 $S D S^{-1}$）
  • LU 分解的前提是无行交换
  • Gram-Schmidt 的前提是输入向量线性无关
  • $\det(AB) = \det(A)\det(B)$ 要求 $A,B$ 是方阵（否则无法各自取行列式）

概念混淆

  • 特征向量 ≠ 零向量（但特征值可以为 0）
  • 写特征向量时不能只写一个，要写特征空间（参数化）
  • 正定性不能靠看矩阵元素正负！例：$\begin{bmatrix} 2 & -1 \\ -1 & 2 \end{bmatrix}$ 有负元素但是 PD
  • $Q^T Q = I$ 但 $Q Q^T \neq I$（除非 $Q$ 是方阵）
