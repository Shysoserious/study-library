## Problem 1 — 项目评估方法比较（Payback / IRR / NPV）

两个互斥项目 A、B，各需 upfront 投资 $25M，税后现金流如下（单位：百万）：

| Year | A | B |
|------|----|----|
| 0 | −25 | −25 |
| 1 | 5 | 20 |
| 2 | 10 | 10 |
| 3 | 15 | 8 |
| 4 | 20 | 6 |

### (1) Payback period（回收期）

思路：把各年现金流逐年累加，看第几年把初始投资 $25M 收回来；不满一年的部分按比例折算。

**Project A：**

| Year | CF | Cumulative |
|------|-----|-----------|
| 1 | 5 | 5 |
| 2 | 10 | 15 |
| 3 | 15 | 30 ≥ 25 ✓ |

第 2 年末累计只收回 15，还差 25 − 15 = 10，第 3 年产生 15，所以第 3 年只需 10/15 = 0.667 年。

$$Payback_A = 2 + \frac{25-15}{15} = 2 + 0.667 = \mathbf{2.67\ years}$$

**Project B：**

| Year | CF | Cumulative |
|------|-----|-----------|
| 1 | 20 | 20 |
| 2 | 10 | 30 ≥ 25 ✓ |

$$Payback_B = 1 + \frac{25-20}{10} = 1 + 0.5 = \mathbf{1.5\ years}$$

B 的回收期更短（1.5 < 2.67）。

### (2) IRR（内部收益率）

IRR 是使 NPV = 0 的折现率，即解方程：

$$NPV = -25 + \frac{CF_1}{1+r} + \frac{CF_2}{(1+r)^2} + \frac{CF_3}{(1+r)^3} + \frac{CF_4}{(1+r)^4} = 0$$

**Project A** 用试错法（trial-and-error）：

- r = 25%：NPV ≈ +1.27（> 0，说明 IRR 更高）
- r = 28%：NPV ≈ −0.39（< 0）

插值得 $$IRR_A \approx \mathbf{27.3\%}$$

**Project B：**

- r = 36%：NPV ≈ +0.05（≈ 0）
- r = 37%：NPV ≈ −0.26

$$IRR_B \approx \mathbf{36.2\%}$$

按 IRR 标准，B（36.2%）> A（27.3%）。

### (3) 资本成本 5%、互斥 → 选哪个？

按 NPV 标准（互斥项目唯一正确标准）：

$$NPV_A = -25 + \frac{5}{1.05} + \frac{10}{1.05^2} + \frac{15}{1.05^3} + \frac{20}{1.05^4} = \mathbf{18.24}$$

$$NPV_B = -25 + \frac{20}{1.05} + \frac{10}{1.05^2} + \frac{8}{1.05^3} + \frac{6}{1.05^4} = \mathbf{14.96}$$

**Answer:** Choose **Project A** (NPV $18.24M > $14.96M).

### (4) 资本成本 15%、互斥 → 选哪个？

$$NPV_A = -25 + \frac{5}{1.15} + \frac{10}{1.15^2} + \frac{15}{1.15^3} + \frac{20}{1.15^4} = \mathbf{8.21}$$

$$NPV_B = -25 + \frac{20}{1.15} + \frac{10}{1.15^2} + \frac{8}{1.15^3} + \frac{6}{1.15^4} = \mathbf{8.64}$$

**Answer:** Choose **Project B** (NPV $8.64M > $8.21M).

### 关键结论（crossover / 规模冲突）

这个题正好演示了 IRR 排名与 NPV 排名的**冲突**：

| 折现率 | A 的 NPV | B 的 NPV | NPV 胜者 |
|--------|----------|----------|----------|
| 5% | 18.24 | 14.96 | A |
| 10% | 12.74 | 11.55 | A |
| 15% | 8.21 | 8.64 | B |

- B 的现金流**前重后轻**（第 1 年就 20），A 的现金流**前轻后重**（大头在第 4 年）。
- 折现率越低，越看重后期现金流 → A 占优；折现率越高，越看重前期现金流 → B 占优。
- 两条 NPV 曲线在约 **13.5%** 处交叉（crossover point）。
- 互斥项目冲突时**永远以 NPV 为准**：5% 选 A，15% 选 B。

## Problem 2 — 自制 vs 外购（Make-or-Buy / 自制铅笔顶）

公司每年外购 200,000 个 tops，单价 $2.00。若改为自制：直接生产成本 $1.50/top，需购置机器 $150,000（直线折旧 8 年、无残值），第 0 年额外垫付营运资金 NWC $30,000（第 10 年末回收）。税率 35%，资本成本 15%，经营期 10 年，现金流均为年末发生。

### 思路

这是一个「成本节约」型项目：没有收入变化，只有**每年成本节约**带来的增量现金流。核心是算**增量**（自制相对于继续外购多出来的现金流），再按 15% 折现。

### 逐步计算

**① 每年成本节约（税前）：**

$$Saving = (2.00 - 1.50) \times 200{,}000 = \$100{,}000\ /\text{年}$$

**② 机器折旧（第 1–8 年）：**

$$Depreciation = \frac{150{,}000}{8} = \$18{,}750\ /\text{年}$$

**③ 增量 EBIT 与税（税率 35%）：**

- 第 1–8 年：$EBIT = 100{,}000 - 18{,}750 = 81{,}250$，$税 = 81{,}250 \times 0.35 = 28{,}437.50$
- 第 9–10 年（无折旧）：$EBIT = 100{,}000$，$税 = 35{,}000$

**④ 无杠杆净利 NI = EBIT − Tax：**

- 第 1–8 年：$81{,}250 \times (1-0.35) = \$52{,}812.50$
- 第 9–10 年：$100{,}000 \times (1-0.35) = \$65{,}000$

**⑤ FCF = NI + Depreciation − ΔNWC − CapEx：**

| Year | 0 | 1–8 | 9 | 10 |
|------|----|-----|----|----|
| NI | — | 52,812.50 | 65,000 | 65,000 |
| + Depreciation | — | 18,750 | — | — |
| − CapEx | −150,000 | — | — | — |
| − ΔNWC | −30,000 | — | — | +30,000（回收） |
| **FCF** | **−180,000** | **71,562.50** | **65,000** | **95,000** |

**⑥ NPV（资本成本 15%）：**

$$NPV = -180{,}000 + 71{,}562.50 \times \frac{1-(1.15)^{-8}}{0.15} + \frac{65{,}000}{1.15^{9}} + \frac{95{,}000}{1.15^{10}}$$

$$NPV = \mathbf{+\$183{,}083.55}$$

### 结论

**Answer: Yes, support the proposal.** The NPV is +$183,084 > 0, so making the tops in-house creates value: the annual pre-tax saving of $100,000 far outweighs the $150,000 machinery cost and the $30,000 working capital tie-up. Note that NWC is a timing difference, not a true cost — it is recovered in full at the end of year 10.

## Problem 3 — Krusty Krab 更新决策（Replacement Decision）

**旧烤架**：2 年前 $50,000 买入，直线折旧 10 年、无残值。年折旧 $5,000，累计折旧 $10,000，账面价值 $40,000。现在可卖 $30,000。

**新烤架**：$80,000，直线折旧 8 年、无残值，年折旧 $10,000。新烤架税前毛利 $50,000/年（8 年），旧烤架 $35,000/年。税率 35%，资本损失可抵减其他资本利得。

### (1) 第 0 年增量 FCF

第 0 年发生三件事（增量）：

**① 买新烤架：** −$80,000

**② 卖旧烤架：** +$30,000

**③ 卖旧的税务影响（资本损失税盾）：**

账面价值 = 50,000 − 2 × 5,000 = **$40,000**，卖价 $30,000，所以产生资本损失：

$$Capital\ loss = 30{,}000 - 40{,}000 = -\$10{,}000$$

损失可抵税，带来税盾（tax shield）：

$$Tax\ shield = 10{,}000 \times 35\% = \$3{,}500$$

**第 0 年增量 FCF：**

$$FCF_0 = -80{,}000 + 30{,}000 + 3{,}500 = \mathbf{-\$46{,}500}$$

### (2) 第 1 年增量 FCF

**① 增量税前毛利：**

$$Incremental\ gross\ profit = 50{,}000 - 35{,}000 = \$15{,}000$$

**② 增量折旧：**

新折旧 $10,000 − 旧折旧 $5,000 = **$5,000**（旧机器若继续用，第 1–8 年仍在折旧）。

**③ 增量 EBIT、税、净利：**

$$EBIT = 15{,}000 - 5{,}000 = \$10{,}000$$

$$Tax = 10{,}000 \times 35\% = \$3{,}500$$

$$NI = 10{,}000 - 3{,}500 = \$6{,}500$$

**④ 增量 FCF = NI + 折旧（无新增 NWC、无新增 CapEx）：**

$$FCF_1 = 6{,}500 + 5{,}000 = \mathbf{\$11{,}500}$$

（等价地：$FCF_1 = 15{,}000 \times (1-0.35) + 5{,}000 \times 0.35 = 9{,}750 + 1{,}750 = 11{,}500$）

### 结论

**Answer:**

**(1)** Year 0 incremental FCF = **−$46,500** (= −80,000 purchase + 30,000 sale of old grill + 3,500 capital-loss tax shield).

**(2)** Year 1 incremental FCF = **$11,500** (= 15,000 incremental gross profit − 5,000 incremental depreciation − 3,500 tax + 5,000 depreciation = 6,500 + 5,000).

## Problem 4 — Epiphany Industries 敏感性分析（Sensitivity Analysis）

3 年项目，资本成本 12%。基础情形（Base case）已给：

| | Year 0 | Year 1 | Year 2 | Year 3 |
|------|--------|--------|--------|--------|
| Sales | | 100,000 | 100,000 | 100,000 |
| COGS | | 50,000 | 50,000 | 50,000 |
| Depreciation | | 30,000 | 30,000 | 30,000 |
| EBIT | | 20,000 | 20,000 | 20,000 |
| Taxes (35%) | | 7,000 | 7,000 | 7,000 |
| Unlevered NI | | 13,000 | 13,000 | 13,000 |
| + Depreciation | | 30,000 | 30,000 | 30,000 |
| − Change in NWC | | 5,000 | 5,000 | −10,000 |
| CapEx | −90,000 | | | |
| **FCF** | **−90,000** | **38,000** | **38,000** | **53,000** |

（第 3 年 ΔNWC = −10,000，表示回收前两年的 5,000 + 5,000 = 10,000，所以 FCF 里是 **−(−10,000) = +10,000**。）

### (1) 基础情形 NPV

$$NPV = -90{,}000 + \frac{38{,}000}{1.12} + \frac{38{,}000}{1.12^2} + \frac{53{,}000}{1.12^3} = \mathbf{\$11{,}946.29}$$

### (2) 销量 ±10% 的敏感性

销量变化时 COGS **同方向同比例**变化，折旧与 NWC 不变。

**销量 +10%：** Sales = 110,000，COGS = 55,000，EBIT = 110,000 − 55,000 − 30,000 = 25,000，税 = 8,750，NI = 16,250。

| Year | FCF |
|------|-----|
| 0 | −90,000 |
| 1–2 | 16,250 + 30,000 − 5,000 = **41,250** |
| 3 | 16,250 + 30,000 − (−10,000) = **56,250** |

$$NPV = -90{,}000 + \frac{41{,}250}{1.12} + \frac{41{,}250}{1.12^2} + \frac{56{,}250}{1.12^3} = \mathbf{\$19{,}752.24}$$

**销量 −10%：** Sales = 90,000，COGS = 45,000，EBIT = 90,000 − 45,000 − 30,000 = 15,000，税 = 5,250，NI = 9,750。

| Year | FCF |
|------|-----|
| 0 | −90,000 |
| 1–2 | 9,750 + 30,000 − 5,000 = **34,750** |
| 3 | 9,750 + 30,000 + 10,000 = **49,750** |

$$NPV = -90{,}000 + \frac{34{,}750}{1.12} + \frac{34{,}750}{1.12^2} + \frac{49{,}750}{1.12^3} = \mathbf{\$4{,}140.34}$$

### (3) COGS ±10% 的敏感性

COGS 变化时 Sales 与 NWC 不变。

**COGS +10%：** COGS = 55,000，EBIT = 100,000 − 55,000 − 30,000 = 15,000 → 与「销量 −10%」完全相同的 FCF（因为两者都把 EBIT 从 20,000 拉到 15,000）。

$$NPV = \mathbf{\$4{,}140.34}$$

**COGS −10%：** COGS = 45,000，EBIT = 100,000 − 45,000 − 30,000 = 25,000 → 与「销量 +10%」完全相同。

$$NPV = \mathbf{\$19{,}752.24}$$

### 敏感性汇总表

| 情形 | EBIT | NPV | 相对基础情形 |
|------|------|-----|-------------|
| Base | 20,000 | 11,946.29 | — |
| Sales +10% | 25,000 | 19,752.24 | +7,805.95 |
| Sales −10% | 15,000 | 4,140.34 | −7,805.95 |
| COGS +10% | 15,000 | 4,140.34 | −7,805.95 |
| COGS −10% | 25,000 | 19,752.24 | +7,805.95 |

### 结论

**Answer:**

**(1)** Base-case NPV = **$11,946.29**.

**(2)** With sales ±10% (COGS moves proportionally, NWC unchanged): NPV = **$19,752.24** (+10%) and **$4,140.34** (−10%).

**(3)** With COGS ±10% (sales and NWC unchanged): NPV = **$4,140.34** (+10%) and **$19,752.24** (−10%).

Because COGS = 50% of sales, a ±10% sales change (which also moves COGS) has the same absolute EBIT impact (±$5,000) as an opposite ±10% COGS change — hence the mirror-image results. The project's NPV is far more sensitive on the downside: a 10% drop in sales (or 10% rise in COGS) cuts NPV by about 65%, while the base case remains comfortably positive.
